§6а.2 · Дифференциальный прототип

Закон сохранения энергии: уравнения переноса и теплопроводности

Уравнение переноса \(u_t + a u_x = 0\), \(u(0,t) = u(l,t)\), \(a = \mathrm{const}\), — дифференциальный прототип «уголка». Умножим уравнение на \(u\) и проинтегрируем по \(x\) от \(0\) до \(l\).

первое слагаемое — производная энергии по \(t\)
\[ \int_0^l u\,u_t\,dx = \int_0^l \tfrac12\bigl(u^2\bigr)_t\,dx = \tfrac12\,\frac{d}{dt}\int_0^l u^2\,dx. \]

\(\mathcal E(t) = \int_0^l u^2\,dx = \|u(\cdot,t)\|^2_{L_2}\) — энергия решения; первое слагаемое равно \(\tfrac12\,d\mathcal E/dt\).

второе слагаемое — производная по \(x\); интеграл сводится к значениям на концах
\[ a\,u\,u_x = \tfrac{a}{2}\bigl(u^2\bigr)_x \ \Rightarrow\ \int_0^l a\,u\,u_x\,dx = \tfrac{a}{2}\Bigl[u^2(x,t)\Bigr]_{x=0}^{x=l} \]
\[ = \tfrac{a}{2}\bigl(\underbrace{u^2(l,t) - u^2(0,t)}_{=\,0\ \text{по периодичности}}\bigr) = 0. \]
\[ \frac{d\mathcal E}{dt} = 0, \qquad \|u(\cdot,t)\|_{L_2} = \|u(\cdot,0)\|_{L_2}; \qquad\text{теплопроводность: }\ \tfrac12\frac{d\mathcal E}{dt} = \nu\int_0^l u\,u_{xx}\,dx = -\nu\int_0^l u_x^2\,dx \le 0. \tag{6а.3–6а.4} \]
Где использовано краевое условиеВнеинтегральный член \(u^2(l,t) - u^2(0,t)\) обращается в нуль в силу периодичности; для уравнения теплопроводности с условиями \(u(0,t) = u(l,t) = 0\) обращается в нуль член \([u\,u_x]_0^l\). На сетке эту роль выполняют условие \(y_0 = y_N\) и сдвиг индекса.

Прежде чем переносить выкладку на сетку, уточним, какая производная по времени стоит в уравнении и почему оценивается интегральная величина \(\mathcal E(t)\).

§6а.2 · Частная и материальная производные

Частная и материальная производные. Почему оценивается \(\mathcal E(t)\), а не \(u\)

\[ \underbrace{\frac{\partial u}{\partial t}\Big|_{x = \mathrm{const}} = -a\,u_x}_{\text{частная производная — стоит в (6а.2)}}, \qquad\qquad \underbrace{\frac{d}{dt}\,u(x_0 + at,\ t) = \frac{\partial u}{\partial t} + a\,\frac{\partial u}{\partial x} = 0}_{\text{материальная производная — вдоль характеристики}} \]
Две производные функции \(u(x,t)\)Частная производная \(\partial u/\partial t\) берётся при фиксированном \(x\); по уравнению она равна \(-a u_x\) и, вообще говоря, отлична от нуля. Материальная (полная) производная берётся вдоль характеристики \(x = x_0 + at\) по правилу дифференцирования сложной функции; по уравнению она равна нулю: значение \(u\) постоянно вдоль характеристики. Только в этом смысле «\(u\) сохраняется».
Величина \(\mathcal E(t)\) и её производная\(\mathcal E(t) = \int_0^l u^2(x,t)\,dx\) — функция одной переменной \(t\); \(d\mathcal E/dt\) — её обыкновенная производная. Пределы интегрирования постоянны, поэтому дифференцирование вносится под знак интеграла: \(\frac{d\mathcal E}{dt} = \int_0^l \frac{\partial(u^2)}{\partial t}\,dx = 2\int_0^l u\,u_t\,dx\). Устойчивость — оценка нормы решения на слое; её даёт интегральная величина, а не значение \(u\) в точке.
Почему \(u^2\), а не \(u\)Интеграл \(\int_0^l u\,dx\) также сохраняется: \(\frac{d}{dt}\int_0^l u\,dx = -a[u]_0^l = 0\). Но это линейный функционал, а не норма: для знакопеременной функции он может равняться нулю при сколь угодно большой амплитуде. Первая величина, которая сохраняется и является нормой, — \(\int_0^l u^2\,dx\).

На сетке частной производной по времени отвечает разностное отношение \((y_i^{n+1} - y_i^n)/\tau\), интегралу — скалярное произведение (§6а.3).

§6а.2 · Назначение вывода; квадрат нормы

Назначение дифференциального вывода. Почему оценивается квадрат нормы

Выкладка §6а.2 — образец: каждый шаг сеточного метода является её сеточным аналогом; понятия §6а.3–§6а.6 вводятся для проведения этой выкладки на сетке.

1. Происхождение квадратаУмножение уравнения на решение даёт \(u\,u_t = \tfrac12(u^2)_t\) — производную квадрата; уравнение доставляет информацию о величине \(\int u^2dx\). Для уравнения переноса сохраняется и \(\int\Phi(u)\,dx\) при любой \(\Phi\); для уравнения теплопроводности \(\frac{d}{dt}\int\Phi(u)dx = -\nu\int\Phi''(u)u_x^2dx\) имеет определённый знак лишь при выпуклой \(\Phi\), и лишь \(\Phi(u) = u^2\) порождена скалярным произведением.
2. Разложение разности квадратов\(\|y\|^2 = (y, y)\) — билинейная форма, поэтому
\[ \|y^{n+1}\|^2 - \|y^{n}\|^2 = \bigl(y^{n+1} - y^{n},\ y^{n+1} + y^{n}\bigr) \]
— сеточный аналог тождества \((u^2)_t = 2u\,u_t\). Приращение слоя схема выражает через оператор \(A\); поэтому схему умножают скалярно на сумму (полусумму) слоёв — в левой части возникает разность энергий.
3. Переход к нормеИз \(\|y^{n+1}\|^2 \le \|y^n\|^2\) следует \(\|y^{n+1}\| \le \|y^n\|\) — устойчивость — оценка (2.14) §2 с постоянной 1; неравенство Коши–Буняковского и \(\varepsilon\)-неравенство также формулируются для квадратов норм.

Соотношения (6а.3), (6а.4) имеют общую форму — закон сохранения с плотностью и потоком.

§6а.2 · Законы сохранения

Законы сохранения: плотность и поток

\[ \frac{\partial T}{\partial t} + \frac{\partial X}{\partial x} = 0 \quad\Longrightarrow\quad \frac{d}{dt}\int_0^l T\,dx = -\Bigl[X\Bigr]_0^l = 0. \tag{6а.5} \]

Соотношение (6а.5) называется законом сохранения (дивергентной формой); \(T\) — плотность, \(X\) — поток, \(\int_0^l T\,dx\) — сохраняющаяся величина (интеграл движения), если поток на концах уничтожается периодичностью или убыванием на бесконечности [7].

Уравнение переноса, (6а.3)\(T = u^2\), \(X = a\,u^2\) — закон сохранения; \(\int_0^l u^2\,dx = \mathrm{const}\).
Уравнение теплопроводности, (6а.4)\((u^2)_t + (-2\nu u u_x)_x = -2\nu u_x^2\) — не закон сохранения, а баланс с неположительным источником: энергия диссипирует.
Связь с устойчивостьюУстойчивость разностной схемы, доказываемая далее, есть сеточный закон сохранения (или баланс) для плотности \(T = y_i^2\): неравенство между \(\sum_i h\,(y_i^{n+1})^2\) и \(\sum_i h\,(y_i^n)^2\).

§6а.3 · Сетка, сеточные функции, пространства

§6а.3 · Разностные производные

Разностные производные \(y_l\), \(y_r\), \(y_c\) и вывод второй разности \(y_{lr}\)

\[ y_{l,i} = \frac{y_i - y_{i-1}}{h}, \qquad y_{r,i} = \frac{y_{i+1} - y_i}{h}, \qquad y_{c,i} = \frac{y_{i+1} - y_{i-1}}{2h} \tag{6а.8} \] — левая (назад), правая (вперёд), центральная; индексы \(l, r, c\) — left, right, centre. Все три — аналог \(\partial u/\partial x\); порядок \(O(h)\), \(O(h)\), \(O(h^2)\).
вторая производная — разность от разности: правая от левой (или левая от правой — то же самое)
\[ (y_l)_{r,i} = \frac{y_{l,i+1} - y_{l,i}}{h} = \frac1h\Bigl(\frac{y_{i+1} - y_i}{h} - \frac{y_i - y_{i-1}}{h}\Bigr) = \frac{y_{i+1} - 2y_i + y_{i-1}}{h^2} = (y_r)_{l,i} \;=:\; y_{lr,i}. \tag{6а.9} \]
Три тождества (6а.10)\(y_c = \tfrac12(y_l + y_r)\), \(\ y_{lr} = (y_r - y_l)/h\), \(\ y_l = y_c - \tfrac h2\,y_{lr}\): односторонняя разность = центральная + половина шага × вторая разность. Почему не \((y_c)_c\): это вторая разность с шагом \(2h\) — чётные и нечётные узлы не связаны, «пила» неотличима от константы.

§6а.3 · Разностные операторы

Разностные операторы \(D_l\), \(D_r\), \(D_c\), \(\Lambda = D_rD_l\) — это матрицы \(N\times N\)

\((D_l y)_i = y_{l,i}\), \((D_r y)_i = y_{r,i}\), \((D_c y)_i = y_{c,i}\), \(\Lambda y = y_{lr}\). На периодической сетке в базисе \((y_1, \dots, y_N)\):

\[ D_l = \frac{1}{h}\begin{pmatrix} 1 & & & & -1\\ -1 & 1 & & & \\ & -1 & 1 & & \\ & & \ddots & \ddots & \\ & & & -1 & 1\end{pmatrix}, \qquad \Lambda = \frac{1}{h^2}\begin{pmatrix} -2 & 1 & & & 1\\ 1 & -2 & 1 & & \\ & 1 & -2 & \ddots & \\ & & \ddots & \ddots & 1\\ 1 & & & 1 & -2\end{pmatrix} \]
Что видно по матрицамЕдиницы в углах — периодичность. \(\Lambda\) симметрична; \(D_l\) — нет: \(D_l^{\mathsf T} = -D_r\). Тождества (6а.10) в операторной записи: \(D_c = \tfrac12(D_l + D_r)\), \(\Lambda = \tfrac1h(D_r - D_l)\), \(D_l = D_c - \tfrac h2\Lambda\).
Аналог и роль\(D_l, D_r, D_c\) — оператор \(\partial/\partial x\); \(\Lambda\) — \(\partial^2/\partial x^2\). Оператор \(A\) канонической формы (§6а.6) собирается из них: \(A = aD_l\) («уголок»), \(A = aD_c\) (центральная схема), \(A = -\nu\Lambda\) (теплопроводность). \(E\) — единичный оператор, \(Ey = y\) (энергия — \(\mathcal E\)).

§6а.3 · Скалярное произведение и норма

Скалярное произведение: одна норма — сеточная \(L_2\) — и почему она

\[ (y, v) = \sum_{i=1}^{N} h\,y_i v_i, \qquad \|y\| = \sqrt{(y, y)}. \tag{6а.11} \] Аналог \(\int_0^l uv\,dx\); \(\|y\|^2\) — энергия \(\mathcal E\). Для разностей суммируем по всем \(N\) промежуткам: \(\|y_l\|^2 = \sum_{i=1}^N h\,y_{l,i}^2\) (для \(y\in H_0\) член \(i = N\) не нуль).
Инструменты разборов\(|(y, v)| \le \|y\|\,\|v\|\) (Коши–Буняковский); сдвиг индекса на периодической сетке: \(\sum h\,y_{i-1}^2 = \|y\|^2\).
Норм много (\(C\), \(L_1\), \(L_2\)) — мы берём одну. Почему \(L_2\)
  1. Только она порождена скалярным произведением: билинейность ⇒ разложение разности квадратов, сопряжённые операторы, Коши–Буняковский. В \(C\), \(L_1\) этого нет.
  2. Прямой аналог энергии прототипа \(\mathcal E = \int u^2dx\); энергетические нормы \(\|y\|_A^2 = (Ay, y)\) — та же конструкция с \((Ay, v)\), копии других энергий (\(\int u_x^2\)).
  3. Согласована с гармониками: Парсеваль \(\|y\|^2 = \sum|c_k|^2\) ⇒ результаты двух методов сравнимы число к числу.
  4. Что теряем — норму \(C\): \(\sqrt h\|y\|_C \le \|y\| \le \sqrt l\|y\|_C\), оценка в \(L_2\) не равномерна по \(h\); принцип максимума — §11.

Норма выбрана; дальше — операторы на \(H\): что такое сопряжённый и что он значит конкретно.

§6а.4 · Операторы

Сопряжённый оператор — транспонированная матрица; три свойства

Сопряжённый оператор \(A^*\): \((Ay, v) = (y, A^*v)\) при всех \(y, v \in H\). Так как \((y, v) = h\,y^{\mathsf T}v\), то \((Ay, v) = h\,y^{\mathsf T}A^{\mathsf T}v\) и \[ A^* = A^{\mathsf T}. \tag{6а.12} \]
  • \(A\) самосопряжён, \(A^* = A\) — симметричная матрица; положителен, \(A > 0\): самосопряжён и \((Ay, y) > 0\) при \(y \ne 0\).
  • \(A\) кососимметричен, \(A^* = -A\); тогда \((Ay, y) = -(Ay, y) = 0\) — не меняет энергии.
  • \(A \ge B\) для самосопряжённых означает \(A - B \ge 0\) — операторное неравенство; в этой форме будут условия устойчивости.
АналогФормально сопряжённый по Лагранжу оператор \(L^*\): \(\int_0^l (Lu)v\,dx = \int_0^l u(L^*v)\,dx\) + внеинтегральные члены. \(L = \partial_x\): \(L^* = -\partial_x\) — кососимметричен; \(L = -\partial_{xx}\): \(L^* = L\), и \(\int(-u'')u\,dx = \int u'^2dx > 0\) при \(u(0) = u(l) = 0\) — положителен. По матрицам §6а.3: \(\Lambda^{\mathsf T} = \Lambda\), \(D_l^{\mathsf T} = -D_r\).

Три названных свойства решают, какой путь выбрать: теорема Самарского (§6а.10) или лемма 2 (§6а.6).

§6а.4 · Энергетическая норма

Какие операторы встретятся и что такое энергетическая норма

Какие операторы будут в разборах
  • \(-\Lambda\) на \(H_0\) — самосопряжён и положителен. Теплопроводность.
  • \(D_c\) на периодической сетке — кососимметричен. Неустойчивая явная схема и Кранк–Николсон.
  • \(aD_l\) в «уголке» — ни то ни другое: односторонность нарушает симметрию; но \(D_l = D_c - \frac h2\Lambda\) (следующий слайд).
Энергетическая норма. Только при \(A = A^* > 0\) форма \((Ay, v)\) — скалярное произведение; порождённая ею норма \[ \|y\|_A = \sqrt{(Ay, y)} \tag{6а.13} \] называется энергетической, пространство — \(H_A\). Для \(A = -\Lambda\): \(\|y\|_A^2 = \|y_l\|^2\) — сеточный интеграл Дирихле \(\int u_x^2\,dx\) из (6а.4).
Норма оператора\(\|A\| = \sup\|Ay\|/\|y\|\); для \(A = A^* \ge 0\): \((Ay, y) \le \|A\|\,\|y\|^2\), т.е. \(A \le \|A\|E\) (6а.15) — переход от операторных неравенств к условиям на \(\tau\), \(h\).

Несамосопряжённый оператор тоже можно измерить: выделить из него симметричную часть.

§6а.4 · Симметричная и кососимметричная части

Симметричная и кососимметричная части оператора: \(A = A_s + A_k\)

Пусть явная схема записана в виде \(y^{n+1} = y^n - \tau Ay^n\), где \(A\colon H\to H\) — линейный оператор (§6а.6). По билинейности \[ \|y^{n+1}\|^2 = \|y^n\|^2 - 2\tau(Ay^n, y^n) + \tau^2\|Ay^n\|^2: \] оператор \(A\) входит в баланс энергии линейно только через число \((Ay, y)\). При \(A = A^*\) это число равно \(\|y\|_A^2\); для несамосопряжённого \(A\) требуется выделить ту часть оператора, которая определяет \((Ay, y)\).

Пусть \(A\colon H\to H\) — линейный оператор, \(A^*\) — сопряжённый к нему (определение 4). Оператор \(A_s = \tfrac12(A + A^*)\) называется симметричной частью \(A\), оператор \(A_k = \tfrac12(A - A^*)\) — кососимметричной частью. Тогда \(A = A_s + A_k\), \(A_s^* = A_s\), \(A_k^* = -A_k\), и для всех \(y\) \[ (Ay, y) = (A_s y, y), \qquad\text{так как } (A_k y, y) = 0. \tag{6а.14} \]
Аналог\(L = a\,\partial_x - \nu\,\partial_{xx}\): \(a\,\partial_x\) — перенос (кососимметричная часть), \(-\nu\,\partial_{xx}\) — диффузия (симметричная); в баланс \(\int u\,Lu\,dx = \nu\int u_x^2dx\) входит только диффузия.
Роль в методе: ветвь IIДля «уголка» \(A = aD_l\): из \(D_l = D_c - \tfrac h2\Lambda\) следует \((D_l)_s = -\tfrac h2\Lambda\) и \((Ay, y) = \tfrac{ah}{2}\|y_l\|^2 \ge 0\) (6а.20) — основа разборов 1, 2, 5; для \(A = aD_c\): \(A_s = 0\), энергия растёт (разбор 3). \(A_s\) — сеточный аналог схемной вязкости.

Свойства операторов — \(A^*\), знак \((Ay, y)\), \(A_s\) — вычисляются одним инструментом: формулой суммирования по частям.

Для любых сеточных функций \(y\), \(v\) на \(\omega_h\): \[ \sum_{i=1}^{N} h\,y_i\,v_{l,i} = -\sum_{i=0}^{N-1} h\,y_{r,i}\,v_i + y_N v_N - y_0 v_0. \tag{6а.16} \]
Доказательство — §6а.5 (самостоятельно)Раскрыть \(v_{l,i}\), разбить сумму на две и перегруппировать индексы; аналог — \(\int_0^l yv'\,dx = -\int_0^l y'v\,dx + [yv]_0^l\). Граничные члены \(y_Nv_N - y_0v_0\) — внеинтегральные члены: через них входят краевые условия.

Следствие 1. Для \(y, v \in H_0\) применить к \(w = y_l\) (\(w_r = \Lambda y\); \(y_{l,0}\) доопределяем нулём — оно умножается на \(v_0 = 0\)); граничные члены исчезают:

\[ (\Lambda y, v) = -\sum_{i=1}^{N} h\,y_{l,i}v_{l,i}, \tag{6а.17} \]
\[ (-\Lambda y, y) = \sum_{i=1}^{N} h\,y_{l,i}^2 = \|y_l\|^2 \ge 0. \tag{6а.18} \]

Правая часть симметрична ⇒ \(\Lambda\) самосопряжён; нуль лишь при \(y = \mathrm{const}\), а с \(y_0 = 0\) — при \(y \equiv 0\). Итак, \(A = -\Lambda\) самосопряжён и положителен на \(H_0\). Краевые условия вошли именно здесь.

§6а.5 · Следствия 2–4 доп.

Периодическая сетка: сопряжённые операторы; схемная вязкость и \(\|\Lambda\|\) — формулировки

Следствие 2. Граничные члены (6а.16) взаимно уничтожаются, суммы по \(\overline{0,N-1}\) и \(\overline{1,N}\) совпадают: \((y, D_lv) = -(D_ry, v)\), то есть \(D_r^* = -D_l\) (меняя ролями \(y\), \(v\): \(D_l^* = -D_r\)); далее \((S + T)^* = S^* + T^*\), \((ST)^* = T^*S^*\):

\[ D_l^* = -D_r,\qquad D_r^* = -D_l,\qquad D_c^* = -D_c, \tag{6а.19} \]
\[ \Lambda^* = (D_rD_l)^* = D_l^*D_r^* = (-D_r)(-D_l) = \Lambda. \]

Центральная разность кососимметрична, \((y_c, y) = 0\) — двойник \(\int uu_x = 0\); \(\Lambda\) самосопряжён, \(-\Lambda \ge 0\) (константа даёт нуль); \(D_l\), \(D_r\) — ни то ни другое.

Следствие 3 (доказательство — ДЗ, упражнение 2)
\[ (D_l)_s = -\tfrac h2\Lambda \ge 0,\qquad (D_ly, y) = \tfrac h2\|y_l\|^2, \tag{6а.20} \]
\[ (D_r)_s = +\tfrac h2\Lambda \le 0. \]
Левая разность = перенос + диффузия с коэффициентом \(\frac h2\); умноженная на \(a\) — схемная вязкость \(\frac{ah}{2}\) п.д.п. «уголка» (§4–§5). У разности вперёд вязкость «не того знака».
Следствие 4 (доказательство — ДЗ, упражнение 2)\(-\Lambda \le \frac{4}{h^2}E\), \(\|\Lambda\| \le \frac{4}{h^2}\) (6а.21) — из (6а.18) и \((a-b)^2 \le 2a^2 + 2b^2\). Точно: \(\|\Lambda\| = \frac{4}{h^2}\cos^2\frac{\pi h}{2l}\), собственные функции — сеточные синусы, гармоники §6 с краевыми условиями.

§6а.6 · Каноническая форма

Каноническая форма: что такое \(A\), \(B\), \(\varphi^n\) и как их прочитать по схеме

Схема записана в канонической форме, если \(\ B\,\dfrac{y^{n+1} - y^{n}}{\tau} + A\,y^{n} = \varphi^{n}\ \) (6а.22), где \(A, B\colon H \to H\) линейны, \(B\) обратим. \(A\) — пространственный оператор (копия \(L\) из \(u_t + Lu = f\)); \(B\) — оператор при разности слоёв (неявность; аналога нет); \(\varphi^n \in H\) — сеточная функция правой части: набор чисел \(\varphi_i^n\), обычно \(f(x_i, t_n)\); для однородной задачи \(\varphi^n = 0\).
\[ P\,y^{n+1} = Q\,y^{n} + \tau\varphi^n \ \ (\text{при новом слое} - P,\ \text{при старом} - Q) \quad\Longrightarrow\quad B = P, \qquad A = \frac{P - Q}{\tau}. \tag{6а.23} \]
Что значит \(B = E\)\(E\) — тождественный оператор, \(Ey = y\), единичная матрица. \(B = E\): при разности слоёв стоит единица,
\[ y^{n+1} = y^n - \tau\bigl(Ay^n - \varphi^n\bigr) \]
новый слой вычисляется по явной формуле, система уравнений не решается. Так устроены все явные схемы.
Что значит \(B \ne E\)На каждом шаге решается система
\[ B\,y^{n+1} = (B - \tau A)\,y^n + \tau\varphi^n \]
с матрицей \(B\) — это и есть неявность; обратимость \(B\) — разрешимость схемы.

Сначала определение 8 — схема с весами, затем явная и неявная схемы: \(P\), \(Q\), \(\varphi^n\) и, значит, \(B\), \(A\).

§6а.6 · Схема с весами

Определение 8. Схема с весами

Пусть \(A\colon H\to H\) — пространственный оператор схемы для \(u_t + Lu = f\). Схема с весами — семейство схем \[ \frac{y^{n+1} - y^{n}}{\tau} + A\bigl(\theta\,y^{n+1} + (1 - \theta)\,y^{n}\bigr) = \varphi^n, \qquad \theta\in[0,1], \tag{6а.24} \] в которых \(A\) применяется к взвешенной комбинации слоёв; \(\theta\) — вес нового слоя. \(\theta = 0\) — явная схема, \(\theta = 1\) — чисто неявная, \(\theta = \tfrac12\) — схема Кранка–Николсон. В канонической форме \(B = E + \theta\tau A\).
Теплопроводность, \(A = -\Lambda\), вес \(\sigma\) — схема (6.18) §6
\[ \frac{y_i^{n+1} - y_i^n}{\tau} = \sigma\,\frac{y_{i+1}^{n+1} - 2y_i^{n+1} + y_{i-1}^{n+1}}{h^2} + (1 - \sigma)\,\frac{y_{i+1}^{n} - 2y_i^{n} + y_{i-1}^{n}}{h^2} \]
Шеститочечный шаблон; \(O(\tau + h^2)\), при \(\sigma = \tfrac12\) — \(O(\tau^2 + h^2)\).
Зачем вводитсяЯвная, неявная и симметричная схемы для одного и того же \(A\) отличаются одним числом \(\theta\): им регулируется неявность, а условия устойчивости получаются сразу для всего семейства (разбор 4 — теорема Самарского, лемма 2 — любой \(A\)). При \(\theta = 0\) новый слой вычисляется явно, при \(\theta > 0\) решается система с матрицей \(E + \theta\tau A\). Аналога у веса нет — это аппроксимация по времени: \(\int_{t_n}^{t_{n+1}}Lu\,dt\) заменяется взвешенной комбинацией значений на концах; \(\theta = \tfrac12\) — формула трапеций.

Все схемы следующего слайда — члены этого семейства с \(\theta = 0, 1, 0, \sigma\).

§6а.6 · Примеры: явная и неявная схемы

Явный и неявный «уголок» с правой частью: \(P\), \(Q\), \(\varphi^n\) → \(B\), \(A\)

Явная: \(u_t + au_x = f\)
\[ \frac{y_i^{n+1} - y_i^n}{\tau} + a\,\frac{y_i^n - y_{i-1}^n}{h} = f(x_i, t_n) \]

\[ P = E,\quad Q = E - \tau aD_l,\quad \varphi^n = \{f(x_i, t_n)\}; \]
\[ B = E,\qquad A = (P - Q)/\tau = aD_l. \]

Неявная: разность на новом слое
\[ \frac{y_i^{n+1} - y_i^n}{\tau} + a\,\frac{y_i^{n+1} - y_{i-1}^{n+1}}{h} = f(x_i, t_{n+1}) \]

\[ P = E + \tau aD_l,\quad Q = E,\quad \varphi^n = \{f(x_i, t_{n+1})\}; \]
\[ B = E + \tau aD_l,\qquad A = (P - Q)/\tau = aD_l. \]
\(B\): диагональ \(1 + r\), поддиагональ \(-r\); на каждом шаге решается \(By^{n+1} = y^n + \tau\varphi^n\). Проверка: \((E + \tau aD_l)\frac{y^{n+1}-y^n}{\tau} + aD_ly^n = \frac{y^{n+1}-y^n}{\tau} + aD_l y^{n+1}\).

§6а.6 · Лемма 2

Лемма 2: энергетическое тождество схемы с весами — для любого \(A\)

Семейство схем с весами (определение 8), \(B = E + \theta\tau A\): все схемы предыдущих слайдов — его члены; одно тождество для всех значений веса \(\theta\).

\[ \frac{y^{n+1} - y^{n}}{\tau} + A\bigl(\theta\,y^{n+1} + (1 - \theta)\,y^{n}\bigr) = 0, \qquad B = E + \theta\tau A, \qquad \theta\in[0,1]. \tag{6а.24} \]
Пусть \(A\colon H\to H\) — произвольный линейный оператор, \(\theta\in[0,1]\), \(v = \theta y^{n+1} + (1-\theta)y^n\). Тогда \[ \|y^{n+1}\|^2 = \|y^{n}\|^2 - 2\tau\,(A_s v, v) + (1 - 2\theta)\,\tau^2\,\|Av\|^2. \tag{6а.26} \]
Доказательство. Из схемы приращение выражается через \(A\), сумма слоёв — через \(v\) и приращение: \[ y^{n+1} - y^n = -\tau Av, \qquad y^{n+1} + y^n = 2v + (1 - 2\theta)(y^{n+1} - y^n) = 2v - (1 - 2\theta)\tau Av \] (коэффициенты: при \(y^{n+1}\) — \(2\theta + 1 - 2\theta = 1\), при \(y^n\) — \(2 - 2\theta - 1 + 2\theta = 1\)). Подставляем в разложение (6а.25) \(\|y^{n+1}\|^2 - \|y^n\|^2 = (y^{n+1} - y^n,\ y^{n+1} + y^n)\): \[ \|y^{n+1}\|^2 - \|y^n\|^2 = \bigl(-\tau Av,\ 2v - (1-2\theta)\tau Av\bigr) = -2\tau(Av, v) + (1 - 2\theta)\tau^2(Av, Av), \] и \((Av, v) = (A_sv, v)\) по (6а.14). Никаких предположений об \(A\) не использовано. □

Тождество точное. Прочитаем его для трёх значений веса.

§6а.10 · Основная теорема

Теорема Самарского об устойчивости в \(H_A\)

Пусть двухслойная разностная схема без правой части записана в каноническом виде \[ B\,\frac{y^{n+1} - y^{n}}{\tau} + A\,y^{n} = 0 \] с линейными операторами \(A, B\colon H \to H\), причём:
  1. оператор \(A\) самосопряжён и положителен, \(A = A^* > 0\);
  2. оператор \(B\) обратим и удовлетворяет операторному неравенству \[ B \ge \tfrac{\tau}{2}\,A, \qquad\text{то есть}\qquad (By, y) \ge \tfrac{\tau}{2}\,(Ay, y) \ \ \text{при всех } y \in H. \tag{6а.34} \]
Тогда в энергетической норме \(\|y\|_A = \sqrt{(Ay, y)}\) справедливы оценки \[ \|y^{n+1}\|_A \le \|y^{n}\|_A \ \ (n = 0, 1, \dots) \qquad\text{и, следовательно,}\qquad \|y^{n}\|_A \le \|y^{0}\|_A. \tag{6а.35} \]

Устойчивость в \(H_A\) с постоянной \(C = 1\), не зависящей от \(\tau\), \(h\), \(n\). От \(B\) — только обратимость и операторное неравенство: ни самосопряжённости, ни вида \(E + \theta\tau A\). Ветвь I алгоритма. Линейность нужна теореме, не методу (семинар № 3).

Доказательство — четыре этапа, копирующие §6а.2 и (6а.25) в норме \(H_A\); после каждого — использованная гипотеза.

\[ \|y^{n+1}\|_A^2 = \|y^{n}\|_A^2 - \frac{2}{\tau}\Bigl(\bigl(B - \tfrac{\tau}{2}A\bigr)(y^{n+1} - y^{n}),\ y^{n+1} - y^{n}\Bigr). \tag{6а.39} \]

Теоремы 2 и 3 — формулировки (доказательства — §6а.10, §6а.12)Теорема 2.
