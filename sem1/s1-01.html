Что такое теория разностных схем

Разностной схемой будем называть приближение дифференциальной задачи (задачи для уравнения в частных производных) системой алгебраических уравнений на некоторой конечной сетке узлов. Точное определение — в §1.10 (Опр. 1); пока достаточно этой рабочей формулировки.

Теория разностных схем (ТРС) — раздел вычислительной математики, посвящённый методам построения таких приближений и методам исследования их свойств: прежде всего аппроксимации, устойчивости и сходимости.

Математическое моделирование и вычислительный эксперимент

Схема вычислительного эксперимента состоит из пяти этапов:

  1. Этап № 1. Объект исследования (физическая постановка задачи).
  2. Этап № 2. Математическая модель (математическая постановка задачи).
  3. Этап № 3. Численный метод решения задачи (дискретная задача и вычислительный алгоритм её решения).
  4. Этап № 4. Программирование на ЭВМ (написание программы).
  5. Этап № 5. Проведение вычислений и исследование полученных результатов.

Построение численного метода (этап № 3), в свою очередь, обычно разбивается на два шага:

  • дискретизация задачи;
  • разработка численного метода решения дискретной задачи.

Классы численных методов

Все численные методы решения задач математической физики можно разделить на несколько крупных классов:

  • Стохастические методы (метод частиц и родственные модификации);
  • Вариационные методы — сводят задачу к задачам оптимизации;
  • Метод конечных элементов (метод Галёркина, разрывный метод Галёркина и др.);
  • Метод конечных объёмов;
  • Метод конечных разностей — наш курс.

Операторная запись задачи

Абстрактно любую задачу математической физики можно записать в операторной форме:

\[ A\,u \;=\; F, \tag{1.0} \]

где

  • \(u = u(x)\), \(x \in \Omega \subset \mathbb{R}^m\) — искомое решение, \(u \in B_1\);
  • \(F \in B_2\) — правая часть задачи;
  • \(B_1, B_2\) — линейные нормированные пространства, в каждом из которых введена своя норма \(\|\cdot\|_1\) и \(\|\cdot\|_2\);
  • \(A \colon B_1 \to B_2\) — дифференциальный оператор задачи (в общем случае может быть нелинейным).

Такая запись позволяет говорить о разных задачах — переносе, теплопроводности, Пуассоне, системах Эйлера — единообразно, и сводит весь дальнейший анализ к свойствам оператора \(A\) и его дискретного аналога.

Корректность задачи

Линейный случай

Если \(A\) — линейный оператор, то для корректности задачи (1.0) требуется, чтобы \(A\) был обратим, т. е. существовал ограниченный обратный оператор \(A^{-1}\). Тогда автоматически выполняются два свойства:

  1. для любой правой части существует единственное решение:
    \[ \forall\, F \in B_2 \ \Rightarrow \ \exists!\; u(x) \in B_1; \tag{1.1a} \]
  2. имеет место непрерывная зависимость решения от входных данных: существует постоянная \(C = \mathrm{const} > 0\), такая что
    \[ \|u\|_1 \;\le\; C\,\|F\|_2, \qquad C = \|A^{-1}\|. \tag{1.1b} \]

Нелинейный случай (условие Липшица)

Если \(A\) — нелинейный оператор, то, вообще говоря, глобальной обратимости требовать нельзя. Потребуем, чтобы задача имела единственное решение локально — для всех \(F\) из окрестности некоторой опорной правой части \(F_0 \in B_2\):

\[ \|F - F_0\|_2 \;<\; \varepsilon. \tag{1.2a} \]

Непрерывная зависимость решения от данных в нелинейном случае формулируется как условие Липшица непрерывности обратного оператора: существует постоянная \(C = \mathrm{const} > 0\), такая что для любых двух допустимых правых частей \(F_1, F_2\) их решения \(u_1, u_2\) удовлетворяют

\[ \|u_2 - u_1\|_1 \;\le\; C\,\|F_2 - F_1\|_2. \tag{1.2b} \]

Корректно поставленная задача — необходимое условие того, что численное решение вообще имеет смысл: даже идеальный метод не спасёт некорректную задачу, потому что малые ошибки округления в правой части приведут к сколь угодно большим отклонениям в решении.

Задача Коши как модельный пример

В качестве конкретного модельного уравнения для всего дальнейшего курса возьмём линейное гиперболическое дифференциальное уравнение в частных производных

\[ \frac{\partial u}{\partial t} + a\,\frac{\partial u}{\partial x} = 0, \qquad -\infty < x < \infty, \tag{1.3} \]

где \(x\) — пространственная координата, \(t\) — время, \(a = \mathrm{const}\). Уравнение (1.3) будем называть уравнением переноса.

Для единственности решения зададим значение \(u(x,t)\) в начальный момент \(t = t_0 = 0\):

\[ u(x, 0) = u_0(x), \qquad -\infty < x < \infty. \tag{1.4} \]

Математическая задача (1.3)–(1.4) называется задачей с начальными данными, или задачей Коши.

Расчётная сетка в области \(\Omega\)

Определение 1. Сеткой в области \(\Omega \subset \mathbb{R}^m\) называется любое непустое конечное множество точек \[ \omega \;=\; \{\,x_k \in \Omega,\ k = \overline{1,N}\;\colon\; x_i = x_j \Leftrightarrow i = j\,\}. \] Элементы множества \(\omega\) называются узлами сетки.

Для одномерной сетки \(\omega\) на отрезке \([a,b]\) вводятся стандартные величины: шаги сетки \(h_k = x_k - x_{k-1}\), характеристический шаг

\[ |h| \;=\; \max_{0 \le k \le N+1} h_k, \tag{1.5} \]

а также усреднённый шаг в узле

\[ \bar h_k \;=\; \tfrac12\,(h_k + h_{k+1}), \qquad k = \overline{1, N-1}. \tag{1.6} \]

Примеры сеток

Пример 1. Равномерная прямоугольная сетка на \([a, b]\)

\[ \omega \;=\; \omega_h \;=\; \Bigl\{\,x_k = a + k\,h,\ k = \overline{0, N},\ h = \tfrac{b-a}{N}\,\Bigr\}. \tag{1.7} \]

Пример 2. Сетка общего вида (неравномерная) на \([a, b]\)

\[ \omega \;=\; \bigl\{\,a \le x_0 < x_1 < \ldots < x_N \le b;\ h_k = x_k - x_{k-1},\ k = \overline{1, N},\ h_k > 0\,\bigr\}. \tag{1.8} \]

Полагая дополнительно \(h_0 = a - x_0\) и \(h_{N+1} = b - x_N\), получаем полный набор шагов \(h_k,\ k = \overline{0, N+1}\), необходимый для формулировки разностных операторов вблизи границы.

Неравномерная сетка на \([a, b]\).

Пример 3. Прямоугольная сетка в прямоугольной области

Пусть расчётная область — прямоугольник \(\Pi = \{\,a \le x \le b,\ c \le y \le d\,\}\). Разобьём отрезок \([a, b]\) на \(N_x\) частей, а отрезок \([c, d]\) — на \(N_y\) частей с шагами

\[ h_x = \tfrac{b - a}{N_x}, \qquad h_y = \tfrac{d - c}{N_y}. \tag{1.9} \]

Тогда сетка есть множество точек пересечения прямых линий \(x = a + i\,h_x\) и \(y = c + j\,h_y\), а узлы обозначаются \(x_{i,j} = (a + i h_x,\ c + j h_y)\), \(i = \overline{0, N_x}\), \(j = \overline{0, N_y}\).

Прямоугольная сетка в прямоугольной области \(\Pi = [a,b]\times[c,d]\).

Пример 4. Сетка через монотонное преобразование

Пусть на отрезке \([0, 1]\) задана непрерывная и монотонно возрастающая функция \(\varphi(t)\), \(t \in [0, 1]\), и пусть \(\omega_h\) — равномерная сетка с шагом \(h = 1/N\) на \([0, 1]\). Определим

\[ \Phi(t) \;=\; \frac{\varphi(t) - \varphi(0)}{\varphi(1) - \varphi(0)}\,(b - a) + a, \qquad x_k \;=\; \Phi(k\,h),\ \ k = \overline{0, N}. \tag{1.10} \]

Тогда получаемая сетка \(\omega = \{x_k\}\) — сетка общего вида (см. Пример 2) с шагами

\[ h_k \;=\; x_k - x_{k-1} \;=\; \Phi(k h) - \Phi((k-1)\,h), \qquad k = \overline{1, N}. \tag{1.11} \]

Выбор функции \(\varphi\) позволяет управлять распределением узлов вдоль отрезка — сгущать их в нужных подобластях, оставаясь в рамках регулярной параметризации.

Расчётная сетка задачи Коши

Вернёмся к задаче (1.3)–(1.4). Приближённое решение методом конечных разностей определяется только в дискретных точках плоскости \((x, t)\).

Введём на оси \(x\) множество узлов

\[ \{0,\;\pm h,\;\pm 2h,\;\ldots\}, \tag{1.12} \]

где \(h > 0\) — пространственный шаг; узлы имеют вид \(x_i = i\,h\), \(i = 0, \pm 1, \pm 2, \ldots\). Предположим, что численное решение должно быть определено на конечном временном промежутке \(0 \le t \le T\), \(0 < T < \infty\), и введём на оси \(t\) сетку

\[ 0 = t_0 < t_1 < t_2 < \ldots < t_{N-1} < t_N = T. \tag{1.13} \]

Сетки (1.12)–(1.13) называются равномерными, если

\[ x_i = i\,h,\ \ i = 0, \pm 1, \pm 2, \ldots\,; \qquad t_n = n\,\tau,\ \ n = \overline{0, N}, \tag{1.14} \]

где \(\tau = T/N\) называется временным шагом. Множество точек пересечения прямых \(x = x_i\) и \(t = t_n\) образует равномерную сетку \(G_h\) в плоскости \((x, t)\).

Функция \(u_i^n\), определённая в узлах сетки \(G_h\), называется сеточной функцией. При этом \(u_i^n\) — приближённое значение решения задачи в узле \((x_i, t_n)\); истинное значение точного решения обозначим \(u(x_i, t_n)\).

Равномерная расчётная сетка \(G_h\) с шагом \(h\) по пространству и \(\tau\) по времени.

Сеточные нормы

Так как далее будут введены различные операторы, то необходимо определиться с понятием нормы в заданном нами дискретном пространстве. Рассмотрим некоторые варианты сеточных норм.

1. Сеточный аналог равномерной нормы

\[ \|u\|_C = \max_{x \in G} |u(x)|, \tag{1.6} \]

где \(G\) — замкнутая ограниченная область, имеет вид

\[ \|u_h\| = \max_{x \in G_h} |u_h(x)|. \tag{1.7} \]

2. Сеточные аналоги нормы \(L_2\)

\[ \|u\|_{L_2} = \left(\int_0^1 u^2(x)\,dx\right)^{1/2} \tag{1.8} \]

в пространстве \(L_2\) определяются с помощью интегральных сумм и имеют вид:

\[ \|u_h\| = \sqrt{\sum_{i=1}^{N} u_h^2(x)\,h\,}, \qquad \|u_h\| = \sqrt{\sum_{i=0}^{N-1} u_h^2(x)\,h\,}. \tag{1.9} \]

Основные определения

Завершим введение и первую тему последними определениями, которые понадобятся в будущем.

Определение 1. Разностная схема — это совокупность разностных уравнений для определения значений сеточной функции внутри расчётной области, дополненная соответствующими начальными и граничными условиями для этой сеточной функции.
Определение 2. Шаблон схемы представляет из себя конфигурацию расчётных узлов в области интегрирования, используемых на каждом элементарном шаге вычислений.
Примеры шаблонов: явный трёхточечный (уголок), неявный трёхточечный и «крест» (три временных слоя).
