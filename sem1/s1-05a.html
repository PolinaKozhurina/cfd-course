Энергетический метод исследования устойчивости. Априорные оценки в сеточных нормах

▶ Слайды

В §5 устойчивость разностной схемы исследовалась по поведению отдельных гармоник: подстановка \(u_m^n = \lambda^n e^{i\alpha m}\) сводила вопрос к модулю множителя перехода \(\lambda(\alpha)\). Настоящий параграф посвящён второму, принципиально иному способу — энергетическому методу, или методу энергетических неравенств. Он не разлагает решение на гармоники, а оценивает его норму целиком, повторяя на сетке ту же выкладку, которой в теории уравнений в частных производных доказывают закон сохранения (или убывания) энергии. Изложение следует книгам А. А. Самарского [1] и А. А. Самарского, А. В. Гулина [2]; подчёркнутые пунктиром термины открывают карточку с точным определением.

§5а.1. Границы метода гармоник и постановка вопроса

Напомним, на чём держался метод §5. Гармоника \(e^{i\alpha m}\) является собственной функцией оператора перехода \(S\colon u^n \mapsto u^{n+1}\) лишь потому, что оператор \(S\) перестановочен со сдвигом по сетке: коэффициенты схемы одинаковы во всех узлах, а границы отсутствуют (сетка бесконечна либо периодична). Как только хотя бы одно из этих свойств нарушается, гармоники перестают быть собственными функциями и подстановка (5.1) теряет смысл.

Задачи, для которых метод гармоник неприменим
  • Переменные коэффициенты: уравнение переноса \(u_t + a(x)\,u_x = 0\) или теплопроводности \(u_t = (k(x)u_x)_x\) — коэффициенты схемы зависят от номера узла.
  • Краевые условия: на отрезке \([0, l]\) с условиями \(u(0,t) = u(l,t) = 0\) сеточные функции обязаны обращаться в нуль на концах, а гармоника \(e^{i\alpha m}\) этого не делает.
  • Неравномерные сетки: шаг \(h_i\) зависит от \(i\), схема не инвариантна относительно сдвига.
  • Нелинейные схемы: принцип суперпозиции, на котором основано разложение по гармоникам, не выполняется.

Есть и вторая причина искать другой инструмент. Условие Неймана (5.5) — лишь необходимое условие устойчивости: оно получено из неравенства (5.3), записанного для одного специального класса начальных данных. Для скалярных двухслойных схем с постоянными коэффициентами на периодической сетке оно оказывается и достаточным в норме \(L_2\) (это следует из равенства Парсеваля), но для систем уравнений и для многослойных схем условие \(|\lambda| \le 1\) может выполняться, а схема — быть неустойчивой.

Энергетический метод устроен иначе. Он даёт априорную оценку решения: неравенство вида

\[ \|y^{n+1}\| \le \|y^{n}\| \qquad\text{или}\qquad \|y^{n}\|^2 \le \|y^{0}\|^2 + C\sum_{k=0}^{n-1}\tau\,\|\varphi^{k}\|^2, \tag{5а.1} \]

полученное до и без решения разностной задачи — только из структуры схемы. Такое неравенство есть в точности оценка (2.14) из Определения 4 §2, то есть устойчивость с явно указанной нормой и явно указанной постоянной. Условия, при которых оценка (5а.1) доказана, являются поэтому достаточными условиями устойчивости. Цена метода — необходимость провести для каждой схемы своё алгебраическое тождество; зато он работает там, где метод гармоник не может быть даже сформулирован.

§5а.2. Дифференциальный прототип: закон сохранения энергии

Прежде чем переносить метод на сетку, проведём выкладку для самого дифференциального уравнения; всё дальнейшее будет её сеточной копией. Рассмотрим уравнение переноса на отрезке \([0, l]\) с периодическими условиями:

\[ \frac{\partial u}{\partial t} + a\,\frac{\partial u}{\partial x} = 0, \qquad u(0, t) = u(l, t), \qquad a = \mathrm{const}. \tag{5а.2} \]

Умножим уравнение на \(u\) и проинтегрируем по \(x\) от \(0\) до \(l\). Первое слагаемое даёт производную по времени от интеграла квадрата решения, второе — интеграл от полной производной:

\[ \int_0^l u\,u_t\,dx = \frac{1}{2}\frac{d}{dt}\int_0^l u^2\,dx, \qquad \int_0^l a\,u\,u_x\,dx = \frac{a}{2}\int_0^l \frac{\partial}{\partial x}\bigl(u^2\bigr)\,dx = \frac{a}{2}\Bigl[u^2(l,t) - u^2(0,t)\Bigr] = 0. \]

Внеинтегральный член обратился в нуль благодаря периодичности — именно здесь в выкладку вошло краевое условие. Обозначив \(E(t) = \int_0^l u^2(x,t)\,dx = \|u(\cdot, t)\|^2_{L_2}\), получаем

\[ \frac{dE}{dt} = 0, \qquad \|u(\cdot,t)\|_{L_2} = \|u(\cdot,0)\|_{L_2} \quad\text{при всех } t \ge 0. \tag{5а.3} \]

Величину \(E(t)\) называют энергией решения: для волнового уравнения \(u_{tt} = c^2 u_{xx}\) аналогичная выкладка даёт сохранение интеграла \(\int (u_t^2 + c^2 u_x^2)\,dx\), который есть механическая энергия струны; название закрепилось за всеми интегралами такого рода. Равенство (5а.3) — априорная оценка: норма решения в любой момент времени выражена через норму начальных данных, хотя само решение мы не находили.

Для уравнения теплопроводности \(u_t = \nu u_{xx}\) с условиями \(u(0,t) = u(l,t) = 0\) та же выкладка требует интегрирования по частям:

\[ \frac{1}{2}\frac{d}{dt}\int_0^l u^2\,dx = \nu\int_0^l u\,u_{xx}\,dx = \nu\Bigl[u\,u_x\Bigr]_0^l - \nu\int_0^l u_x^2\,dx = -\,\nu\int_0^l u_x^2\,dx \le 0, \tag{5а.4} \]

откуда \(\|u(\cdot,t)\|_{L_2} \le \|u(\cdot,0)\|_{L_2}\): энергия не сохраняется, а убывает (диссипирует). Внеинтегральный член снова исчез благодаря краевым условиям.

Что именно переносится на сетку Выкладки (5а.3) и (5а.4) состоят из трёх действий: умножение уравнения на решение и интегрирование (на сетке — скалярное произведение), интегрирование по частям (на сетке — суммирование по частям, §5а.5) и обращение внеинтегральных членов в нуль за счёт краевых условий (на сетке — за счёт значений сеточной функции в граничных узлах). Производная по времени заменяется разностью между слоями. Энергетический метод для разностных схем — это в точности повторение этих трёх действий в сеточных терминах.

§5а.3. Пространство сеточных функций со скалярным произведением

Введём на отрезке \([0, l]\) равномерную сетку \(\omega_h = \{x_i = ih,\ i = \overline{0, N},\ h = l/N\}\) и, как в §1.10, пространство \(H\) сеточных функций \(y = \{y_i\}\). Будем использовать обозначения А. А. Самарского для разностных отношений:

\[ y_{x,i} = \frac{y_{i+1} - y_i}{h}, \qquad y_{\bar x,i} = \frac{y_i - y_{i-1}}{h}, \qquad y_{\mathring{x},i} = \frac{y_{i+1} - y_{i-1}}{2h}, \qquad y_{\bar x x,i} = \frac{y_{i+1} - 2y_i + y_{i-1}}{h^2} \tag{5а.5} \]

(разность вперёд, назад, центральная и вторая разность). Индекс \(i\) при записи операторов опускается: \(y_{\bar x x} = (y_{\bar x})_x\). Оператор второй разности обозначим \(\Lambda y = y_{\bar x x}\). Для двухслойных схем удобно обозначить \(y = y^n\) (текущий слой), \(\hat y = y^{n+1}\) (следующий слой) и

\[ y_t = \frac{\hat y - y}{\tau}, \qquad y^{(\sigma)} = \sigma\hat y + (1 - \sigma)\,y, \qquad y^{(1/2)} = \frac{\hat y + y}{2}. \tag{5а.6} \]

Первое из этих выражений — разностная производная по времени, второе — взвешенная комбинация двух слоёв (при \(\sigma = 0\) явная, при \(\sigma = 1\) чисто неявная), третье — полусумма слоёв, которая будет играть главную роль в доказательстве основной теоремы.

Скалярное произведение сеточных функций. Пусть \(H\) — пространство сеточных функций на \(\omega_h\), удовлетворяющих периодическому условию \(y_0 = y_N\). Положим \[ (y, v) = \sum_{i=1}^{N} h\,y_i v_i, \qquad \|y\| = \sqrt{(y, y)} = \Bigl(\sum_{i=1}^{N} h\,y_i^2\Bigr)^{1/2}. \tag{5а.7} \] Для краевой задачи первого рода рассматривается пространство \(H_0\) функций с \(y_0 = y_N = 0\), и сумма в (5а.7) берётся по внутренним узлам \(i = \overline{1, N-1}\).

Форма (5а.7) есть скалярное произведение в конечномерном пространстве \(H\): она билинейна, симметрична, и \((y, y) > 0\) при \(y \ne 0\). Норма \(\|y\|\) совпадает с сеточной нормой \(L_2\) из формулы (1.14) — это интегральная сумма для \(\int_0^l y^2\,dx\), и множитель \(h\) в ней нужен именно для того, чтобы норма имела предел при \(h \to 0\). Для неё выполняется неравенство Коши–Буняковского \(|(y, v)| \le \|y\|\,\|v\|\).

Почему не норма \(C\) Нормы \(\|y\|_C = \max_i |y_i|\) и \(\|y\|\) связаны неравенствами \(\sqrt{h}\,\|y\|_C \le \|y\| \le \sqrt{l}\,\|y\|_C\). При фиксированном \(h\) они эквивалентны, но постоянная \(\sqrt{h}\) в левом неравенстве стремится к нулю: оценка в \(L_2\) не влечёт оценки в \(C\), равномерной по \(h\). Энергетический метод естественно работает в \(L_2\) и в порождённых ею энергетических нормах, потому что только в них есть скалярное произведение. Устойчивость в норме \(C\) доказывается другими средствами — принципом максимума (§11).

§5а.4. Самосопряжённые, положительные и кососимметричные операторы. Энергетическая норма

Пусть \(A\colon H \to H\) — линейный оператор. Так как \(H\) конечномерно, \(A\) задаётся матрицей; все приводимые ниже понятия — обычные понятия линейной алгебры, записанные через скалярное произведение (5а.7).

Сопряжённый, самосопряжённый, положительный оператор. Оператор \(A^*\) называется сопряжённым к \(A\), если \((Ay, v) = (y, A^*v)\) при всех \(y, v \in H\). Оператор называется самосопряжённым, если \(A^* = A\), то есть \((Ay, v) = (y, Av)\) при всех \(y, v\). Самосопряжённый оператор называется положительным, \(A > 0\), если \((Ay, y) > 0\) при всех \(y \ne 0\), и неотрицательным, \(A \ge 0\), если \((Ay, y) \ge 0\) при всех \(y\). Для самосопряжённых операторов запись \(A \ge B\) означает \(A - B \ge 0\), то есть \((Ay, y) \ge (By, y)\) при всех \(y \in H\).

Запись \(A \ge B\) называется операторным неравенством. Именно в такой форме будут формулироваться условия устойчивости: не как неравенства между числами \(\tau\) и \(h\), а как неравенства между операторами схемы, из которых уже потом извлекаются ограничения на шаги.

Энергетическая норма. Пусть \(A = A^* > 0\). Форма \((Ay, v)\) есть скалярное произведение в \(H\); порождённая ею норма \[ \|y\|_A = \sqrt{(Ay, y)} \tag{5а.8} \] называется энергетической нормой, а пространство \(H\) с этой нормой обозначается \(H_A\).

Условие \(A = A^*\) обеспечивает симметричность формы \((Ay, v) = (Av, y)\), условие \(A > 0\) — её положительную определённость; в конечномерном пространстве это в точности условия того, что симметричная матрица \(A\) задаёт скалярное произведение. Название объясняется дифференциальным прототипом: для \(A = -\Lambda\) (см. ниже) величина \(\|y\|_A^2\) есть сеточный аналог \(\int u_x^2\,dx\) — «энергии» из (5а.4).

Оператор \(A\) называется кососимметричным, если \(A^* = -A\). Для него \((Ay, y) = (y, A^*y) = -(Ay, y)\), откуда \((Ay, y) = 0\) при всех \(y\): кососимметричный оператор не меняет энергии. Это сеточный аналог того, что в (5а.3) член с \(a u_x\) выпал из энергетического баланса.

Наконец, нормой оператора называется число \(\|A\| = \sup_{y \ne 0}\|Ay\|/\|y\|\). Для \(A = A^* \ge 0\) справедливо неравенство

\[ (Ay, y) \le \|A\|\,\|y\|^2, \qquad\text{то есть}\qquad A \le \|A\|\,E, \tag{5а.9} \]

где \(E\) — единичный оператор; оно следует из неравенства Коши–Буняковского: \((Ay, y) \le \|Ay\|\,\|y\| \le \|A\|\,\|y\|^2\). Неравенство (5а.9) — основной способ превращать операторные условия устойчивости в условия на \(\tau\) и \(h\).

§5а.5. Формулы суммирования по частям (разностные формулы Грина)

Сеточным аналогом интегрирования по частям служит преобразование Абеля, или формула суммирования по частям. Сформулируем её для произвольных сеточных функций, без предположений о значениях на концах — чтобы было видно, откуда берутся граничные члены.

Формула суммирования по частям. Для любых сеточных функций \(y\), \(v\), заданных на \(\omega_h\), \[ \sum_{i=1}^{N} h\,y_i\,v_{\bar x,i} = -\sum_{i=0}^{N-1} h\,y_{x,i}\,v_i + y_N v_N - y_0 v_0. \tag{5а.10} \]
Доказательство. Раскроем разность назад и разобьём сумму на две: \[ \sum_{i=1}^{N} h\,y_i\,\frac{v_i - v_{i-1}}{h} = \sum_{i=1}^{N} y_i v_i - \sum_{i=1}^{N} y_i v_{i-1}. \] Во второй сумме заменим индекс \(i - 1 = j\): она равна \(\sum_{j=0}^{N-1} y_{j+1} v_j\). Первую сумму запишем как \(\sum_{j=0}^{N-1} y_j v_j + y_N v_N - y_0 v_0\) — добавили и вычли член с \(j = 0\), отделили член с \(j = N\). Вычитая, получаем \[ y_N v_N - y_0 v_0 - \sum_{j=0}^{N-1}(y_{j+1} - y_j)\,v_j = y_N v_N - y_0 v_0 - \sum_{j=0}^{N-1} h\,y_{x,j}\,v_j, \] что и требовалось.

Сравните с формулой \(\int_0^l y\,v'\,dx = -\int_0^l y'\,v\,dx + \bigl[y v\bigr]_0^l\): роль производной играют разности, роль внеинтегрального члена — \(y_N v_N - y_0 v_0\). Из леммы вытекают три следствия, которыми будем постоянно пользоваться.

Следствие 1. Первая разностная формула Грина; оператор \(-\Lambda\) на \(H_0\)

Пусть \(y, v \in H_0\), то есть \(y_0 = y_N = v_0 = v_N = 0\). Применим (5а.10) к функциям \(w = y_{\bar x}\) и \(v\), поменяв в ней ролями индексы (то есть используя её в форме \(\sum_{i=0}^{N-1} h\,w_{x,i} v_i = -\sum_{i=1}^{N} h\,w_i v_{\bar x,i} + w_N v_N - w_0 v_0\)). Граничные члены исчезают, так как \(v_0 = v_N = 0\), а слагаемое с \(i = 0\) в левой части равно нулю по той же причине. Получаем

\[ (\Lambda y, v) = \sum_{i=1}^{N-1} h\,y_{\bar x x,i}\,v_i = -\sum_{i=1}^{N} h\,y_{\bar x,i}\,v_{\bar x,i} \equiv -\,(y_{\bar x}, v_{\bar x}]. \tag{5а.11} \]

Правая часть симметрична относительно \(y\) и \(v\), поэтому \((\Lambda y, v) = (\Lambda v, y)\): оператор \(\Lambda\) самосопряжён на \(H_0\). Полагая \(v = y\), находим

\[ (-\Lambda y, y) = \sum_{i=1}^{N} h\,y_{\bar x,i}^2 \ge 0, \tag{5а.12} \]

причём равенство возможно лишь при \(y_{\bar x} \equiv 0\), то есть при \(y = \mathrm{const}\), а с учётом \(y_0 = 0\) — лишь при \(y \equiv 0\). Итак, \(A = -\Lambda\) — самосопряжённый положительный оператор на \(H_0\), и \(\|y\|_A^2 = (y_{\bar x}, y_{\bar x}]\) — сеточный аналог \(\int_0^l u_x^2\,dx\).

Следствие 2. Периодическая сетка: кососимметричность центральной разности

На периодической сетке (\(y_{i+N} = y_i\)) граничные члены в (5а.10) взаимно уничтожаются, и (5а.11), (5а.12) выполняются без всяких условий на концах; при этом \(-\Lambda \ge 0\), но уже не \(> 0\): постоянная функция обращает (5а.12) в нуль. Кроме того, для оператора центральной разности \(Dy = y_{\mathring x}\)

\[ (y_{\mathring x}, y) = \sum_{i=1}^{N} h\,\frac{y_{i+1} - y_{i-1}}{2h}\,y_i = \frac{1}{2}\Bigl(\sum_{i=1}^{N} y_i y_{i+1} - \sum_{i=1}^{N} y_i y_{i-1}\Bigr) = 0, \tag{5а.13} \]

поскольку обе суммы при периодическом сдвиге индекса совпадают. Более того, \((y_{\mathring x}, v) = -(y, v_{\mathring x})\), то есть \(D^* = -D\): центральная разность на периодической сетке — кососимметричный оператор. Это сеточный двойник равенства \(\int u\,u_x\,dx = 0\) из (5а.3).

Следствие 3. Оценка нормы оператора \(-\Lambda\)

Из (5а.12) и элементарного неравенства \((a - b)^2 \le 2a^2 + 2b^2\):

\[ (-\Lambda y, y) = \sum_{i=1}^{N} h\,\frac{(y_i - y_{i-1})^2}{h^2} \le \frac{2}{h^2}\sum_{i=1}^{N} h\,\bigl(y_i^2 + y_{i-1}^2\bigr) \le \frac{4}{h^2}\,\|y\|^2, \qquad\text{то есть}\qquad -\Lambda \le \frac{4}{h^2}\,E. \tag{5а.14} \]
Замечание. Оценка (5а.14) неулучшаема по порядку: собственные функции оператора \(-\Lambda\) на \(H_0\) — сеточные синусы \(\sin(k\pi x_i/l)\), а собственные числа \(\lambda_k = \frac{4}{h^2}\sin^2\frac{k\pi h}{2l}\), \(k = \overline{1, N-1}\); наибольшее из них равно \(\frac{4}{h^2}\cos^2\frac{\pi h}{2l}\) и отличается от \(4/h^2\) на величину порядка \(1\) при \(h \to 0\). Именно эти сеточные синусы — «гармоники» §5, приспособленные к краевым условиям первого рода.

§5а.6. Пример 1: схема «уголок» в норме \(L_2\)

Начнём с самой простой ситуации, где энергетическая оценка получается в две строки и может быть сопоставлена с результатом §5. Рассмотрим явную схему «уголок» для уравнения (5а.2) на периодической сетке:

\[ \hat y_i = (1 - r)\,y_i + r\,y_{i-1}, \qquad r = \frac{a\tau}{h}, \qquad 0 \le r \le 1. \tag{5а.15} \]

Нам понадобится неравенство выпуклости для квадрата: если \(\alpha, \beta \ge 0\) и \(\alpha + \beta = 1\), то для любых чисел \(p, q\)

\[ (\alpha p + \beta q)^2 \le \alpha p^2 + \beta q^2. \tag{5а.16} \]

Оно доказывается прямым вычислением: \(\alpha p^2 + \beta q^2 - (\alpha p + \beta q)^2 = \alpha(1-\alpha)p^2 + \beta(1-\beta)q^2 - 2\alpha\beta pq = \alpha\beta\,(p - q)^2 \ge 0\), где использовано \(1 - \alpha = \beta\). Существенно, что оба коэффициента неотрицательны — при \(r > 1\) неравенство (5а.16) неприменимо.

Применим (5а.16) к (5а.15) с \(\alpha = 1 - r\), \(\beta = r\): \(\hat y_i^2 \le (1 - r)\,y_i^2 + r\,y_{i-1}^2\). Умножим на \(h\) и просуммируем по \(i = \overline{1, N}\); сумма \(\sum h\,y_{i-1}^2\) на периодической сетке равна \(\|y\|^2\):

\[ \|\hat y\|^2 \le (1 - r)\,\|y\|^2 + r\,\|y\|^2 = \|y\|^2, \qquad\text{откуда}\qquad \|y^n\| \le \|y^{n-1}\| \le \dots \le \|y^0\|. \tag{5а.17} \]
Сопоставление с §5 Оценка (5а.17) есть устойчивость по начальным данным в норме \(L_2\) с постоянной \(C = 1\). Достаточное условие \(0 \le r \le 1\) совпало с необходимым условием Неймана \(r \le 1\) из §5: для этой схемы спектральный метод даёт точный ответ. Обратите внимание, что в выкладке нигде не использовалась постоянность \(a\): при \(a = a(x) > 0\) и \(r_i = a_i\tau/h \le 1\) неравенство \(\hat y_i^2 \le (1 - r_i)y_i^2 + r_i y_{i-1}^2\) сохраняется, и в §5а.12 мы доведём этот случай до конца.
Замечание. Та же выкладка в норме \(C\) ещё проще: \(|\hat y_i| \le (1 - r)|y_i| + r|y_{i-1}| \le \|y\|_C\), откуда \(\|\hat y\|_C \le \|y\|_C\). Это частный случай принципа максимума для схем с положительными коэффициентами (§11). Оценка в \(L_2\) потребовала неравенства (5а.16), а оценка в \(C\) — только неравенства треугольника; зато для неявных схем и для схем с коэффициентами разных знаков работает, как правило, именно \(L_2\)-техника.

§5а.7. Каноническая форма двухслойной схемы

Чтобы формулировать условия устойчивости сразу для всех двухслойных схем, приведём их к единой записи.

Каноническая форма двухслойной схемы. Двухслойная разностная схема записана в канонической форме, если она имеет вид \[ B\,\frac{y^{n+1} - y^{n}}{\tau} + A\,y^{n} = \varphi^{n}, \qquad n = 0, 1, \dots, \qquad y^0 \text{ задано}, \tag{5а.18} \] где \(A\), \(B\colon H \to H\) — линейные операторы, \(\varphi^n \in H\) — правая часть, и оператор \(B\) обратим. В обозначениях (5а.6): \(B y_t + A y = \varphi\).

Обратимость \(B\) означает, что схема разрешима: \(y^{n+1} = y^n - \tau B^{-1}(Ay^n - \varphi^n)\), то есть следующий слой однозначно определяется по предыдущему. Оператор \(B\) описывает неявную часть схемы, \(A\) — пространственный оператор. Разберём, как выглядят \(A\) и \(B\) для типичных схем.

Примеры приведения к канонической форме
  1. Явная схема для уравнения теплопроводности \(y_t = \Lambda y + \varphi\) на \(H_0\): переносим \(\Lambda y\) влево, \(y_t - \Lambda y = \varphi\); значит, \(B = E\), \(A = -\Lambda\).
  2. Схема с весами \(y_t = \Lambda y^{(\sigma)} + \varphi\), где \(y^{(\sigma)} = \sigma\hat y + (1-\sigma)y = y + \sigma\tau y_t\). Подставляя, \(y_t = \Lambda y + \sigma\tau\Lambda y_t + \varphi\), то есть \((E - \sigma\tau\Lambda)\,y_t - \Lambda y = \varphi\). Итак, \(A = -\Lambda\), \(B = E + \sigma\tau A\). При \(\sigma = 0\) получаем предыдущий пример, при \(\sigma = 1\) — чисто неявную схему, при \(\sigma = 1/2\) — схему Кранка–Николсон.
  3. Схема «уголок» (5а.15): \(y_t + a\,y_{\bar x} = 0\); \(B = E\), \(A = a\,\partial_{\bar x}\), где \(\partial_{\bar x} y = y_{\bar x}\). Этот оператор не самосопряжён — поэтому в §5а.6 понадобился прямой приём, а не общая теорема ниже.

§5а.8. Основная теорема об устойчивости в энергетической норме

Следующая теорема А. А. Самарского [1, гл. VI] — центральный результат энергетического метода для двухслойных схем. Она превращает вопрос об устойчивости в проверку одного операторного неравенства.

Устойчивость по начальным данным в \(H_A\). Пусть в схеме (5а.18) с \(\varphi \equiv 0\) оператор \(A\) самосопряжён и положителен, \(A = A^* > 0\), а оператор \(B\) обратим и удовлетворяет операторному неравенству \[ B \ge \frac{\tau}{2}\,A, \qquad\text{то есть}\qquad (By, y) \ge \frac{\tau}{2}\,(Ay, y)\ \ \text{при всех } y \in H. \tag{5а.19} \] Тогда решение схемы удовлетворяет оценке \[ \|y^{n+1}\|_A \le \|y^{n}\|_A, \qquad n = 0, 1, \dots, \qquad\text{и, следовательно,}\qquad \|y^{n}\|_A \le \|y^{0}\|_A. \tag{5а.20} \]

Оценка (5а.20) — устойчивость по начальным данным в энергетической норме с постоянной \(C = 1\), не зависящей ни от \(\tau\), ни от \(h\), ни от числа шагов. Доказательство разобьём на этапы и после каждого укажем, какая гипотеза теоремы использована.

Доказательство. Этап 1. Замена текущего слоя полусуммой слоёв Выразим \(y = y^n\) через полусумму \(y^{(1/2)} = \frac{1}{2}(\hat y + y)\) и разностную производную \(y_t = \frac{1}{\tau}(\hat y - y)\): \[ y = y^{(1/2)} - \frac{\tau}{2}\,y_t \qquad\Bigl(\text{проверка: } \tfrac{1}{2}(\hat y + y) - \tfrac{1}{2}(\hat y - y) = y\Bigr). \] Подставим это тождество в уравнение \(B y_t + A y = 0\): \[ B y_t + A y^{(1/2)} - \frac{\tau}{2}\,A y_t = 0, \qquad\text{то есть}\qquad \Bigl(B - \frac{\tau}{2}A\Bigr)y_t + A\,y^{(1/2)} = 0. \tag{5а.21} \] Никакие гипотезы пока не использованы — это тождественное преобразование. Этап 2. Умножение на \(2\tau y_t\) Умножим (5а.21) скалярно на \(2\tau y_t\) — это и есть сеточное «умножение на решение и интегрирование»; множитель \(2\tau\) подобран так, чтобы второе слагаемое стало разностью энергий: \[ 2\tau\Bigl(\bigl(B - \tfrac{\tau}{2}A\bigr)y_t,\ y_t\Bigr) + 2\tau\bigl(A y^{(1/2)},\ y_t\bigr) = 0. \tag{5а.22} \] Этап 3. Второе слагаемое — разность энергий используется A = A* Подставим \(y^{(1/2)} = \frac{1}{2}(\hat y + y)\), \(y_t = \frac{1}{\tau}(\hat y - y)\) и раскроем билинейную форму: \[ 2\tau\bigl(A y^{(1/2)}, y_t\bigr) = \bigl(A(\hat y + y),\ \hat y - y\bigr) = (A\hat y, \hat y) - (A\hat y, y) + (Ay, \hat y) - (Ay, y). \] По самосопряжённости \((Ay, \hat y) = (y, A\hat y) = (A\hat y, y)\), так что два средних слагаемых взаимно уничтожаются, и \[ 2\tau\bigl(A y^{(1/2)}, y_t\bigr) = \|\hat y\|_A^2 - \|y\|_A^2. \tag{5а.23} \] Это сеточный аналог равенства \(2\int u\,u_t\,dx = \frac{d}{dt}\int u^2\,dx\) из (5а.3). Этап 4. Энергетическое тождество и оценка используется B ≥ (τ/2)A Из (5а.22) и (5а.23) получаем точное энергетическое тождество \[ \|\hat y\|_A^2 = \|y\|_A^2 - 2\tau\Bigl(\bigl(B - \tfrac{\tau}{2}A\bigr)y_t,\ y_t\Bigr). \tag{5а.24} \] По условию (5а.19) оператор \(B - \frac{\tau}{2}A\) неотрицателен, поэтому вычитаемое неотрицательно и \(\|\hat y\|_A^2 \le \|y\|_A^2\). используется A > 0 — именно положительность \(A\) гарантирует, что \(\|\cdot\|_A\) является нормой (Определение 3), и извлечение корня даёт (5а.20). Применяя неравенство последовательно при \(n, n-1, \dots, 0\), получаем \(\|y^n\|_A \le \|y^0\|_A\).
Почему это работает: смысл тождества (5а.24) Тождество (5а.24) — сеточный закон изменения энергии. Энергия на новом слое равна энергии на старом минус «диссипация» \(2\tau((B - \frac{\tau}{2}A)y_t, y_t)\). Условие \(B \ge \frac{\tau}{2}A\) означает ровно то, что схема не производит энергии: диссипация неотрицательна. Для явной схемы \(B = E\) условие превращается в \(\frac{\tau}{2}A \le E\) — ограничение на шаг \(\tau\) через норму \(A\); для неявных схем \(B\) содержит слагаемое \(\sigma\tau A\), которое «оплачивает» правую часть неравенства при любом \(\tau\). Так одна и та же теорема объясняет, почему явные схемы условно, а неявные — безусловно устойчивы.
Устойчивость в \(H_B\); необходимость условия. Пусть \(A = A^* > 0\) и \(B = B^* > 0\). Тогда условие (5а.19) необходимо и достаточно для оценки (5а.20); при его выполнении справедлива также оценка \(\|y^{n+1}\|_B \le \|y^{n}\|_B\). В частности, для явных схем (\(B = E\)) условие \(E \ge \frac{\tau}{2}A\) равносильно оценке \(\|y^{n+1}\| \le \|y^{n}\|\) в норме \(L_2\).

Доказательство достаточности в \(H_B\) и необходимости можно найти в [1, гл. VI, §2] и [2]; мы примем эту теорему без доказательства. Для явной схемы утверждение легко проверить непосредственно: \(\hat y = (E - \tau A)y\), и \(\|E - \tau A\| \le 1\) в точности тогда, когда все собственные числа \(1 - \tau\lambda_k\) оператора \(E - \tau A\) лежат на отрезке \([-1, 1]\), то есть когда \(\tau\lambda_k \le 2\) для всех \(k\), а это и есть \(\frac{\tau}{2}A \le E\).

§5а.9. Устойчивость по правой части

Определение 4 §2 требует оценки решения через правую часть. Покажем, что энергетический метод даёт и её — ценой небольшого усиления условия (5а.19). Понадобится \(\varepsilon\)-неравенство

\[ |(\varphi, v)| \le \|\varphi\|\,\|v\| \le \varepsilon\,\|v\|^2 + \frac{1}{4\varepsilon}\,\|\varphi\|^2, \qquad \varepsilon > 0, \tag{5а.25} \]

которое следует из неравенства Коши–Буняковского и из \(ab \le \varepsilon a^2 + b^2/(4\varepsilon)\) (последнее — раскрытое неравенство \((\sqrt{\varepsilon}\,a - b/(2\sqrt{\varepsilon}))^2 \ge 0\)). Его роль — «разменять» произведение двух норм на сумму квадратов с произвольно малым коэффициентом при одной из них.

Устойчивость по правой части. Пусть \(A = A^* > 0\), \(B\) обратим и при некотором \(\varepsilon > 0\), не зависящем от \(\tau\) и \(h\), \[ B \ge \varepsilon E + \frac{\tau}{2}\,A. \tag{5а.26} \] Тогда решение схемы (5а.18) удовлетворяет оценке \[ \|y^{n+1}\|_A^2 \le \|y^{0}\|_A^2 + \frac{1}{2\varepsilon}\sum_{k=0}^{n}\tau\,\|\varphi^{k}\|^2. \tag{5а.27} \]
Доказательство. Повторим этапы 1–3 предыдущего доказательства для уравнения с правой частью: умножая \((B - \frac{\tau}{2}A)y_t + Ay^{(1/2)} = \varphi\) скалярно на \(2\tau y_t\) и используя (5а.23), получаем \[ 2\tau\Bigl(\bigl(B - \tfrac{\tau}{2}A\bigr)y_t, y_t\Bigr) + \|\hat y\|_A^2 - \|y\|_A^2 = 2\tau\,(\varphi, y_t). \] используется (5а.26) Левую часть оценим снизу: \(((B - \frac{\tau}{2}A)y_t, y_t) \ge \varepsilon\|y_t\|^2\). Правую — сверху по (5а.25) с тем же \(\varepsilon\): \(2\tau(\varphi, y_t) \le 2\tau\varepsilon\|y_t\|^2 + \frac{\tau}{2\varepsilon}\|\varphi\|^2\). Слагаемые \(2\tau\varepsilon\|y_t\|^2\) в обеих частях сокращаются, и остаётся \[ \|\hat y\|_A^2 \le \|y\|_A^2 + \frac{\tau}{2\varepsilon}\,\|\varphi\|^2. \] Суммируя это неравенство по слоям \(k = 0, 1, \dots, n\), приходим к (5а.27).

Оценка (5а.27) — это неравенство вида (2.14): норма решения ограничена нормой данных с постоянной \(1/(2\varepsilon)\), не зависящей от сетки. Сумма \(\sum\tau\|\varphi^k\|^2\) есть сеточный аналог \(\int_0^T\|\varphi(\cdot,t)\|^2\,dt\). Плата за правую часть — условие (5а.26), которое чуть сильнее, чем (5а.19): для явной схемы оно даёт \(\tau \le (1 - \varepsilon)\,h^2/2\) вместо \(\tau \le h^2/2\). Так проявляется общее свойство энергетического метода: он даёт достаточные условия, иногда с небольшим запасом.

§5а.10. Пример 2: явная схема для уравнения теплопроводности

Рассмотрим первую краевую задачу \(u_t = u_{xx}\), \(u(0,t) = u(l,t) = 0\), и явную схему

\[ \frac{y_i^{n+1} - y_i^{n}}{\tau} = \frac{y_{i+1}^{n} - 2y_i^{n} + y_{i-1}^{n}}{h^2}, \quad i = \overline{1, N-1}; \qquad y_0^{n} = y_N^{n} = 0. \tag{5а.28} \]

Шаг 1: каноническая форма. \(y_t = \Lambda y\), то есть \(B = E\), \(A = -\Lambda\) на \(H_0\).

Шаг 2: свойства \(A\). По Следствию 1 оператор \(A = -\Lambda\) самосопряжён и положителен на \(H_0\) — гипотеза теоремы 1 выполнена, и энергетическая норма \(\|y\|_A^2 = (y_{\bar x}, y_{\bar x}]\) определена. Здесь впервые в дело вошли краевые условия: без них \(\Lambda\) не был бы положительным.

Шаг 3: проверка (5а.19). Требуется \(E \ge \frac{\tau}{2}A\). По (5а.9) достаточно, чтобы \(\frac{\tau}{2}\|A\| \le 1\), а по (5а.14) \(\|A\| \le 4/h^2\). Значит, условие (5а.19) заведомо выполнено, если

\[ \frac{\tau}{2}\cdot\frac{4}{h^2} \le 1, \qquad\text{то есть}\qquad \tau \le \frac{h^2}{2}. \tag{5а.29} \]

Вывод. При \(\tau \le h^2/2\) по теореме 1 схема (5а.28) устойчива в \(H_A\): \(\|y^n\|_A \le \|y^0\|_A\), а по теореме 2 — и в \(L_2\): \(\|y^n\| \le \|y^0\|\).

Сопоставление с методом гармоник Подставляя \(y_m^n = \lambda^n e^{i\alpha m}\) в (5а.28), находим \(\lambda = 1 - \frac{4\tau}{h^2}\sin^2\frac{\alpha}{2}\); условие \(|\lambda| \le 1\) при всех \(\alpha\) равносильно \(\frac{4\tau}{h^2} \le 2\), то есть тому же \(\tau \le h^2/2\). Разница в том, что метод гармоник игнорировал краевые условия и дал условие необходимое, а энергетический метод учёл условия \(y_0 = y_N = 0\) и дал оценку в явно указанной норме — условие достаточное. Здесь оба ответа совпали; так бывает не всегда.

§5а.11. Пример 3: схема с весами

Для той же задачи рассмотрим семейство схем с весом \(\sigma \in [0, 1]\):

\[ y_t = \Lambda\bigl(\sigma\hat y + (1 - \sigma)\,y\bigr), \qquad y_0 = y_N = 0. \tag{5а.30} \]

По §5а.7 каноническая форма имеет \(A = -\Lambda\), \(B = E + \sigma\tau A\). Оператор \(B\) самосопряжён и положителен при \(\sigma \ge 0\) (как сумма положительного \(E\) и неотрицательного \(\sigma\tau A\)), значит, обратим; гипотезы теорем 1 и 2 выполнены. Условие (5а.19) принимает вид

\[ E + \sigma\tau A \ge \frac{\tau}{2}A \qquad\Longleftrightarrow\qquad E + \Bigl(\sigma - \frac{1}{2}\Bigr)\tau A \ge 0. \tag{5а.31} \]

Разберём два случая.

Случай \(\sigma \ge 1/2\). Коэффициент \(\sigma - \frac12\) неотрицателен, \(A \ge 0\), поэтому (5а.31) выполняется при любых \(\tau\) и \(h\): чисто неявная схема (\(\sigma = 1\)) и схема Кранка–Николсон (\(\sigma = 1/2\)) безусловно устойчивы.

Случай \(\sigma < 1/2\). Теперь \((\frac12 - \sigma)\tau A\) вычитается, и нужно \((\frac{1}{2} - \sigma)\tau\,(Ay, y) \le \|y\|^2\). По (5а.9) и (5а.14) для этого достаточно \((\frac{1}{2} - \sigma)\tau\cdot\frac{4}{h^2} \le 1\), то есть

\[ \sigma \ge \frac{1}{2} - \frac{h^2}{4\tau}. \tag{5а.32} \]

При \(\sigma = 0\) условие (5а.32) превращается в \(\tau \le h^2/2\) — результат Примера 2. Условие (5а.32) — классический результат А. А. Самарского; оно показывает, как «доля неявности» \(\sigma\) снимает ограничение на шаг.

Рис. 1. Область достаточных условий устойчивости схемы с весами (5а.30) на плоскости \((\tau/h^2,\ \sigma)\). Явная схема \(\sigma = 0\) устойчива лишь при \(\tau/h^2 \le 1/2\); при \(\sigma \ge 1/2\) ограничений нет.

§5а.12. Пример 4: перенос с переменной скоростью — там, где метод гармоник не работает

Вернёмся к уравнению переноса, но теперь со скоростью, зависящей от координаты:

\[ \frac{\partial u}{\partial t} + a(x)\,\frac{\partial u}{\partial x} = 0, \qquad a(x) > 0, \qquad |a'(x)| \le L, \qquad u(0,t) = u(l,t). \tag{5а.33} \]

Схема «уголок» с локальным числом Куранта:

\[ \hat y_i = (1 - r_i)\,y_i + r_i\,y_{i-1}, \qquad r_i = \frac{a(x_i)\,\tau}{h}, \qquad 0 \le r_i \le 1 \ \text{при всех } i. \tag{5а.34} \]

Метод гармоник здесь неприменим: коэффициенты зависят от \(i\), и \(e^{i\alpha m}\) не является собственной функцией оператора перехода. Обычно в таких случаях рассуждают эвристически — «замораживают» коэффициенты и требуют выполнения условия Куранта в каждом узле, \(\max_i r_i \le 1\). Энергетический метод позволяет доказать, что это условие достаточно.

Как и в §5а.6, по (5а.16) \(\hat y_i^2 \le (1 - r_i)\,y_i^2 + r_i\,y_{i-1}^2\). Умножим на \(h\) и просуммируем; в сумме \(\sum_i h\,r_i\,y_{i-1}^2\) сдвинем индекс на периодической сетке: она равна \(\sum_i h\,r_{i+1}\,y_i^2\). Тогда

\[ \|\hat y\|^2 \le \sum_{i=1}^{N} h\,\bigl[(1 - r_i) + r_{i+1}\bigr]\,y_i^2 = \|y\|^2 + \sum_{i=1}^{N} h\,(r_{i+1} - r_i)\,y_i^2. \tag{5а.35} \]

При постоянной скорости \(r_{i+1} = r_i\), и вторая сумма исчезает — это (5а.17). При переменной скорости она мала: по теореме Лагранжа \(r_{i+1} - r_i = \frac{\tau}{h}\bigl(a(x_{i+1}) - a(x_i)\bigr) = \tau\,a'(\xi_i) \le \tau L\). Следовательно,

\[ \|\hat y\|^2 \le (1 + \tau L)\,\|y\|^2, \qquad \|y^{n}\|^2 \le (1 + \tau L)^{n}\,\|y^{0}\|^2 \le e^{L\,n\tau}\,\|y^{0}\|^2 = e^{L t_n}\,\|y^{0}\|^2, \tag{5а.36} \]

где использовано \(1 + \tau L \le e^{\tau L}\). Итак, при \(t_n \le T\)

\[ \|y^{n}\| \le e^{LT/2}\,\|y^{0}\|. \tag{5а.37} \]

Постоянная \(C = e^{LT/2}\) не зависит от \(\tau\) и \(h\) — это устойчивость по начальным данным в смысле Определения 3 §2. Обратите внимание на структуру: норма может расти на каждом шаге, но не более чем в \(1 + C\tau\) раз, и за конечное время \(T\) рост ограничен. Это в точности та ситуация, ради которой в условии Неймана (5.5) стоит \(1 + C\tau\), а не \(1\).

Что здесь сделал энергетический метод Он заменил разложение по гармоникам, которого нет, на суммирование неравенства по узлам. Переменность коэффициента проявилась в единственном месте — в разности \(r_{i+1} - r_i\), и её вклад был оценен через гладкость \(a(x)\). Тот же приём проходит для неравномерной сетки (в \(r_i\) входит локальный шаг \(h_i\)) и для задач с краевыми условиями (\(y_0^n\) задано: в (5а.35) появится член \(h\,r_1\,(y_0^n)^2\), оцениваемый через данные). Ни одно из этих обобщений методу гармоник недоступно.

Порядок исследования схемы энергетическим методом
  1. Записать схему в канонической форме (5а.18), выписать операторы \(A\) и \(B\) и пространство \(H\) (или \(H_0\)) с учётом краевых условий.
  2. Проверить свойства \(A\): самосопряжённость и положительность — формулами суммирования по частям (§5а.5); при этом граничные члены обязаны исчезнуть за счёт краевых условий, иначе оператор нужно переопределить.
  3. Если \(A = A^* > 0\) — проверить операторное неравенство \(B \ge \frac{\tau}{2}A\) (или (5а.26) для оценки по правой части). Для явных схем оно сводится к \(\tau \le 2/\|A\|\); норму \(A\) оценивать через (5а.9) и формулы вида (5а.14). Вывод — по теоремам 1–3.
  4. Если \(A\) не самосопряжён (уравнение переноса, несимметричные разности) — действовать напрямую: умножить схему скалярно на \(\hat y\) или на \(y^{(1/2)}\), выделить разность \(\|\hat y\|^2 - \|y\|^2\), остальные члены оценить формулами Грина, неравенством Коши–Буняковского и \(\varepsilon\)-неравенством; цель — неравенство вида \(\|\hat y\|^2 \le (1 + c\tau)\|y\|^2\).
  5. Сформулировать результат: норма, постоянная, условия на \(\tau\), \(h\); сопоставить с необходимым условием Неймана, если оно доступно, — расхождение указывает либо на запас метода, либо на подлинную неустойчивость в норме \(C\).
Типичные ошибки. (1) Потерянные граничные члены в (5а.10): для условий второго или третьего рода они не равны нулю и должны входить в энергию. (2) Грубая оценка \(\|A\|\): даёт слишком жёсткое условие на \(\tau\), которое метод гармоник тут же «опровергает»; это не противоречие, а следствие достаточности. (3) Перенос \(L_2\)-оценки на норму \(C\): неверен равномерно по \(h\) (§5а.3). (4) Применение теоремы 1 к несамосопряжённому \(A\): теорема молчит, нужен прямой приём пункта 4.

§5а.14. Упражнения

Упражнение 1. Докажите неравенства (5а.16) и (5а.25), а также неравенства \(\sqrt{h}\,\|y\|_C \le \|y\| \le \sqrt{l}\,\|y\|_C\) из §5а.3. Приведите пример последовательности сеточных функций \(y^{(h)}\), для которой \(\|y^{(h)}\| \to 0\), а \(\|y^{(h)}\|_C = 1\) при всех \(h\).
Упражнение 2. Пользуясь леммой 1, докажите равенство \((\Lambda y, v) = (y, \Lambda v)\) для \(y, v \in H_0\) непосредственно (дважды применяя суммирование по частям), не опираясь на симметрию правой части (5а.11). Укажите, в каком месте использовано каждое из условий \(y_0 = y_N = 0\), \(v_0 = v_N = 0\).
Упражнение 3 (сохранение энергии). На периодической сетке рассмотрите схему Кранка–Николсон для уравнения переноса с центральной разностью: \[ \frac{\hat y - y}{\tau} + a\,\frac{\hat y_{\mathring x} + y_{\mathring x}}{2} = 0. \] Умножив её скалярно на \(y^{(1/2)}\) и используя (5а.13), докажите, что \(\|\hat y\| = \|y\|\) при любых \(\tau\), \(h\). Сопоставьте с методом гармоник: покажите, что \(|\lambda(\alpha)| = 1\).
Упражнение 4 (абсолютная неустойчивость). Для явной схемы с центральной разностью \(\hat y = y - \tau a\,y_{\mathring x}\) на периодической сетке получите точное энергетическое тождество \(\|\hat y\|^2 = \|y\|^2 + \tau^2 a^2\,\|y_{\mathring x}\|^2\) и объясните, почему из него следует рост нормы при любом \(\tau > 0\). Подтвердите вывод методом гармоник (§5).
Упражнение 5 (неявный «уголок»). Докажите, что на периодической сетке \((y_{\bar x}, y) = \frac{h}{2}\,\|y_{\bar x}\|^2 \ge 0\). Используя это и неравенство Коши–Буняковского, покажите, что неявная схема \(\hat y + \tau a\,\hat y_{\bar x} = y\) удовлетворяет оценке \(\|\hat y\| \le \|y\|\) при любых \(\tau\), \(h\) (умножьте схему скалярно на \(\hat y\)).
Упражнение 6 (переменный коэффициент теплопроводности). Для оператора \(Ay = -(k\,y_{\bar x})_x\) с \(0 < c_1 \le k_i \le c_2\) на \(H_0\) докажите, что \(A = A^* > 0\) и \(\|A\| \le 4c_2/h^2\). Выведите достаточное условие устойчивости явной схемы \(y_t = -Ay\): \(\tau \le h^2/(2c_2)\). Можно ли получить этот результат методом гармоник?
