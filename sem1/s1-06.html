§6 · Семестр 1

Спектральный признак устойчивости. Метод гармоник. Множитель перехода

▶ Слайды

В §2 устойчивость разностной схемы была определена, а в §3 теорема Лакса сделала её решающим свойством: аппроксимация и устойчивость вместе дают сходимость. Однако определение не даёт способа устойчивость проверить. Настоящий параграф и следующий за ним §6а излагают два метода такой проверки. Первый — спектральный признак, или метод гармоник (метод фон Неймана): он прост, почти механичен и применим к любой линейной схеме с постоянными коэффициентами, но даёт лишь необходимое условие. Второй — энергетический метод §6а — даёт достаточные условия и работает там, где первый неприменим. Основной объект обоих методов — множитель перехода \(\lambda(\alpha)\) гармоники — уже был введён в §5, где через него описаны диссипация и дисперсия; здесь мы используем только модуль \(|\lambda|\) и получим условия, при которых он не превосходит единицы. Изложение следует книгам [1–3] и атласу [4].

§6.1. Что именно нужно проверить

Напомним Определение 4 §2: семейство схем \(L_h u_h = f_h\) устойчиво (корректно), если решение существует, единственно и \(\|u_h\| \le C\|f_h\|\) с постоянной \(C\), не зависящей от \(h\). Для эволюционных задач, где решение вычисляется послойно, \(u^0 \to u^1 \to \dots \to u^n\), удобна форма устойчивости по начальным данным:

\[ \|u^{n}\| \le C\,\|u^{0}\| \qquad\text{при всех } n = 0, 1, \dots, N = T/\tau, \qquad C \ne C(h, \tau, n). \tag{6.1} \]

Существенна равномерность: при фиксированных \(h\), \(\tau\) любая разрешимая линейная схема даёт оценку (6.1) с какой-то постоянной; содержание понятия — в том, что постоянная одна для всего семейства сеток и для всех номеров слоёв до заданного момента времени \(T\).

Почему нужен специальный метод Неравенство (6.1) должно выполняться при всех начальных данных и всех сетках. Проверять его непосредственно — значит решить задачу для всех данных сразу. Нужен приём, сводящий проверку к конечному вычислению. Идея спектрального признака: если у оператора, переводящего решение со слоя на слой, есть удобный базис из собственных функций, то достаточно проследить за поведением каждой собственной функции — а оно описывается одним числом.

§6.2. Оператор перехода и гармоники

Оператор перехода. Оператор \(S\), обеспечивающий переход решения с предыдущего временного слоя на следующий, \(u^{n+1} = S\,u^{n}\), называется оператором перехода двухслойной разностной схемы. Для явной схемы он выписывается непосредственно; для неявной схемы \(B_1 u^{n+1} = B_0 u^n\) он равен \(S = B_1^{-1}B_0\) и существует, если схема разрешима.

Удобно записывать \(S\) через оператор сдвига \(T\), действующий на сеточные функции по правилу \((Tu)_m = u_{m+1}\). Тогда \((T^{-1}u)_m = u_{m-1}\) — сдвиг в обратную сторону, \(E\) — тождественный оператор, а разностные операции (6.6) §1 выражаются через \(T\), \(T^{-1}\), \(E\) с числовыми коэффициентами. Приведём три примера, к которым будем возвращаться в §§6.5–5.8.

Оператор перехода: три примера
  1. Схема «уголок» \(u^{n+1}_m = (1 - r)u^n_m + r\,u^n_{m-1}\), \(r = a\tau/h\). Оператор — линейная комбинация \(E\) и \(T^{-1}\): \[ S = (1 - r)\,E + r\,T^{-1}. \] Проверка: \((Su)_m = (1 - r)u_m + r\,u_{m-1}\) — та же формула схемы.
  2. Явная центральная схема \(u^{n+1}_m = u^n_m - \tfrac{r}{2}(u^n_{m+1} - u^n_{m-1})\). Здесь \[ S = E - \tfrac{r}{2}\bigl(T - T^{-1}\bigr). \]
  3. Неявный «уголок» \((1 + r)u^{n+1}_m - r\,u^{n+1}_{m-1} = u^n_m\), то есть \(B_1 u^{n+1} = u^n\) с \(B_1 = (1 + r)E - r\,T^{-1}\), \(B_0 = E\). Значит \[ S = B_1^{-1} = \bigl((1 + r)E - r\,T^{-1}\bigr)^{-1}. \] Существует, потому что \(B_1\) обратим (диагонально преобладающая треугольная система при \(r > 0\)).
В каждом из трёх случаев \(S\) — многочлен от \(T\) и \(T^{-1}\) с постоянными коэффициентами (в третьем — обратный к такому многочлену). Это ключевое обстоятельство: в него мы сейчас превратим содержательное утверждение.

Рассмотрим схему на бесконечной (или периодической) сетке \(x_m = mh\) с коэффициентами, не зависящими от номера узла. Тогда оператор \(S\) перестановочен со сдвигом \(T\): \(ST = TS\). Это равенство операторов, и разберёмся, что оно означает.

Что значит \(ST = TS\) Оба произведения — операторы; их равенство означает, что для любой сеточной функции \(u\) справедливо \((ST)u = (TS)u\), т.е. значения в каждом узле совпадают: \[ (Su)_{m+1} = S(u_{\cdot + 1})_m \qquad\text{при всех } m. \] Смысл: «применить схему, потом сдвинуть» и «сначала сдвинуть, потом применить схему» — одно и то же. Иными словами, схема не различает узлы: результат в узле \(m + 1\) от исходной функции такой же, как результат в узле \(m\) от сдвинутой. Именно это обычно называют однородностью схемы по пространству.
Проверка \(ST = TS\) на «уголке» \(S = (1 - r)E + rT^{-1}\), и \(T\) перестановочен и с \(E\) (тождественный оператор коммутирует со всем), и с \(T^{-1}\) (\(TT^{-1} = T^{-1}T = E\)). Поэтому \[ ST = \bigl((1 - r)E + rT^{-1}\bigr)T = (1 - r)T + rT^{-1}T = (1 - r)T + rE, \] \[ TS = T\bigl((1 - r)E + rT^{-1}\bigr) = (1 - r)T + r\,TT^{-1} = (1 - r)T + rE. \] Правые части совпали. Проверка узловая: \((STu)_m = (S(u_{\cdot+1}))_m = (1 - r)u_{m+1} + r\,u_m\); \((TSu)_m = (Su)_{m+1} = (1 - r)u_{m+1} + r\,u_m\) — тот же ответ.

Общее правило. Если \(S\) — многочлен от \(T\), \(T^{-1}\) с постоянными коэффициентами (или обратный к такому многочлену), то \(S\) перестановочен со сдвигом. Это то же элементарное свойство, что «многочлены от одной переменной коммутируют друг с другом»: раз \(T\) и \(T^{-1}\) коммутируют между собой (оба — степени одной операции), любой многочлен от них коммутирует с \(T\). Ровно этому свойству и отвечает однородность схемы по пространству; переменные коэффициенты его нарушают — тогда \(T\)-компонента и коэффициенты меняются местами лишь с ошибкой, и \(ST \ne TS\).

Собственные функции сдвига известны — это экспоненты: \(T e^{i\alpha m} = e^{i\alpha(m+1)} = e^{i\alpha}e^{i\alpha m}\). Оказывается, они же — собственные функции \(S\).

Гармоники — собственные функции оператора перехода. Пусть \(S\) — линейный оператор на сеточных функциях, перестановочный со сдвигом \(T\): \(ST = TS\). Тогда для каждого \(\alpha\) сеточная функция \(e_\alpha = \{e^{i\alpha m}\}\) является собственной функцией \(S\): \(S e_\alpha = \lambda(\alpha)\,e_\alpha\) с некоторым числом \(\lambda(\alpha)\).
Доказательство. Идея: показать, что образ \(v = S e_\alpha\) сам является собственной функцией сдвига с тем же собственным числом, что и \(e_\alpha\); тогда по единственности решения уравнения сдвига \(v\) окажется пропорциональной \(e_\alpha\). Шаг 1. Сдвиг гармоники Сдвиг \(T\) переводит \(e_\alpha = \{e^{i\alpha m}\}\) в функцию с компонентами \(e^{i\alpha(m+1)} = e^{i\alpha}\cdot e^{i\alpha m}\); значит \[ T e_\alpha = e^{i\alpha}\,e_\alpha, \tag{6.$\ast$} \] то есть \(e_\alpha\) — собственная функция сдвига с собственным числом \(e^{i\alpha}\). Это единственное, что мы знаем про \(e_\alpha\) заранее; свойство \(ST = TS\) переносит его на образ. Шаг 2. Применяем T к образу и используем перестановочность Обозначим \(v = S e_\alpha\). Подействуем на \(v\) сдвигом: \[ T v = T(S e_\alpha) = (TS)\,e_\alpha \stackrel{\text{ST=TS}}{=} (ST)\,e_\alpha = S(T e_\alpha) \stackrel{\text{(6.$\ast$)}}{=} S\bigl(e^{i\alpha}\,e_\alpha\bigr) = e^{i\alpha}\,S e_\alpha = e^{i\alpha}\,v. \] Здесь понадобились два свойства \(S\): перестановочность со сдвигом (второе равенство) и линейность — вынесение числового множителя \(e^{i\alpha}\) за знак \(S\) (предпоследнее). Итог: \(v\) — собственная функция сдвига с тем же собственным числом \(e^{i\alpha}\), что и \(e_\alpha\). Шаг 3. Единственность собственной функции сдвига с точностью до множителя Соотношение \(Tv = e^{i\alpha}v\) в координатах есть рекуррентное уравнение \[ v_{m+1} = e^{i\alpha}\,v_m, \qquad m \in \mathbb Z. \] Оно решается индукцией: \(v_1 = e^{i\alpha}v_0\), \(v_2 = e^{i\alpha}v_1 = e^{2i\alpha}v_0\), …, \(v_m = e^{i\alpha m}v_0\). Таким образом, значение \(v_0\) в одном узле определяет всю сеточную функцию, и решениями рекурсии являются в точности функции \(v = v_0\,e_\alpha\) — одномерное собственное подпространство. Шаг 4. Собираем Так как \(v = S e_\alpha\) — собственная функция сдвига с собственным числом \(e^{i\alpha}\), она попадает в это одномерное подпространство: \(v = \lambda\,e_\alpha\) при некотором \(\lambda \in \mathbb C\) (совпадающем с \(v_0\)). По определению \(v = S e_\alpha\), поэтому \(S e_\alpha = \lambda\,e_\alpha\), что и требовалось. Число \(\lambda\) зависит от \(\alpha\), т.е. \(\lambda = \lambda(\alpha)\).

Кратко: линейный оператор, перестановочный со сдвигом, действует на каждую гармонику как умножение на число. Это тот же приём, что превращает дифференциальные операторы с постоянными коэффициентами в алгебраические при переходе к преобразованию Фурье: собственные функции сдвига — экспоненты, и любой сдвиг-инвариантный оператор в этом базисе диагонален.

Для функций непрерывных аргументов гармоникой называют выражение \(u = e^{i\omega t + ikx}\), где \(k\) вещественно. На сетке \(x_m = mh\), \(t_n = n\tau\) она принимает вид

\[ u_m^n = e^{i\omega\tau\,n}\,e^{ikh\,m} = \lambda^n\,e^{i\alpha m}, \qquad \lambda = e^{i\omega\tau}, \quad \alpha = kh. \tag{6.2} \]
Гармоника и множитель перехода. Сеточная функция (6.2) называется гармоникой с приведённым волновым числом \(\alpha = kh\). Собственное число \(\lambda = \lambda(\alpha)\) оператора перехода на гармонике, для которого \(u_m^{n+1} = \lambda\,u_m^n\), называется множителем (коэффициентом) перехода.

Число \(\alpha\) меняется от \(0\) (постоянная по \(x\) функция) до \(\pi\) (функция \((-1)^m\) — «пила», самая короткая волна, различимая на сетке: знак меняется в каждом узле). Значения \(\alpha\) и \(\alpha + 2\pi\) на сетке неразличимы, поэтому достаточно рассматривать \(\alpha \in [-\pi, \pi]\) или, что то же, \([0, 2\pi]\). Для схем с вещественными коэффициентами \(\lambda(-\alpha) = \overline{\lambda(\alpha)}\), так что \(|\lambda|\) достаточно изучить на \([0, \pi]\).

§6.3. Характеристическое уравнение

Подставим гармонику (6.2) в разностную схему. Значение в узле шаблона с индексами \((m + p,\ n + s)\) равно

\[ u_{m+p}^{\,n+s} = \lambda^{n+s}e^{i\alpha(m+p)} = \underbrace{\lambda^n e^{i\alpha m}}_{\text{общий множитель}}\cdot\lambda^{s}\,e^{i\alpha p}. \tag{6.3} \]

После сокращения общего множителя \(\lambda^n e^{i\alpha m} \ne 0\) остаётся алгебраическое уравнение, связывающее \(\lambda\) и \(\alpha\).

Характеристическое уравнение. При подстановке гармоники (6.2) в разностную схему и сокращении общего множителя \(\lambda^n e^{i\alpha m}\) получается алгебраическое уравнение относительно \(\lambda\) с коэффициентами, зависящими от \(\alpha\) и параметров схемы. Оно называется характеристическим уравнением разностной схемы. Для двухслойной схемы оно линейно относительно \(\lambda\) и определяет единственный множитель перехода \(\lambda = \lambda(\alpha)\); для трёхслойной — квадратное относительно \(\lambda\), у него два корня \(\lambda_1(\alpha)\), \(\lambda_2(\alpha)\), и каждой гармонике отвечают две моды с этими множителями.
Порядок действий: как найти множитель перехода
  1. Ввести безразмерные параметры схемы: для уравнения переноса \(r = a\tau/h\) (число Куранта), для уравнения теплопроводности \(\varkappa = \tau/h^2\).
  2. Каждое значение \(u_{m+p}^{n+s}\) в схеме заменить множителем \(\lambda^s e^{i\alpha p}\) по правилу (6.3).
  3. Сократить общий множитель; решить полученное уравнение относительно \(\lambda\) (для неявных схем — разделить на коэффициент при \(\lambda\)).
  4. Выделить вещественную и мнимую части \(\lambda\), вычислить \(|\lambda|^2\); использовать формулы \(e^{\pm i\alpha} = \cos\alpha \pm i\sin\alpha\), \(1 - \cos\alpha = 2\sin^2(\alpha/2)\).

Из (6.2) следует \(u_m^{n} = \lambda^n u_m^{0}\), где \(u_m^0 = e^{i\alpha m}\) — начальное условие. Значит,

\[ \max_m |u_m^n| = |\lambda|^n\,\max_m |u_m^0|. \tag{6.4} \]

§6.4. Необходимое условие устойчивости (условие Неймана)

Возьмём в (6.1) норму \(\|u^n\| = \max_m|u_m^n|\) и подставим гармонику. По (6.4) неравенство (6.1) для неё означает \(|\lambda|^n\max|u^0| \le C\max|u^0|\), то есть

\[ |\lambda(\alpha)|^n \le C \qquad\text{при всех } n = 0, 1, \dots, N = T/\tau \text{ и всех } \alpha \in [-\pi, \pi]. \tag{6.5} \]

Число шагов \(N = T/\tau\) растёт при \(\tau \to 0\): \(n \sim 1/\tau\). Из (6.5) при \(n = N\) следует \(|\lambda| \le C^{1/N} = C^{\tau/T} = e^{(\tau/T)\ln C} \le 1 + C_1\tau\) при малых \(\tau\) (с \(C_1\) порядка \(\ln C/T\)). Обратно, если \(|\lambda| \le 1 + C_1\tau\), то \(|\lambda|^N \le (1 + C_1\tau)^{T/\tau} \le e^{C_1 T}\) — ограничено равномерно по \(\tau\). Итак, (6.5) равносильно неравенству

\[ |\lambda(\alpha)| \le 1 + C_1\tau \qquad\text{при всех } \alpha. \tag{6.6} \]
Условие Неймана (необходимое спектральное условие устойчивости). Если разностная схема с постоянными коэффициентами устойчива по начальным данным в норме \(\max_m|u_m^n|\) на бесконечной сетке, то множитель перехода \(\lambda(\alpha)\) при всех \(\alpha \in [-\pi, \pi]\) удовлетворяет неравенству \[ \boxed{\ |\lambda(\alpha)| \le 1\ } \qquad\text{при всех }\alpha \tag{6.7} \] в задачах, где точное решение не растёт со временем, и — более общо́ — \[ |\lambda(\alpha)| \le 1 + C_1\tau \qquad\text{при всех }\alpha, \tag{6.6} \] с постоянной \(C_1\), не зависящей от \(\tau\), \(h\) и \(\alpha\), — в задачах с растущими решениями. Это неравенство называется условием Неймана.

Условие получено проверкой неравенства (6.1) на одном специальном классе начальных данных — гармониках, поэтому оно необходимо: если нарушено хотя бы для одной гармоники, схема неустойчива. Обратный вопрос — достаточно ли его — разобран в §6.11.

Геометрическое истолкование: при \(\alpha\), пробегающем \([-\pi, \pi]\), точка \(\lambda(\alpha)\) описывает в комплексной плоскости замкнутую кривую; условие (6.7) означает, что она лежит в замкнутом единичном круге, а (6.6) — в круге радиуса \(1 + C_1\tau\) (обычно на всех дальнейших рисунках отступ от единичной окружности не изображают — он исчезающе мал). Запас \(C_1\tau\) нужен лишь тогда, когда само дифференциальное уравнение допускает растущие решения: например, для \(u_t + au_x = u\) решение растёт как \(e^t\), и всякая аппроксимирующая схема обязана давать \(|\lambda| = 1 + \tau + O(\tau^2)\). Для уравнения переноса без младших членов точное решение не растёт, и (6.7) — естественное требование. Множество значений параметра схемы (например, \(r\)), при которых выполняется (6.7), называется областью устойчивости схемы.

§6.5. Пример 1: схема «уголок»

Исходное уравнение \(u_t + au_x = 0\), \(a = \mathrm{const} > 0\). Явная схема с несимметричной аппроксимацией \(u_x\) разностью назад:

\[ \frac{u_m^{n+1} - u_m^n}{\tau} + a\,\frac{u_m^n - u_{m-1}^n}{h} = 0 \qquad\Longleftrightarrow\qquad u_m^{n+1} = (1 - r)\,u_m^n + r\,u_{m-1}^n, \qquad r = \frac{a\tau}{h}. \tag{6.8} \]

Шаг 2–3. По правилу (6.3) узлу \((m, n+1)\) отвечает множитель \(\lambda\), узлу \((m, n)\) — \(1\), узлу \((m-1, n)\) — \(e^{-i\alpha}\):

\[ \lambda^{n+1}e^{i\alpha m} = (1 - r)\lambda^n e^{i\alpha m} + r\lambda^n e^{i\alpha m}e^{-i\alpha} \qquad\Longrightarrow\qquad \lambda = 1 - r + r\,e^{-i\alpha}. \tag{6.9} \]

Это уравнение окружности радиуса \(r\) с центром в точке \(1 - r\) вещественной оси: к точке \(1 - r\) прибавляется вектор длины \(r\), поворачивающийся вместе с \(\alpha\); при \(\alpha = 0\) окружность проходит через \(\lambda = 1\), при \(\alpha = \pi\) — через \(1 - 2r\).

Шаг 4. \(\lambda = (1 - r + r\cos\alpha) - i\,r\sin\alpha\), откуда

\[ |\lambda|^2 = (1 - r + r\cos\alpha)^2 + r^2\sin^2\alpha = 1 - 2r(1 - r)(1 - \cos\alpha) = 1 - 4r(1 - r)\sin^2\frac{\alpha}{2}. \tag{6.10} \]

(Раскрываем скобки: \((1-r)^2 + 2r(1-r)\cos\alpha + r^2\cos^2\alpha + r^2\sin^2\alpha = (1-r)^2 + r^2 + 2r(1-r)\cos\alpha\), и \((1-r)^2 + r^2 = 1 - 2r(1-r)\).) Поскольку \(\sin^2(\alpha/2) \ge 0\) и обращается в единицу при \(\alpha = \pi\), условие \(|\lambda| \le 1\) при всех \(\alpha\) равносильно \(r(1 - r) \ge 0\):

\[ 0 \le r = \frac{a\tau}{h} \le 1. \tag{6.11} \]

Условие Неймана выполняется при \(r \le 1\), что совпадает с критерием Куранта (Куранта–Фридрихса–Леви). При \(r > 1\) наибольший модуль имеет «пила»: \(|\lambda(\pi)| = |1 - 2r| > 1\), и она растёт как \(|1 - 2r|^n\) — типичная картина неустойчивости: решение покрывается пилообразными осцилляциями, растущими экспоненциально.

Рис. 2. Схема «уголок»: а) кривая множителя перехода — окружность радиуса \(r\) с центром \(1 - r\); при \(r = 1.2\) точка \(\alpha = \pi\) выходит из единичного круга; б) геометрический смысл условия \(r \le 1\).
Геометрический смысл условия Куранта Точное значение \(u(x_m, t_{n+1})\) определяется значением на слое \(t_n\) в основании характеристики \(x = x_m - a\tau\). Разностное значение \(u_m^{n+1}\) определяется значениями в узлах шаблона \(x_{m-1}\), \(x_m\). Если \(a\tau > h\), основание характеристики лежит левее \(x_{m-1}\) — вне шаблона: схема не получает информацию, от которой зависит точное решение, и не может сходиться. Это условие Куранта–Фридрихса–Леви (1928): область зависимости разностной схемы должна содержать область зависимости уравнения. Условие Неймана получено алгебраически, условие КФЛ — геометрически; для «уголка» они совпали. В общем случае КФЛ — лишь необходимое условие, более грубое, чем спектральное (пример 3 ниже).

§6.6. Пример 2: явная схема с разностью вперёд

Заменим в (6.8) разность назад разностью вперёд:

\[ \frac{u_m^{n+1} - u_m^n}{\tau} + a\,\frac{u_{m+1}^n - u_m^n}{h} = 0 \qquad\Longleftrightarrow\qquad u_m^{n+1} = (1 + r)\,u_m^n - r\,u_{m+1}^n. \tag{6.12} \]

Узлу \((m+1, n)\) отвечает множитель \(e^{+i\alpha}\), поэтому \(\lambda = 1 + r - r\,e^{i\alpha}\) — окружность радиуса \(r\) с центром \(1 + r\). Модуль:

\[ |\lambda|^2 = (1 + r - r\cos\alpha)^2 + r^2\sin^2\alpha = 1 + 2r(1 + r)(1 - \cos\alpha) = 1 + 4r(1 + r)\sin^2\frac{\alpha}{2} \ge 1, \tag{6.13} \]

причём при \(\alpha \ne 0\) и любом \(r > 0\) неравенство строгое. Условие Неймана нарушено при всех \(\tau\), \(h\): схема абсолютно неустойчива. Геометрически: при \(a > 0\) характеристика приходит в узел слева, а шаблон схемы (6.12) берёт информацию справа — условие КФЛ нарушено при любом \(r\). (При \(a < 0\) картина зеркальна: устойчива именно схема с разностью вперёд при \(|a|\tau/h \le 1\).) Правило «разность против потока» и есть содержание этого примера.

§6.7. Пример 3: явная схема с центральной разностью

Попытка «улучшить» уголок, взяв симметричную разность второго порядка:

\[ \frac{u_m^{n+1} - u_m^n}{\tau} + a\,\frac{u_{m+1}^n - u_{m-1}^n}{2h} = 0 \qquad\Longleftrightarrow\qquad u_m^{n+1} = u_m^n - \frac{r}{2}\bigl(u_{m+1}^n - u_{m-1}^n\bigr). \tag{6.14} \]

Множители узлов \(m \pm 1\) равны \(e^{\pm i\alpha}\), и \(e^{i\alpha} - e^{-i\alpha} = 2i\sin\alpha\), так что

\[ \lambda = 1 - i\,r\sin\alpha, \qquad |\lambda|^2 = 1 + r^2\sin^2\alpha \ge 1. \tag{6.15} \]

Схема абсолютно неустойчива, хотя условие КФЛ при \(r \le 1\) выполнено: основание характеристики лежит в шаблоне \([x_{m-1}, x_{m+1}]\). Это показывает, что условие КФЛ необходимо, но не достаточно, а спектральный признак точнее. Причина неустойчивости видна из первого дифференциального приближения (§4, §5): П-форма схемы (6.14) имеет вид \(u_t + au_x = -\frac{a^2\tau}{2}u_{xx} + \dots\) — отрицательная схемная вязкость, «антидиффузия», которая раскачивает короткие волны. В §6а (разбор 3) тот же вывод получен энергетическим методом: \(\|u^{n+1}\|^2 = \|u^n\|^2 + \tau^2a^2\|u_{\mathring x}\|^2\).

§6.8. Пример 4: неявный «уголок»

Возьмём разность назад на верхнем слое:

\[ \frac{u_m^{n+1} - u_m^n}{\tau} + a\,\frac{u_m^{n+1} - u_{m-1}^{n+1}}{h} = 0 \qquad\Longleftrightarrow\qquad (1 + r)\,u_m^{n+1} - r\,u_{m-1}^{n+1} = u_m^n. \tag{6.16} \]

Узлу \((m-1, n+1)\) отвечает множитель \(\lambda e^{-i\alpha}\). Подстановка даёт \((1 + r)\lambda - r\lambda e^{-i\alpha} = 1\), откуда

\[ \lambda = \frac{1}{1 + r - r\,e^{-i\alpha}}, \qquad |\lambda|^2 = \frac{1}{(1 + r - r\cos\alpha)^2 + r^2\sin^2\alpha} = \frac{1}{1 + 4r(1 + r)\sin^2\frac{\alpha}{2}} \le 1 \tag{6.17} \]

при всех \(r > 0\) (знаменатель — выражение (6.13)). Условие Неймана выполнено при любых \(\tau\), \(h\): неявный уголок безусловно устойчив. Геометрически это понятно: в неявной схеме значение \(u_m^{n+1}\) связано уравнением со всеми узлами верхнего слоя левее \(m\), поэтому область зависимости схемы бесконечна и условие КФЛ выполнено при любом \(r\). Плата — необходимость решать на каждом шаге систему уравнений; для уравнения переноса при \(a > 0\) она решается «бегущим счётом» слева направо, если задано граничное значение \(u_0^{n+1}\).

§6.9. Пример 5: схема с весами для уравнения теплопроводности

Метод не привязан к уравнению переноса. Рассмотрим уравнение теплопроводности \(u_t = u_{xx}\) и семейство схем с весом \(\sigma \in [0, 1]\):

\[ \frac{u_m^{n+1} - u_m^n}{\tau} = \sigma\,\frac{u_{m+1}^{n+1} - 2u_m^{n+1} + u_{m-1}^{n+1}}{h^2} + (1 - \sigma)\,\frac{u_{m+1}^{n} - 2u_m^{n} + u_{m-1}^{n}}{h^2}. \tag{6.18} \]

При \(\sigma = 0\) схема явная, при \(\sigma = 1\) — чисто неявная, при \(\sigma = 1/2\) — схема Кранка–Николсон. Введём \(\varkappa = \tau/h^2\). Вторая разность на гармонике даёт множитель \(e^{i\alpha} - 2 + e^{-i\alpha} = 2\cos\alpha - 2 = -4\sin^2(\alpha/2)\). Обозначив \(s = \varkappa\sin^2(\alpha/2) \in [0, \varkappa]\), получаем

\[ \lambda - 1 = -4s\bigl(\sigma\lambda + 1 - \sigma\bigr) \qquad\Longrightarrow\qquad \lambda = \frac{1 - 4(1 - \sigma)s}{1 + 4\sigma s}. \tag{6.19} \]

Множитель вещественный. Неравенство \(\lambda \le 1\) выполнено всегда (числитель не больше знаменателя при \(s \ge 0\)). Неравенство \(\lambda \ge -1\) равносильно \(1 - 4(1-\sigma)s \ge -1 - 4\sigma s\), то есть \(4s(1 - 2\sigma) \le 2\). Если \(\sigma \ge 1/2\), левая часть неположительна и условие выполнено при всех \(s\): схема безусловно устойчива. Если \(\sigma < 1/2\), нужно \(s \le \dfrac{1}{2(1 - 2\sigma)}\) при всех \(s \le \varkappa\), то есть \(\varkappa(1 - 2\sigma) \le 1/2\):

\[ \sigma \ge \frac12 - \frac{h^2}{4\tau}; \qquad\text{в частности, при } \sigma = 0:\quad \tau \le \frac{h^2}{2}. \tag{6.20} \]
Та же схема — вторым методом В §6а (разбор 4) условие (6.20) будет получено энергетическим методом как достаточное условие устойчивости в норме \(L_2\) для задачи на отрезке с краевыми условиями \(u_0 = u_N = 0\). Здесь оно получено как необходимое для задачи без границ. Совпадение необходимого и достаточного условий означает, что для схемы с весами ответ найден точно. Это первый из «парных» разборов, которых в §6а будет несколько: одна схема — два исследования.

§6.10. Трёхслойная схема «крест»

Для трёхслойной схемы характеристическое уравнение квадратное. Рассмотрим схему «крест» (leap-frog) для уравнения переноса:

\[ \frac{u_m^{n+1} - u_m^{n-1}}{2\tau} + a\,\frac{u_{m+1}^n - u_{m-1}^n}{2h} = 0. \tag{6.21} \]

Узлу \((m, n-1)\) отвечает множитель \(\lambda^{-1}\). Подстановка: \(\lambda - \lambda^{-1} + r(e^{i\alpha} - e^{-i\alpha}) = 0\); умножая на \(\lambda\), получаем

\[ \lambda^2 + 2i\,r\sin\alpha\,\lambda - 1 = 0, \qquad \lambda_{1,2} = -i\,r\sin\alpha \pm \sqrt{1 - r^2\sin^2\alpha}. \tag{6.22} \]

Если \(r \le 1\), подкоренное выражение неотрицательно, корень вещественный, и \(|\lambda_{1,2}|^2 = (1 - r^2\sin^2\alpha) + r^2\sin^2\alpha = 1\): оба корня лежат на единичной окружности при всех \(\alpha\) — схема устойчива и бездиссипативна. Если \(r > 1\), то при \(\alpha = \pi/2\) корень мнимый, \(\lambda_{1,2} = -i\bigl(r \pm \sqrt{r^2 - 1}\bigr)\), и один из корней по модулю больше единицы — неустойчивость. Область устойчивости — снова \(r \in [0, 1]\).

Два корня — два решения. Гармоника трёхслойной схемы есть комбинация \(c_1\lambda_1^n + c_2\lambda_2^n\); её поведение определяется обоими корнями, и условие Неймана должно выполняться для каждого. Корень \(\lambda_1 \to 1\) при \(\alpha \to 0\) называется реальным: он аппроксимирует множитель перехода точного решения. Корень \(\lambda_2 \to -1\) — паразитный: он описывает эволюцию рассогласования начальных данных на двух стартовых слоях и не имеет отношения к дифференциальной задаче. Подробнее — в упражнениях §5. Если корни характеристического уравнения кратные и лежат на единичной окружности, гармоника содержит член \(n\lambda^n\), и условие \(|\lambda| \le 1\) уже не гарантирует ограниченности — ещё одна причина, по которой условие Неймана лишь необходимо.

§6.11. Границы применимости. Когда условия Неймана достаточно

Всё изложенное держалось на лемме 1: гармоники — собственные функции оператора перехода. Лемма требует, чтобы \(S\) был перестановочен со сдвигом, а для этого нужны:

  • линейность и однородность схемы — иначе нет принципа суперпозиции и разложения по гармоникам;
  • постоянные коэффициенты — при \(a = a(x)\) оператор перехода не перестановочен со сдвигом; на практике коэффициенты «замораживают» и требуют выполнения условия в каждом узле, но это эвристика, а не доказательство;
  • отсутствие границ — сетка бесконечна или периодична; гармоника не удовлетворяет условию \(u = 0\) на границе, и краевые условия метод не видит.
Достаточность для скалярных двухслойных схем. Пусть двухслойная схема с постоянными коэффициентами рассматривается на периодической сетке из \(N\) узлов, и множитель перехода удовлетворяет условию \(|\lambda(\alpha)| \le 1\) при всех \(\alpha\). Тогда схема устойчива в сеточной норме \(L_2\): \(\|u^n\| \le \|u^0\|\).
Доказательство. Гармоники \(e_{\alpha_k}\), \(\alpha_k = 2\pi k/N\), \(k = 0, \dots, N-1\), образуют ортогональный базис пространства сеточных функций на периоде (дискретное преобразование Фурье), и любое начальное условие разлагается: \(u^0 = \sum_k c_k e_{\alpha_k}\). По лемме 1 \(u^n = S^n u^0 = \sum_k c_k\lambda(\alpha_k)^n e_{\alpha_k}\). По равенству Парсеваля для ортогонального базиса \[ \|u^n\|^2 = \sum_k |c_k|^2\,|\lambda(\alpha_k)|^{2n}\,\|e_{\alpha_k}\|^2 \le \max_k|\lambda(\alpha_k)|^{2n}\sum_k|c_k|^2\|e_{\alpha_k}\|^2 = \max_k|\lambda(\alpha_k)|^{2n}\,\|u^0\|^2 \le \|u^0\|^2. \]

Заметим, что теорема говорит только о норме \(L_2\): равенство Парсеваля — свойство именно этой нормы, и об устойчивости в норме \(C\) она ничего не утверждает. В следующих случаях условие Неймана остаётся лишь необходимым:

  • системы уравнений: \(\lambda\) — матрица \(G(\alpha)\); если она недиагонализуема (жорданова клетка), нормы степеней \(G^n\) растут, хотя все собственные числа по модулю не больше единицы; нужны дополнительные условия (Крайса);
  • многослойные схемы с кратными корнями на единичной окружности (§6.10);
  • переменные коэффициенты и краевые условия — метод вообще не формулируется.

Инструмент, который даёт достаточные условия и работает с краевыми условиями и переменными коэффициентами, — энергетический метод (§6а).

Порядок исследования схемы спектральным признаком
  1. Убедиться, что схема линейна, коэффициенты постоянны, границ нет (или сетка периодична). Иначе — §6а.
  2. Разрешить схему относительно верхнего слоя (для неявных — оставить как есть), ввести \(r = a\tau/h\) или \(\varkappa = \tau/h^2\).
  3. Подставить гармонику: узлу \((m+p, n+s)\) отвечает множитель \(\lambda^s e^{i\alpha p}\); сократить общий множитель — характеристическое уравнение.
  4. Найти \(\lambda(\alpha)\) (для трёхслойных схем — оба корня) и вычислить \(|\lambda|^2\) через \(\sin^2(\alpha/2)\) или \(\sin^2\alpha\).
  5. Потребовать \(|\lambda| \le 1\) при всех \(\alpha\); худшая гармоника, как правило, — «пила» \(\alpha = \pi\) или \(\alpha = \pi/2\). Описать область устойчивости в терминах параметров.
  6. Помнить: условие необходимое; для скалярных двухслойных схем в \(L_2\) — и достаточное (теорема 2).

§6.13. Упражнения

Упражнение 1 (схема Лакса). Для схемы \(\dfrac{u_m^{n+1} - \tfrac12(u_{m-1}^n + u_{m+1}^n)}{\tau} + a\,\dfrac{u_{m+1}^n - u_{m-1}^n}{2h} = 0\) (вопрос 1 §4) получите \(\lambda = \cos\alpha - ir\sin\alpha\), \(|\lambda|^2 = \cos^2\alpha + r^2\sin^2\alpha\) и область устойчивости \(r \le 1\). Объясните, чем замена \(u_m^n\) полусуммой соседей «вылечила» неустойчивость схемы (6.14).
Упражнение 2 (неявная центральная схема). Исследуйте схему \(\dfrac{u_m^{n+1} - u_m^n}{\tau} + a\,\dfrac{u_{m+1}^{n+1} - u_{m-1}^{n+1}}{2h} = 0\). Покажите, что \(|\lambda|^2 = (1 + r^2\sin^2\alpha)^{-1}\) и схема безусловно устойчива, хотя её явный аналог (6.14) абсолютно неустойчив.
Упражнение 3 (Кранк–Николсон для переноса). Для схемы \(\dfrac{u_m^{n+1} - u_m^n}{\tau} + \dfrac{a}{2}\Bigl(\dfrac{u_{m+1}^{n+1} - u_{m-1}^{n+1}}{2h} + \dfrac{u_{m+1}^{n} - u_{m-1}^{n}}{2h}\Bigr) = 0\) покажите, что \(|\lambda| = 1\) при всех \(r\) и \(\alpha\): схема безусловно устойчива и бездиссипативна. Сравните с упражнением 3 §6а (сохранение энергии).
Упражнение 4 (схема с весами для переноса). Для схемы \(\dfrac{u_m^{n+1} - u_m^n}{\tau} + a\Bigl[\sigma\,\dfrac{u_m^{n+1} - u_{m-1}^{n+1}}{h} + (1 - \sigma)\,\dfrac{u_m^{n} - u_{m-1}^{n}}{h}\Bigr] = 0\) найдите \(\lambda(\alpha)\) и покажите, что область устойчивости — \(r \le \dfrac{1}{1 - 2\sigma}\) при \(\sigma < 1/2\) и вся полуось при \(\sigma \ge 1/2\).
Упражнение 5 (двумерная теплопроводность). Для явной схемы \(\dfrac{u^{n+1}_{m,l} - u^{n}_{m,l}}{\tau} = \dfrac{u_{m+1,l} - 2u_{m,l} + u_{m-1,l}}{h^2} + \dfrac{u_{m,l+1} - 2u_{m,l} + u_{m,l-1}}{h^2}\) подставьте двумерную гармонику \(\lambda^n e^{i(\alpha m + \beta l)}\) и получите условие \(\tau \le h^2/4\).
Упражнение 6 (схема Ричардсона). Трёхслойная схема «крест» для уравнения теплопроводности: \(\dfrac{u_m^{n+1} - u_m^{n-1}}{2\tau} = \dfrac{u_{m+1}^n - 2u_m^n + u_{m-1}^n}{h^2}\). Получите квадратное характеристическое уравнение \(\lambda^2 + 8\varkappa\sin^2(\alpha/2)\,\lambda - 1 = 0\) и покажите, что произведение корней равно \(-1\), а потому один из них по модулю больше единицы при любом \(\varkappa > 0\): схема абсолютно неустойчива, несмотря на второй порядок аппроксимации.
