Полная вариация сеточной функции. TVD-свойство. TVD-теоремы

▶ Слайды практики §8–§10

Полная вариация

Определение 1. Пусть \(\{u_i^n\}\) — сеточная функция, заданная на одномерной равномерной сетке. Полной вариацией сеточной функции на временном слое \(t_n\) называется величина \[ \mathrm{TV}(u^n) = \sum_i |u_{i+1}^n - u_i^n|. \tag{10.1} \]
Замечание. Полная вариация характеризует суммарную «изломанность» профиля решения. Для гладких функций она аппроксимирует интеграл от модуля производной, а для разрывных функций включает вклад скачков.
Полная вариация \(\mathrm{TV}(u^n)\) — сумма модулей перепадов между соседними узлами. TVD-свойство гарантирует, что эта сумма не растёт со временем.

TVD-свойство

Определение 2. Разностная схема называется TVD (total variation diminishing), если для всех \(n\) выполняется неравенство \[ \mathrm{TV}(u^{n+1}) \le \mathrm{TV}(u^n). \tag{10.2} \]
Замечание. Свойство TVD является глобальным: оно ограничивает рост полной вариации решения, но не запрещает локальное перераспределение вариации. В частности, возможны новые локальные максимумы и минимумы, если они не приводят к увеличению суммы (10.1).
Замечание. TVD-свойство является более слабым, чем монотонность схемы. Любая монотонная схема является TVD, но обратное утверждение, вообще говоря, неверно.

TVD и линейные разностные схемы

Рассмотрим линейную консервативную схему

\[ u_i^{n+1} = u_i^n - \lambda\left(F_{i+1/2}^n - F_{i-1/2}^n\right), \tag{10.3} \]

где \(\lambda = \Delta t / \Delta x\).

TVD-условие Хартена

Для линейной схемы \(u_i^{n+1} = \sum_k a_k u_{i+k}^n\) с \(\sum_k a_k = 1\) свойство TVD равносильно монотонности \(a_k \ge 0\): достаточность доказана в §8, а необходимость следует из одного шага по ступеньке \(u_i^0 = 1\) при \(i \le 0\), \(u_i^0 = 0\) при \(i > 0\): у неё единственный скачок, \(\mathrm{TV}(u^0) = 1\), а после шага \(\mathrm{TV}(u^1) = \sum_k |a_k| \ge \sum_k a_k = 1\) с равенством только при всех \(a_k \ge 0\). Для нелинейных схем, коэффициенты которых зависят от решения, нужен другой инструмент.

Теорема 2 (лемма Хартена). Пусть схема записана в приращениях \[ u_i^{n+1} = u_i^n + C_{i+1/2}\,\Delta_{i+1/2} - D_{i-1/2}\,\Delta_{i-1/2}, \qquad \Delta_{i+1/2} = u_{i+1}^n - u_i^n, \tag{10.4} \] где коэффициенты \(C\), \(D\) могут зависеть от \(u^n\), и для всех \(i\): \(C_{i+1/2} \ge 0\), \(D_{i+1/2} \ge 0\), \(C_{i+1/2} + D_{i+1/2} \le 1\). Тогда схема является TVD.

Вычитая уравнения (10.4) для \(i+1\) и \(i\), получаем \[ u_{i+1}^{n+1} - u_i^{n+1} = \bigl(1 - C_{i+1/2} - D_{i+1/2}\bigr)\Delta_{i+1/2} + C_{i+3/2}\,\Delta_{i+3/2} + D_{i-1/2}\,\Delta_{i-1/2}. \] Все три множителя неотрицательны. Берём модуль, суммируем по \(i\) и сдвигаем индексы во второй и третьей суммах: при каждом \(|\Delta_{i+1/2}|\) собирается коэффициент \((1 - C - D) + C + D = 1\), откуда \(\mathrm{TV}(u^{n+1}) \le \mathrm{TV}(u^n)\). ∎

Связь TVD с теоремой Годунова

Замечание. По теореме Годунова (§9) линейная монотонная схема имеет порядок не выше первого; поскольку для линейных схем TVD равносильно монотонности, то же верно для линейных TVD-схем. Следовательно, TVD-схема второго порядка обязана быть нелинейной: её коэффициенты зависят от решения.

Ограничители потока

Для уравнения переноса \(u_t + a u_x = 0\), \(a > 0\), \(r = a\Delta t/\Delta x\), поток схемы Лакса–Вендроффа равен потоку «уголка» плюс антидиффузионная поправка: \(F_{i+1/2}/a = u_i + \frac{1-r}{2}\Delta_{i+1/2}\). Поправка умножается на число, вычисляемое по решению:

\[ \frac{F_{i+1/2}}{a} = u_i + \frac{1 - r}{2}\,\varphi(\theta_i)\,\Delta_{i+1/2}, \qquad \theta_i = \frac{\Delta_{i-1/2}}{\Delta_{i+1/2}}, \tag{10.5} \]

где \(\varphi\) — ограничитель: \(\varphi \equiv 0\) даёт «уголок», \(\varphi \equiv 1\) — схему Лакса–Вендроффа. Отношение \(\theta_i\) — индикатор гладкости: на гладком монотонном участке \(\theta_i = 1 + O(\Delta x)\), в экстремуме \(\theta_i \lt 0\), у разрыва \(\theta_i\) близко к нулю или велико. Эквивалентно \(F = (1-\varphi)F^{\text{уг}} + \varphi F^{\text{ЛВ}}\): \(\varphi\) — доля потока Лакса–Вендроффа на грани. При \(a \lt 0\) «уголок» берёт \(u_{i+1}\), поправка входит со знаком минус и множителем \(1 - |r|\), а \(\theta\) строится по разности выше по потоку: \(\theta = \Delta_{i+3/2}/\Delta_{i+1/2}\).

Теорема 3 (Свеби). Схема с потоком (10.5) при \(0 \le r \le 1\) является TVD, если \[ \varphi(\theta) = 0 \ \ (\theta \le 0), \qquad 0 \le \varphi(\theta) \le \min(2\theta, 2) \ \ (\theta > 0). \tag{10.6} \]

Подставляя \(\Delta_{i+1/2} = \Delta_{i-1/2}/\theta_i\), приводим схему к виду (10.4) с \(C = 0\) и \(D_{i-1/2} = r\bigl[1 + \frac{1-r}{2}\bigl(\varphi(\theta_i)/\theta_i - \varphi(\theta_{i-1})\bigr)\bigr]\). При (10.6) выражение в круглых скобках лежит в \([-2, 2]\), откуда \(r^2 \le D_{i-1/2} \le r(2-r) \le 1\), и по теореме 2 схема TVD. ∎

Второй порядок на гладких монотонных участках обеспечивается условием \(\varphi(1) = 1\) (и липшицевостью \(\varphi\) вблизи единицы). Классические ограничители:

\[ \begin{aligned} &\text{minmod: } \max\bigl(0, \min(1, \theta)\bigr), &\qquad &\text{superbee: } \max\bigl(0, \min(2\theta, 1), \min(\theta, 2)\bigr),\\ &\text{van Leer: } \frac{\theta + |\theta|}{1 + |\theta|}, & &\text{MC: } \max\bigl(0, \min(2\theta, \tfrac{1+\theta}{2}, 2)\bigr). \end{aligned} \]
Замечание. В экстремуме \(\theta_i \lt 0\), ограничитель обнуляет поправку, и схема локально переходит в «уголок»: TVD-схемы срезают гладкие экстремумы и в них имеют лишь первый порядок. Диаграмма Свеби, разбор и упражнение — в слайдах практики §8–§10.

Примеры

Пример. Противопоточная схема первого порядка для уравнения переноса является монотонной и TVD, но обладает высокой численной диффузией.

Пример. Схемы второго порядка с нелинейными ограничителями могут быть TVD, обеспечивая при этом повышенную точность на гладких участках и отсутствие роста осцилляций вблизи разрывов.
