Численное интегрирование I. Формулы Ньютона-Котеса

▶ Слайды ▶ Лаба

Численное интегрирование — обратная задача к дифференцированию: по значениям \(f\) в узлах восстановить определённый интеграл \(I = \int_a^b f(x)\,dx\). В отличие от дифференцирования, здесь ошибка округления играет минимальную роль (сумма положительных величин не теряет значимости), а на первый план выходит ошибка усечения. Классический подход — квадратурные формулы Ньютона-Котеса: интерполируем \(f\) многочленом низкой степени на подотрезках и интегрируем интерполянт.

Задача численного интегрирования

квадратурная формула. Приближение определённого интеграла линейной комбинацией значений подынтегральной функции в фиксированных узлах: \[ \int_a^b f(x)\,dx \;\approx\; \sum_{i=0}^{n} w_i\,f(x_i). \tag{7.1} \] Узлы \(x_i \in [a, b]\) и веса \(w_i\) не зависят от \(f\) и подбираются заранее.

Формулы Ньютона-Котеса — семейство квадратур с равномерно расположенными узлами. Веса подбираются так, чтобы формула была точна для многочленов возможно более высокой степени.

Идея: интеграл интерполяционного многочлена

Пусть \(P_n(x)\) — интерполяционный многочлен \(f\) в узлах \(x_0, \ldots, x_n\) (например, форма Лагранжа § 3). Тогда естественная квадратурная формула — интеграл интерполянта:

\[ \int_a^b f(x)\,dx \;\approx\; \int_a^b P_n(x)\,dx \;=\; \sum_{i=0}^n f(x_i)\int_a^b \ell_i(x)\,dx \;=\; \sum_{i=0}^n w_i f(x_i), \tag{7.2} \]

где \(w_i = \int_a^b \ell_i(x)\,dx\) — интегралы базисных многочленов Лагранжа. Формула точно вычисляет любой многочлен степени \(\le n\), потому что для такого многочлена интерполянт \(P_n\) совпадает с \(f\) целиком.

степень точности квадратуры. Наибольшая степень \(m\), при которой формула (7.1) вычисляет \(\int_a^b x^k\,dx\) точно для всех \(k = 0, 1, \ldots, m\). Величину \(m\) называют алгебраическим порядком точности.

Формулы прямоугольников

Самая простая квадратура — средней точки (midpoint rule): интерполируем \(f\) константой \(f((a+b)/2)\):

формула средней точки. \[ M(f) \;=\; (b - a)\,f\!\left(\frac{a+b}{2}\right). \tag{7.3} \] Точна для многочленов степени \(\le 1\) (степень точности 1). Ошибка на гладкой \(f\): \[ \int_a^b f\,dx - M(f) \;=\; \frac{(b-a)^3}{24}\,f''(\xi),\qquad \xi \in (a, b). \tag{7.4} \]

Аналогично строятся формулы левого и правого прямоугольника, интерполирующие \(f\) значением в левом / правом конце. У них степень точности 0 (точны только для констант), ошибка \(O((b-a)^2)\).

Формула трапеций

Интерполяция \(f\) линейной функцией через два конца отрезка \([a, b]\):

формула трапеций. \[ T(f) \;=\; \frac{b - a}{2}\bigl(f(a) + f(b)\bigr). \tag{7.5} \] Точна для многочленов степени \(\le 1\); ошибка на гладкой \(f\): \[ \int_a^b f\,dx - T(f) \;=\; -\frac{(b-a)^3}{12}\,f''(\xi),\qquad \xi \in (a, b). \tag{7.6} \]

Обратите внимание: константа при \(f''\) у трапеций в 2 раза больше, чем у средних точек — то есть одна средняя точка точнее одной трапеции. Плата — «середина» отрезка неудобна, если функция задана только в узлах равномерной сетки.

Формула Симпсона

Интерполируем \(f\) квадратичной параболой через три равноотстоящие точки: \(a\), \((a+b)/2\), \(b\):

формула Симпсона. \[ S(f) \;=\; \frac{b - a}{6}\left(f(a) + 4\,f\!\left(\frac{a+b}{2}\right) + f(b)\right). \tag{7.7} \]

Удивительный факт: формула Симпсона, построенная по трём точкам (интерполяция квадратичной параболой) точна не только для многочленов степени 2, но и для кубических:

степень точности Симпсона. Формула (7.7) точна для многочленов степени \(\le 3\); ошибка на гладкой \(f\): \[ \int_a^b f\,dx - S(f) \;=\; -\frac{(b-a)^5}{2880}\,f^{(4)}(\xi),\qquad \xi \in (a, b). \tag{7.8} \]

Причина. Кубический член в интерполируемой функции \(x^3\) на симметричном интервале даёт нулевой вклад в ошибку — он «убивается» симметрией квадратуры. Это общий эффект: симметричные формулы Ньютона-Котеса с нечётным числом узлов имеют степень точности на единицу выше, чем можно было бы ожидать.

Рис. 1. Три классических квадратуры: прямоугольник (константа), трапеция (прямая), Симпсон (парабола).

Составные формулы

На большом отрезке \([a, b]\) одна квадратура высокой степени точна лишь для очень гладкой \(f\); практически удобнее разбить \([a, b]\) на \(N\) подотрезков \([x_i, x_{i+1}]\) с шагом \(h = (b-a)/N\) и применить простую формулу на каждом подотрезке.

составная формула трапеций. \[ T_N(f) \;=\; h\left(\frac{f(x_0) + f(x_N)}{2} + \sum_{i=1}^{N-1} f(x_i)\right),\qquad h = \frac{b - a}{N}. \tag{7.9} \] Ошибка: \(\displaystyle -\frac{(b-a)\,h^2}{12}\,f''(\eta) = O(h^2)\).
составная формула Симпсона. При чётном \(N\): \[ S_N(f) \;=\; \frac{h}{3}\!\left(f(x_0) + f(x_N) + 4\!\!\sum_{i\ \text{нечёт}} f(x_i) + 2\!\!\sum_{i\ \text{чёт}, i\ne 0, N} f(x_i)\right). \tag{7.10} \] Ошибка: \(\displaystyle -\frac{(b-a)\,h^4}{180}\,f^{(4)}(\eta) = O(h^4)\).

Порядок точности и выигрыш от Симпсона

Для гладкой \(f\) удвоение числа узлов при трапециях уменьшает ошибку в 4 раза (порядок 2), при Симпсоне — в 16 раз (порядок 4). Разница особенно заметна при высоких требованиях к точности.

Пример: \(\int_0^1 e^x dx = e - 1\)
  • Трапеции с \(N = 10\): ошибка \(\sim 2\cdot 10^{-3}\).
  • Трапеции с \(N = 100\): ошибка \(\sim 2\cdot 10^{-5}\) (в 100 раз меньше).
  • Симпсон с \(N = 10\): ошибка \(\sim 5\cdot 10^{-7}\).
  • Симпсон с \(N = 20\): ошибка \(\sim 3\cdot 10^{-8}\) (в 16 раз меньше).
При том же числе вычислений \(f\) Симпсон точнее трапеций в тысячи раз.

Экстраполяция Ромберга

Как и для дифференцирования (§ 6), для интегрирования работает экстраполяция Ричардсона. Для составной формулы трапеций справедлива формула Эйлера–Маклорена: разложение ошибки по чётным степеням \(h\):

\[ T_N(f) \;=\; I + c_1 h^2 + c_2 h^4 + c_3 h^6 + \ldots \tag{7.11} \]

Комбинируя \(T_N\) и \(T_{2N}\) с коэффициентами, «убирающими» \(h^2\), получаем формулу порядка 4. Итерируя, поднимаемся до порядков 6, 8, ... Это метод Ромберга:

метод Ромберга. Пусть \(R_{k,0} = T_{2^k}(f)\) — составные трапеции с \(2^k\) отрезками. Тогда \[ R_{k, j} \;=\; \frac{4^{j}\,R_{k, j-1} - R_{k-1, j-1}}{4^{j} - 1},\qquad j = 1, 2, \ldots, k. \tag{7.12} \] Величина \(R_{k, j}\) имеет порядок точности \(2j + 2\).

Таблица Ромберга — треугольник значений; в правом нижнем углу лежит наиболее точное приближение. При \(k = 4\) (16 подотрезков) и \(j = 4\) достигается порядок 10 — на гладких функциях даёт машинную точность буквально за 32 вычисления \(f\).

Итоги занятия

Что нужно унести с занятия 7.
  1. Квадратурная формула — линейная комбинация значений \(f\) в узлах; веса — интегралы базисных многочленов Лагранжа.
  2. Простые формулы: средних точек и трапеций — точны для степени 1; Симпсона — для степени 3 (симметрия «дарит» лишний порядок).
  3. Составные формулы разбивают отрезок на \(N\) кусков и применяют простую квадратуру. Ошибка убывает как \(O(h^2)\) для трапеций и \(O(h^4)\) для Симпсона.
  4. Удвоение \(N\) уменьшает ошибку трапеций в 4 раза, Симпсона — в 16 раз.
  5. Ромберг — итеративная экстраполяция трапеций, поднимающая порядок по два за шаг: 2 → 4 → 6 → 8 → ...
