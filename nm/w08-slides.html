Разбор · Лабораторная 6, задача 2

Размер массива

В задаче \(N\le160\) узлов на грубой сетке, \(4N\le640\) на мелкой, а число шагов по времени \(n=\lceil aTN^2\rceil\) достигает \(4\cdot10^5\).

Неверная запись
int n = time_steps(N, a, T);
double u_tmp[n];      // n — число шагов
...
double u1[100], u2[100], u4[100];
transport_run(4*N, a, T, S, u0, u4);
Первый массив на стеке занимает до 3 МБ при стеке 1 МБ; во втором при \(N=160\) пишется 640 элементов в буфер на 100.
Верная запись
double u_new[640];    // по числу узлов
...
double u1[160], u2[320], u4[640];
transport_run(4*N, a, T, S, u0, u4);
Размер определяется наибольшей сеткой из условия.
Правило. Размер массива — число узлов наибольшей сетки, а не число шагов по времени. Массивы переменной длины double u[n] не входят в стандарт C++; выход за границу массива ничем не сообщается и портит соседние данные.

Вторая группа ошибок — в правой части схемы.

Разбор · Лабораторная 6, задача 2

Правая часть: инициализация и операция

Правая часть (6.22): \(f_i=-\dfrac ah\sum_jw_ju_{i+s_j}\), индекс берётся по модулю \(N\).

Неверная запись
double h, sum;          // h не задано
...
sum += S.w[j] + u[k];   // сложение
f[i] = -a / h * sum;
Значение h не определено; вес прибавляется к значению, а не умножается на него.
Верная запись
double h = 1.0 / N;
...
sum += S.w[j] * u[(i + S.s[j] + N) % N];
f[i] = -a / h * sum;
Слагаемое + N делает индекс неотрицательным при \(s_j\ge-N\).
Правило. Каждую переменную задают при объявлении. Остаток % от отрицательного числа в C++ отрицателен, поэтому к индексу прибавляют \(N\). Сборка с предупреждениями (-Wall) сообщает о неинициализированных переменных.

Модуль числа и узлы сетки

Неверная запись
double d = abs(u[i] - v[i]);
...
double x = a;
for (int i = 1; i < n; ++i) {
    x += h;               // накопление
    s += f(x);
}
В зависимости от подключённых заголовков abs может оказаться целочисленной и отбросить дробную часть; шаг \(h\) накапливает ошибку округления.
Верная запись
double d = std::fabs(u[i] - v[i]);
...
for (int i = 1; i < n; ++i)
    s += f(a + i * h);   // узел заново
Ошибка узла \(a+ih\) — одно округление, а не \(i\).
Правило. Для чисел с плавающей точкой — std::fabs. Узел сетки вычисляют по формуле \(x_i=a+ih\), а не прибавлением шага: при \(n=10^7\) накопленная ошибка в последнем узле достигает \(10^{-10}\).

Разбор · Лабораторная 7, задача 1

Адаптивный метод Симпсона

Неверная запись
double S  = simpson(f, a, b, n);
double Sl = simpson(f, a, (b-a)/2, n);
double D  = (S + Sl + Sr) / 15;
...
double w[3] = {-5.0/9, 8.0/9, 5.0/9};
\((b-a)/2\) — половина длины, а не середина; в оценке Рунге нужна разность; значения на концах вычисляются заново на каждом уровне; вес Гаусса со знаком минус.
Верная запись
double m = 0.5 * (a + b), fm = f(m);
double l = 0.5 * (a + m), fl = f(l);
double L = (m - a) / 6 * (fa + 4*fl + fm);
double D = (L + R - S) / 15;
...
const double w[3] = {5.0/9, 8.0/9, 5.0/9};
\(f_a,f_m,f_b\) передаются в рекурсию; новые значения — только \(f_l\), \(f_r\).
Правило. Середина отрезка — полусумма концов. Оценка ошибки по Рунге — разность двух приближений, делённая на \(2^p-1\). Значения функции, уже вычисленные на отрезке, передаются в рекурсию. Все веса формулы Гаусса положительны; на отрезке длины \(h\) они умножаются на \(h/2\).

Теперь — новая тема.

I. ПостановкаIIIIIIVVЧто такое метод Монте-Карло

Метод статистического моделирования

Метод Монте-Карло — способ вычислить величину, разыграв на компьютере случайный процесс, средний результат которого равен этой величине, и усреднив результаты многих независимых повторений.

Схема
  1. Построить случайную величину \(\eta\) с \(\mathsf E\eta=I\), где \(I\) — искомая величина. Часто процесс задан самой задачей, и его нужно лишь воспроизвести в программе.
  2. Получить \(N\) независимых реализаций \(\eta_1,\ldots,\eta_N\) с помощью генератора случайных чисел.
  3. Взять среднее \(\bar\eta=\frac1N\sum_i\eta_i\approx I\).
  4. Оценить погрешность по разбросу самих \(\eta_i\): она убывает как \(1/\sqrt N\) (§ 8.2).

Метод предложили С. Улам и Дж. фон Нейман в Лос-Аламосе в 1946–1949 гг. для расчётов переноса нейтронов; название, по казино в Монако, дал Н. Метрополис.

Первый такой опыт описал Бюффон.

I. ПостановкаIIIIIIVVПример: задача Бюффона

Пример: игла Бюффона (1777)

На плоскость, расчерченную параллельными прямыми с шагом \(a\), наугад бросают иглу длины \(l\le a\). Положение иглы: расстояние \(y\in[0,a/2]\) от её середины до ближайшей прямой и угол \(\theta\in[0,\pi]\). «Наугад» — \(y\) и \(\theta\) независимы и равномерны, совместная плотность \(\frac2a\cdot\frac1\pi\).

Игла пересекает прямую при \(y\le\frac l2\sin\theta\). Результат опыта: \(\eta=1\) при пересечении, \(\eta=0\) иначе. Его ожидание — интеграл плотности по благоприятной области:

\[\mathsf E\eta=\int_0^\pi\!\int_0^{\frac l2\sin\theta}\frac2{a\pi}\,dy\,d\theta=\frac l{a\pi}\int_0^\pi\sin\theta\,d\theta=\frac{2l}{\pi a}.\]

Доля пересечений \(\bar\eta_N\) за \(N\) бросков даёт оценку \(\pi\approx2l/(a\,\bar\eta_N)\).

Две стороны метода. Опыт воспроизводит физический процесс, а его средний результат есть интеграл.

III. МетодIIIIVV§8.1. Ожидание и дисперсия

Математическое ожидание и дисперсия

Пусть случайная величина \(X\) со значениями в \(D\) имеет плотность \(p(x)\ge0\), \(\int_Dp\,dx=1\).

математическое ожидание и дисперсия. Для функции \(g\) \[\mathsf E\,g(X)=\int_Dg(x)\,p(x)\,dx,\tag{8.1}\] \[\mathsf D\,g(X)=\mathsf E\bigl(g(X)-\mathsf E\,g(X)\bigr)^2=\mathsf E\,g(X)^2-\bigl(\mathsf E\,g(X)\bigr)^2.\tag{8.2}\] Величину \(\sigma=\sqrt{\mathsf D\,g(X)}\) называют среднеквадратичным отклонением.
ПримерДля \(X\), равномерно распределённой на \([0,1]\), и \(g(x)=x\): \(\mathsf EX=\tfrac12\), \(\mathsf EX^2=\tfrac13\), \(\mathsf DX=\tfrac13-\tfrac14=\tfrac1{12}\).

Формула (8.1) уже содержит интеграл. Осталось выбрать плотность.

III. МетодIIIIVV§8.1. Интеграл как среднее

Интеграл как математическое ожидание

Возьмём \(X\) равномерно распределённой в \(D\): \(p=1/|D|\), где \(|D|\) — объём области. По (8.1)

\[I=\int_Df\,dx=|D|\,\mathsf E f(X).\tag{8.3}\]
оценка Монте-Карло. Пусть \(X_1,\ldots,X_N\) — независимые точки, равномерно распределённые в \(D\). Оценкой Монте-Карло интеграла называют \[I_N=\frac{|D|}{N}\sum_{i=1}^Nf(X_i).\tag{8.4}\]

Оценка несмещённая: по линейности ожидания \(\mathsf EI_N=\frac{|D|}N\sum_i\mathsf Ef(X_i)=I\). В среднем по многим повторениям ошибка равна нулю, в отдельном расчёте она случайна.

Почему среднее значений в случайных точках приближает интеграл?

III. МетодIIIIVV§8.1. Почему среднее равно интегралу

Почему среднее приближает интеграл

Разобьём \([0,1]\) на \(M\) равных отрезков длины \(\Delta x=1/M\) с серединами \(x_k\). Из \(N\) равномерных точек в каждый отрезок попадает около \(N\Delta x\) точек, и значения \(f\) в них близки к \(f(x_k)\). Поэтому

\[\frac1N\sum_{i=1}^Nf(X_i)\;\approx\;\frac1N\sum_{k=1}^M(N\Delta x)\,f(x_k)\;=\;\sum_{k=1}^Mf(x_k)\,\Delta x\;\approx\;\int_0^1f\,dx.\]

Среднее по случайным точкам — это интегральная сумма, в которой каждый отрезок представлен числом попавших в него точек, пропорциональным его длине. При плотности \(p\) в отрезок попадает около \(Np(x_k)\Delta x\) точек — отсюда множитель \(p\) в (8.1).

Строго. Закон больших чисел: среднее независимых одинаково распределённых величин с конечным ожиданием сходится к этому ожиданию. С какой скоростью — ответ в § 8.2.

III. МетодIIIIVV§8.2. Дисперсия оценки

Дисперсия оценки

дисперсия оценки. Пусть \(\sigma^2=\mathsf Df(X)\) конечна. Тогда \[\mathsf DI_N=\frac{|D|^2\sigma^2}{N},\qquad\sqrt{\mathsf E(I_N-I)^2}=\frac{|D|\,\sigma}{\sqrt N}.\tag{8.5}\]

Доказательство.

  1. Для независимых величин перекрёстные члены \(\mathsf E\bigl(f(X_i)-\mathsf Ef\bigr)\bigl(f(X_j)-\mathsf Ef\bigr)\), \(i\ne j\), равны нулю, поэтому \(\mathsf D\sum_if(X_i)=N\sigma^2\).
  2. Множитель выносится в квадрате: \(\mathsf DI_N=(|D|/N)^2N\sigma^2\).
  3. Так как \(\mathsf EI_N=I\), то \(\mathsf E(I_N-I)^2=\mathsf DI_N\). \(\square\)

Главное — множитель \(N^{-1/2}\), в котором нет размерности \(d\). Размерность входит только через \(\sigma\).

Формула (8.5) говорит о средней ошибке. Что можно сказать об отдельном расчёте?

III. МетодIIIIVV§8.2. Правило трёх сигм

Ошибка отдельного расчёта

Гарантированную, но грубую оценку даёт неравенство Чебышёва: для любого \(k>0\)

\[\mathsf P\Bigl(|I_N-I|\ge k\,\frac{|D|\sigma}{\sqrt N}\Bigr)\le\frac1{k^2}.\tag{8.6}\]
центральная предельная теорема. При \(N\to\infty\) распределение величины \(\sqrt N\,(I_N-I)/(|D|\sigma)\) стремится к стандартному нормальному. В частности, при большом \(N\) \[\mathsf P\Bigl(|I_N-I|<3\,\frac{|D|\sigma}{\sqrt N}\Bigr)\approx0{,}997.\tag{8.7}\]

Это правило трёх сигм. Неравенство (8.6) при \(k=3\) гарантирует лишь вероятность \(8/9\), зато при любом \(N\).

Остаётся вопрос: откуда взять \(\sigma\)?

III. МетодIIIIVV§8.2. Оценка по выборке

Апостериорная оценка погрешности

\(\sigma\) оценивают по уже вычисленным значениям \(f_i=f(X_i)\):

\[s^2=\frac1{N-1}\sum_{i=1}^N\bigl(f_i-\bar f\bigr)^2,\quad\bar f=\frac1N\sum_{i=1}^Nf_i,\qquad I\approx I_N\pm3\,\frac{|D|\,s}{\sqrt N}.\tag{8.8}\]

Величину \(|D|s/\sqrt N\) называют стандартной ошибкой. По смыслу это то же, что правило Рунге в § 6.5 и § 7.3: ошибка оценивается по результатам самого расчёта, без производных и без точного ответа.

В программе вместе с \(\sum f_i\) накапливают \(\sum f_i^2\); при большом разбросе значений надёжнее алгоритм Уэлфорда из полусеместрового задания.

Порядок \(1/2\) — это медленно. Чтобы получить ещё один верный знак, \(N\) нужно увеличить в 100 раз.

Проверим оценку на числах.

IIIIII. Случайные числаIVV§8.4. Генераторы

Псевдослучайные числа

Компьютер детерминирован: числа получают рекуррентно, \(x_{k+1}=\Phi(x_k)\), \(u_k=x_k/m\in[0,1)\). Начальное значение \(x_0\) называют зерном.

Требования: равномерность; независимость соседних чисел (пары и тройки равномерно заполняют квадрат и куб); большой период; скорость; воспроизводимость по зерну.

линейный конгруэнтный генератор. Для целых \(m>0\), \(0\lt a\lt m\), \(0\le c\lt m\) \[x_{k+1}=(a\,x_k+c)\bmod m,\qquad u_k=x_k/m.\tag{8.10}\] Период не превосходит \(m\). Пример: \(a=37\), \(c=1\), \(m=256\), \(x_0=1\) дают \(38,127,92,\ldots\) с периодом 256.

Каждая координата распределена равномерно. Посмотрим на пары.

IIIIII. Случайные числаIVV§8.4. Решётка

Пары лежат на прямых

Точки \((u_k,u_{k+1})\) линейного генератора лежат на небольшом числе прямых, в размерности \(d\) — на не более чем \((d!\,m)^{1/d}\) гиперплоскостях (теорема Марсальи). Генератор RANDU (\(a=2^{16}+3\), \(c=0\), \(m=2^{31}\)):

\[a^2=2^{32}+6\cdot2^{16}+9\equiv6a-9\pmod{2^{31}}\ \Rightarrow\ x_{k+2}\equiv6x_{k+1}-9x_k,\]

и все тройки лежат на 15 плоскостях единичного куба.

Какие генераторы применять на практике?

IIIIII. Случайные числаIVV§8.4. На практике

Генератор в программе

Применяют генераторы с проверенными многомерными свойствами: вихрь Мерсенна (std::mt19937_64), семейства xoshiro и PCG. В лабораторной работе — splitmix64:

unsigned long long s;                       // состояние, s = зерно
double uniform() {                           // число из [0, 1)
    unsigned long long z = (s += 0x9E3779B97F4A7C15ULL);
    z = (z ^ (z >> 30)) * 0xBF58476D1CE4E5B9ULL;
    z = (z ^ (z >> 27)) * 0x94D049BB133111EBULL;
    z ^= z >> 31;
    return (z >> 11) * (1.0 / 9007199254740992.0);   // 53 бита
}
Функция rand() для расчётов непригодна. Стандарт гарантирует лишь \(\mathtt{RAND\_MAX}\ge32767\); младшие биты у многих реализаций плохо перемешаны, а rand() % n вносит смещение. При параллельном счёте каждому потоку нужен свой поток чисел.

Генератор даёт равномерные числа. А физике нужны другие распределения.

IIIIII. Случайные числаIVV§8.5. Обратная функция

Метод обратной функции

метод обратной функции. Пусть \(F\) — непрерывная строго возрастающая функция распределения, \(\xi\) равномерно распределена на \((0,1)\). Тогда величина \[X=F^{-1}(\xi)\tag{8.11}\] имеет функцию распределения \(F\).

Доказательство. Неравенства \(F^{-1}(\xi)\le x\) и \(\xi\le F(x)\) равносильны, поэтому \(\mathsf P(X\le x)=\mathsf P(\xi\le F(x))=F(x)\). \(\square\)

Пробег частицы: \(F(s)=1-e^{-\Sigma s}\). Косинус направления после изотропного рассеяния равномерен на \([-1,1]\) (теорема Архимеда о поясе сферы). Отсюда

\[s=-\frac{\ln(1-\xi)}{\Sigma},\qquad\mu=2\xi-1.\tag{8.12}\]

А если обратную функцию выписать нельзя?

IIIIII. Случайные числаIVV§8.5. Метод отбора

Метод отбора

Пусть плотность \(p\) ограничена: \(p(x)\le M g(x)\), где \(g\) — плотность, которую моделировать легко.

Алгоритм
  1. Взять \(Y\) с плотностью \(g\) и равномерное \(\xi\).
  2. Если \(\xi\le p(Y)/(Mg(Y))\), принять \(X=Y\); иначе повторить.

Принятые значения имеют плотность \(p\), а доля принятых равна \(1/M\).

ПримерРавномерная точка в круге получается из равномерной точки в описанном квадрате: точки вне круга отбрасываются. Доля принятых равна \(\pi/4\).

Нормальное распределение удобнее получать преобразованием Бокса — Мюллера, переводящим два равномерных числа в два независимых нормальных.

Случайные точки получать умеем. Вернёмся к главной проблеме — медленной сходимости.

IIIIIIIV. ДисперсияV§8.6. Выборка по значимости

Метод 1. Выборка по значимости

Постановка. Ошибка равна \(\sigma/\sqrt N\): уменьшить \(\sigma\) в 10 раз — то же, что увеличить \(N\) в 100 раз. Равномерные точки тратятся одинаково там, где \(f\) велика, и там, где она почти нуль.

Формула. Для плотности \(p>0\) там, где \(f\ne0\): \(I=\int\frac fp\,p\,dx=\mathsf E\frac{f(X)}{p(X)}\), \(X\sim p\), и

\[I_N^{(p)}=\frac1N\sum_{i=1}^N\frac{f(X_i)}{p(X_i)},\qquad X_i\sim p,\tag{8.13}\]
\[\sigma_p^2=\int_D\frac{f^2}{p}\,dx-I^2.\tag{8.14}\]

При \(f\ge0\) и \(p=f/I\) дисперсия равна нулю. Такую плотность построить нельзя, она содержит искомый \(I\), но вывод ясен: \(p\) должна повторять форму \(f\) и моделироваться по (8.11).

Применим к функции с пиком.

Плотность не должна убывать быстрее функции. Иначе интеграл в (8.14) велик или бесконечен: редкие точки с огромным весом \(f/p\) делают оценку неустойчивой, а выборочное \(s\) занижает ошибку.

Второй приём использует не плотность, а известный интеграл.

IIIIIIIV. ДисперсияV§8.6. Контрольная переменная

Метод 2. Контрольная переменная

Постановка. Известна функция \(g\), близкая к \(f\), интеграл которой \(J=\int_Dg\,dx\) вычисляется точно.

Формула. Для любого числа \(c\)

\[I=\int_D(f-c\,g)\,dx+c\,J,\qquad c_{\text{опт}}=\frac{\operatorname{cov}(f(X),g(X))}{\mathsf Dg(X)},\tag{8.15}\]

и методом Монте-Карло оценивают только интеграл разности. Её дисперсия \(\mathsf Df-2c\operatorname{cov}(f,g)+c^2\mathsf Dg\) минимальна при \(c_{\text{опт}}\) и равна \(\mathsf Df\,(1-\rho^2)\), где \(\rho\) — коэффициент корреляции.

Пример E. \(f=e^x\), \(g=1+x\), \(J=1{,}5\)\(\operatorname{cov}(e^X,X)=1-\tfrac12(e-1)=0{,}1409\), \(\mathsf DX=\tfrac1{12}\), откуда \(c_{\text{опт}}=1{,}690\), \(\rho=0{,}992\). Дисперсия уменьшается в \(1/(1-\rho^2)\approx61\) раз; при \(c=1\) — только в \(5{,}5\) раза.

Другие приёмы: антитетические пары \(\xi\) и \(1-\xi\); расслоение области на части.

Соберём сведения о методе.

IIIIIIIV. ДисперсияV§8.6. Паспорт

Паспорт: метод Монте-Карло для интеграла

Входпрограмма, вычисляющая \(f\) в любой точке; генератор псевдослучайных чисел
Хорошобольшая размерность (\(d>2p\)); сложная область (достаточно проверять принадлежность точки); разрывные функции; задачи, которые сами являются случайными процессами
Плохомалая размерность и гладкая функция; функция сосредоточена в малой части области; нужна высокая точность

Можно ли улучшить сам показатель \(1/2\)? Для этого придётся отказаться от случайности.

IIIIIIIV. ДисперсияV§8.7. Квазислучайные точки

Квазислучайные последовательности

последовательность ван дер Корпута. Для номера \(i=\sum_ja_jb^j\) в системе с основанием \(b\) \[\varphi_b(i)=\sum_ja_j\,b^{-j-1}.\tag{8.16}\] Точки Холтона: \(\bigl(\varphi_2(i),\varphi_3(i),\varphi_5(i),\ldots\bigr)\).

При \(b=2\): \(\tfrac12,\tfrac14,\tfrac34,\tfrac18,\tfrac58,\ldots\) — каждая точка попадает в середину самого большого промежутка. Ошибка порядка \((\ln N)^d/N\) (неравенство Коксмы — Хлавки).

IIIIIIIVV. Перенос§8.8. Задача о пластине

Прохождение частиц через пластину

Дано слой \(0\le x\le L\); на границу \(x=0\) по нормали падает пучок. Пробег до столкновения экспоненциален с параметром \(\Sigma\) (\(1/\Sigma\) — средний пробег). При столкновении частица с вероятностью \(c\) рассеивается изотропно, иначе поглощается.
Найти вероятности прохождения \(P_t\), отражения \(P_r\), поглощения \(P_a\) с оценкой погрешности.

Без рассеяния \(P_t=e^{-\Sigma L}\) — закон ослабления пучка. С рассеянием задача описывается уравнением переноса, и аналитического решения нет.

Путь с \(k\) столкновениями задаётся \(2k+1\) случайными числами: \(P_t\) есть интеграл неограниченной размерности.

Метод Монте-Карло моделирует процесс непосредственно.

IIIIIIIVV. Перенос§8.8. Алгоритм

История одной частицы

Алгоритм
  1. Положить \(x=0\), \(\mu=1\) (координата и косинус направления).
  2. Разыграть пробег \(s\) по (8.12) и сдвинуться: \(x\leftarrow x+\mu s\).
  3. Если \(x\lt0\), частица отражена; если \(x>L\), прошла. История окончена.
  4. Иначе столкновение. Если \(\xi\lt c\), разыграть \(\mu=2\xi'-1\) и перейти к шагу 2; иначе частица поглощена.

Повторив историю \(N\) раз, получаем доли \(P_t\), \(P_r\), \(P_a\). Каждая есть среднее величины, равной 0 или 1, поэтому по (8.5)

\[\sigma_P=\sqrt{\frac{P(1-P)}{N}}.\tag{8.17}\]
