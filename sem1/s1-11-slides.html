§11 · Семестр 1

Линейные схемы с положительными коэффициентами

Консервативность, монотонность, принцип максимума, устойчивость в \(C\) и TVD — что из этого следует из знака коэффициентов.

Определение · Консервативность · Монотонность · Устойчивость · TVD · Итог

Схема \(y_i^{n+1} = \sum_k a_k\, y_{i+k}^n\) с постоянными коэффициентами.

§11.1 · Определение

Схема с положительными коэффициентами

Определение. Схема \[ y_i^{n+1} = \sum_{k\in S} a_k\, y_{i+k}^n \] называется схемой с положительными коэффициентами, если \(a_k \ge 0\) при всех \(k\).
ДаПротивопоточная схема: \(a_0 = 1 - r\), \(a_{-1} = r\) при \(0 \le r \le 1\). Схема Лакса–Фридрихса при \(|r| \le 1\).
НетСхема Лакса–Вендроффа: \(a_{+1} = r(r-1)/2 < 0\) при \(0 < r < 1\).

Значение \(y_i^{n+1}\) — взвешенная сумма соседних значений; вопрос в том, могут ли веса быть отрицательными.

§11.2 · Теорема 1

Консервативность определяется суммой коэффициентов

Теорема 1. Схема записывается в консервативной форме (8.2) с линейным потоком тогда и только тогда, когда \[ \sum_k a_k = 1 . \]
Почему необходимоВ консервативной схеме потоки сокращаются, и сумма \(\sum_i y_i\) не меняется; а по схеме она умножается на \(\sum_k a_k\).
Почему достаточноПри \(\sum a_k = 1\) приращение \(y_i^{n+1} - y_i^n\) раскладывается по разностям соседних значений, и его можно записать как разность потоков.

Знак коэффициентов здесь не важен: схема Лакса–Вендроффа консервативна.

§11.3 · Теорема 2

Монотонность и принцип максимума

Теорема 2. Схема монотонна (оператор перехода не убывает по каждому аргументу) \(\iff a_k \ge 0\). При \(\sum a_k = 1\) это равносильно принципу максимума: \[ \min y^n \le y_i^{n+1} \le \max y^n . \]
Если \(a_k \ge 0\)Новое значение — выпуклая комбинация старых и лежит между их минимумом и максимумом.
Если \(a_m < 0\)Возьмём единицу в узле \(i + m\) и нули в остальных: \(y_i^{n+1} = a_m < 0\) — появился новый минимум.

Отрицательный коэффициент — это источник новых экстремумов, то есть осцилляций.

§11.4 · Теорема 3

Устойчивость в равномерной норме

Теорема 3. Пусть \(\sum_k a_k = 1\). Тогда \(\max_i |y_i^{n+1}| \le \max_i |y_i^n|\) для всех \(y^n\) \(\iff a_k \ge 0\).
ИдеяНаибольший рост максимума за шаг равен \(\sum_k |a_k|\) (берём \(y_{i+k} = \operatorname{sign} a_k\)). При \(\sum a_k = 1\) величина \(\sum |a_k|\) равна единице только при неотрицательных \(a_k\).

Устойчивость доказывается одним неравенством, без гармоник, и переносится на переменные коэффициенты \(a_{ik} \ge 0\), \(\sum_k a_{ik} = 1\). Вместе с аппроксимацией — сходимость по теореме Лакса (§3).

§11.5 · Теорема 4

TVD — то же самое условие

Теорема 4. Пусть \(\sum_k a_k = 1\). Схема является TVD \(\iff a_k \ge 0\).
Достаточность (§8)Разности нового слоя — та же комбинация разностей старого; неравенство треугольника и сумма по \(i\).
Необходимость (§10)Один шаг по ступеньке: \(\mathrm{TV}(y^1) = \sum |a_k| > 1 = \mathrm{TV}(y^0)\), если есть отрицательный коэффициент.
§11.6 · Итог

Для линейных схем все пять свойств равносильны

Следствие (§9)По теореме Годунова такие схемы имеют только первый порядок аппроксимации.
ВыходНелинейные схемы (ограничители потока, §10) или искусственная вязкость в схеме второго порядка (§13).

Далее — газовая динамика: схема «крест» второго порядка и искусственная вязкость.
