§5а.1 · Границы метода гармоник

Где метод гармоник не может быть даже сформулирован

Гармоника \(e^{i\alpha m}\) — собственная функция оператора перехода лишь потому, что он перестановочен со сдвигом по сетке: коэффициенты одинаковы во всех узлах, границ нет. Стоит нарушить это — и подстановки (5.1) больше нет.

коэффициенты
\(u_t + a(x)\,u_x = 0\), \(\;u_t = (k(x)u_x)_x\)
Коэффициенты схемы зависят от номера узла: оператор перехода не перестановочен со сдвигом.
границы
\(u(0,t) = u(l,t) = 0\)
Гармоника не обращается в нуль на концах; краевые условия метод не видит.
сетка
Неравномерный шаг \(h_i\)
Схема не инвариантна относительно сдвига.
и главное
Условие Неймана — только необходимое
Для систем и многослойных схем \(|\lambda| \le 1\) может выполняться при неустойчивости.

Нужен метод, который даёт достаточные условия и не требует ни постоянных коэффициентов, ни отсутствия границ.

§5а.1 · Что даёт энергетический метод

Результат метода — априорная оценка, то есть устойчивость с явной постоянной

Энергетический метод доказывает неравенство вида

\[ \|y^{n+1}\| \le \|y^{n}\| \qquad\text{или}\qquad \|y^{n}\|^2 \le \|y^{0}\|^2 + C\sum_{k=0}^{n-1}\tau\,\|\varphi^{k}\|^2, \tag{5а.1} \]

полученное до и без решения задачи, из одной лишь структуры схемы. Это априорная оценка; она есть в точности оценка (2.14) Определения 4 §2 — устойчивость с явно указанной нормой и постоянной.

Следствие Условия, при которых доказана (5а.1), — достаточные условия устойчивости. Метод гармоник давал необходимые; вместе они зажимают ответ с двух сторон.
Цена Для каждой схемы нужно провести своё алгебраическое тождество. Зато метод работает с границами, переменными коэффициентами и нелинейностью.

Само тождество — сеточная копия одной выкладки из теории уравнений в частных производных. Проведём её сначала для уравнения.

§5а.2 · Дифференциальный прототип

Закон сохранения энергии для уравнения переноса

Периодическая задача \(u_t + a u_x = 0\), \(u(0,t) = u(l,t)\), \(a = \mathrm{const}\) (5а.2). Умножим уравнение на \(u\) и проинтегрируем по \(x\):

\[ \int_0^l u\,u_t\,dx = \frac{1}{2}\frac{d}{dt}\int_0^l u^2\,dx, \qquad \int_0^l a\,u\,u_x\,dx = \frac{a}{2}\int_0^l \frac{\partial}{\partial x}(u^2)\,dx = \frac{a}{2}\Bigl[u^2(l,t) - u^2(0,t)\Bigr] = 0. \]

Обозначив \(E(t) = \int_0^l u^2\,dx = \|u(\cdot,t)\|_{L_2}^2\), получаем

\[ \frac{dE}{dt} = 0, \qquad \|u(\cdot,t)\|_{L_2} = \|u(\cdot,0)\|_{L_2}. \tag{5а.3} \]
Где вошло краевое условие В одном месте: внеинтегральный член \(\frac{a}{2}[u^2]_0^l\) обратился в нуль благодаря периодичности. Всё остальное — тождества.
Термин \(E(t)\) — энергия решения: для волнового уравнения такая же выкладка даёт сохранение механической энергии струны \(\int(u_t^2 + c^2u_x^2)\,dx\).

Равенство (5а.3) — априорная оценка: норму решения мы знаем, не решая уравнения. Для уравнения теплопроводности понадобится ещё один шаг.

§5а.2 · Дифференциальный прототип

Уравнение теплопроводности: энергия убывает

Для \(u_t = \nu u_{xx}\), \(u(0,t) = u(l,t) = 0\), та же выкладка требует интегрирования по частям:

\[ \frac{1}{2}\frac{d}{dt}\int_0^l u^2\,dx = \nu\int_0^l u\,u_{xx}\,dx = \nu\Bigl[u\,u_x\Bigr]_0^l - \nu\int_0^l u_x^2\,dx = -\,\nu\int_0^l u_x^2\,dx \le 0, \tag{5а.4} \]

откуда \(\|u(\cdot,t)\|_{L_2} \le \|u(\cdot,0)\|_{L_2}\): энергия не сохраняется, а диссипирует. Внеинтегральный член снова исчез благодаря краевым условиям.

1
Умножение на решение и интегрирование
на сетке — скалярное произведение сеточных функций (§5а.3)
2
Интегрирование по частям
на сетке — суммирование по частям, разностные формулы Грина (§5а.5)
3
Граничные члены обращаются в нуль
на сетке — за счёт значений в граничных узлах или периодичности

Энергетический метод для разностных схем — это ровно эти три действия в сеточных терминах. Построим их по порядку.

§5а.3 · Обозначения

Обозначения А. А. Самарского для разностных отношений

Сетка \(\omega_h = \{x_i = ih,\ i = \overline{0, N},\ h = l/N\}\), пространство \(H\) сеточных функций \(y = \{y_i\}\) (§1.10). Разности вперёд, назад, центральная и вторая:

\[ y_{x,i} = \frac{y_{i+1} - y_i}{h}, \qquad y_{\bar x,i} = \frac{y_i - y_{i-1}}{h}, \qquad y_{\mathring{x},i} = \frac{y_{i+1} - y_{i-1}}{2h}, \]
\[ y_{\bar x x,i} = \frac{y_{i+1} - 2y_i + y_{i-1}}{h^2}. \tag{5а.5} \]

Индекс узла при записи операторов опускается: \(y_{\bar x x} = (y_{\bar x})_x\); оператор второй разности \(\Lambda y = y_{\bar x x}\). По времени: \(y = y^n\), \(\hat y = y^{n+1}\) и

\[ y_t = \frac{\hat y - y}{\tau}, \qquad y^{(\sigma)} = \sigma\hat y + (1 - \sigma)\,y, \qquad y^{(1/2)} = \frac{\hat y + y}{2}. \tag{5а.6} \]

Первое из (5а.6) — разностная производная по времени, второе — взвешенная комбинация слоёв, третье — полусумма, которая сыграет главную роль в основной теореме.

§5а.3 · Скалярное произведение

Скалярное произведение сеточных функций

Пусть \(H\) — пространство сеточных функций на \(\omega_h\) с периодическим условием \(y_0 = y_N\). Положим \[ (y, v) = \sum_{i=1}^{N} h\,y_i v_i, \qquad \|y\| = \sqrt{(y, y)}. \tag{5а.7} \] Для краевой задачи первого рода рассматривается \(H_0\) — функции с \(y_0 = y_N = 0\); сумма берётся по внутренним узлам.

Форма (5а.7) билинейна, симметрична, \((y, y) > 0\) при \(y \ne 0\) — это скалярное произведение; \(\|y\|\) — сеточная норма \(L_2\) из (1.14). Выполняется неравенство Коши–Буняковского \(|(y, v)| \le \|y\|\,\|v\|.\)

Зачем множитель \(h\) Сумма \(\sum h\,y_i v_i\) — интегральная сумма для \(\int_0^l yv\,dx\): она имеет предел при \(h \to 0\).
Почему не норма \(C\) \(\sqrt{h}\,\|y\|_C \le \|y\| \le \sqrt{l}\,\|y\|_C\): постоянная \(\sqrt{h}\) стремится к нулю, оценка в \(L_2\) не влечёт равномерной оценки в \(C\). В \(L_2\) есть скалярное произведение — в \(C\) нет.

Скалярное произведение позволяет говорить о сопряжённых, самосопряжённых и положительных операторах — языке, на котором формулируются условия устойчивости.

§5а.4 · Операторы

Сопряжённый, самосопряжённый, положительный оператор

Оператор \(A^*\) называется сопряжённым к \(A\colon H \to H\), если \((Ay, v) = (y, A^*v)\) при всех \(y, v \in H\). Оператор самосопряжён, если \(A^* = A\). Самосопряжённый оператор положителен, \(A > 0\), если \((Ay, y) > 0\) при всех \(y \ne 0\), и неотрицателен, \(A \ge 0\), если \((Ay, y) \ge 0\). Для самосопряжённых операторов запись \(A \ge B\) означает \(A - B \ge 0\).
На языке матриц \(H\) конечномерно, скалярное произведение (5а.7) — с одинаковым весом \(h\). Самосопряжённость — симметричность матрицы, положительность — положительная определённость: вещественный спектр, ортогональный базис собственных функций.
Операторное неравенство \(A \ge B\) ⟺ \((Ay, y) \ge (By, y)\) при всех \(y\). Условия устойчивости будут формулироваться именно так — как неравенства между операторами схемы, из которых затем извлекаются ограничения на \(\tau\) и \(h\).

Самосопряжённый положительный оператор порождает собственное скалярное произведение — и собственную норму.

§5а.4 · Энергетическая норма

Энергетическая норма, кососимметричные операторы, норма оператора

Пусть \(A = A^* > 0\). Форма \((Ay, v)\) есть скалярное произведение в \(H\); порождённая ею норма \[ \|y\|_A = \sqrt{(Ay, y)} \tag{5а.8} \] называется энергетической нормой; пространство \(H\) с этой нормой обозначается \(H_A\).

Для \(A = -\Lambda\): \(\|y\|_A^2 = \sum h\,y_{\bar x,i}^2\) — сеточный аналог \(\int u_x^2\,dx\), «энергии» из (5а.4).

Кососимметричный оператор \(A^* = -A\). Тогда \((Ay, y) = -(Ay, y)\), то есть \((Ay, y) = 0\): такой оператор не меняет энергии — как член \(a u_x\) в (5а.3).
Норма оператора \(\|A\| = \sup_{y \ne 0}\|Ay\|/\|y\|\). Для \(A = A^* \ge 0\) по неравенству Коши–Буняковского \[ (Ay, y) \le \|A\|\,\|y\|^2, \quad\text{то есть}\quad A \le \|A\|\,E. \tag{5а.9} \]

Неравенство (5а.9) — мост от операторных условий к условиям на \(\tau\) и \(h\). Теперь второе действие прототипа: суммирование по частям.

§5а.5 · Суммирование по частям

Лемма 1: формула суммирования по частям

Для любых сеточных функций \(y\), \(v\), заданных на \(\omega_h\), \[ \sum_{i=1}^{N} h\,y_i\,v_{\bar x,i} = -\sum_{i=0}^{N-1} h\,y_{x,i}\,v_i + y_N v_N - y_0 v_0. \tag{5а.10} \]

Доказательство. Раскрываем \(v_{\bar x}\) и разбиваем сумму:

\[ \sum_{i=1}^{N} y_i(v_i - v_{i-1}) = \sum_{i=1}^{N} y_i v_i - \sum_{j=0}^{N-1} y_{j+1} v_j. \]

В первой сумме отделяем член \(i = N\) и добавляем-вычитаем член \(j = 0\); разность сумм даёт \(-\sum_{j=0}^{N-1}(y_{j+1} - y_j)v_j = -\sum h\,y_{x,j}v_j\). □

Сравните \[ \int_0^l y\,v'\,dx = -\int_0^l y'\,v\,dx + \bigl[y v\bigr]_0^l. \] Разности вместо производных, \(y_N v_N - y_0 v_0\) вместо внеинтегрального члена.
Историческая справка Это преобразование Абеля (1826) — тот же приём, что в признаке Дирихле для рядов.

Из леммы вытекают три следствия, которыми будем пользоваться постоянно.

§5а.5 · Следствие 1

Первая разностная формула Грина: \(-\Lambda\) самосопряжён и положителен на \(H_0\)

Пусть \(y, v \in H_0\): \(y_0 = y_N = v_0 = v_N = 0\). Применим (5а.10) к \(w = y_{\bar x}\) и \(v\); граничные члены исчезают, так как \(v_0 = v_N = 0\):

\[ (\Lambda y, v) = \sum_{i=1}^{N-1} h\,y_{\bar x x,i}\,v_i = -\sum_{i=1}^{N} h\,y_{\bar x,i}\,v_{\bar x,i} \equiv -\,(y_{\bar x}, v_{\bar x}]. \tag{5а.11} \]
Самосопряжённость Правая часть (5а.11) симметрична относительно \(y\) и \(v\), поэтому \((\Lambda y, v) = (\Lambda v, y)\): оператор \(\Lambda\) самосопряжён на \(H_0\).
Положительность При \(v = y\): \[ (-\Lambda y, y) = \sum_{i=1}^{N} h\,y_{\bar x,i}^2 \ge 0, \tag{5а.12} \] равенство лишь при \(y = \mathrm{const}\), а с \(y_0 = 0\) — при \(y \equiv 0\).

Итак, \(A = -\Lambda\) — самосопряжённый положительный оператор на \(H_0\), и \(\|y\|_A^2 = (y_{\bar x}, y_{\bar x}]\). Краевые условия вошли именно здесь.

§5а.5 · Следствия 2 и 3

Периодическая сетка; оценка нормы \(-\Lambda\)

На периодической сетке (\(y_{i+N} = y_i\)) граничные члены (5а.10) взаимно уничтожаются; (5а.11)–(5а.12) верны без условий на концах, но \(-\Lambda \ge 0\) уже не \(> 0\) (постоянная функция).

Центральная разность \(Dy = y_{\mathring x}\):

\[ (y_{\mathring x}, y) = \frac{1}{2}\Bigl(\sum_{i=1}^{N} y_i y_{i+1} - \sum_{i=1}^{N} y_i y_{i-1}\Bigr) = 0, \tag{5а.13} \]

и \(D^* = -D\): центральная разность на периодической сетке кососимметрична — двойник \(\int u\,u_x\,dx = 0\).

Из (5а.12) и \((a - b)^2 \le 2a^2 + 2b^2\):

\[ (-\Lambda y, y) \le \frac{2}{h^2}\sum_{i=1}^{N} h\,(y_i^2 + y_{i-1}^2) \le \frac{4}{h^2}\,\|y\|^2, \]
\[ \text{то есть}\qquad -\Lambda \le \frac{4}{h^2}\,E. \tag{5а.14} \]
Точное значение Собственные числа \(-\Lambda\) на \(H_0\): \(\frac{4}{h^2}\sin^2\frac{k\pi h}{2l}\); наибольшее — \(\frac{4}{h^2}\cos^2\frac{\pi h}{2l} < \frac{4}{h^2}\). Оценка точна по порядку.

Инструменты собраны. Первый пример — простейший, где оценка получается в две строки и сравнима с §5.

§5а.6 · Пример 1

Пример 1: схема «уголок» в норме \(L_2\)

Периодическая сетка, \(\hat y_i = (1 - r)\,y_i + r\,y_{i-1}\), \(r = a\tau/h\), \(0 \le r \le 1\) (5а.15). Неравенство выпуклости: при \(\alpha, \beta \ge 0\), \(\alpha + \beta = 1\),

\[ (\alpha p + \beta q)^2 \le \alpha p^2 + \beta q^2 \qquad\bigl(\text{разность равна } \alpha\beta(p - q)^2 \ge 0\bigr). \tag{5а.16} \]

С \(\alpha = 1 - r\), \(\beta = r\): \(\hat y_i^2 \le (1 - r)y_i^2 + r\,y_{i-1}^2\). Умножаем на \(h\), суммируем; на периодической сетке \(\sum h\,y_{i-1}^2 = \|y\|^2\):

\[ \|\hat y\|^2 \le (1 - r)\|y\|^2 + r\|y\|^2 = \|y\|^2 \quad\Rightarrow\quad \|y^n\| \le \|y^0\|. \tag{5а.17} \]
Сопоставление с §5 Достаточное условие \(0 \le r \le 1\) совпало с необходимым условием Неймана: для «уголка» спектральный метод точен.
Где использовано \(r \le 1\) В (5а.16): оба коэффициента \(1 - r\), \(r\) должны быть неотрицательны. При \(r > 1\) приём не проходит — и схема действительно неустойчива.
Заметьте Постоянство \(a\) нигде не использовалось — см. Пример 4.

Чтобы формулировать условия устойчивости сразу для всех двухслойных схем, нужна единая запись.

§5а.7 · Каноническая форма

Каноническая форма двухслойной схемы

Двухслойная схема записана в канонической форме, если она имеет вид \[ B\,\frac{y^{n+1} - y^{n}}{\tau} + A\,y^{n} = \varphi^{n}, \qquad\text{в обозначениях (5а.6):}\quad B y_t + A y = \varphi, \tag{5а.18} \] где \(A, B\colon H \to H\) — линейные операторы, \(\varphi^n \in H\), и оператор \(B\) обратим.

Обратимость \(B\) — разрешимость: \(y^{n+1} = y^n - \tau B^{-1}(Ay^n - \varphi^n)\). Оператор \(B\) описывает неявную часть, \(A\) — пространственный оператор.

СхемаЗапись\(A\)\(B\)Свойства \(A\)
Явная, теплопроводность\(y_t = \Lambda y + \varphi\) на \(H_0\)\(-\Lambda\)\(E\)\(A = A^* > 0\)
С весами \(\sigma\)\(y_t = \Lambda y^{(\sigma)} + \varphi\), \(y^{(\sigma)} = y + \sigma\tau y_t\)\(-\Lambda\)\(E + \sigma\tau A\)\(A = A^* > 0\)
«Уголок», перенос\(y_t + a\,y_{\bar x} = 0\)\(a\,\partial_{\bar x}\)\(E\)не самосопряжён

Для схем с \(A = A^* > 0\) есть общая теорема; для остальных — прямой приём, как в Примере 1.

§5а.8 · Основная теорема

Теорема Самарского об устойчивости в \(H_A\)

Пусть в схеме (5а.18) с \(\varphi \equiv 0\) оператор \(A\) самосопряжён и положителен, \(A = A^* > 0\), а оператор \(B\) обратим и удовлетворяет операторному неравенству \[ B \ge \frac{\tau}{2}\,A, \qquad\text{то есть}\qquad (By, y) \ge \frac{\tau}{2}\,(Ay, y)\ \ \text{при всех } y \in H. \tag{5а.19} \] Тогда \[ \|y^{n+1}\|_A \le \|y^{n}\|_A, \qquad n = 0, 1, \dots, \qquad\text{и, следовательно,}\qquad \|y^{n}\|_A \le \|y^{0}\|_A. \tag{5а.20} \]
Что утверждается Устойчивость по начальным данным в энергетической норме с постоянной \(C = 1\), не зависящей от \(\tau\), \(h\) и числа шагов.
Обратите внимание От \(B\) не требуется ни самосопряжённости, ни положительности — только обратимость и одно неравенство (5а.19).

Доказательство — четыре этапа; после каждого отмечаем, какая гипотеза использована.

§5а.8 · Доказательство, этапы 1–2

Этап 1: полусумма слоёв. Этап 2: умножение на \(2\tau y_t\)

Этап 1 · тождественное преобразование, гипотезы не используются

Выразим \(y\) через полусумму \(y^{(1/2)} = \frac12(\hat y + y)\) и разностную производную \(y_t = \frac1\tau(\hat y - y)\):

\[ y = y^{(1/2)} - \frac{\tau}{2}\,y_t \qquad\Bigl(\text{проверка: } \tfrac12(\hat y + y) - \tfrac12(\hat y - y) = y\Bigr). \]

Подставим в \(By_t + Ay = 0\) и сгруппируем:

\[ \Bigl(B - \frac{\tau}{2}A\Bigr)y_t + A\,y^{(1/2)} = 0. \tag{5а.21} \]
Этап 2 · сеточное «умножение на решение и интегрирование»

Умножим (5а.21) скалярно на \(2\tau y_t\); множитель \(2\tau\) подобран так, чтобы второе слагаемое стало разностью энергий:

\[ 2\tau\Bigl(\bigl(B - \tfrac{\tau}{2}A\bigr)y_t,\ y_t\Bigr) + 2\tau\bigl(A y^{(1/2)},\ y_t\bigr) = 0. \tag{5а.22} \]

Осталось увидеть, что второе слагаемое — это \(\|\hat y\|_A^2 - \|y\|_A^2\).

§5а.8 · Доказательство, этапы 3–4

Этап 3: разность энергий. Этап 4: энергетическое тождество

Этап 3 · используется A = A*
\[ 2\tau\bigl(A y^{(1/2)}, y_t\bigr) = \bigl(A(\hat y + y),\ \hat y - y\bigr) = (A\hat y, \hat y) - \underbrace{(A\hat y, y) + (Ay, \hat y)}_{=\,0\ \text{по самосопряжённости}} - (Ay, y) = \|\hat y\|_A^2 - \|y\|_A^2. \tag{5а.23} \]
Этап 4 · используется B ≥ (τ/2)A, затем A > 0

Из (5а.22) и (5а.23) — точное энергетическое тождество:

\[ \|\hat y\|_A^2 = \|y\|_A^2 - 2\tau\Bigl(\bigl(B - \tfrac{\tau}{2}A\bigr)y_t,\ y_t\Bigr). \tag{5а.24} \]

По (5а.19) вычитаемое неотрицательно, значит \(\|\hat y\|_A^2 \le \|y\|_A^2\). Положительность \(A\) гарантирует, что \(\|\cdot\|_A\) — норма, и извлечение корня даёт (5а.20). □

Смысл тождества Энергия на новом слое = энергия на старом − диссипация. Условие \(B \ge \frac{\tau}{2}A\) означает: схема не производит энергии. Для \(B = E\) это ограничение на \(\tau\); слагаемое \(\sigma\tau A\) в \(B\) неявных схем «оплачивает» его при любом \(\tau\).

Одна теорема объясняет и условную устойчивость явных схем, и безусловную — неявных. Есть и обратное утверждение.

§5а.8 · Теорема 2

Устойчивость в \(H_B\); необходимость условия (5а.19)

Пусть \(A = A^* > 0\) и \(B = B^* > 0\). Тогда условие (5а.19) необходимо и достаточно для оценки (5а.20); при его выполнении справедлива также оценка \(\|y^{n+1}\|_B \le \|y^{n}\|_B\). В частности, для явных схем (\(B = E\)) условие \(E \ge \frac{\tau}{2}A\) равносильно оценке \(\|y^{n+1}\| \le \|y^{n}\|\) в норме \(L_2\).

Принимаем без доказательства [1, гл. VI, §2; 2]. Для явной схемы проверяется по спектру: \(\hat y = (E - \tau A)y\), и

\[ \|E - \tau A\| \le 1 \iff 1 - \tau\lambda_k \in [-1, 1]\ \forall k \iff \tau\lambda_k \le 2 \iff \frac{\tau}{2}A \le E. \]
Практический вывод Для схем с самосопряжёнными \(A\) и \(B\) энергетический метод даёт критерий. Запас появляется лишь при грубой оценке \(\|A\|\) и при переходе к оценке по правой части.

Определение 4 §2 требует оценки через правую часть. Покажем, что метод даёт и её — ценой небольшого усиления условия.

§5а.9 · Устойчивость по правой части

ε-неравенство и теорема 3

Понадобится \(\varepsilon\)-неравенство (раскрытый квадрат \((\sqrt{\varepsilon}\,a - b/(2\sqrt{\varepsilon}))^2 \ge 0\)):

\[ |(\varphi, v)| \le \|\varphi\|\,\|v\| \le \varepsilon\,\|v\|^2 + \frac{1}{4\varepsilon}\,\|\varphi\|^2, \qquad \varepsilon > 0. \tag{5а.25} \]
Пусть \(A = A^* > 0\), \(B\) обратим и при некотором \(\varepsilon > 0\), не зависящем от \(\tau\) и \(h\), \(\;B \ge \varepsilon E + \frac{\tau}{2}A\;\) (5а.26). Тогда \[ \|y^{n+1}\|_A^2 \le \|y^{0}\|_A^2 + \frac{1}{2\varepsilon}\sum_{k=0}^{n}\tau\,\|\varphi^{k}\|^2. \tag{5а.27} \]
Доказательство в одну строку Этапы 1–3 с правой частью: \(2\tau((B - \frac{\tau}{2}A)y_t, y_t) + \|\hat y\|_A^2 - \|y\|_A^2 = 2\tau(\varphi, y_t)\). Слева \(\ge 2\tau\varepsilon\|y_t\|^2\), справа по (5а.25) \(\le 2\tau\varepsilon\|y_t\|^2 + \frac{\tau}{2\varepsilon}\|\varphi\|^2\); члены с \(\|y_t\|^2\) сокращаются, остаётся \(\|\hat y\|_A^2 \le \|y\|_A^2 + \frac{\tau}{2\varepsilon}\|\varphi\|^2\). Суммируем по слоям. □
Плата Для явной схемы условие (5а.26) даёт \(\tau \le (1 - \varepsilon)h^2/2\) вместо \(\tau \le h^2/2\): достаточные условия с запасом.

Теория готова. Применим её к трём схемам для уравнения теплопроводности и к переносу с переменной скоростью.

§5а.10 · Пример 2

Пример 2: явная схема для уравнения теплопроводности

\(u_t = u_{xx}\), \(u(0,t) = u(l,t) = 0\); схема \(y_t = \Lambda y\), \(y_0 = y_N = 0\) (5а.28).

1
Каноническая форма
\(B = E\), \(A = -\Lambda\) на \(H_0\).
2
Свойства \(A\)
По Следствию 1: \(A = A^* > 0\); \(\|y\|_A^2 = (y_{\bar x}, y_{\bar x}]\). Здесь вошли краевые условия.
3
Проверка (5а.19): \(E \ge \frac{\tau}{2}A\)
По (5а.9) достаточно \(\frac{\tau}{2}\|A\| \le 1\); по (5а.14) \(\|A\| \le 4/h^2\). Итого \(\;\dfrac{\tau}{2}\cdot\dfrac{4}{h^2} \le 1 \iff \tau \le \dfrac{h^2}{2}\) (5а.29).
Вывод При \(\tau \le h^2/2\): \(\|y^n\|_A \le \|y^0\|_A\) (теорема 1) и \(\|y^n\| \le \|y^0\|\) (теорема 2).
Сопоставление с §5 Гармоники: \(\lambda = 1 - \frac{4\tau}{h^2}\sin^2\frac{\alpha}{2}\), \(|\lambda| \le 1 \iff \tau \le h^2/2\). Тот же ответ, но здесь — с краевыми условиями и в явной норме.

Тот же порядок действий для семейства схем с весом \(\sigma\) даёт классический результат.

§5а.11 · Пример 3

Пример 3: схема с весами \(y_t = \Lambda\bigl(\sigma\hat y + (1 - \sigma)y\bigr)\)

\(A = -\Lambda\), \(B = E + \sigma\tau A\) — самосопряжён и положителен при \(\sigma \ge 0\). Условие (5а.19):

\[ E + \sigma\tau A \ge \frac{\tau}{2}A \iff E + \Bigl(\sigma - \frac12\Bigr)\tau A \ge 0. \tag{5а.31} \]

\(\sigma \ge 1/2\): выполнено при любых \(\tau\), \(h\) — неявная схема и схема Кранка–Николсон безусловно устойчивы.

\(\sigma < 1/2\): по (5а.9), (5а.14) достаточно \((\frac12 - \sigma)\tau\cdot\frac{4}{h^2} \le 1\):

\[ \sigma \ge \frac{1}{2} - \frac{h^2}{4\tau}. \tag{5а.32} \]
Область достаточных условий на плоскости \((\tau/h^2,\ \sigma)\).

При \(\sigma = 0\) получаем \(\tau \le h^2/2\) — Пример 2. Теперь задача, где метод гармоник не работает вовсе.

§5а.12 · Пример 4

Пример 4: перенос с переменной скоростью \(a(x)\)

\(u_t + a(x)u_x = 0\), \(a > 0\), \(|a'(x)| \le L\), периодичность (5а.33). Схема с локальным числом Куранта: \(\hat y_i = (1 - r_i)y_i + r_i y_{i-1}\), \(r_i = a(x_i)\tau/h \le 1\) (5а.34). Гармоники неприменимы — коэффициенты зависят от \(i\).

По (5а.16) \(\hat y_i^2 \le (1 - r_i)y_i^2 + r_i y_{i-1}^2\); суммируем, в последней сумме сдвигаем индекс:

\[ \|\hat y\|^2 \le \|y\|^2 + \sum_{i=1}^{N} h\,(r_{i+1} - r_i)\,y_i^2, \qquad r_{i+1} - r_i = \tau\,a'(\xi_i) \le \tau L. \tag{5а.35} \]
\[ \|\hat y\|^2 \le (1 + \tau L)\|y\|^2 \ \Rightarrow\ \|y^n\|^2 \le (1 + \tau L)^n\|y^0\|^2 \le e^{Lt_n}\|y^0\|^2 \ \Rightarrow\ \|y^n\| \le e^{LT/2}\,\|y^0\|. \tag{5а.36–37} \]
Что получено Устойчивость по начальным данным (Опр. 3 §2) с постоянной \(C = e^{LT/2}\), не зависящей от \(\tau\), \(h\). Эвристика «замороженных коэффициентов» стала теоремой.
Структура оценки Норма может расти на каждом шаге, но не более чем в \(1 + C\tau\) раз — ровно та ситуация, ради которой в условии Неймана (5.5) стоит \(1 + C\tau\), а не \(1\).

Переменность коэффициента вошла в одном месте — в разность \(r_{i+1} - r_i\). Тот же приём проходит для неравномерных сеток и краевых условий.

§5а.13 · Порядок действий

Порядок исследования схемы энергетическим методом

1
Каноническая форма
Выписать \(A\), \(B\), пространство \(H\) или \(H_0\) с учётом краевых условий.
2
Свойства \(A\)
Самосопряжённость и положительность — суммированием по частям; граничные члены обязаны исчезнуть.
3
Если \(A = A^* > 0\)
Проверить \(B \ge \frac{\tau}{2}A\) (или (5а.26)); для явных схем — \(\tau \le 2/\|A\|\). Вывод по теоремам 1–3.
4
Если \(A\) не самосопряжён
Умножить схему на \(\hat y\) или \(y^{(1/2)}\), выделить \(\|\hat y\|^2 - \|y\|^2\), остальное оценить формулами Грина и \(\varepsilon\)-неравенством; цель — \(\|\hat y\|^2 \le (1 + c\tau)\|y\|^2\).
5
Результат
Норма, постоянная, условия на \(\tau\), \(h\); сопоставить с условием Неймана.
Типичные ошибки
  1. Потерянные граничные члены в (5а.10) при условиях второго и третьего рода.
  2. Грубая оценка \(\|A\|\) → слишком жёсткое условие; гармоники его «опровергают» — это не противоречие.
  3. Перенос \(L_2\)-оценки на норму \(C\).
  4. Теорема 1 для несамосопряжённого \(A\).

Упражнения к §5а — на странице лекции: сохранение энергии для схемы Кранка–Николсон, абсолютная неустойчивость центральной явной схемы, неявный «уголок», переменный коэффициент теплопроводности.

§5а · Итоги

Итоги §5а

  1. Прототип: умножить на решение, проинтегрировать, интегрировать по частям, граничные члены — нуль; \(dE/dt \le 0\).
  2. Сетка: скалярное произведение (5а.7); суммирование по частям (5а.10); \(-\Lambda = (-\Lambda)^* > 0\) на \(H_0\), \(\|\Lambda\| \le 4/h^2\); центральная разность кососимметрична.
  3. Каноническая форма \(By_t + Ay = \varphi\).
  4. Теорема 1: \(A = A^* > 0\), \(B \ge \frac{\tau}{2}A\) ⇒ \(\|\hat y\|_A \le \|y\|_A\); энергетическое тождество (5а.24). Теорема 2 — критерий; теорема 3 — по правой части.
  5. Примеры: уголок \(r \le 1\); явная теплопроводность \(\tau \le h^2/2\); веса \(\sigma \ge \frac12 - \frac{h^2}{4\tau}\); переменная скорость \(\|y^n\| \le e^{LT/2}\|y^0\|\).
Главное Энергетический метод даёт достаточные условия и работает с краевыми условиями, переменными коэффициентами и неявными схемами — там, где метод гармоник не может быть сформулирован.
