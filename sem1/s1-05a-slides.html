§5а.1 · Зачем второй метод

Где гармоники не работают и что даёт энергия

коэффициенты
\(u_t + a(x)u_x = 0\)
оператор перехода не перестановочен со сдвигом
границы
\(u(0,t) = u(l,t) = 0\)
гармоника не обращается в нуль на концах
и главное
Условие Неймана — только необходимое
для систем и многослойных схем его может не хватать

Энергетический метод доказывает априорную оценку — из одной лишь структуры схемы, до и без её решения:

\[ \|y^{n+1}\| \le \|y^{n}\| \quad\text{или}\quad \|y^{n}\|^2 \le \|y^{0}\|^2 + C\sum_{k=0}^{n-1}\tau\,\|\varphi^{k}\|^2. \tag{5а.1} \]
СледствиеЭто оценка (2.14) Определения 4 §2 с явной нормой и постоянной. Условия, при которых она доказана, — достаточные. Гармоники дают необходимые; совпали — ответ точен.

Само тождество — сеточная копия одной выкладки из теории уравнений в частных производных. Проведём её для уравнения.

§5а.2 · Дифференциальный прототип

Закон сохранения энергии: перенос и теплопроводность

\(u_t + au_x = 0\), \(u(0,t) = u(l,t)\). Умножим на \(u\), проинтегрируем:

\[ \int_0^l u\,u_t\,dx = \frac12\frac{d}{dt}\int_0^l u^2\,dx, \qquad \int_0^l a\,u\,u_x\,dx = \frac{a}{2}\Bigl[u^2\Bigr]_0^l = 0. \]
\[ E(t) = \|u(\cdot,t)\|^2_{L_2}, \qquad \frac{dE}{dt} = 0. \tag{5а.3} \]
Где вошло краевое условиеВ одном месте: внеинтегральный член обратился в нуль благодаря периодичности.

\(u_t = \nu u_{xx}\), \(u(0,t) = u(l,t) = 0\) — нужно интегрирование по частям:

\[ \frac12\frac{dE}{dt} = \nu\int_0^l u\,u_{xx}\,dx = \nu\Bigl[u\,u_x\Bigr]_0^l - \nu\int_0^l u_x^2\,dx \le 0. \tag{5а.4} \]
1
Умножить на решение, проинтегрировать
на сетке — скалярное произведение
2
Интегрировать по частям
на сетке — суммирование по частям
3
Граничные члены — в нуль
за счёт значений в граничных узлах

Энергетический метод для схем — ровно эти три действия в сеточных терминах. Построим их по порядку.

§5а.3 · Обозначения и скалярное произведение

Обозначения Самарского. Скалярное произведение сеточных функций

\[ y_{x,i} = \frac{y_{i+1} - y_i}{h}, \quad y_{\bar x,i} = \frac{y_i - y_{i-1}}{h}, \quad y_{\mathring{x},i} = \frac{y_{i+1} - y_{i-1}}{2h}, \quad y_{\bar x x,i} = \frac{y_{i+1} - 2y_i + y_{i-1}}{h^2}; \qquad y_t = \frac{\hat y - y}{\tau}, \quad y^{(1/2)} = \frac{\hat y + y}{2}. \]
\(H\) — сеточные функции на \(\omega_h\) с периодическим условием \(y_0 = y_N\); \[ (y, v) = \sum_{i=1}^{N} h\,y_i v_i, \qquad \|y\| = \sqrt{(y, y)}. \tag{5а.7} \] Для краевой задачи первого рода — \(H_0\): \(y_0 = y_N = 0\), сумма по внутренним узлам.
СвойстваБилинейно, симметрично, \((y,y) > 0\) при \(y \ne 0\) — скалярное произведение; \(\|y\|\) — сеточная норма \(L_2\) (1.14). Коши–Буняковский: \(|(y,v)| \le \|y\|\,\|v\|\). На периодической сетке \(\sum h\,y_{i-1}^2 = \|y\|^2\).
Почему не норма \(C\)\(\sqrt{h}\|y\|_C \le \|y\| \le \sqrt{l}\|y\|_C\): оценка в \(L_2\) не влечёт равномерной оценки в \(C\). В \(L_2\) есть скалярное произведение — в \(C\) нет.

Скалярное произведение даёт язык операторов: сопряжённых, самосопряжённых, положительных.

§5а.4 · Операторы и энергетическая норма

Самосопряжённые, положительные, кососимметричные операторы

\(A^*\) — сопряжённый к \(A\), если \((Ay, v) = (y, A^*v)\) при всех \(y, v\). \(A\) самосопряжён, если \(A^* = A\); кососимметричен, если \(A^* = -A\) (тогда \((Ay, y) = 0\)). Самосопряжённый \(A\) положителен, \(A > 0\), если \((Ay, y) > 0\) при \(y \ne 0\); неотрицателен, \(A \ge 0\), если \((Ay, y) \ge 0\). Запись \(A \ge B\) означает \(A - B \ge 0\).
Пусть \(A = A^* > 0\). Тогда \((Ay, v)\) — скалярное произведение, и норма \[ \|y\|_A = \sqrt{(Ay, y)} \tag{5а.8} \] называется энергетической; пространство с ней — \(H_A\). Для \(A = -\Lambda\): \(\|y\|_A^2 = \sum h\,y_{\bar x,i}^2\) — сеточный аналог \(\int u_x^2\,dx\).
Норма оператора и мост к числам\(\|A\| = \sup\|Ay\|/\|y\|\); для \(A = A^* \ge 0\) по Коши–Буняковскому \[ (Ay, y) \le \|A\|\,\|y\|^2, \quad\text{то есть}\quad A \le \|A\|\,E. \tag{5а.9} \] Так операторное условие устойчивости превращается в условие на \(\tau\), \(h\).

Второе действие прототипа — суммирование по частям.

§5а.5 · Суммирование по частям

Лемма 1 и первая формула Грина

Для любых сеточных функций \(y\), \(v\) на \(\omega_h\): \[ \sum_{i=1}^{N} h\,y_i\,v_{\bar x,i} = -\sum_{i=0}^{N-1} h\,y_{x,i}\,v_i + y_N v_N - y_0 v_0. \tag{5а.10} \]
Доказательство. \(\sum_{i=1}^N y_i(v_i - v_{i-1}) = \sum_{i=1}^N y_iv_i - \sum_{j=0}^{N-1} y_{j+1}v_j\); в первой сумме отделяем \(i = N\), добавляем и вычитаем \(j = 0\); разность даёт \(-\sum_{j=0}^{N-1}(y_{j+1} - y_j)v_j = -\sum h\,y_{x,j}v_j\). □ Сравните: \(\int_0^l yv'\,dx = -\int_0^l y'v\,dx + [yv]_0^l\).

Следствие 1. Для \(y, v \in H_0\) граничные члены исчезают:

\[ (\Lambda y, v) = -\sum_{i=1}^{N} h\,y_{\bar x,i}v_{\bar x,i}, \tag{5а.11} \]
\[ (-\Lambda y, y) = \sum_{i=1}^{N} h\,y_{\bar x,i}^2 \ge 0. \tag{5а.12} \]

Правая часть симметрична ⇒ \(\Lambda\) самосопряжён; равенство нулю лишь при \(y = \mathrm{const}\), а с \(y_0 = 0\) — при \(y \equiv 0\). Итак, \(A = -\Lambda\) самосопряжён и положителен на \(H_0\). Краевые условия вошли именно здесь.

§5а.5 · Следствия 2 и 3

Периодическая сетка; оценка \(\|\Lambda\|\)

Следствие 2. На периодической сетке граничные члены (5а.10) взаимно уничтожаются; \(-\Lambda \ge 0\) (постоянная функция даёт нуль). Для центральной разности

\[ (y_{\mathring x}, y) = \frac12\Bigl(\sum_{i=1}^{N} y_iy_{i+1} - \sum_{i=1}^{N} y_iy_{i-1}\Bigr) = 0, \tag{5а.13} \]

и \((y_{\mathring x}, v) = -(y, v_{\mathring x})\): центральная разность кососимметрична — двойник \(\int u\,u_x\,dx = 0\).

Следствие 3. Из (5а.12) и \((a - b)^2 \le 2a^2 + 2b^2\):

\[ (-\Lambda y, y) \le \frac{2}{h^2}\sum_{i=1}^{N} h\,(y_i^2 + y_{i-1}^2) \le \frac{4}{h^2}\|y\|^2, \]
\[ -\Lambda \le \frac{4}{h^2}E. \tag{5а.14} \]
ТочноСобственные числа \(-\Lambda\) на \(H_0\): \(\frac{4}{h^2}\sin^2\frac{k\pi h}{2l}\); наибольшее \(\frac{4}{h^2}\cos^2\frac{\pi h}{2l} < \frac{4}{h^2}\). Оценка точна по порядку.

Инструменты собраны. Первый парный разбор — схема, которую мы знаем лучше всех.

§5а.6 · Разбор 1

Разбор 1. Явный «уголок»: \(\hat y_i = (1 - r)y_i + r\,y_{i-1}\)

Гармоники (§5.5)

\(\lambda = 1 - r + re^{-i\alpha}\),

\[ |\lambda|^2 = 1 - 4r(1 - r)\sin^2\frac{\alpha}{2} \le 1 \iff 0 \le r \le 1. \]

Результат: необходимое условие \(r \le 1\).

Энергия

Неравенство выпуклости: при \(\alpha, \beta \ge 0\), \(\alpha + \beta = 1\),

\[ (\alpha p + \beta q)^2 \le \alpha p^2 + \beta q^2 \quad\bigl(\text{разность} = \alpha\beta(p - q)^2\bigr). \tag{5а.16} \]

При \(0 \le r \le 1\): \(\hat y_i^2 \le (1 - r)y_i^2 + ry_{i-1}^2\); умножаем на \(h\), суммируем, \(\sum h\,y_{i-1}^2 = \|y\|^2\):

\[ \|\hat y\|^2 \le (1 - r)\|y\|^2 + r\|y\|^2 = \|y\|^2. \tag{5а.17} \]

Результат: \(\|y^n\| \le \|y^0\|\) при \(0 \le r \le 1\) — достаточное условие.

Сопоставление. Условия совпали: \(r \le 1\) — точный ответ. Энергия использовала \(r \le 1\) в единственном месте — оба коэффициента в (5а.16) должны быть неотрицательны. Постоянство \(a\) не использовано вовсе (разбор 5). Та же выкладка в норме \(C\) — принцип максимума (§11).
§5а.7 · Разбор 2

Разбор 2. Неявный «уголок»: \((1 + r)\hat y_i - r\,\hat y_{i-1} = y_i\)

Гармоники (§5.8)

\(\lambda = \bigl(1 + r - re^{-i\alpha}\bigr)^{-1}\),

\[ |\lambda|^2 = \frac{1}{1 + 4r(1 + r)\sin^2\frac{\alpha}{2}} \le 1 \quad\text{при всех } r > 0. \]

Результат: условие Неймана не даёт ограничений — безусловная устойчивость.

Энергия

Умножим уравнение скалярно на новый слой \(\hat y\):

\[ (1 + r)\|\hat y\|^2 - r\,(\hat y_{-1}, \hat y) = (y, \hat y). \]

Коши–Буняковский и периодичность: \((\hat y_{-1}, \hat y) \le \|\hat y\|^2\), значит слева не меньше \(\|\hat y\|^2\); справа не больше \(\|y\|\,\|\hat y\|\):

\[ \|\hat y\|^2 \le \|y\|\,\|\hat y\| \ \Longrightarrow\ \|\hat y\| \le \|y\| \quad\text{при любом } r \ge 0. \tag{5а.19} \]

Результат: безусловная устойчивость в \(L_2\).

Сопоставление. Оба метода — безусловная устойчивость; энергетическая выкладка заняла три строки. Неявность вошла через умножение на новый слой: слагаемое \((1 + r)\|\hat y\|^2\) «перевешивает» \(r(\hat y_{-1}, \hat y)\) при любом \(r\). Так выглядит безусловная устойчивость неявных схем в энергетическом методе.
§5а.8 · Разбор 3

Разбор 3. Явная центральная схема: \(\hat y = y - \tau a\,y_{\mathring x}\)

Гармоники (§5.7)

\(\lambda = 1 - ir\sin\alpha\),

\[ |\lambda|^2 = 1 + r^2\sin^2\alpha \ge 1. \]

Результат: условие Неймана нарушено при любых \(\tau, h\) — абсолютная неустойчивость.

Энергия

Норма нового слоя точно:

\[ \|\hat y\|^2 = \|y\|^2 - 2\tau a\,(y_{\mathring x}, y) + \tau^2a^2\|y_{\mathring x}\|^2 = \|y\|^2 + \tau^2a^2\|y_{\mathring x}\|^2, \tag{5а.20} \]

так как по (5а.13) \((y_{\mathring x}, y) = 0\). Энергия растёт на каждом шаге. На гармонике \(\|y_{\mathring x}\|^2 = \frac{\sin^2\alpha}{h^2}\|y\|^2\), и (5а.20) даёт \(\|\hat y\|^2 = (1 + r^2\sin^2\alpha)\|y\|^2\).

Сопоставление. Оба — неустойчивость, и тождество на гармонике воспроизводит \(|\lambda|^2\) буквально. Но тождество говорит больше: рост за шаг пропорционален \(\|y_{\mathring x}\|^2\) — мал для гладких данных, велик для «пилы». Отсюда типичная картина: схема «работает» на гладком профиле десятки шагов, а затем взрывается пилой.
§5а.9 · Каноническая форма

Каноническая форма двухслойной схемы

Двухслойная схема записана в канонической форме, если она имеет вид \[ B\,\frac{y^{n+1} - y^{n}}{\tau} + A\,y^{n} = \varphi^{n}, \qquad\text{то есть}\qquad B y_t + A y = \varphi, \tag{5а.21} \] где \(A, B\colon H \to H\) — линейные операторы и \(B\) обратим (разрешимость: \(y^{n+1} = y^n - \tau B^{-1}(Ay^n - \varphi^n)\)).
СхемаЗапись\(A\)\(B\)Свойства \(A\)
Явная, теплопроводность\(y_t = \Lambda y + \varphi\) на \(H_0\)\(-\Lambda\)\(E\)\(A = A^* > 0\)
С весами \(\sigma\)\(y_t = \Lambda y^{(\sigma)} + \varphi\), \(y^{(\sigma)} = y + \sigma\tau y_t\)\(-\Lambda\)\(E + \sigma\tau A\)\(A = A^* > 0\)
«Уголок», перенос\(y_t + a\,y_{\bar x} = 0\)\(a\,\partial_{\bar x}\)\(E\)не самосопряжён

Для схем с \(A = A^* > 0\) есть общая теорема; разборы 1–3 велись напрямую именно потому, что их \(A\) не самосопряжён.

§5а.10 · Основная теорема

Теорема Самарского об устойчивости в \(H_A\)

Пусть в схеме (5а.21) с \(\varphi \equiv 0\) оператор \(A\) самосопряжён и положителен, \(A = A^* > 0\), а \(B\) обратим и удовлетворяет операторному неравенству \[ B \ge \frac{\tau}{2}\,A, \qquad\text{то есть}\qquad (By, y) \ge \frac{\tau}{2}\,(Ay, y)\ \ \text{при всех } y \in H. \tag{5а.22} \] Тогда \(\ \|y^{n+1}\|_A \le \|y^{n}\|_A\), \(n = 0, 1, \dots\), и, следовательно, \(\|y^{n}\|_A \le \|y^{0}\|_A\). \(\tag{5а.23}\)
Что утверждаетсяУстойчивость по начальным данным в энергетической норме с постоянной \(C = 1\), не зависящей от \(\tau\), \(h\) и числа шагов.
Обратите вниманиеОт \(B\) не требуется ни самосопряжённости, ни положительности — только обратимость и неравенство (5а.22).

Доказательство — четыре этапа; после каждого отмечаем, какая гипотеза использована.

§5а.10 · Доказательство, этапы 1–2

Этап 1: полусумма слоёв. Этап 2: умножение на \(2\tau y_t\)

Этап 1 · тождественное преобразование, гипотезы не используются

Выразим \(y\) через полусумму \(y^{(1/2)} = \frac12(\hat y + y)\) и разностную производную \(y_t = \frac1\tau(\hat y - y)\):

\[ y = y^{(1/2)} - \frac{\tau}{2}\,y_t \qquad\Bigl(\text{проверка: } \tfrac12(\hat y + y) - \tfrac12(\hat y - y) = y\Bigr). \]

Подставим в \(By_t + Ay = 0\) и сгруппируем:

\[ \Bigl(B - \frac{\tau}{2}A\Bigr)y_t + A\,y^{(1/2)} = 0. \tag{5а.24} \]
Этап 2 · сеточное «умножение на решение и интегрирование»

Умножим (5а.24) скалярно на \(2\tau y_t\); множитель \(2\tau\) подобран так, чтобы второе слагаемое стало разностью энергий:

\[ 2\tau\Bigl(\bigl(B - \tfrac{\tau}{2}A\bigr)y_t,\ y_t\Bigr) + 2\tau\bigl(A y^{(1/2)},\ y_t\bigr) = 0. \tag{5а.25} \]

Осталось увидеть, что второе слагаемое — это \(\|\hat y\|_A^2 - \|y\|_A^2\).

§5а.10 · Доказательство, этапы 3–4

Этап 3: разность энергий. Этап 4: энергетическое тождество

Этап 3 · используется A = A*
\[ 2\tau\bigl(A y^{(1/2)}, y_t\bigr) = \bigl(A(\hat y + y),\ \hat y - y\bigr) = (A\hat y, \hat y) - \underbrace{(A\hat y, y) + (Ay, \hat y)}_{=\,0\ \text{по самосопряжённости}} - (Ay, y) = \|\hat y\|_A^2 - \|y\|_A^2. \tag{5а.26} \]
Этап 4 · используется B ≥ (τ/2)A, затем A > 0
\[ \|\hat y\|_A^2 = \|y\|_A^2 - 2\tau\Bigl(\bigl(B - \tfrac{\tau}{2}A\bigr)y_t,\ y_t\Bigr). \tag{5а.27} \]

Точное энергетическое тождество. По (5а.22) вычитаемое неотрицательно ⇒ \(\|\hat y\|_A^2 \le \|y\|_A^2\). Положительность \(A\) делает \(\|\cdot\|_A\) нормой; извлекаем корень — (5а.23). □

Смысл тождестваЭнергия нового слоя = энергия старого − диссипация. Условие \(B \ge \frac{\tau}{2}A\): схема не производит энергии. Для \(B = E\) это ограничение на \(\tau\); слагаемое \(\sigma\tau A\) в \(B\) неявных схем «оплачивает» его при любом \(\tau\).

Одна теорема объясняет условную устойчивость явных схем и безусловную — неявных. Есть и обратное утверждение.

§5а.10 · Теорема 2

Устойчивость в \(H_B\); необходимость условия (5а.22)

Пусть \(A = A^* > 0\) и \(B = B^* > 0\). Тогда условие (5а.22) необходимо и достаточно для оценки (5а.23); при его выполнении справедлива также оценка \(\|y^{n+1}\|_B \le \|y^{n}\|_B\). В частности, для явных схем (\(B = E\)) условие \(E \ge \frac{\tau}{2}A\) равносильно оценке \(\|y^{n+1}\| \le \|y^{n}\|\) в норме \(L_2\).

Принимаем без доказательства [Самарский, гл. VI, §2]. Для явной схемы проверяется по спектру: \(\hat y = (E - \tau A)y\), и

\[ \|E - \tau A\| \le 1 \iff 1 - \tau\lambda_k \in [-1, 1]\ \forall k \iff \tau\lambda_k \le 2 \iff \frac{\tau}{2}A \le E. \]
Практический выводДля схем с самосопряжёнными \(A\) и \(B\) энергетический метод даёт критерий. Запас появляется лишь при грубой оценке \(\|A\|\) и при переходе к правой части.

Применим теорему к схеме из примера 5 §5 — четвёртый парный разбор.

§5а.11 · Разбор 4

Разбор 4. Схема с весами: \(y_t = \Lambda\bigl(\sigma\hat y + (1 - \sigma)y\bigr)\), \(y_0 = y_N = 0\)

Гармоники (§5.9) — задача без границ
\[ \lambda = \frac{1 - 4(1 - \sigma)s}{1 + 4\sigma s}, \quad s = \frac{\tau}{h^2}\sin^2\frac{\alpha}{2}. \]

\(-1 \le \lambda \le 1\) при всех \(s \le \tau/h^2\) ⟺

\[ \sigma \ge \frac12 - \frac{h^2}{4\tau}. \]

Результат: необходимое условие.

Энергия (теорема 1) — краевая задача

\(A = -\Lambda\), \(B = E + \sigma\tau A\); \(A = A^* > 0\), \(B = B^* > 0\) на \(H_0\). Условие (5а.22):

\[ E + \sigma\tau A \ge \frac{\tau}{2}A \iff E + \Bigl(\sigma - \frac12\Bigr)\tau A \ge 0. \tag{5а.29} \]

\(\sigma \ge \frac12\): верно всегда. \(\sigma < \frac12\): по (5а.9), (5а.14) достаточно \((\frac12 - \sigma)\tau\cdot\frac{4}{h^2} \le 1\):

\[ \sigma \ge \frac12 - \frac{h^2}{4\tau}. \tag{5а.30} \]

Результат: достаточное; \(\|y^n\|_A \le \|y^0\|_A\), \(\|y^n\| \le \|y^0\|\).

Сопоставление. Условия совпали — критерий устойчивости схемы с весами (классический результат Самарского): \(\sigma = 0\) — \(\tau \le h^2/2\); \(\sigma \ge \frac12\) — безусловно. Разница — в том, что доказано: гармоники — ограниченность волн на прямой, энергия — оценка нормы решения краевой задачи с явной постоянной.
§5а.12 · Устойчивость по правой части

ε-неравенство и теорема 3

\[ |(\varphi, v)| \le \|\varphi\|\,\|v\| \le \varepsilon\,\|v\|^2 + \frac{1}{4\varepsilon}\,\|\varphi\|^2 \qquad\bigl((\sqrt{\varepsilon}a - b/2\sqrt{\varepsilon})^2 \ge 0\bigr). \tag{5а.31} \]
Пусть \(A = A^* > 0\), \(B\) обратим и при некотором \(\varepsilon > 0\), не зависящем от \(\tau, h\): \(\ B \ge \varepsilon E + \frac{\tau}{2}A\ \) (5а.32). Тогда \[ \|y^{n+1}\|_A^2 \le \|y^{0}\|_A^2 + \frac{1}{2\varepsilon}\sum_{k=0}^{n}\tau\,\|\varphi^{k}\|^2. \tag{5а.33} \]
Доказательство. Этапы 1–3 с правой частью: \(2\tau((B - \frac{\tau}{2}A)y_t, y_t) + \|\hat y\|_A^2 - \|y\|_A^2 = 2\tau(\varphi, y_t)\). Слева \(\ge 2\tau\varepsilon\|y_t\|^2\), справа по (5а.31) \(\le 2\tau\varepsilon\|y_t\|^2 + \frac{\tau}{2\varepsilon}\|\varphi\|^2\); члены с \(\|y_t\|^2\) сокращаются, остаётся \(\|\hat y\|_A^2 \le \|y\|_A^2 + \frac{\tau}{2\varepsilon}\|\varphi\|^2\). Суммируем по слоям. □
ПлатаДля явной схемы (5а.32) даёт \(\tau \le (1 - \varepsilon)h^2/2\) вместо \(\tau \le h^2/2\): достаточные условия с запасом.

Последний разбор — задача, где гармоник нет вовсе.

§5а.13 · Разбор 5

Разбор 5. Перенос с переменной скоростью: \(\hat y_i = (1 - r_i)y_i + r_i y_{i-1}\), \(r_i = a(x_i)\tau/h\)

Гармоники

Неприменимы: коэффициенты зависят от \(i\), \(e^{i\alpha m}\) — не собственная функция оператора перехода.

Эвристика «замороженных коэффициентов»: потребовать условие Куранта в каждом узле, \(\max_i r_i \le 1\). Правдоподобно — но не доказательство.

Энергия

По (5а.16) \(\hat y_i^2 \le (1 - r_i)y_i^2 + r_iy_{i-1}^2\); суммируем, в последней сумме сдвигаем индекс:

\[ \|\hat y\|^2 \le \|y\|^2 + \sum_{i=1}^{N} h\,(r_{i+1} - r_i)\,y_i^2, \qquad r_{i+1} - r_i = \tau\,a'(\xi_i) \le \tau L. \tag{5а.36} \]
\[ \|\hat y\|^2 \le (1 + \tau L)\|y\|^2 \ \Rightarrow\ \|y^n\|^2 \le e^{Lt_n}\|y^0\|^2 \ \Rightarrow\ \|y^n\| \le e^{LT/2}\|y^0\|. \tag{5а.37} \]
Результат. Устойчивость по начальным данным с постоянной \(e^{LT/2}\), не зависящей от \(\tau, h\): эвристика стала теоремой. Норма может расти на каждом шаге не более чем в \(1 + C\tau\) раз — ровно та ситуация, ради которой в условии Неймана стоит \(1 + C_1\tau\). Переменность коэффициента вошла в одном месте — в разность \(r_{i+1} - r_i\); тот же приём проходит для неравномерных сеток и границ.

§5а.14 · Порядок действий

Порядок исследования схемы энергетическим методом

1
Сначала — гармоники
Если применимы: быстро дают необходимое условие и подсказывают ответ.
2
Каноническая форма
\(A\), \(B\), пространство \(H\) или \(H_0\) с учётом краевых условий.
3
Свойства \(A\)
Самосопряжённость, положительность — суммированием по частям; граничные члены обязаны исчезнуть.
4
Если \(A = A^* > 0\)
Проверить \(B \ge \frac{\tau}{2}A\) (для явных — \(\tau \le 2/\|A\|\)); вывод по теоремам 1–3.
5
Если \(A\) не самосопряжён
Умножить на \(\hat y\) или \(y^{(1/2)}\), выделить \(\|\hat y\|^2 - \|y\|^2\), остальное — Грин, Коши–Буняковский, ε; цель \(\|\hat y\|^2 \le (1 + c\tau)\|y\|^2\).
6
Сопоставить с гармониками
Совпадение — критерий; расхождение — запас метода или неустойчивость в \(C\).
Типичные ошибкипотерянные граничные члены при условиях второго и третьего рода; грубая \(\|A\|\) → слишком жёсткое условие (гармоники его «опровергают» — это не противоречие); перенос \(L_2\)-оценки на норму \(C\); теорема 1 для несамосопряжённого \(A\).
