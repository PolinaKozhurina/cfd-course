§5.1 · Что нужно проверить

Устойчивость по начальным данным — что именно надо доказать

В §2 устойчивость определена, в §3 теорема Лакса сделала её решающей: аппроксимация + устойчивость = сходимость. Для эволюционных задач, где решение считается послойно, удобна форма:

\[ \|u^{n}\| \le C\,\|u^{0}\| \qquad\text{при всех } n = 0, 1, \dots, N = T/\tau, \qquad C \ne C(h, \tau, n). \tag{5.1} \]
ТрудностьНеравенство должно выполняться при всех начальных данных, всех сетках и с одной постоянной. Проверять «в лоб» — значит решить задачу для всех данных сразу.
ИдеяНайти для оператора, переводящего решение со слоя на слой, базис из собственных функций и проследить за каждой: её поведение описывается одним числом.

Для линейных схем с постоянными коэффициентами такие собственные функции известны заранее — это гармоники. Начнём с оператора перехода.

§5.2 · Оператор перехода

Оператор перехода и его перестановочность со сдвигом

Оператор \(S\), обеспечивающий переход решения с предыдущего временного слоя на следующий, \(u^{n+1} = S\,u^{n}\), называется оператором перехода двухслойной схемы. Для неявной схемы \(B_1u^{n+1} = B_0u^n\) это \(S = B_1^{-1}B_0\).

Пусть сетка бесконечна (или периодична), а коэффициенты схемы одинаковы во всех узлах. Тогда \(S\) перестановочен со сдвигом \(T\colon u_m \mapsto u_{m+1}\): всё равно, сдвинуть функцию до применения схемы или после,

\[ ST = TS. \]
Собственные функции сдвига \[ T\,e^{i\alpha m} = e^{i\alpha(m+1)} = e^{i\alpha}\cdot e^{i\alpha m}. \] Экспонента \(e^{i\alpha m}\) — собственная функция сдвига с собственным числом \(e^{i\alpha}\).

Операторы, перестановочные со сдвигом, наследуют его собственные функции — это и есть лемма, на которой держится весь метод.

§5.2 · Лемма о гармониках

Лемма 1: гармоники — собственные функции оператора перехода

Пусть \(S\) — линейный оператор на сеточных функциях, перестановочный со сдвигом: \(ST = TS\). Тогда для каждого \(\alpha\) функция \(e_\alpha = \{e^{i\alpha m}\}\) — собственная функция \(S\): \(S e_\alpha = \lambda(\alpha)\,e_\alpha\).
Доказательство. Положим \(v = Se_\alpha\). Тогда \[ Tv = TSe_\alpha = STe_\alpha = S(e^{i\alpha}e_\alpha) = e^{i\alpha}\,v, \] то есть \(v\) — собственная функция сдвига с тем же числом \(e^{i\alpha}\). Но уравнение \(v_{m+1} = e^{i\alpha}v_m\) задаёт \(v\) с точностью до множителя: \(v_m = v_0e^{i\alpha m}\). Значит \(v = \lambda e_\alpha\). □

На сетке \(x_m = mh\), \(t_n = n\tau\) непрерывная гармоника \(e^{i\omega t + ikx}\) принимает вид

\[ u_m^n = \lambda^n e^{i\alpha m}, \qquad \lambda = e^{i\omega\tau}, \quad \alpha = kh. \tag{5.2} \]
Функция (5.2) — гармоника с приведённым волновым числом \(\alpha\); собственное число \(\lambda(\alpha)\), для которого \(u_m^{n+1} = \lambda u_m^n\), — множитель перехода.

Единственное, что использовано, — \(ST = TS\). Без постоянных коэффициентов и без отсутствия границ леммы нет; это отправная точка §5а.

§5.2–5.3 · Гармоники на сетке. Правило подстановки

Какие бывают гармоники и как их подставлять

\(\alpha \in [-\pi, \pi]\): значения \(\alpha\) и \(\alpha + 2\pi\) на сетке неразличимы.

Значение гармоники в узле шаблона \((m + p,\ n + s)\):

\[ u_{m+p}^{\,n+s} = \underbrace{\lambda^n e^{i\alpha m}}_{\text{общий множитель}}\cdot\lambda^{s}e^{i\alpha p}. \tag{5.3} \]
Шпаргалка \(u_m^{n+1} \to \lambda\), \(u_m^{n-1} \to \lambda^{-1}\), \(u_{m-1}^n \to e^{-i\alpha}\), \(u_{m+1}^n \to e^{i\alpha}\), \(u_{m-1}^{n+1} \to \lambda e^{-i\alpha}\).

После сокращения общего множителя остаётся алгебраическое уравнение на \(\lambda\) — характеристическое.

§5.3 · Характеристическое уравнение

Характеристическое уравнение и алгоритм

Соотношение \(\lambda = \lambda(\alpha)\), получаемое подстановкой гармоники (5.2) в схему и сокращением общего множителя, называется характеристическим (дисперсионным) уравнением. Для двухслойной схемы оно линейно по \(\lambda\), для трёхслойной — квадратное.
1
Безразмерные параметры
\(r = a\tau/h\) для переноса, \(\varkappa = \tau/h^2\) для теплопроводности.
2
Подстановка по правилу (5.3)
Каждое \(u_{m+p}^{n+s}\) заменить на \(\lambda^se^{i\alpha p}\).
3
Сократить и решить относительно \(\lambda\)
Для неявных схем — разделить на коэффициент при \(\lambda\).
4
Вычислить \(|\lambda|^2\)
\(e^{\pm i\alpha} = \cos\alpha \pm i\sin\alpha\), \(1 - \cos\alpha = 2\sin^2\frac{\alpha}{2}\), \(e^{i\alpha} - e^{-i\alpha} = 2i\sin\alpha\).

Из (5.2) \(u_m^{n} = \lambda^n u_m^{0}\), где \(u_m^0 = e^{i\alpha m}\) — начальное условие. Значит,

\[ \max_m |u_m^n| = |\lambda|^n\,\max_m |u_m^0|. \tag{5.4} \]
Готовая оценкаРавенство (5.4) — это оценка решения через начальные данные для одной гармоники. Осталось сопоставить её с требованием (5.1).
§5.4 · Вывод условия Неймана

От оценки (5.1) к условию на \(\lambda\)

Возьмём в (5.1) норму \(\|u^n\| = \max_m|u_m^n|\) и подставим гармонику. По (5.4) требование (5.1) для неё означает

\[ |\lambda(\alpha)|^n \le C \qquad\text{при всех } n = 0, 1, \dots, N = T/\tau \text{ и всех } \alpha. \tag{5.5} \]

Число шагов \(N = T/\tau \to \infty\) при \(\tau \to 0\). При \(n = N\):

\[ |\lambda| \le C^{1/N} = C^{\tau/T} = e^{(\tau/T)\ln C} \le 1 + C_1\tau. \]

Обратно, \((1 + C_1\tau)^{T/\tau} \le e^{C_1T}\) — ограничено. Итак, (5.5) равносильно

\[ |\lambda(\alpha)| \le 1 + C_1\tau \quad\text{при всех } \alpha. \tag{5.6} \]
Если схема с постоянными коэффициентами устойчива по начальным данным в норме \(\max|u_m^n|\) на бесконечной сетке, то множитель перехода каждой гармоники удовлетворяет (5.6) с постоянной, не зависящей от \(\tau, h, \alpha\). Неравенство (5.6) — необходимое спектральное условие устойчивости (условие Неймана).

Условие получено проверкой (5.1) на одном классе данных — гармониках. Поэтому оно необходимое: нарушено для одной гармоники — схема неустойчива.

§5.4 · Геометрический смысл

Кривая \(\lambda(\alpha)\) должна лежать в единичном круге

При \(\alpha\), пробегающем \([-\pi, \pi]\), точка \(\lambda(\alpha)\) описывает замкнутую кривую в комплексной плоскости; (5.6) означает, что она не выходит из круга радиуса \(1 + C_1\tau\). На практике требуют

\[ |\lambda(\alpha)| \le 1 \qquad\text{при всех } \alpha. \tag{5.7} \]
Когда нужен запас \(C_1\tau\)Только если само уравнение допускает растущие решения (\(u_t + au_x = u\)): тогда любая схема обязана давать \(|\lambda| = 1 + \tau + O(\tau^2)\). Для переноса без младших членов (5.7) — естественное требование.

Множество значений параметра (например, \(r\)), при которых верно (5.7), — область устойчивости схемы.

Схема «уголок», \(r = 0.7\): окружность радиуса \(r\) с центром \(1 - r\).

Пять схем по алгоритму. Первая — «уголок».

§5.5 · Пример 1: схема «уголок»

Пример 1. Схема «уголок»: подстановка

Уравнение \(u_t + au_x = 0\), \(a > 0\). Явная схема с разностью назад, разрешённая относительно верхнего слоя:

\[ \frac{u_m^{n+1} - u_m^n}{\tau} + a\,\frac{u_m^n - u_{m-1}^n}{h} = 0 \quad\Longleftrightarrow\quad u_m^{n+1} = (1 - r)\,u_m^n + r\,u_{m-1}^n, \qquad r = \frac{a\tau}{h}. \tag{5.8} \]
шаги 2–3 · подстановка и сокращение
\[ \lambda^{n+1}e^{i\alpha m} = (1 - r)\lambda^n e^{i\alpha m} + r\lambda^n e^{i\alpha m}e^{-i\alpha} \]
\[ \Longrightarrow\qquad \lambda = 1 - r + r\,e^{-i\alpha}. \tag{5.9} \]
Что за криваяК точке \(1 - r\) прибавляется вектор длины \(r\), поворачивающийся вместе с \(\alpha\): окружность радиуса \(r\) с центром \(1 - r\). При \(\alpha = 0\) она проходит через \(\lambda = 1\), при \(\alpha = \pi\) — через \(1 - 2r\).

Шаг 4 — модуль. Здесь пригодится формула \(1 - \cos\alpha = 2\sin^2(\alpha/2)\).

§5.5 · Пример 1: модуль и область устойчивости

Уголок: \(|\lambda|^2\) и условие \(0 \le r \le 1\)

шаг 4 · модуль

\(\lambda = (1 - r + r\cos\alpha) - i\,r\sin\alpha\), поэтому

\[ |\lambda|^2 = (1 - r + r\cos\alpha)^2 + r^2\sin^2\alpha = 1 - 2r(1 - r)(1 - \cos\alpha) = 1 - 4r(1 - r)\sin^2\frac{\alpha}{2}. \tag{5.10} \]

Так как \(\sin^2(\alpha/2) \in [0, 1]\) и достигает единицы при \(\alpha = \pi\), условие \(|\lambda| \le 1\) при всех \(\alpha\) равносильно \(r(1 - r) \ge 0\):

\[ 0 \le r = \frac{a\tau}{h} \le 1 \qquad\text{— критерий Куранта.} \tag{5.11} \]

При \(r > 1\) наибольший модуль у «пилы»: \(|\lambda(\pi)| = |1 - 2r| > 1\), она растёт как \(|1 - 2r|^n\).

При \(r = 1.2\) точка \(\alpha = \pi\) выходит из круга.
§5.5 · Условие Куранта — геометрия

Почему \(r \le 1\): область зависимости

Точное значение \(u(x_m, t_{n+1})\) определяется значением на слое \(t_n\) в основании характеристики \(x = x_m - a\tau\). Разностное \(u_m^{n+1}\) — значениями в узлах шаблона \(x_{m-1}\), \(x_m\).

Условие Куранта–Фридрихса–ЛевиОбласть зависимости схемы должна содержать область зависимости уравнения: \(x_m - a\tau \ge x_{m-1}\), то есть \(a\tau \le h\). Иначе схема не получает информацию, от которой зависит точное решение.

Нейман — алгебра, КФЛ — геометрия; для «уголка» они совпали. В общем случае КФЛ грубее (пример 3).

Проверим признак на схеме, у которой шаблон «смотрит» в другую сторону.

§5.6 · Пример 2: разность вперёд

Пример 2. Разность вперёд: абсолютная неустойчивость

\[ \frac{u_m^{n+1} - u_m^n}{\tau} + a\,\frac{u_{m+1}^n - u_m^n}{h} = 0 \quad\Longleftrightarrow\quad u_m^{n+1} = (1 + r)\,u_m^n - r\,u_{m+1}^n. \tag{5.12} \]

Узлу \((m+1, n)\) отвечает \(e^{+i\alpha}\): \(\lambda = 1 + r - r\,e^{i\alpha}\) — окружность радиуса \(r\) с центром \(1 + r\).

\[ |\lambda|^2 = (1 + r - r\cos\alpha)^2 + r^2\sin^2\alpha = 1 + 4r(1 + r)\sin^2\frac{\alpha}{2} \ge 1, \tag{5.13} \]

строго больше единицы при \(\alpha \ne 0\) и любом \(r > 0\). Условие Неймана нарушено при всех \(\tau, h\): схема абсолютно неустойчива.

ГеометрияПри \(a > 0\) характеристика приходит в узел слева, а шаблон берёт информацию справа: условие КФЛ нарушено при любом \(r\).
ПравилоПри \(a < 0\) картина зеркальна: устойчива именно разность вперёд при \(|a|\tau/h \le 1\). Разность берётся против потока.

А если взять симметричную разность — не «за» и не «против»?

§5.7 · Пример 3: центральная разность

Пример 3. Центральная разность: КФЛ выполнено, схема неустойчива

\[ \frac{u_m^{n+1} - u_m^n}{\tau} + a\,\frac{u_{m+1}^n - u_{m-1}^n}{2h} = 0 \quad\Longleftrightarrow\quad u_m^{n+1} = u_m^n - \frac{r}{2}\bigl(u_{m+1}^n - u_{m-1}^n\bigr). \tag{5.14} \]

Множители узлов \(m \pm 1\) равны \(e^{\pm i\alpha}\), и \(e^{i\alpha} - e^{-i\alpha} = 2i\sin\alpha\):

\[ \lambda = 1 - i\,r\sin\alpha, \qquad |\lambda|^2 = 1 + r^2\sin^2\alpha \ge 1. \tag{5.15} \]

Абсолютно неустойчива — хотя при \(r \le 1\) условие КФЛ выполнено: основание характеристики лежит в \([x_{m-1}, x_{m+1}]\).

МоральКФЛ — необходимое условие, но не достаточное; спектральный признак точнее.
Причина (§4)П-форма п.д.п.: \(u_t + au_x = -\dfrac{a^2\tau}{2}u_{xx} + \dots\) — отрицательная схемная вязкость, «антидиффузия», раскачивающая короткие волны. В §5а (разбор 3): \(\|u^{n+1}\|^2 = \|u^n\|^2 + \tau^2a^2\|u_{\mathring x}\|^2\).

Неявные схемы ведут себя иначе — пример 4.

§5.8 · Пример 4: неявный «уголок»

Пример 4. Неявный «уголок»: безусловная устойчивость

\[ \frac{u_m^{n+1} - u_m^n}{\tau} + a\,\frac{u_m^{n+1} - u_{m-1}^{n+1}}{h} = 0 \quad\Longleftrightarrow\quad (1 + r)\,u_m^{n+1} - r\,u_{m-1}^{n+1} = u_m^n. \tag{5.16} \]

Узлу \((m-1, n+1)\) отвечает \(\lambda e^{-i\alpha}\): \((1 + r)\lambda - r\lambda e^{-i\alpha} = 1\), откуда

\[ \lambda = \frac{1}{1 + r - r\,e^{-i\alpha}}, \qquad |\lambda|^2 = \frac{1}{1 + 4r(1 + r)\sin^2\frac{\alpha}{2}} \le 1 \tag{5.17} \]

при всех \(r > 0\) (знаменатель — выражение (5.13)). Условие Неймана выполнено при любых \(\tau, h\).

ПочемуВ неявной схеме \(u_m^{n+1}\) связано уравнением со всеми узлами верхнего слоя левее \(m\): область зависимости бесконечна, КФЛ выполнено при любом \(r\).
ЦенаСистема уравнений на каждом шаге; для переноса при \(a > 0\) — «бегущий счёт» слева направо при заданном \(u_0^{n+1}\).

Метод не привязан к уравнению переноса. Пример 5 — уравнение теплопроводности и целое семейство схем сразу.

§5.9 · Пример 5: схема с весами

Пример 5. Уравнение теплопроводности, семейство схем с весом \(\sigma\)

\[ \frac{u_m^{n+1} - u_m^n}{\tau} = \sigma\,\frac{u_{m+1}^{n+1} - 2u_m^{n+1} + u_{m-1}^{n+1}}{h^2} + (1 - \sigma)\,\frac{u_{m+1}^{n} - 2u_m^{n} + u_{m-1}^{n}}{h^2}, \qquad \sigma \in [0, 1]. \tag{5.18} \]

\(\sigma = 0\) — явная, \(\sigma = 1\) — неявная, \(\sigma = \tfrac12\) — Кранк–Николсон. Параметр \(\varkappa = \tau/h^2\). Вторая разность на гармонике даёт множитель

\[ e^{i\alpha} - 2 + e^{-i\alpha} = -4\sin^2\frac{\alpha}{2}. \]

Обозначим \(s = \varkappa\sin^2(\alpha/2) \in [0, \varkappa]\).

Подстановка: \(\lambda - 1 = -4s\bigl(\sigma\lambda + 1 - \sigma\bigr)\), откуда

\[ \lambda = \frac{1 - 4(1 - \sigma)s}{1 + 4\sigma s}. \tag{5.19} \]
ЗаметьтеМножитель вещественный — схема симметрична по \(x\); осталось найти, когда \(-1 \le \lambda \le 1\).
§5.9 · Пример 5: условие устойчивости

Схема с весами: \(\sigma \ge \tfrac12 - \tfrac{h^2}{4\tau}\)

\(\lambda \le 1\) — всегда: числитель (5.19) не больше знаменателя при \(s \ge 0\).

\(\lambda \ge -1\) ⟺ \(1 - 4(1 - \sigma)s \ge -1 - 4\sigma s\) ⟺ \(4s(1 - 2\sigma) \le 2\).

  • \(\sigma \ge \tfrac12\): левая часть неположительна — верно при всех \(s\): безусловная устойчивость.
  • \(\sigma < \tfrac12\): нужно \(s \le \dfrac{1}{2(1 - 2\sigma)}\) при всех \(s \le \varkappa\), то есть \(\varkappa(1 - 2\sigma) \le \tfrac12\).
\[ \sigma \ge \frac12 - \frac{h^2}{4\tau}; \qquad \sigma = 0:\ \ \tau \le \frac{h^2}{2}. \tag{5.20} \]
Та же схема — вторым методомЗдесь (5.20) получено как необходимое условие для задачи без границ. В §5а (разбор 4) оно же будет получено энергетическим методом как достаточное — для краевой задачи \(u_0 = u_N = 0\). Совпадение означает: ответ найден точно.
ИтогНеявная схема и схема Кранка–Николсон устойчивы при любых \(\tau, h\); явная — при \(\tau \le h^2/2\).

Все пять схем были двухслойными. У трёхслойной характеристическое уравнение квадратное — и корней два.

§5.10 · Трёхслойная схема «крест»

Трёхслойная схема: квадратное характеристическое уравнение

\[ \frac{u_m^{n+1} - u_m^{n-1}}{2\tau} + a\,\frac{u_{m+1}^n - u_{m-1}^n}{2h} = 0 \tag{5.21} \]

Узлу \((m, n-1)\) отвечает \(\lambda^{-1}\). После умножения на \(\lambda\):

\[ \lambda^2 + 2i\,r\sin\alpha\,\lambda - 1 = 0, \qquad \lambda_{1,2} = -i\,r\sin\alpha \pm \sqrt{1 - r^2\sin^2\alpha}. \tag{5.22} \]

При \(r \le 1\) корень вещественный и \(|\lambda_{1,2}|^2 = (1 - r^2\sin^2\alpha) + r^2\sin^2\alpha = 1\): оба корня на единичной окружности — устойчива и бездиссипативна. При \(r > 1\) и \(\alpha = \pi/2\): \(\lambda_{1,2} = -i(r \pm \sqrt{r^2 - 1})\), один корень по модулю больше 1.

Два корня — два решенияГармоника трёхслойной схемы: \(c_1\lambda_1^n + c_2\lambda_2^n\); условие Неймана — для каждого корня.
Реальный и паразитный\(\lambda_1 \to 1\) при \(\alpha \to 0\) — реальный корень, аппроксимирует точный множитель. \(\lambda_2 \to -1\) — паразитный: эволюция рассогласования двух стартовых слоёв. Подробнее — упражнения §6.

Кратные корни на единичной окружности дают член \(n\lambda^n\): условие \(|\lambda| \le 1\) уже не гарантирует ограниченности. Пора сказать точно, когда условие Неймана достаточно.

§5.11 · Границы и достаточность

Когда условия Неймана достаточно, а когда — нет

Пусть двухслойная схема с постоянными коэффициентами рассматривается на периодической сетке из \(N\) узлов и \(|\lambda(\alpha)| \le 1\) при всех \(\alpha\). Тогда \(\|u^n\| \le \|u^0\|\) в сеточной норме \(L_2\).
Доказательство. Гармоники \(\alpha_k = 2\pi k/N\) — ортогональный базис; \(u^0 = \sum c_ke_{\alpha_k}\), по лемме 1 \(u^n = \sum c_k\lambda(\alpha_k)^ne_{\alpha_k}\), и по равенству Парсеваля \[ \|u^n\|^2 = \sum_k|c_k|^2|\lambda(\alpha_k)|^{2n}\|e_{\alpha_k}\|^2 \le \max_k|\lambda(\alpha_k)|^{2n}\,\|u^0\|^2. \]
Требования метода (лемма 1)Линейность и однородность; постоянные коэффициенты; отсутствие границ. Иначе гармоники — не собственные функции.
Недостаточно
  • Системы: \(\lambda\) — матрица; при недиагонализуемой матрице \(\|G^n\|\) растёт (условия Крайса).
  • Многослойные схемы с кратными корнями на окружности: рост \(n\lambda^n\).
  • Границы, переменные коэффициенты: метод не формулируется.
  • Теорема 2 говорит только о норме \(L_2\), не о \(C\).

Инструмент, дающий достаточные условия и работающий с границами и переменными коэффициентами, — энергетический метод (§5а).
