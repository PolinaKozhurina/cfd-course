План занятия

Решатели систем линейных уравнений сами не пишут: их берут из библиотек. Поэтому цель занятия — понимать, какие бывают решатели, для каких матриц предназначен каждый и как подключить его к своей программе.

IОткуда берутся матрицы (§ 9.0): из каких задач приходят системы и на какие классы делятся их матрицы. IIКак работают решатели (§ 9.1–9.3): метод Га́усса, LU-разложение и разложение Холе́цкого — на примерах и блок-схемах. IIIРазреженные матрицы (§ 9.4): как их хранят и почему для них нужны особые решатели. IVПроверка и выбор (§ 9.5–9.6): чему говорит невязка и как выбрать решатель по свойствам матрицы. VПакеты (§ 9.7): как установить и подключить Eigen и SciPy и когда нужны PARDISO, MUMPS и PETSc.

Начнём с того, откуда берётся система \(Ax=b\).

I. МатрицыIIIIIIVV§9.0. Пример: неявная схема

Откуда берётся система: неявная схема

Решим уравнение теплопроводности \(u_t=u_{xx}\) по неявной схеме, в которой вторая производная берётся на новом слое. Обозначив \(\sigma=\tau/h^2\) и перенеся неизвестные налево, получаем уравнения

\[-\sigma\,y_{i-1}^{n+1}+(1+2\sigma)\,y_i^{n+1}-\sigma\,y_{i+1}^{n+1}=y_i^n,\qquad i=1,\ldots,n.\]

Каждое уравнение связывает значение в узле с двумя соседними, поэтому ненулевые элементы матрицы стоят на трёх диагоналях. Матрица одна и та же на всех шагах по времени, а правая часть на каждом шаге новая.

I. МатрицыIIIIIIVV§9.0. Плотные и разреженные

Плотные и разреженные матрицы

В двумерной задаче та же схема на сетке \(m\times m\) даёт \(n=m^2\) неизвестных, и в каждой строке матрицы всего пять ненулевых элементов: узел и четыре соседа.

Матрицу, большинство элементов которой равны нулю, называют разреженной, остальные матрицы — плотными. Для сетки \(1000\times1000\) различие между ними принципиальное:

I. МатрицыIIIIIIVV§9.0. Положительная определённость

Симметричные положительно определённые матрицы

Определение. Матрица \(A\) называется симметричной положительно определённой, если \(A=A^{\mathsf T}\) и \(x^{\mathsf T}Ax>0\) для любого \(x\ne0\).

Квадратичная форма \(x^{\mathsf T}Ax\) имеет смысл энергии. Для матрицы неявной схемы она равна сумме квадратов

\[x^{\mathsf T}Ax=\sum_ix_i^2+\sigma\sum_i(x_{i+1}-x_i)^2+\ldots>0,\]

то есть дискретному аналогу \(\int(u^2+\tau u_x^2)\,dx\). Так же положительно определены матрицы диффузии и упругости и нормальные уравнения МНК из § 5, поскольку \(x^{\mathsf T}A^{\mathsf T}Ax=\|Ax\|^2\). Перенос нарушает симметрию: связь узла с соседом слева не равна связи с соседом справа. Условие несжимаемости в задаче Стокса даёт симметричную матрицу, которая не является положительно определённой.

Соберём классы матриц и задачи, из которых они берутся.

I. МатрицыIIIIIIVV§9.0. Каталог матриц

Классы матриц и откуда они берутся

На портретах закрашены ненулевые элементы. Плотная матрица возникает, когда каждое неизвестное связано с каждым. Сеточные задачи дают разреженные матрицы: одномерная — трёхдиагональную, двумерная — пятидиагональную.

Перенос и метод Ньютона дают несимметричные матрицы, а задача Стокса — седловую.

По классу матрицы выбирают решатель. Сначала разделим методы решения на два вида.

I. МатрицыIIIIIIVV§9.0. Прямые и итерационные

I. МатрицыIIIIIIVV§9.0. Как решать не нужно

Как решать не нужно

В правиле Кра́мера \(x_i=\det A_i/\det A\) каждый определитель, вычисленный по определению, стоит порядка \(n!\) операций, а всё правило — \(n\cdot n!\). Метод Гаусса, который мы разберём, требует около \(\tfrac23n^3\) операций.

Обратную матрицу не вычисляют. Решение через \(A^{-1}b\) втрое дороже решения через разложение и менее точно. В опыте с Eigen при \(n=2000\) разложение заняло 0,20 с, а вычисление \(A^{-1}b\) — 0,77 с.

Все применяемые на практике прямые методы основаны на исключении Гаусса.

III. РешателиIIIIVV§9.1. Метод Гаусса

Метод 1. Исключение Гаусса

Идея метода: вычитая из уравнений подходящие кратные других уравнений, привести систему к треугольному виду, который решается подстановкой.

Прямой ход. На шаге \(k\) элемент \(a_{kk}\) называют ведущим. Из каждой строки \(i>k\) вычитают строку \(k\), умноженную на множитель \(m_{ik}\), так что элемент \(a_{ik}\) обращается в ноль:

\[m_{ik}=\frac{a_{ik}}{a_{kk}},\qquad a_{ij}\leftarrow a_{ij}-m_{ik}a_{kj},\qquad b_i\leftarrow b_i-m_{ik}b_k,\qquad i,j>k. \tag{9.2}\]

Обратный ход. После \(n-1\) шагов матрица верхнетреугольная, и неизвестные находят снизу вверх:

\[x_i=\Bigl(b_i-\sum_{j>i}a_{ij}x_j\Bigr)\Big/a_{ii},\qquad i=n,\ldots,1. \tag{9.3}\]

Стоимость. На шаге \(k\) пересчитываются \((n-k)^2\) элементов по две операции, всего \(2\sum_k(n-k)^2\approx\tfrac23n^3\); обратный ход стоит \(n^2\). При удвоении \(n\) время растёт в 8 раз.

Проследим метод на числах.

III. РешателиIIIIVV§9.1. Пример B

Пример B: система третьего порядка

Дано: \(2x_1+x_2+x_3=4,\ \ 4x_1+3x_2+3x_3=10,\ \ 8x_1+7x_2+9x_3=24\). Найти решение методом Гаусса.

На первом шаге из второй и третьей строк вычитается первая, умноженная на 2 и на 4; на втором из третьей вычитается утроенная вторая. Обратный ход даёт \(x=(1,1,1)\).

В формуле (9.2) выполняется деление на ведущий элемент. Что будет, если он мал?

III. РешателиIIIIVV§9.1. Малый ведущий элемент

Пример C: малый ведущий элемент

Дано: \(0{,}0001\,x_1+x_2=1,\ \ x_1+x_2=2\); точное решение \(x_1=1{,}0001\ldots,\ x_2=0{,}9999\ldots\) Будем считать с тремя значащими цифрами.

Без перестановки Множитель \(m_{21}=10^4\). Второе уравнение принимает вид \((1-10^4)x_2=2-10^4\); после округления это \(-1{,}00\cdot10^4x_2=-1{,}00\cdot10^4\), откуда \(x_2=1\). Тогда \(x_1=(1-x_2)/0{,}0001=0\). Ответ неверен.
С перестановкой уравнений Ведущим становится 1, множитель \(m_{21}=0{,}0001\). Из \((1-0{,}0001)x_2=1-0{,}0002\) получаем \(x_2=1\), затем \(x_1=2-x_2=1\). Ответ верен.

Большой множитель \(10^4\) усиливает ошибку округления, и при округлении информация о первом уравнении теряется. В арифметике double то же происходит при ведущем элементе \(10^{-20}\).

Отсюда правило: ведущим нужно брать наибольший по модулю элемент столбца.

III. РешателиIIIIVV§9.1. Выбор главного элемента

Частичный выбор главного элемента

На шаге \(k\) среди элементов \(a_{kk},\ldots,a_{nk}\) столбца \(k\) находят наибольший по модулю и переставляют его строку на место \(k\)-й. Перестановка строк — это перестановка уравнений, и решение от неё не меняется.

После перестановки все множители по модулю не больше единицы, поэтому ошибки округления не усиливаются. Почему условие \(\det A\ne0\): перестановки меняют лишь знак определителя, вычитание строк его не меняет, поэтому \(\det A=\pm u_{11}\cdots u_{nn}\). При \(\det A\ne0\) все ведущие элементы ненулевые и метод доходит до конца; при \(\det A=0\) на каком-то шаге столбец под диагональю нулевой — решения нет или их бесконечно много. Для симметричных положительно определённых матриц и матриц с диагональным преобладанием \(|a_{ii}|>\sum_{j\ne i}|a_{ij}|\) выбор не нужен: ведущий элемент у них и так не мал.

III. РешателиIIIIVV§9.1. Блок-схема

Блок-схема метода Гаусса

Цикл по \(k\) — прямой ход: выбор главного элемента, проверка вырожденности и исключение по формуле (9.2). Он выполняется ровно \(n-1\) раз; условие «\(k\lt n-1\)?» — счётчик шагов, а не проверка точности. Затем выполняется обратный ход (9.3).

Метод с выбором главного элемента применим к любой невырожденной плотной матрице и устойчив. Его недостатки — \(\tfrac23n^3\) операций и \(n^2\) памяти, а также то, что матрица и правая часть обрабатываются вместе.

В неявной схеме матрица одна, а правых частей тысячи. Нельзя ли выполнять прямой ход один раз?

III. РешателиIIIIVV§9.2. LU-разложение

Метод 2. LU-разложение

Множители \(m_{ik}\) прямого хода зависят только от матрицы. Если их сохранить, правую часть можно обработать потом. Множители образуют нижнетреугольную матрицу \(L\) с единицами на диагонали, а результат прямого хода — верхнетреугольную \(U\). Для примера B:

С учётом перестановок строк, записанных в матрицу \(P\), получаем разложение и две подстановки вместо прямого хода:

\[PA=LU;\qquad Ly=Pb\ \ (\text{сверху вниз}),\qquad Ux=y\ \ (\text{снизу вверх}). \tag{9.4}\]
III. РешателиIIIIVV§9.2. Матрица P и правые части

Что такое \(P\) и откуда разные \(b\)

\(P\) — единичная матрица с переставленными строками: она записывает перестановки, сделанные выбором главного элемента (в программе — вектор номеров строк). Выбор главного и множители зависят только от \(A\), поэтому \(P\), \(L\), \(U\) вычисляют один раз. С каждой новой \(b\) повторяют те же действия: перестановку (\(Pb\)) и вычитания (\(Ly=Pb\)), затем \(Ux=y\).

Разложение (один раз). \(A=\begin{pmatrix}1&2\\3&4\end{pmatrix}\): главный элемент \(3\) во второй строке,

\[P=\begin{pmatrix}0&1\\1&0\end{pmatrix},\quad L=\begin{pmatrix}1&0\\ \tfrac13&1\end{pmatrix},\quad U=\begin{pmatrix}3&4\\0&\tfrac23\end{pmatrix}.\]

\(b^{(1)}=(5,11)\): \(Pb=(11,5)\), \(y=(11,\tfrac43)\), \(x=(1,2)\).

\(b^{(2)}=(3,7)\): \(Pb=(7,3)\), \(y=(7,\tfrac23)\), \(x=(1,1)\).

Для второй правой части главный элемент и множитель уже не вычисляются.

III. РешателиIIIIVV§9.2. Один раз и много раз

Разложение один раз — решение много раз

Откуда правые части. Матрица задаётся постановкой, правая часть — меняющимися данными: решение предыдущего слоя неявной схемы \(b^{(s)}=y^s\), варианты нагрузки в упругости, итерации упрощённого метода Ньютона \(J(x^0)\Delta x=-F(x^k)\), уточнение по невязке \(Ad=b-A\tilde x\).

Разложение стоит \(\tfrac23n^3\) операций и выполняется один раз, а каждая правая часть обходится двумя подстановками по \(n^2\). При \(n=1000\) и ста правых частях метод Гаусса заново потребовал бы \(7\cdot10^{10}\) операций, а одно разложение и сто подстановок — \(9\cdot10^8\). В опыте с Eigen при \(n=2000\) разложение заняло 0,20 с, а одно решение — 0,0007 с.

Для симметричной положительно определённой матрицы работу можно сократить вдвое.

III. РешателиIIIIVV§9.2. Почему A = LU

Почему \(A=LU\) и чем это лучше

Шаг \(k\) прямого хода — умножение слева на элементарную матрицу \(L_k=I-m_ke_k^{\mathsf T}\), где в столбце \(m_k\) стоят множители шага \(k\), а на местах \(1,\ldots,k\) — нули. Прямой ход: \(L_{n-1}\cdots L_1A=U\). Вычитание отменяется прибавлением, \(L_k^{-1}=I+m_ke_k^{\mathsf T}\), и перекрёстные слагаемые в произведении обращаются в нуль, так как \(e_j^{\mathsf T}m_k=0\) при \(j\le k\):

\[A=L_1^{-1}\cdots L_{n-1}^{-1}U=LU,\qquad L=I+m_1e_1^{\mathsf T}+\ldots+m_{n-1}e_{n-1}^{\mathsf T}.\]

Множитель \(L\) вычислять не нужно: это множители, записанные на свои места. Для одной правой части LU-разложение совпадает с методом Гаусса. Выигрыш — при повторных решениях, когда правая часть следующего шага зависит от решения предыдущего и все правые части сразу не известны.

Почему не обратная матрица. Обращение стоит \(2n^3\) — втрое больше разложения; \(A^{-1}b\) менее точно; обратная к разреженной матрице плотная: у трёхдиагональной матрицы примера A обратная не имеет нулей, а \(L\) и \(U\) двухдиагональны.

III. РешателиIIIIVV§9.3. Разложение Холецкого

Метод 3. Разложение Холецкого

Симметричную положительно определённую матрицу можно разложить в произведение \(A=LL^{\mathsf T}\), где \(L\) — нижнетреугольная с положительной диагональю. Разложение предложил А.-Л. Холе́цкий около 1910 года для задач геодезии. Элементы \(L\) находят по столбцам:

\[l_{jj}=\sqrt{a_{jj}-\sum_{k\lt j}l_{jk}^2},\qquad l_{ij}=\frac1{l_{jj}}\Bigl(a_{ij}-\sum_{k\lt j}l_{ik}l_{jk}\Bigr),\ \ i>j. \tag{9.6}\]

Пример D. Для \(b=(8,10,11)\) из \(Ly=b\) находим \(y=(4,3,2)\), из \(L^{\mathsf T}x=y\) — \(x=(1,1,1)\). Хранится один треугольник, операций вдвое меньше, чем у LU, и выбор главного элемента не нужен.

III. РешателиIIIIVV§9.3. Почему Холецкий

Почему Холецкий вдвое дешевле и не требует выбора

Вдвое дешевле. После шага метода Гаусса блок \(a_{ij}-a_{i1}a_{1j}/a_{11}\) симметричной матрицы снова симметричен, и обновлять нужно только нижний треугольник: \(\tfrac13n^3\) операций и половина памяти. Строки \(U\) — столбцы \(L\), умноженные на ведущие элементы: \(U=DL^{\mathsf T}\), \(A=LDL^{\mathsf T}=(L\sqrt D)(L\sqrt D)^{\mathsf T}\).

Корень извлекается. Исключение без перестановок не меняет угловых миноров, поэтому ведущий элемент шага \(k\) и критерий Сильве́стра дают

\[d_k=l_{kk}^2=\frac{\det A_k}{\det A_{k-1}}>0;\qquad\text{пример D: }\det A_k=4,\ 16,\ 64,\quad d_k=4.\]

Выбор главного не нужен. Диагональ равенства \(A=LL^{\mathsf T}\) даёт \(a_{ii}=l_{i1}^2+\ldots+l_{ii}^2\), поэтому \(|l_{ik}|\le\sqrt{a_{ii}}\): элементы множителя не растут. Без перестановок порядок исключения разреженной матрицы выбирают заранее по шаблону, и значения его не нарушают.

III. РешателиIIIIVV§9.3. Холецкий как проверка

Разложение как проверка положительной определённости

Если матрица не положительно определена, на некотором шаге окажется \(d\le0\). Для \(A=\begin{pmatrix}1&2\\2&1\end{pmatrix}\) получаем \(l_{11}=1\), \(l_{21}=2\) и \(l_{22}^2=1-4=-3\lt0\); действительно, при \(x=(1,-1)\) имеем \(x^{\mathsf T}Ax=-2\).

Библиотеки (LAPACK potrf, Eigen LLT, SciPy cho_factor) сообщают о неудаче кодом ошибки, и его обязательно проверяют. Для знаконеопределённых матриц применяют \(LDL^{\mathsf T}\) или LU.

Все три метода хранят матрицу целиком. Матрицы сеточных задач так хранить нельзя.

IIIIII. РазреженныеIVV§9.4. Хранение: плотное, ленточное

Форматы хранения: плотный, ленточный, симметричный

Плотную матрицу хранят одним массивом по строкам (так делают C и NumPy) или по столбцам (Fortran, LAPACK, Eigen); если перепутать порядок, будет решена система \(A^{\mathsf T}x=b\) без всякого сообщения об ошибке. У ленточной матрицы хранят только \(p+q+1\) диагоналей, а у симметричной — один треугольник.

IIIIII. РазреженныеIVV§9.4. Хранение: COO, CSR, CSC

Разреженные форматы: COO, CSR, CSC

Формат COO хранит тройки в любом порядке и складывает повторы, поэтому в нём собирают матрицу. В CSR строки лежат подряд, и быстро умножение \(Ax\); в CSC подряд лежат столбцы, и этот формат принимают прямые решатели.

Заполнение и переупорядочение

Вычитание строки \(k\) из строки \(i\) создаёт ненулевые элементы в строке \(i\) везде, где они есть в строке \(k\). Новые ненулевые элементы множителей \(L\) и \(U\) называют заполнением; его объём зависит от нумерации неизвестных.

Пуассон, сетка \(300\times300\), \(n=9\cdot10^4\)ненулевыхвремя (Eigen)

Шаг \(k\) стоит около \(c_k^2\), где \(c_k\) — число ненулевых в столбце \(k\) множителя \(L\); всё разложение — \(\sum_kc_k^2\) вместо \(\tfrac13n^3\). У трёх диагоналей \(c_k=1\) и стоимость \(O(n)\), у сетки при естественной нумерации \(c_k\approx\sqrt n\) и \(n^2\).

IIIIII. РазреженныеIVV§9.4. Порядок исключения

Почему важен порядок исключения

В «стрелочной» матрице одна неизвестная связана со всеми. Исключённая первой, она заполняет всю матрицу (заполнение — \(\bullet\)); занумерованная последней, не даёт заполнения вовсе.

\[\begin{pmatrix}\times&\times&\times&\times&\times\\ \times&\times&&&\\ \times&&\times&&\\ \times&&&\times&\\ \times&&&&\times\end{pmatrix}\to\begin{pmatrix}\times&\times&\times&\times&\times\\ \times&\times&\bullet&\bullet&\bullet\\ \times&\bullet&\times&\bullet&\bullet\\ \times&\bullet&\bullet&\times&\bullet\\ \times&\bullet&\bullet&\bullet&\times\end{pmatrix},\qquad\begin{pmatrix}\times&&&&\times\\ &\times&&&\times\\ &&\times&&\times\\ &&&\times&\times\\ \times&\times&\times&\times&\times\end{pmatrix}\to\text{без заполнения}\]

Правило на графе. Неизвестные — вершины, ненулевой \(a_{ij}\) — ребро. Исключение вершины соединяет попарно всех её неисключённых соседей; каждое новое ребро — элемент заполнения. Минимальная степень (AMD) исключает первой вершину с наименьшим числом соседей. Вложенные сечения (METIS) разрезают сетку разделителем, нумеруют его последним и повторяют для половин: исключение в одной половине не связывает её с другой.

Ещё два приёма: столбцы \(L\) с одинаковым шаблоном объединяют в плотные блоки (суперузлы), а независимые части раскладывают параллельно.

IIIIII. РазреженныеIVV§9.4. Три фазы

Три фазы разреженного решателя

Анализ использует только шаблон ненулевых элементов: решатель выбирает нумерацию и заранее вычисляет шаблон множителя \(L\). Численное разложение работает со значениями, а решение — с правой частью. Каждую фазу повторяют лишь тогда, когда изменились её входные данные: в нелинейной задаче меняются значения элементов, но не шаблон, и анализ выполняется один раз на весь расчёт.

IIIIII. РазреженныеIVV§9.4. Предобуславливание

Предобуславливание и прямой решатель

В прямом разреженном решателе предобуславливания нет: он не делает итераций, и ускорять в нём нечего. Переупорядочение в фазе анализа меняет только нумерацию неизвестных и уменьшает заполнение, не меняя ни решения, ни обусловленности.

Предобуславливатель — понятие итерационных методов (§ 10): это легко применяемая матрица \(M\approx A^{-1}\), с которой итерационный метод решает систему \(MAx=Mb\) за меньшее число итераций.

Самый распространённый предобуславливатель строят разложением этого параграфа, но неполным: в ILU и неполном Холецком заполнение отбрасывают, оставляя элементы только на шаблоне \(A\). Полное разложение — идеальный предобуславливатель, с которым итерационный метод сходится за одну итерацию. Поэтому в PETSc прямой решатель задаётся как предобуславливатель -pc_type lu при методе -ksp_type preonly, то есть без итераций.

IIIIIIIV. Проверка и выборV§9.5. Невязка

Проверка решения: невязка

Точное решение \(x^*\) неизвестно, поэтому ошибку \(\tilde x-x^*\) вычислить нельзя. Вместо неё вычисляют невязку — то, насколько найденное решение не удовлетворяет системе:

\[r=b-A\tilde x. \tag{9.7}\]
Факт (Дж. Уи́лкинсон, 1961). Решение, найденное LU-разложением с выбором главного элемента или разложением Холецкого, практически всегда является точным решением близкой системы \((A+\delta A)\tilde x=b\), где \(\delta A\) порядка ошибки округления.

Поэтому у правильно вызванного решателя невязка мала: \(\|r\|\sim10^{-16}\|A\|\|\tilde x\|\). Большая невязка означает ошибку в программе — неверно собранную матрицу, перепутанный формат хранения или непроверенный код ошибки.

Значит ли малая невязка, что ответ точен?

IIIIIIIV. Проверка и выборV§9.5. Невязка и ошибка

Пример E: малая невязка, большая ошибка

Дано: система \(x_1+x_2=2,\ \ x_1+1{,}0001\,x_2=2{,}0001\) с решением \(x^*=(1,1)\) и приближение \(\tilde x=(2,0)\). Найти невязку и ошибку.

Невязка \(r=(0;\ 0{,}0001)\) мала, а ошибка \((1;\,-1)\) того же порядка, что и само решение. Во сколько раз ошибка может превышать невязку, определяет число обусловленности \(\kappa(A)\); здесь \(\kappa\approx4\cdot10^4\). Это свойство задачи, а не метода, и подробно оно разбирается в § 10.

IIIIIIIV. Проверка и выборV§9.6. Выбор решателя

Как выбрать решатель

Решатель выбирают, отвечая на три вопроса о матрице. Первый — разреженная ли она: от этого зависит, хранить ли её целиком. Второй — есть ли у неё особая структура, например три диагонали. Третий — симметрична ли она и положительно определена: тогда применим вдвое более быстрый метод Холецкого.

Если матрица неизвестна, пробуют Холецкого: его неудача сама сообщает, что матрица не положительно определена.

IIIIIIIVV. Пакеты§9.7. Как устроены библиотеки

Как устроены библиотеки

Библиотеки линейной алгебры устроены слоями, и каждый слой опирается на предыдущий.

В основании лежит BLAS (Basic Linear Algebra Subprograms) — стандарт на простейшие операции: скалярное произведение, умножение матрицы на вектор и на матрицу. Его реализации (OpenBLAS, Intel oneMKL, Apple Accelerate) используют векторные команды процессора и все ядра, и именно от них почти целиком зависит скорость решателя.

На BLAS построен LAPACK — разложения и решатели для плотных и ленточных матриц. Имена функций составлены из букв: dgesv — double, general, solve; dpotrf — positive definite, triangular factorization.

Пользователь обычно работает с обёртками — Eigen в C++ и NumPy/SciPy в Python, — а для больших задач применяет PARDISO, MUMPS и PETSc.

Начнём с Eigen.

Matrix3d A;

     2, 5, 3,

LLT<Matrix3d> chol(S);         // S = L L^T
if (chol.info() != Success) {

#include <Eigen/Sparse>
std::vector<Triplet<double>> t;              // (строка, столбец, значение)

    t.emplace_back(i, i, 1 + 2 * s);

IIIIIIIVV. Пакеты§9.7. NumPy и SciPy

NumPy и SciPy

Пакеты устанавливаются командой pip install numpy scipy. Внутри них работает LAPACK с OpenBLAS или oneMKL, поэтому плотные системы решаются так же быстро, как в C++.

import numpy as np
from scipy import linalg

x = np.linalg.solve(A, b)        # LU (gesv)

lu, piv = linalg.lu_factor(A)    # один раз
x = linalg.lu_solve((lu, piv), b)

c = linalg.cho_factor(S)         # Холецкий
y = linalg.cho_solve(c, b)
from scipy import sparse
from scipy.sparse.linalg import spsolve, splu

A = sparse.diags([-s, 1 + 2*s, -s], [-1, 0, 1],
                 shape=(n, n), format='csc')
x = spsolve(A, b)                # SuperLU

F = splu(A)                      # один раз
x = F.solve(b)

Для ленточных систем есть linalg.solve_banded. SciPy удобен для проверки: систему, собранную программой на C++, можно сохранить в файл и решить в SciPy.

IIIIIIIVV. Пакеты§9.7. PETSc, MUMPS, PARDISO

Большие задачи: PARDISO, MUMPS, PETSc

PARDISO — разреженный прямой решатель, который использует все ядра одного компьютера. Он входит в бесплатную библиотеку Intel oneMKL; из Eigen его вызывают классами PardisoLU и PardisoLLT, из Python — пакетом pypardiso.

MUMPS — разреженный прямой решатель для кластеров, работающий через MPI; он решает несимметричные, симметричные и седловые системы. Обычно его подключают через PETSc.

PETSc — среда для больших систем на кластерах: распределённые матрицы, итерационные методы и внешние прямые решатели; на ней построены FEniCS и Firedrake. Решатель выбирают ключами запуска: -ksp_type задаёт итерационный метод, -pc_type — предобуславливатель.

./configure --download-mumps --download-scalapack --download-metis --download-parmetis
mpiexec -n 8 ./prog -ksp_type preonly -pc_type lu -pc_factor_mat_solver_type mumps
mpiexec -n 8 ./prog -ksp_type cg -pc_type gamg          # итерационный, §10
