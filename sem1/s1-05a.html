§5а · Семестр 1

Энергетический метод исследования устойчивости. Одна схема — два исследования

▶ Слайды

В §5 устойчивость проверялась по поведению отдельных гармоник: подстановка \(u_m^n = \lambda^n e^{i\alpha m}\) сводила вопрос к модулю множителя перехода. Настоящий параграф посвящён второму, принципиально иному способу — энергетическому методу, или методу энергетических неравенств. Он не разлагает решение на гармоники, а оценивает его норму целиком, повторяя на сетке ту выкладку, которой в теории уравнений в частных производных доказывают закон сохранения энергии. Чтобы различие и взаимодополнительность двух методов были видны, каждая схема ниже исследуется дважды — гармониками и энергией — и результаты сравниваются. Изложение следует книгам А. А. Самарского [1] и А. А. Самарского, А. В. Гулина [2]; подчёркнутые пунктиром термины открывают карточку с определением.

§5а.1. Зачем нужен второй метод

Метод гармоник держался на лемме 1 §5: гармоника \(e^{i\alpha m}\) — собственная функция оператора перехода, потому что оператор перестановочен со сдвигом по сетке. Это требует постоянных коэффициентов и отсутствия границ. Как только хотя бы одно из условий нарушается, подстановка (5.2) теряет смысл:

Задачи, для которых метод гармоник неприменим
  • Переменные коэффициенты: \(u_t + a(x)u_x = 0\), \(u_t = (k(x)u_x)_x\) — коэффициенты схемы зависят от номера узла.
  • Краевые условия: на отрезке с условиями \(u(0,t) = u(l,t) = 0\) сеточные функции обязаны обращаться в нуль на концах, а гармоника этого не делает.
  • Неравномерные сетки и нелинейные схемы: нет инвариантности относительно сдвига, нет принципа суперпозиции.

Есть и вторая причина. Условие Неймана — необходимое (теорема 1 §5); для систем уравнений и многослойных схем оно может выполняться при неустойчивости. Энергетический метод устроен иначе: он доказывает априорную оценку решения — неравенство вида

\[ \|y^{n+1}\| \le \|y^{n}\| \qquad\text{или}\qquad \|y^{n}\|^2 \le \|y^{0}\|^2 + C\sum_{k=0}^{n-1}\tau\,\|\varphi^{k}\|^2, \tag{5а.1} \]

полученное до и без решения задачи, из одной лишь структуры схемы. Такое неравенство есть в точности оценка (2.14) Определения 4 §2 — устойчивость с явно указанной нормой и постоянной. Условия, при которых оценка доказана, — достаточные условия устойчивости. Гармоники дают необходимые условия, энергия — достаточные; когда они совпадают, ответ найден точно. Цена метода — необходимость провести для каждой схемы своё алгебраическое тождество.

§5а.2. Дифференциальный прототип: закон сохранения энергии

Проведём выкладку для самого дифференциального уравнения; всё дальнейшее будет её сеточной копией. Уравнение переноса на отрезке \([0, l]\) с периодическими условиями:

\[ \frac{\partial u}{\partial t} + a\,\frac{\partial u}{\partial x} = 0, \qquad u(0, t) = u(l, t), \qquad a = \mathrm{const}. \tag{5а.2} \]

Умножим уравнение на \(u\) и проинтегрируем по \(x\) от \(0\) до \(l\):

\[ \int_0^l u\,u_t\,dx = \frac{1}{2}\frac{d}{dt}\int_0^l u^2\,dx, \qquad \int_0^l a\,u\,u_x\,dx = \frac{a}{2}\int_0^l \frac{\partial}{\partial x}\bigl(u^2\bigr)\,dx = \frac{a}{2}\Bigl[u^2(l,t) - u^2(0,t)\Bigr] = 0. \]

Внеинтегральный член обратился в нуль благодаря периодичности — именно здесь в выкладку вошло краевое условие. Обозначив \(E(t) = \int_0^l u^2\,dx = \|u(\cdot,t)\|^2_{L_2}\), получаем

\[ \frac{dE}{dt} = 0, \qquad \|u(\cdot,t)\|_{L_2} = \|u(\cdot,0)\|_{L_2}. \tag{5а.3} \]

Величину \(E(t)\) называют энергией решения: для волнового уравнения такая же выкладка даёт сохранение механической энергии струны \(\int(u_t^2 + c^2u_x^2)\,dx\). Для уравнения теплопроводности \(u_t = \nu u_{xx}\), \(u(0,t) = u(l,t) = 0\), нужно ещё интегрирование по частям:

\[ \frac{1}{2}\frac{d}{dt}\int_0^l u^2\,dx = \nu\int_0^l u\,u_{xx}\,dx = \nu\Bigl[u\,u_x\Bigr]_0^l - \nu\int_0^l u_x^2\,dx = -\,\nu\int_0^l u_x^2\,dx \le 0, \tag{5а.4} \]

откуда \(\|u(\cdot,t)\| \le \|u(\cdot,0)\|\): энергия убывает (диссипирует); внеинтегральный член снова исчез благодаря краевым условиям.

Три действия, которые переносятся на сетку Умножение уравнения на решение и интегрирование — на сетке скалярное произведение (§5а.3). Интегрирование по частям — на сетке суммирование по частям (§5а.5). Обращение внеинтегральных членов в нуль за счёт краевых условий — на сетке за счёт значений в граничных узлах или периодичности. Производная по времени заменяется разностью между слоями. Энергетический метод для разностных схем — это ровно эти три действия в сеточных терминах.

§5а.3. Скалярное произведение сеточных функций

Введём на \([0, l]\) равномерную сетку \(\omega_h = \{x_i = ih,\ i = \overline{0, N},\ h = l/N\}\) и пространство \(H\) сеточных функций \(y = \{y_i\}\) (§1.10). Обозначения А. А. Самарского для разностных отношений:

\[ y_{x,i} = \frac{y_{i+1} - y_i}{h}, \qquad y_{\bar x,i} = \frac{y_i - y_{i-1}}{h}, \qquad y_{\mathring{x},i} = \frac{y_{i+1} - y_{i-1}}{2h}, \qquad y_{\bar x x,i} = \frac{y_{i+1} - 2y_i + y_{i-1}}{h^2} \tag{5а.5} \]

(разность вперёд, назад, центральная, вторая). Индекс узла при записи операторов опускаем; \(\Lambda y = y_{\bar x x}\). Для двухслойных схем \(y = y^n\), \(\hat y = y^{n+1}\) и

\[ y_t = \frac{\hat y - y}{\tau}, \qquad y^{(\sigma)} = \sigma\hat y + (1 - \sigma)\,y, \qquad y^{(1/2)} = \frac{\hat y + y}{2}. \tag{5а.6} \]
Скалярное произведение сеточных функций. Пусть \(H\) — пространство сеточных функций на \(\omega_h\), удовлетворяющих периодическому условию \(y_0 = y_N\). Положим \[ (y, v) = \sum_{i=1}^{N} h\,y_i v_i, \qquad \|y\| = \sqrt{(y, y)} = \Bigl(\sum_{i=1}^{N} h\,y_i^2\Bigr)^{1/2}. \tag{5а.7} \] Для краевой задачи первого рода рассматривается пространство \(H_0\) функций с \(y_0 = y_N = 0\), и сумма берётся по внутренним узлам \(i = \overline{1, N-1}\).

Форма (5а.7) — скалярное произведение: билинейна, симметрична, \((y, y) > 0\) при \(y \ne 0\). Норма \(\|y\|\) — сеточная норма \(L_2\) из формулы (1.14): интегральная сумма для \(\int_0^l y^2\,dx\); множитель \(h\) нужен, чтобы норма имела предел при \(h \to 0\). Выполняется неравенство Коши–Буняковского \(|(y, v)| \le \|y\|\,\|v\|\). На периодической сетке сдвиг индекса не меняет нормы: \(\sum_i h\,y_{i-1}^2 = \|y\|^2\).

Почему не норма \(C\) Нормы связаны неравенствами \(\sqrt{h}\,\|y\|_C \le \|y\| \le \sqrt{l}\,\|y\|_C\). Постоянная \(\sqrt{h}\) стремится к нулю: оценка в \(L_2\) не влечёт оценки в \(C\), равномерной по \(h\). Энергетический метод работает в \(L_2\) и в порождённых ею энергетических нормах, потому что только в них есть скалярное произведение. Устойчивость в норме \(C\) доказывается принципом максимума (§11).

§5а.4. Самосопряжённые, положительные и кососимметричные операторы. Энергетическая норма

Сопряжённый, самосопряжённый, положительный оператор. Оператор \(A^*\) называется сопряжённым к линейному оператору \(A\colon H \to H\), если \((Ay, v) = (y, A^*v)\) при всех \(y, v \in H\). Оператор называется самосопряжённым, если \(A^* = A\), и кососимметричным, если \(A^* = -A\). Самосопряжённый оператор называется положительным, \(A > 0\), если \((Ay, y) > 0\) при \(y \ne 0\), и неотрицательным, \(A \ge 0\), если \((Ay, y) \ge 0\). Для самосопряжённых операторов запись \(A \ge B\) означает \(A - B \ge 0\).

Пространство \(H\) конечномерно, \(A\) задаётся матрицей, и всё это — обычные понятия линейной алгебры: самосопряжённость есть симметричность матрицы, положительность — положительная определённость. Запись \(A \ge B\) называется операторным неравенством; именно в такой форме будут формулироваться условия устойчивости. Для кососимметричного оператора \((Ay, y) = (y, A^*y) = -(Ay, y)\), откуда \((Ay, y) = 0\): такой оператор не меняет энергии — сеточный аналог того, что в (5а.3) член \(au_x\) выпал из баланса.

Энергетическая норма. Пусть \(A = A^* > 0\). Форма \((Ay, v)\) есть скалярное произведение в \(H\); порождённая ею норма \[ \|y\|_A = \sqrt{(Ay, y)} \tag{5а.8} \] называется энергетической нормой, а пространство \(H\) с этой нормой обозначается \(H_A\).

Наконец, норма оператора \(\|A\| = \sup_{y\ne 0}\|Ay\|/\|y\|\). Для \(A = A^* \ge 0\) по неравенству Коши–Буняковского \((Ay, y) \le \|Ay\|\,\|y\| \le \|A\|\,\|y\|^2\):

\[ (Ay, y) \le \|A\|\,\|y\|^2, \qquad\text{то есть}\qquad A \le \|A\|\,E. \tag{5а.9} \]

Неравенство (5а.9) — основной способ превращать операторные условия устойчивости в условия на \(\tau\) и \(h\).

§5а.5. Формулы суммирования по частям (разностные формулы Грина)

Формула суммирования по частям. Для любых сеточных функций \(y\), \(v\), заданных на \(\omega_h\), \[ \sum_{i=1}^{N} h\,y_i\,v_{\bar x,i} = -\sum_{i=0}^{N-1} h\,y_{x,i}\,v_i + y_N v_N - y_0 v_0. \tag{5а.10} \]
Доказательство. Раскроем разность назад и разобьём сумму на две: \[ \sum_{i=1}^{N} h\,y_i\,\frac{v_i - v_{i-1}}{h} = \sum_{i=1}^{N} y_i v_i - \sum_{i=1}^{N} y_i v_{i-1}. \] Во второй сумме заменим индекс \(i - 1 = j\): она равна \(\sum_{j=0}^{N-1} y_{j+1} v_j\). Первую сумму запишем как \(\sum_{j=0}^{N-1} y_j v_j + y_N v_N - y_0 v_0\) — добавили и вычли член с \(j = 0\), отделили член с \(j = N\). Вычитая, получаем \[ y_N v_N - y_0 v_0 - \sum_{j=0}^{N-1}(y_{j+1} - y_j)\,v_j = y_N v_N - y_0 v_0 - \sum_{j=0}^{N-1} h\,y_{x,j}\,v_j. \]

Это сеточный аналог формулы \(\int_0^l y\,v'\,dx = -\int_0^l y'\,v\,dx + [yv]_0^l\) (преобразование Абеля). Три следствия.

Следствие 1. Первая разностная формула Грина: \(-\Lambda\) самосопряжён и положителен на \(H_0\)

Пусть \(y, v \in H_0\). Применим (5а.10) к \(w = y_{\bar x}\) и \(v\) в форме \(\sum_{i=0}^{N-1} h\,w_{x,i}v_i = -\sum_{i=1}^{N} h\,w_i v_{\bar x,i} + w_Nv_N - w_0v_0\). Граничные члены исчезают, так как \(v_0 = v_N = 0\), и слагаемое \(i = 0\) слева — тоже:

\[ (\Lambda y, v) = \sum_{i=1}^{N-1} h\,y_{\bar x x,i}\,v_i = -\sum_{i=1}^{N} h\,y_{\bar x,i}\,v_{\bar x,i} \equiv -\,(y_{\bar x}, v_{\bar x}]. \tag{5а.11} \]

Правая часть симметрична по \(y, v\), поэтому \(\Lambda\) самосопряжён на \(H_0\); полагая \(v = y\), находим

\[ (-\Lambda y, y) = \sum_{i=1}^{N} h\,y_{\bar x,i}^2 \ge 0, \tag{5а.12} \]

причём равенство возможно лишь при \(y = \mathrm{const}\), а с учётом \(y_0 = 0\) — лишь при \(y \equiv 0\). Итак, \(A = -\Lambda\) — самосопряжённый положительный оператор на \(H_0\), и \(\|y\|_A^2 = (y_{\bar x}, y_{\bar x}]\) — сеточный аналог \(\int_0^l u_x^2\,dx\). Краевые условия вошли именно здесь.

Следствие 2. Периодическая сетка: кососимметричность центральной разности

На периодической сетке граничные члены (5а.10) взаимно уничтожаются; (5а.11)–(5а.12) верны без условий на концах, но \(-\Lambda \ge 0\) уже не \(> 0\) (постоянная функция). Для центральной разности

\[ (y_{\mathring x}, y) = \frac{1}{2}\Bigl(\sum_{i=1}^{N} y_i y_{i+1} - \sum_{i=1}^{N} y_i y_{i-1}\Bigr) = 0, \tag{5а.13} \]

так как обе суммы при периодическом сдвиге индекса совпадают; более того, \((y_{\mathring x}, v) = -(y, v_{\mathring x})\): центральная разность на периодической сетке кососимметрична — двойник равенства \(\int u\,u_x\,dx = 0\).

Следствие 3. Оценка нормы \(-\Lambda\)

Из (5а.12) и неравенства \((a - b)^2 \le 2a^2 + 2b^2\):

\[ (-\Lambda y, y) = \sum_{i=1}^{N} h\,\frac{(y_i - y_{i-1})^2}{h^2} \le \frac{2}{h^2}\sum_{i=1}^{N} h\bigl(y_i^2 + y_{i-1}^2\bigr) \le \frac{4}{h^2}\,\|y\|^2, \qquad\text{то есть}\qquad -\Lambda \le \frac{4}{h^2}\,E. \tag{5а.14} \]

Оценка точна по порядку: собственные числа \(-\Lambda\) на \(H_0\) равны \(\frac{4}{h^2}\sin^2\frac{k\pi h}{2l}\), наибольшее — \(\frac{4}{h^2}\cos^2\frac{\pi h}{2l} < \frac{4}{h^2}\). Собственные функции — сеточные синусы \(\sin(k\pi x_i/l)\): это гармоники §5, приспособленные к краевым условиям первого рода.

§5а.6. Разбор 1: явный «уголок» — гармоники и энергия

Инструменты собраны. Первая схема — явный «уголок» (5.8) на периодической сетке:

\[ \hat y_i = (1 - r)\,y_i + r\,y_{i-1}, \qquad r = \frac{a\tau}{h}. \tag{5а.15} \]
Гармоники (§5.5)

Подстановка \(y_i = \lambda^n e^{i\alpha i}\) даёт \(\lambda = 1 - r + re^{-i\alpha}\) и

\[ |\lambda|^2 = 1 - 4r(1 - r)\sin^2\frac{\alpha}{2}. \]

Условие \(|\lambda| \le 1\) при всех \(\alpha\) равносильно \(r(1 - r) \ge 0\), то есть \(0 \le r \le 1\).

Результат: необходимое условие \(r \le 1\); для схемы без границ оно и достаточно в \(L_2\) (теорема 2 §5).

Энергия

Неравенство выпуклости: при \(\alpha, \beta \ge 0\), \(\alpha + \beta = 1\), для любых чисел \(p, q\)

\[ (\alpha p + \beta q)^2 \le \alpha p^2 + \beta q^2, \tag{5а.16} \]

так как разность правой и левой частей равна \(\alpha\beta(p - q)^2 \ge 0\). При \(0 \le r \le 1\) коэффициенты \(1 - r\), \(r\) неотрицательны, и \(\hat y_i^2 \le (1 - r)y_i^2 + r\,y_{i-1}^2\). Умножаем на \(h\), суммируем; на периодической сетке \(\sum h\,y_{i-1}^2 = \|y\|^2\):

\[ \|\hat y\|^2 \le (1 - r)\|y\|^2 + r\|y\|^2 = \|y\|^2. \tag{5а.17} \]

Результат: \(\|y^n\| \le \|y^0\|\) при \(0 \le r \le 1\) — достаточное условие, устойчивость в \(L_2\) с \(C = 1\).

Сопоставление. Необходимое условие гармоник и достаточное условие энергии совпали: \(r \le 1\) — точный ответ. Обратите внимание, где энергетический метод использовал \(r \le 1\): в неравенстве (5а.16) оба коэффициента должны быть неотрицательны; при \(r > 1\) приём не проходит — и схема действительно неустойчива. Постоянство \(a\) в энергетической выкладке нигде не использовано (см. разбор 5). Та же выкладка в норме \(C\): \(|\hat y_i| \le (1 - r)|y_i| + r|y_{i-1}| \le \|y\|_C\) — принцип максимума (§11).

§5а.7. Разбор 2: неявный «уголок»

Схема (5.16) на периодической сетке:

\[ (1 + r)\,\hat y_i - r\,\hat y_{i-1} = y_i. \tag{5а.18} \]
Гармоники (§5.8)

\(\lambda = \bigl(1 + r - re^{-i\alpha}\bigr)^{-1}\),

\[ |\lambda|^2 = \frac{1}{1 + 4r(1 + r)\sin^2\frac{\alpha}{2}} \le 1 \]

при всех \(r > 0\).

Результат: условие Неймана выполнено при любых \(\tau\), \(h\) — безусловная устойчивость (необходимое условие не даёт ограничений).

Энергия

Умножим (5а.18) скалярно на \(\hat y\): \((1 + r)\|\hat y\|^2 - r\,(\hat y_{-1}, \hat y) = (y, \hat y)\), где \(\hat y_{-1}\) — сдвинутая функция \(\{\hat y_{i-1}\}\). По неравенству Коши–Буняковского и периодичности \((\hat y_{-1}, \hat y) \le \|\hat y_{-1}\|\,\|\hat y\| = \|\hat y\|^2\), поэтому левая часть не меньше \((1 + r)\|\hat y\|^2 - r\|\hat y\|^2 = \|\hat y\|^2\). Правая часть не больше \(\|y\|\,\|\hat y\|\). Итого

\[ \|\hat y\|^2 \le \|y\|\,\|\hat y\| \quad\Longrightarrow\quad \|\hat y\| \le \|y\|. \tag{5а.19} \]

Результат: \(\|y^n\| \le \|y^0\|\) при любых \(r \ge 0\) — достаточное условие.

Сопоставление. Оба метода дают безусловную устойчивость. Энергетическая выкладка заняла три строки и не потребовала ни одной формулы Грина: неявность вошла через то, что уравнение умножается на новый слой \(\hat y\), и слагаемое \((1 + r)\|\hat y\|^2\) «перевешивает» \(r(\hat y_{-1}, \hat y)\) при любом \(r\). Именно так безусловная устойчивость неявных схем выглядит в энергетическом методе: неявная часть попадает в левую часть тождества с нужным знаком.

§5а.8. Разбор 3: явная схема с центральной разностью

Схема (5.14) на периодической сетке в обозначениях (5а.5): \(\hat y = y - \tau a\,y_{\mathring x}\).

Гармоники (§5.7)

\(\lambda = 1 - ir\sin\alpha\),

\[ |\lambda|^2 = 1 + r^2\sin^2\alpha \ge 1, \]

строго больше единицы при \(\alpha \ne 0, \pi\).

Результат: условие Неймана нарушено при любых \(\tau\), \(h\) — абсолютная неустойчивость.

Энергия

Вычислим норму нового слоя точно:

\[ \|\hat y\|^2 = \|y\|^2 - 2\tau a\,(y_{\mathring x}, y) + \tau^2a^2\,\|y_{\mathring x}\|^2 = \|y\|^2 + \tau^2a^2\,\|y_{\mathring x}\|^2, \tag{5а.20} \]

так как по (5а.13) \((y_{\mathring x}, y) = 0\). Энергия растёт на каждом шаге на \(\tau^2a^2\|y_{\mathring x}\|^2 > 0\), если \(y \ne \mathrm{const}\).

Результат: оценки \(\|\hat y\| \le \|y\|\) нет ни при каком \(\tau\); для гармоники \(\|y_{\mathring x}\|^2 = \frac{\sin^2\alpha}{h^2}\|y\|^2\), и (5а.20) даёт \(\|\hat y\|^2 = (1 + r^2\sin^2\alpha)\|y\|^2\).

Сопоставление. Оба метода дают неустойчивость, и энергетическое тождество (5а.20) на гармонике воспроизводит число \(|\lambda|^2\) буквально. Но тождество говорит больше: рост энергии за шаг пропорционален \(\|y_{\mathring x}\|^2\), то есть велик для негладких данных и мал для гладких. Это объясняет, почему такая схема на гладком профиле «работает» несколько десятков шагов, а затем взрывается пилой: пила имеет наибольшую \(\|y_{\mathring x}\|\). Кососимметричность центральной разности, из-за которой в (5а.20) выпал линейный член, в §5а.15 (упражнение 3) станет источником сохранения энергии — если аппроксимировать по времени симметрично.

§5а.9. Каноническая форма двухслойной схемы

Три разбора выше проведены «вручную». Для схем с самосопряжённым пространственным оператором есть общая теорема; чтобы её сформулировать, приведём двухслойные схемы к единой записи.

Каноническая форма. Двухслойная разностная схема записана в канонической форме, если она имеет вид \[ B\,\frac{y^{n+1} - y^{n}}{\tau} + A\,y^{n} = \varphi^{n}, \qquad\text{в обозначениях (5а.6):}\quad B y_t + A y = \varphi, \tag{5а.21} \] где \(A\), \(B\colon H \to H\) — линейные операторы, \(\varphi^n \in H\) — правая часть, и оператор \(B\) обратим.

Обратимость \(B\) означает разрешимость: \(y^{n+1} = y^n - \tau B^{-1}(Ay^n - \varphi^n)\). Оператор \(B\) описывает неявную часть схемы, \(A\) — пространственный оператор.

Примеры приведения к канонической форме
  1. Явная схема для уравнения теплопроводности \(y_t = \Lambda y + \varphi\) на \(H_0\): \(y_t - \Lambda y = \varphi\), значит \(B = E\), \(A = -\Lambda\).
  2. Схема с весами \(y_t = \Lambda y^{(\sigma)} + \varphi\), \(y^{(\sigma)} = y + \sigma\tau y_t\): \(y_t = \Lambda y + \sigma\tau\Lambda y_t + \varphi\), то есть \((E - \sigma\tau\Lambda)y_t - \Lambda y = \varphi\). Итак, \(A = -\Lambda\), \(B = E + \sigma\tau A\).
  3. «Уголок» (5а.15): \(y_t + a\,y_{\bar x} = 0\); \(B = E\), \(A = a\,\partial_{\bar x}\) — оператор не самосопряжён, поэтому разборы 1–3 велись напрямую.

§5а.10. Основная теорема об устойчивости в энергетической норме

Устойчивость по начальным данным в \(H_A\) (А. А. Самарский). Пусть в схеме (5а.21) с \(\varphi \equiv 0\) оператор \(A\) самосопряжён и положителен, \(A = A^* > 0\), а оператор \(B\) обратим и удовлетворяет операторному неравенству \[ B \ge \frac{\tau}{2}\,A, \qquad\text{то есть}\qquad (By, y) \ge \frac{\tau}{2}\,(Ay, y)\ \ \text{при всех } y \in H. \tag{5а.22} \] Тогда \[ \|y^{n+1}\|_A \le \|y^{n}\|_A, \qquad n = 0, 1, \dots, \qquad\text{и, следовательно,}\qquad \|y^{n}\|_A \le \|y^{0}\|_A. \tag{5а.23} \]

Оценка (5а.23) — устойчивость по начальным данным в энергетической норме с постоянной \(C = 1\), не зависящей ни от \(\tau\), ни от \(h\), ни от числа шагов. Доказательство разобьём на этапы и после каждого укажем, какая гипотеза использована.

Доказательство. Этап 1. Замена текущего слоя полусуммой слоёв Выразим \(y = y^n\) через полусумму \(y^{(1/2)} = \frac12(\hat y + y)\) и разностную производную \(y_t = \frac1\tau(\hat y - y)\): \[ y = y^{(1/2)} - \frac{\tau}{2}\,y_t \qquad\Bigl(\text{проверка: } \tfrac12(\hat y + y) - \tfrac12(\hat y - y) = y\Bigr). \] Подставим в \(By_t + Ay = 0\): \[ \Bigl(B - \frac{\tau}{2}A\Bigr)y_t + A\,y^{(1/2)} = 0. \tag{5а.24} \] Гипотезы пока не использованы — это тождественное преобразование. Этап 2. Умножение на \(2\tau y_t\) Умножим (5а.24) скалярно на \(2\tau y_t\) — сеточное «умножение на решение и интегрирование»; множитель \(2\tau\) подобран так, чтобы второе слагаемое стало разностью энергий: \[ 2\tau\Bigl(\bigl(B - \tfrac{\tau}{2}A\bigr)y_t,\ y_t\Bigr) + 2\tau\bigl(A y^{(1/2)},\ y_t\bigr) = 0. \tag{5а.25} \] Этап 3. Второе слагаемое — разность энергий используется A = A* \[ 2\tau\bigl(A y^{(1/2)}, y_t\bigr) = \bigl(A(\hat y + y),\ \hat y - y\bigr) = (A\hat y, \hat y) - (A\hat y, y) + (Ay, \hat y) - (Ay, y). \] По самосопряжённости \((Ay, \hat y) = (y, A\hat y) = (A\hat y, y)\), средние слагаемые уничтожаются, и \[ 2\tau\bigl(A y^{(1/2)}, y_t\bigr) = \|\hat y\|_A^2 - \|y\|_A^2 \tag{5а.26} \] — сеточный аналог равенства \(2\int u\,u_t\,dx = \frac{d}{dt}\int u^2\,dx\). Этап 4. Энергетическое тождество и оценка используется B ≥ (τ/2)A Из (5а.25) и (5а.26) — точное энергетическое тождество \[ \|\hat y\|_A^2 = \|y\|_A^2 - 2\tau\Bigl(\bigl(B - \tfrac{\tau}{2}A\bigr)y_t,\ y_t\Bigr). \tag{5а.27} \] По (5а.22) вычитаемое неотрицательно, поэтому \(\|\hat y\|_A^2 \le \|y\|_A^2\). используется A > 0 — положительность \(A\) гарантирует, что \(\|\cdot\|_A\) — норма, и извлечение корня даёт (5а.23).
Смысл тождества (5а.27) Энергия на новом слое равна энергии на старом минус «диссипация» \(2\tau((B - \frac{\tau}{2}A)y_t, y_t)\). Условие \(B \ge \frac{\tau}{2}A\) означает ровно то, что схема не производит энергии. Для явной схемы \(B = E\) оно превращается в \(\frac{\tau}{2}A \le E\) — ограничение на шаг через норму \(A\); для неявных схем \(B\) содержит слагаемое \(\sigma\tau A\), которое «оплачивает» правую часть при любом \(\tau\). Так одна теорема объясняет и условную устойчивость явных схем, и безусловную — неявных.
Устойчивость в \(H_B\); необходимость условия. Пусть \(A = A^* > 0\) и \(B = B^* > 0\). Тогда условие (5а.22) необходимо и достаточно для оценки (5а.23); при его выполнении справедлива также оценка \(\|y^{n+1}\|_B \le \|y^{n}\|_B\). В частности, для явных схем (\(B = E\)) условие \(E \ge \frac{\tau}{2}A\) равносильно оценке \(\|y^{n+1}\| \le \|y^{n}\|\) в норме \(L_2\).

Принимаем без доказательства [1, гл. VI, §2; 2]. Для явной схемы утверждение проверяется по спектру: \(\hat y = (E - \tau A)y\), и \(\|E - \tau A\| \le 1\) тогда и только тогда, когда все собственные числа \(1 - \tau\lambda_k\) лежат на \([-1, 1]\), то есть \(\tau\lambda_k \le 2\) — это и есть \(\frac{\tau}{2}A \le E\). Для схем с самосопряжёнными \(A\), \(B\) энергетический метод даёт, таким образом, критерий.

§5а.11. Разбор 4: схема с весами для уравнения теплопроводности

Задача \(u_t = u_{xx}\), \(u(0,t) = u(l,t) = 0\); схема с весом \(\sigma \in [0, 1]\) (5.18):

\[ y_t = \Lambda\bigl(\sigma\hat y + (1 - \sigma)\,y\bigr), \qquad y_0 = y_N = 0. \tag{5а.28} \]
Гармоники (§5.9)

Задача без границ. Подстановка гармоники даёт вещественный множитель

\[ \lambda = \frac{1 - 4(1 - \sigma)s}{1 + 4\sigma s}, \qquad s = \frac{\tau}{h^2}\sin^2\frac{\alpha}{2}. \]

Условие \(-1 \le \lambda \le 1\) при всех \(s \le \tau/h^2\) равносильно

\[ \sigma \ge \frac12 - \frac{h^2}{4\tau}; \]

при \(\sigma \ge 1/2\) — выполнено всегда.

Результат: необходимое условие.

Энергия (теорема 1)

Задача с краевыми условиями. \(A = -\Lambda\), \(B = E + \sigma\tau A\) (§5а.9); по следствию 1 \(A = A^* > 0\) на \(H_0\), \(B = B^* > 0\) при \(\sigma \ge 0\). Условие (5а.22):

\[ E + \sigma\tau A \ge \frac{\tau}{2}A \iff E + \Bigl(\sigma - \frac12\Bigr)\tau A \ge 0. \tag{5а.29} \]

При \(\sigma \ge 1/2\) верно при любых \(\tau, h\) (сумма положительного и неотрицательного). При \(\sigma < 1/2\) нужно \((\frac12 - \sigma)\tau(Ay, y) \le \|y\|^2\); по (5а.9), (5а.14) достаточно \((\frac12 - \sigma)\tau\cdot\frac{4}{h^2} \le 1\), то есть

\[ \sigma \ge \frac12 - \frac{h^2}{4\tau}. \tag{5а.30} \]

Результат: достаточное условие; при нём \(\|y^n\|_A \le \|y^0\|_A\) и \(\|y^n\| \le \|y^0\|\) (теоремы 1, 2).

Сопоставление. Условия совпали — это критерий устойчивости схемы с весами (классический результат Самарского). При \(\sigma = 0\) получаем \(\tau \le h^2/2\) для явной схемы, при \(\sigma \ge 1/2\) — безусловную устойчивость неявной схемы и схемы Кранка–Николсон. Разница между методами — в том, что доказано: гармоники — ограниченность отдельных волн на бесконечной прямой, энергия — оценку нормы решения краевой задачи с явной постоянной. Заметьте, что грубая оценка \(\|A\| \le 4/h^2\) вместо точной \(\frac{4}{h^2}\cos^2\frac{\pi h}{2l}\) дала условие с запасом порядка \(O(h^2)\) — характерная «плата» энергетического метода, здесь несущественная.
Рис. 1. Область устойчивости схемы с весами (5а.28) на плоскости \((\tau/h^2,\ \sigma)\): один и тот же ответ получен гармониками (необходимость) и энергетическим методом (достаточность).

§5а.12. Устойчивость по правой части

Определение 4 §2 требует оценки решения через правую часть. Энергетический метод даёт и её — ценой небольшого усиления условия (5а.22). Понадобится \(\varepsilon\)-неравенство

\[ |(\varphi, v)| \le \|\varphi\|\,\|v\| \le \varepsilon\,\|v\|^2 + \frac{1}{4\varepsilon}\,\|\varphi\|^2, \qquad \varepsilon > 0, \tag{5а.31} \]

которое следует из неравенства Коши–Буняковского и из \(ab \le \varepsilon a^2 + b^2/(4\varepsilon)\) (раскрытый квадрат \((\sqrt{\varepsilon}\,a - b/(2\sqrt{\varepsilon}))^2 \ge 0\)). Его роль — «разменять» произведение двух норм на сумму квадратов с произвольно малым коэффициентом при одной из них.

Устойчивость по правой части. Пусть \(A = A^* > 0\), \(B\) обратим и при некотором \(\varepsilon > 0\), не зависящем от \(\tau\) и \(h\), \[ B \ge \varepsilon E + \frac{\tau}{2}\,A. \tag{5а.32} \] Тогда решение схемы (5а.21) удовлетворяет оценке \[ \|y^{n+1}\|_A^2 \le \|y^{0}\|_A^2 + \frac{1}{2\varepsilon}\sum_{k=0}^{n}\tau\,\|\varphi^{k}\|^2. \tag{5а.33} \]
Доказательство. Этапы 1–3 предыдущего доказательства для уравнения с правой частью дают \[ 2\tau\Bigl(\bigl(B - \tfrac{\tau}{2}A\bigr)y_t, y_t\Bigr) + \|\hat y\|_A^2 - \|y\|_A^2 = 2\tau\,(\varphi, y_t). \] используется (5а.32) Слева \(((B - \frac{\tau}{2}A)y_t, y_t) \ge \varepsilon\|y_t\|^2\). Справа по (5а.31): \(2\tau(\varphi, y_t) \le 2\tau\varepsilon\|y_t\|^2 + \frac{\tau}{2\varepsilon}\|\varphi\|^2\). Слагаемые \(2\tau\varepsilon\|y_t\|^2\) сокращаются, остаётся \(\|\hat y\|_A^2 \le \|y\|_A^2 + \frac{\tau}{2\varepsilon}\|\varphi\|^2\); суммируя по слоям \(k = 0, \dots, n\), получаем (5а.33).

Оценка (5а.33) — неравенство вида (2.14): решение ограничено данными с постоянной \(1/(2\varepsilon)\), не зависящей от сетки; сумма \(\sum\tau\|\varphi^k\|^2\) — сеточный аналог \(\int_0^T\|\varphi\|^2\,dt\). Для явной схемы условие (5а.32) даёт \(\tau \le (1 - \varepsilon)h^2/2\) вместо \(\tau \le h^2/2\): достаточные условия с запасом.

§5а.13. Разбор 5: перенос с переменной скоростью — там, где гармоники бессильны

Уравнение переноса со скоростью, зависящей от координаты:

\[ \frac{\partial u}{\partial t} + a(x)\,\frac{\partial u}{\partial x} = 0, \qquad a(x) > 0, \qquad |a'(x)| \le L, \qquad u(0,t) = u(l,t), \tag{5а.34} \]

и схема «уголок» с локальным числом Куранта:

\[ \hat y_i = (1 - r_i)\,y_i + r_i\,y_{i-1}, \qquad r_i = \frac{a(x_i)\,\tau}{h}, \qquad 0 \le r_i \le 1 \ \text{при всех } i. \tag{5а.35} \]
Гармоники

Неприменимы: коэффициенты зависят от \(i\), оператор перехода не перестановочен со сдвигом, \(e^{i\alpha m}\) — не собственная функция.

Эвристика «замороженных коэффициентов»: зафиксировать \(a = a(x_i)\) в каждом узле и потребовать выполнения условия Куранта локально, \(\max_i r_i \le 1\). Это правдоподобно, но не является доказательством.

Энергия

По (5а.16) \(\hat y_i^2 \le (1 - r_i)\,y_i^2 + r_i\,y_{i-1}^2\). Умножаем на \(h\), суммируем; в сумме \(\sum h\,r_i\,y_{i-1}^2\) сдвигаем индекс на периодической сетке: она равна \(\sum h\,r_{i+1}\,y_i^2\):

\[ \|\hat y\|^2 \le \sum_{i=1}^{N} h\bigl[(1 - r_i) + r_{i+1}\bigr]y_i^2 = \|y\|^2 + \sum_{i=1}^{N} h\,(r_{i+1} - r_i)\,y_i^2. \tag{5а.36} \]

По теореме Лагранжа \(r_{i+1} - r_i = \frac{\tau}{h}\bigl(a(x_{i+1}) - a(x_i)\bigr) = \tau\,a'(\xi_i) \le \tau L\), поэтому

\[ \|\hat y\|^2 \le (1 + \tau L)\,\|y\|^2, \qquad \|y^{n}\|^2 \le (1 + \tau L)^{n}\|y^{0}\|^2 \le e^{L t_n}\|y^{0}\|^2. \tag{5а.37} \]
Результат. При \(t_n \le T\) получена оценка \(\|y^n\| \le e^{LT/2}\|y^0\|\) с постоянной, не зависящей от \(\tau\), \(h\) — устойчивость по начальным данным в смысле Определения 3 §2. Эвристика замороженных коэффициентов стала теоремой. Обратите внимание на структуру: норма может расти на каждом шаге, но не более чем в \(1 + C\tau\) раз, и за конечное время рост ограничен, — это в точности ситуация, ради которой в условии Неймана (5.6) стоит \(1 + C_1\tau\), а не \(1\). Переменность коэффициента вошла в выкладку в единственном месте — в разности \(r_{i+1} - r_i\) — и была оценена через гладкость \(a(x)\). Тот же приём проходит для неравномерной сетки и для задачи с краевыми условиями (в (5а.36) появится член \(h\,r_1(y_0^n)^2\), оцениваемый через данные).

  2. Каноническая форма (5а.21): выписать \(A\), \(B\), пространство \(H\) или \(H_0\) с учётом краевых условий.
  3. Свойства \(A\): самосопряжённость и положительность — формулами суммирования по частям; граничные члены обязаны исчезнуть за счёт краевых условий.
  4. Если \(A = A^* > 0\) — проверить \(B \ge \frac{\tau}{2}A\) (или (5а.32)); для явных схем это \(\tau \le 2/\|A\|\), норму \(A\) оценивать по (5а.9), (5а.14). Вывод — по теоремам 1–3.
  5. Если \(A\) не самосопряжён (перенос, односторонние разности) — прямой приём: умножить схему скалярно на \(\hat y\) или \(y^{(1/2)}\), выделить \(\|\hat y\|^2 - \|y\|^2\), остальное оценить формулами Грина, неравенством Коши–Буняковского и \(\varepsilon\)-неравенством; цель — \(\|\hat y\|^2 \le (1 + c\tau)\|y\|^2\).
  6. Сопоставить с необходимым условием гармоник: совпадение — критерий; расхождение — либо запас метода (грубая оценка \(\|A\|\)), либо подлинная неустойчивость в норме \(C\) при устойчивости в \(L_2\).
Типичные ошибки. (1) Потерянные граничные члены в (5а.10): для условий второго или третьего рода они не равны нулю и должны входить в энергию. (2) Грубая оценка \(\|A\|\) даёт слишком жёсткое условие, которое гармоники «опровергают» — это не противоречие, а достаточность. (3) Перенос \(L_2\)-оценки на норму \(C\): неверен равномерно по \(h\). (4) Применение теоремы 1 к несамосопряжённому \(A\): теорема молчит, нужен прямой приём.

§5а.15. Упражнения

Упражнение 1. Докажите неравенства (5а.16) и (5а.31), а также неравенства \(\sqrt{h}\,\|y\|_C \le \|y\| \le \sqrt{l}\,\|y\|_C\). Приведите пример последовательности сеточных функций \(y^{(h)}\), для которой \(\|y^{(h)}\| \to 0\), а \(\|y^{(h)}\|_C = 1\) при всех \(h\).
Упражнение 2. Пользуясь леммой 1, докажите равенство \((\Lambda y, v) = (y, \Lambda v)\) для \(y, v \in H_0\) непосредственно, дважды применяя суммирование по частям. Укажите, в каком месте использовано каждое из условий \(y_0 = y_N = 0\), \(v_0 = v_N = 0\).
Упражнение 3 (сохранение энергии). На периодической сетке рассмотрите схему Кранка–Николсон для уравнения переноса с центральной разностью \(\dfrac{\hat y - y}{\tau} + a\,\dfrac{\hat y_{\mathring x} + y_{\mathring x}}{2} = 0\). Умножив её скалярно на \(y^{(1/2)}\) и используя (5а.13), докажите, что \(\|\hat y\| = \|y\|\) при любых \(\tau\), \(h\). Сопоставьте с упражнением 3 §5: \(|\lambda(\alpha)| = 1\). Проведите тот же парный разбор для схемы с переменной скоростью \(a(x)\), записав пространственный оператор в кососимметричной форме \(\frac12\bigl[a\,y_{\mathring x} + (ay)_{\mathring x}\bigr]\).
Упражнение 4 (схема Лакса). Для схемы \(\hat y_i = \frac{1 - r}{2}\,y_{i+1} + \frac{1 + r}{2}\,y_{i-1}\) (упражнение 1 §5) проведите парный разбор: гармоники дают \(|\lambda|^2 = \cos^2\alpha + r^2\sin^2\alpha\); энергетический метод — оценку \(\|\hat y\| \le \|y\|\) при \(r \le 1\) по неравенству (5а.16). Совпали ли условия?
Упражнение 5 (неявная центральная схема). Для схемы \(\hat y + \tau a\,\hat y_{\mathring x} = y\) на периодической сетке умножьте уравнение скалярно на \(\hat y\) и, пользуясь (5а.13), докажите \(\|\hat y\| \le \|y\|\) при любых \(\tau\), \(h\). Сопоставьте с упражнением 2 §5 и с разбором 3: почему явный вариант абсолютно неустойчив, а неявный — безусловно устойчив?
Упражнение 6 (переменный коэффициент теплопроводности). Для оператора \(Ay = -(k\,y_{\bar x})_x\) с \(0 < c_1 \le k_i \le c_2\) на \(H_0\) докажите, что \(A = A^* > 0\) и \(\|A\| \le 4c_2/h^2\). Выведите достаточное условие устойчивости явной схемы \(y_t = -Ay\): \(\tau \le h^2/(2c_2)\). Что в этой задаче может предложить метод гармоник?
