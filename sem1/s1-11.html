§11 · Семестр 1

Линейные схемы с положительными коэффициентами: консервативность, монотонность, устойчивость

▶ Слайды

Параграф собирает в одном месте свойства линейных схем, полученные в §8–§10, для класса схем с неотрицательными коэффициентами. Главный вывод: для линейных схем консервативность определяется суммой коэффициентов, а монотонность, принцип максимума, устойчивость в равномерной норме и TVD-свойство — одно и то же условие \(a_k \ge 0\).

§11.1. Схемы с положительными коэффициентами

Рассмотрим явную линейную схему с постоянными коэффициентами (на сетке с шагами \(\tau\), \(h\)):

\[ y_i^{n+1} = \sum_{k \in S} a_k\, y_{i+k}^n , \tag{11.1} \]

где \(S\) — шаблон (конечное множество целых сдвигов), а коэффициенты \(a_k\) не зависят от \(i\) и \(n\). Для уравнения переноса \(u_t + a\,u_x = 0\) условия аппроксимации нулевого и первого порядка — \(\sum_k a_k = 1\) и \(\sum_k k\,a_k = -r\), \(r = a\tau/h\) (§7, §9).

Схема с положительными коэффициентами. Схема (11.1) называется схемой с положительными (точнее, неотрицательными) коэффициентами, если \(a_k \ge 0\) для всех \(k \in S\).

Пример. Противопоточная схема \(y_i^{n+1} = (1 - r)\,y_i^n + r\,y_{i-1}^n\) при \(0 \le r \le 1\) и схема Лакса–Фридрихса при \(|r| \le 1\) — схемы с положительными коэффициентами; у схемы Лакса–Вендроффа при \(0 < r < 1\) коэффициент \(a_{+1} = r(r - 1)/2 < 0\).

§11.2. Консервативность

Консервативность линейной схемы. Схема (11.1) записывается в консервативной форме (8.2) с линейным численным потоком \(F_{i+1/2} = \sum_j \beta_j\, y_{i+j}\) тогда и только тогда, когда \[ \sum_{k \in S} a_k = 1 . \tag{11.2} \]
Необходимость. В консервативной схеме на периодической сетке потоки сокращаются, и \(\sum_i y_i^{n+1} = \sum_i y_i^n\). С другой стороны, по (11.1) \(\sum_i y_i^{n+1} = \bigl(\sum_k a_k\bigr)\sum_i y_i^n\). Взяв \(y^n\) с \(\sum_i y_i^n \ne 0\), получаем (11.2).
Достаточность. При (11.2) \(y_i^{n+1} - y_i^n = \sum_k a_k\,(y_{i+k}^n - y_i^n)\), и каждая разность \(y_{i+k} - y_i\) раскладывается в сумму разностей соседних значений \(\Delta_{i+j+1/2} = y_{i+j+1} - y_{i+j}\). Собирая коэффициенты, получаем \(y_i^{n+1} - y_i^n = \sum_j \gamma_j\,\Delta_{i+j+1/2} = G_{i+1/2} - G_{i-1/2}\), где \(G_{i+1/2} = \sum_j \gamma_j\, y_{i+j+1}\). Это форма (8.2) с потоком \(F = -(h/\tau)\,G\). ∎
Замечание. Для консервативности знак коэффициентов не важен: схема Лакса–Вендроффа консервативна, хотя у неё есть отрицательный коэффициент. Если коэффициенты зависят от номера узла, \(y_i^{n+1} = \sum_k a_{ik}\,y_k^n\), то условия различаются: сохранение суммы \(\sum_i y_i\) равносильно \(\sum_i a_{ik} = 1\) (суммы по столбцам), а сохранение постоянного решения — \(\sum_k a_{ik} = 1\) (суммы по строкам). Для схем с постоянными коэффициентами оба условия совпадают с (11.2).

§11.3. Монотонность и принцип максимума

Монотонность. Схема (11.1) монотонна в смысле определений 2 и 3 из §8 (оператор перехода не убывает по каждому аргументу, схема сохраняет порядок) тогда и только тогда, когда \(a_k \ge 0\) для всех \(k\). При выполнении (11.2) это равносильно также дискретному принципу максимума (8.5).
Для (11.1) \(\partial y_i^{n+1}/\partial y_{i+k}^n = a_k\), откуда первое утверждение. Если \(a_k \ge 0\) и \(\sum a_k = 1\), то \(y_i^{n+1}\) — выпуклая комбинация значений \(y^n_{i+k}\) и лежит между их минимумом и максимумом. Обратно, если \(a_m < 0\), возьмём \(y^n_{i+m} = 1\), остальные значения нули: тогда \(y_i^{n+1} = a_m < 0 = \min y^n\), принцип максимума нарушен. ∎

§11.4. Устойчивость в равномерной норме

Устойчивость. Пусть выполнено (11.2). Тогда неравенство \(\|y^{n+1}\|_\infty \le \|y^n\|_\infty\) для всех \(y^n\) выполняется в том и только в том случае, когда \(a_k \ge 0\) для всех \(k\). В частности, схема с положительными коэффициентами устойчива в норме \(C\) (\(\|y\|_\infty = \max_i |y_i|\)).
Норма оператора (11.1) в \(\ell_\infty\) равна \(\sum_k |a_k|\): неравенство \(|y_i^{n+1}| \le \sum_k |a_k|\,\|y^n\|_\infty\) очевидно, а равенство достигается на \(y^n_{i+k} = \operatorname{sign} a_k\). При (11.2) \(\sum_k |a_k| \ge \sum_k a_k = 1\), и равенство \(\sum_k |a_k| = 1\) выполняется только при всех \(a_k \ge 0\). ∎

Вместе с аппроксимацией теорема 3 даёт по теореме Лакса (§3) сходимость в норме \(C\). Это и есть «устойчивость схем с положительными коэффициентами» из названия параграфа: она доказывается без гармоник, одним неравенством, и переносится на схемы с переменными коэффициентами \(a_{ik} \ge 0\), \(\sum_k a_{ik} = 1\).

§11.5. TVD-свойство

TVD. Пусть выполнено (11.2). Схема (11.1) является TVD тогда и только тогда, когда \(a_k \ge 0\) для всех \(k\).
Достаточность: разности нового слоя \(\Delta^{n+1}_{i+1/2} = \sum_k a_k\,\Delta^n_{i+k+1/2}\); по неравенству треугольника и после суммирования по \(i\) получаем \(\mathrm{TV}(y^{n+1}) \le \sum_k a_k\,\mathrm{TV}(y^n) = \mathrm{TV}(y^n)\) (§8). Необходимость: шаг по ступеньке даёт \(\mathrm{TV}(y^1) = \sum_k |a_k|\), что не превосходит \(\mathrm{TV}(y^0) = 1\) только при \(a_k \ge 0\) (§10). ∎

§11.6. Итог: все свойства равносильны

Рис. 1. Для линейной схемы (11.1) с \(\sum_k a_k = 1\) все пять свойств равносильны. Для нелинейных схем (§10, ограничители потока) остаются только стрелки слева направо: TVD-схема может не быть монотонной.

Следствие для дальнейшего: по теореме Годунова (§9) схема с положительными коэффициентами имеет первый порядок аппроксимации. Поэтому для линейных схем «устойчива в \(C\)», «монотонна» и «TVD» — это всегда схемы первого порядка; схемы второго порядка без осцилляций обязаны быть нелинейными (§10) или использовать искусственную вязкость (§13.5).

Замечание. Устойчивость в \(L_2\) (по гармоникам, §6) слабее: схема Лакса–Вендроффа устойчива в \(L_2\) при \(|r| \le 1\), но для неё неравенство теоремы 3 не выполняется (у разрыва максимум растёт — появляются осцилляции), и она не является TVD.
