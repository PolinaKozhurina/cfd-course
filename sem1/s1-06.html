Диссипативные и дисперсионные свойства разностных схем. Паспорт схемы

▶ Слайды

В §5 и §5а мы научились отвечать на вопрос «устойчива ли схема». Устойчивость — условие необходимое, но само по себе оно ничего не говорит о качестве численного решения: две устойчивые схемы могут переносить один и тот же профиль совершенно по-разному — одна размажет фронт, другая обвесит его осцилляциями. Настоящий параграф даёт язык, на котором эти различия описываются точно: диссипативная и дисперсионная поверхности схемы. Изложение следует «атласу» В. М. Головизнина и А. В. Соловьёва [1], где для каждой схемы составлен единый паспорт: шаблон → дифференциальное приближение → характеристическое уравнение → область устойчивости → поверхности → тестовые расчёты. В конце параграфа мы составим такие паспорта для схем «уголок» и Лакса–Вендроффа.

§6.1. Однородные разностные операторы и бегущие волны. Множитель перехода

Все разностные схемы для уравнения переноса

\[ \frac{\partial u}{\partial t} + c\,\frac{\partial u}{\partial x} = 0, \qquad c = \mathrm{const} > 0, \tag{6.1} \]

построенные на равномерной сетке \(x_j = jh\), \(t_n = n\tau\), являются однородными: их коэффициенты не зависят от номера узла. Для однородных линейных операторов, как и для самого уравнения (6.1), можно построить частные решения в виде бегущих волн. У дифференциального уравнения это \(u = D\,e^{i(\omega t - kx)}\), где \(k\) — волновое число, \(\omega\) — круговая частота; подстановка в (6.1) даёт \(i\omega - ick = 0\), то есть \(\omega = ck\): все волны бегут вправо со скоростью \(c\). На сетке та же волна записывается так:

\[ u_j^n = D\exp\bigl\{i(\omega\,n\tau - kh\,j)\bigr\} = D\,q^{\,n}\,e^{-ikh\,j}, \qquad q = e^{i\omega\tau}. \tag{6.2} \]
Множитель перехода. Комплексное число \(q = e^{i\omega\tau}\) в (6.2), на которое умножается бегущая волна при переходе на следующий временной слой, \(u_j^{n+1} = q\,u_j^n\), называется множителем перехода. Величина \(kh \in [-\pi, \pi]\) называется приведённым волновым числом.

Знак в показателе \(e^{-ikhj}\) выбран так, чтобы при \(\omega, k > 0\) волна бежала вправо — в ту же сторону, что и решение (6.1) при \(c > 0\); это соглашение атласа [1]. В §5 гармоника записывалась как \(\lambda^n e^{i\alpha m}\) — то же самое с точностью до знака \(k\) и обозначений: \(\alpha = kh\), \(\lambda = q\) для волны, бегущей влево. На модуль множителя перехода выбор знака не влияет.

Подставим (6.2) в разностную схему. Каждому узлу шаблона \((j + p,\ n + m)\) отвечает значение

\[ u_{j+p}^{\,n+m} = D\,q^{\,n+m}e^{-ikh(j+p)} = \underbrace{D\,q^{\,n}e^{-ikhj}}_{\text{общий множитель}}\cdot q^{\,m}\,e^{-ikh\,p}, \tag{6.3} \]

общий множитель сокращается, и остаётся алгебраическое уравнение на \(q\).

Характеристическое уравнение. Соотношение, выражающее множитель перехода \(q\) через число Куранта \(r = c\tau/h\) и приведённое волновое число \(kh\), которое получается подстановкой бегущей волны (6.2) в разностную схему, называется характеристическим уравнением разностной схемы. Для двухслойных схем оно линейно по \(q\), для трёхслойных — квадратное.
Пример: схема «уголок» Схема \(\dfrac{u_j^{n+1} - u_j^n}{\tau} + c\,\dfrac{u_j^n - u_{j-1}^n}{h} = 0\), разрешённая относительно верхнего слоя: \[ u_j^{n+1} = (1 - r)\,u_j^n + r\,u_{j-1}^n, \qquad r = \frac{c\tau}{h}. \tag{6.4} \] По правилу (6.3): узлу \((j, n+1)\) отвечает множитель \(q\), узлу \((j, n)\) — \(1\), узлу \((j-1, n)\) — \(e^{+ikh}\) (здесь \(p = -1\)). Сокращая общий множитель, получаем характеристическое уравнение \[ q = (1 - r) + r\,e^{ikh}. \tag{6.5} \] Это окружность радиуса \(r\) с центром в точке \(1 - r\) вещественной оси — та же, что в §5.

Выделим в (6.5) вещественную и мнимую части, \(q = (1 - r + r\cos kh) + i\,r\sin kh\), и вычислим модуль:

\[ |q(r, kh)| = \sqrt{\bigl((1 - r) + r\cos kh\bigr)^2 + r^2\sin^2 kh} = \sqrt{1 - 4r(1 - r)\sin^2\frac{kh}{2}}. \tag{6.6} \]

Вторая форма получается раскрытием скобок: \((1-r)^2 + 2r(1-r)\cos kh + r^2\cos^2 kh + r^2\sin^2 kh = (1-r)^2 + r^2 + 2r(1-r)\cos kh\); поскольку \((1-r)^2 + r^2 = 1 - 2r(1-r)\), подкоренное выражение равно \(1 - 2r(1-r)(1 - \cos kh) = 1 - 4r(1-r)\sin^2(kh/2)\). Именно вторая форма удобна для анализа: поправка к единице есть произведение множителя \(r(1-r)\), зависящего только от числа Куранта, и множителя \(\sin^2(kh/2)\), зависящего только от длины волны.

§6.2. Область устойчивости. Численная диссипация

Модуль множителя перехода показывает, как изменяется амплитуда бегущей волны при переходе на следующий слой: за \(n\) шагов амплитуда умножается на \(|q|^n\). Если \(|q| \le 1\), амплитуда не возрастает. Отсюда — определение, повторяющее на языке бегущих волн условие Неймана §5.

Область устойчивости. Число Куранта \(r\) принадлежит области устойчивости дискретного оператора, если при этом \(r\) амплитуды всех волн не возрастают: \(|q(r, kh)| \le 1\) при всех \(kh \in [-\pi, \pi]\).

Для схемы «уголок» из второй формы (6.6) видно, что \(|q| \le 1\) при всех \(kh\) тогда и только тогда, когда \(r(1 - r) \ge 0\), то есть

\[ r \in [0, 1] \tag{6.7} \]

— область устойчивости представляет собой единичный отрезок. Это условие Куранта из §5; в §5а оно же было получено энергетическим методом как достаточное. Внутри области устойчивости множитель \(|q|\) может быть строго меньше единицы — тогда схема гасит волны.

Бездиссипативный оператор. Если в области устойчивости модуль перехода любой волны равен единице, дискретный оператор называется бездиссипативным; в противном случае имеет место численная диссипация.
Уголок: где диссипации нет и где она максимальна
  • \(r = 1\): \(q = e^{ikh}\), \(|q| = 1\) при всех \(kh\) — диссипации нет. Действительно, при \(r = 1\) схема (6.4) превращается в \(u_j^{n+1} = u_{j-1}^n\): точный сдвиг на одну ячейку.
  • \(r = 1/2\), \(kh = \pi\): \(|q|^2 = 1 - 4\cdot\tfrac12\cdot\tfrac12\cdot 1 = 0\). Самая короткая волна на сетке — «пила» \(u_j = (-1)^j\) — исчезает за один шаг: \(u_j^{n+1} = \tfrac12(u_j^n + u_{j-1}^n)\), а у пилы соседние значения противоположны.
  • Длинные волны, \(kh \to 0\): \(|q| \to 1\) при любом \(r\) — они почти не затухают.

§6.3. Диссипативная поверхность

Диссипативная поверхность. График функции \(|q| = f(r, kh)\) над прямоугольником \(r \in [r_{\min}, r_{\max}]\) (область устойчивости), \(kh \in [-\pi, \pi]\) называется диссипативной поверхностью дискретного оператора. Отклонение поверхности от единичной плоскости \(|q| = 1\) в каждой точке характеризует степень затухания гармоники с приведённым волновым числом \(kh\) при данном числе Куранта \(r\).

Для схемы «уголок» диссипативная поверхность изображена на рис. 1: по оси \(x\) отложено число Куранта \(r \in [0, 1]\), по оси \(y\) — приведённое волновое число \(kh \in [-\pi, \pi]\), по оси \(z\) — модуль перехода; полупрозрачная плоскость — уровень \(|q| = 1\).

а) диссипативная поверхность \(|q(r, kh)|\)
б) её сечения при фиксированных \(r\) (по чётности показана половина \(kh \in [0, \pi]\))
Рис. 1. Диссипативная поверхность схемы «уголок».
Как читать диссипативную поверхность
  • Вдоль всей линии \(kh = 0\) поверхность касается единичной плоскости: длинноволновые гармоники не затухают ни при каком \(r\). Это общее свойство всех схем, аппроксимирующих уравнение переноса (§6.7).
  • На границе области устойчивости \(r = 1\) поверхность лежит в единичной плоскости при всех \(kh\): точный перенос. При \(r = 0\) — тоже (шаг по времени нулевой, ничего не происходит).
  • Самая глубокая «долина» — при \(r = 1/2\), \(kh = \pm\pi\), где \(|q| = 0\). Поверхность симметрична относительно \(r = 1/2\), поскольку (6.6) не меняется при замене \(r \to 1 - r\).
  • Чем короче волна (ближе \(kh\) к \(\pm\pi\)), тем сильнее она гасится при любом \(r \in (0, 1)\): уголок «съедает» мелкие детали решения в первую очередь.

§6.4. Дисперсионное соотношение и фазовая скорость

Модуль множителя перехода описывает амплитуду; его аргумент описывает фазу, то есть скорость волны. По определению \(q = e^{i\omega\tau}\), поэтому, логарифмируя характеристическое уравнение, получаем дисперсионное соотношение разностной схемы — зависимость частоты от волнового числа:

\[ \omega = -\frac{i}{\tau}\ln q = \frac{1}{\tau}\arg q \;-\; \frac{i}{\tau}\ln|q|; \qquad\text{для «уголка»:}\quad \omega = -\frac{i}{\tau}\ln\bigl[(1 - r) + r\,e^{ikh}\bigr]. \tag{6.8} \]

Частота оказывается комплексной, и обе её части имеют ясный смысл. Вещественная часть \(\mathrm{Re}\,\omega = \arg q/\tau\) — истинная частота колебаний: сдвиг фазы за один шаг по времени равен \(\arg q\). Мнимая часть \(\mathrm{Im}\,\omega = -\ln|q|/\tau \ge 0\) описывает затухание, поскольку \(|e^{i\omega\tau}| = e^{-\mathrm{Im}\,\omega\cdot\tau} = |q|\). Таким образом, один множитель перехода несёт и диссипацию (через модуль), и дисперсию (через аргумент). Для точного уравнения (6.1) частота вещественна и линейна по \(k\): \(\omega = ck\).

Фазовая скорость. Поверхность постоянной фазы бегущей волны \(\omega t - kx = \mathrm{const}\) перемещается со скоростью \(\omega/k\); она называется фазовой скоростью волны. Отношение фазовой скорости к скорости переноса \(c\) называется приведённой фазовой скоростью: \[ \gamma(r, kh) = \frac{\mathrm{Re}\,\omega}{kc} = \frac{\arg q}{\tau k c} = \frac{\arg q(r, kh)}{r\cdot kh}, \tag{6.9} \] где использовано \(\tau k c = \dfrac{c\tau}{h}\,kh = r\cdot kh\).

Для точного уравнения \(\gamma = ck/(kc) \equiv 1\): приведённая фазовая скорость волн, описываемых исходным дифференциальным оператором, не зависит от волнового числа. У разностной схемы \(\gamma\) зависит от \(kh\).

Дисперсия. Нормальная и аномальная дисперсия. Зависимость фазовой скорости от длины волны называется дисперсией. Если приведённая фазовая скорость меньше единицы, \(\gamma < 1\), дисперсия называется нормальной; если больше единицы, \(\gamma > 1\), — аномальной.

В случае нормальной дисперсии гармоника отстаёт от «эталонной» гармоники — той же волны, перенесённой точным уравнением со скоростью \(c\); в случае аномальной дисперсии — опережает её. Термины заимствованы из оптики.

Замечание о ветви аргумента. Аргумент комплексного числа определён с точностью до \(2\pi\); стандартная функция \(\arg\) возвращает значение из \((-\pi, \pi]\) и на дисперсионной поверхности давала бы линии разрыва. Правильный выбор: та непрерывная по \(kh\) ветвь, для которой \(\arg q \to 0\) при \(kh \to 0\) — она отвечает реальному решению, а не его сдвигу на период. Именно так строятся поверхности атласа [1, п. 3.7] и рисунки этого параграфа.

§6.5. Дисперсионная поверхность схемы «уголок»

Дисперсионные свойства дискретного оператора представляются его дисперсионной поверхностью — графиком \(\gamma = \gamma(r, kh)\) над той же областью, что и диссипативная поверхность. Для «уголка» она приведена на рис. 2.

а) дисперсионная поверхность \(\gamma(r, kh)\); значения выше 1.5 обрезаны
б) сечения при фиксированных \(r\)
Рис. 2. Дисперсионная поверхность схемы «уголок».
Как читать дисперсионную поверхность
  • Вдоль линии \(kh = 0\) поверхность касается единичной плоскости: длинные волны бегут с правильной скоростью при любом \(r\).
  • При \(r = 1\) поверхность лежит в единичной плоскости: \(q = e^{ikh}\), \(\arg q = kh\), \(\gamma = 1\) — точный перенос.
  • При \(r = 1/2\) дисперсии тоже нет, хотя диссипация при этом \(r\) максимальна. Доказательство: \[ q = \tfrac12\bigl(1 + e^{ikh}\bigr) = e^{ikh/2}\cdot\tfrac12\bigl(e^{-ikh/2} + e^{ikh/2}\bigr) = e^{ikh/2}\cos\frac{kh}{2}, \tag{6.10} \] и при \(|kh| < \pi\) косинус положителен, так что \(\arg q = kh/2\) и \(\gamma = (kh/2)/(kh/2) = 1\).
  • При \(r < 1/2\) поверхность лежит ниже единичной плоскости — дисперсия нормальная; при \(1/2 < r < 1\) — выше, дисперсия аномальная.
  • Край \(kh = \pm\pi\): здесь \(q = 1 - 2r\) — вещественное число. При \(r < 1/2\) оно положительно, \(\arg q = 0\), \(\gamma = 0\): «пила» не движется вовсе, она стоит на месте и затухает. При \(r > 1/2\) число \(1 - 2r\) отрицательно, \(\arg q = \pm\pi\), \(\gamma = 1/r > 1\) — отсюда крутой «обрыв» поверхности вдоль \(r = 1/2\) у краёв \(kh = \pm\pi\).
Числа для контроля \(kh = \pi/2\). При \(r = 0.3\): \(q = 0.7 + 0.3i\), \(\arg q = \arctan(0.3/0.7) \approx 0.405\), \(\gamma = 0.405/(0.3\cdot\pi/2) \approx 0.86 < 1\) — нормальная дисперсия, волна отстаёт. При \(r = 0.8\): \(q = 0.2 + 0.8i\), \(\arg q = \arctan 4 \approx 1.326\), \(\gamma \approx 1.326/1.257 \approx 1.05 > 1\) — аномальная, волна опережает. При \(r = 0.5\): \(q = 0.5 + 0.5i\), \(\arg q = \pi/4\), \(\gamma = (\pi/4)/(\pi/4) = 1\).

§6.6. Связь с первым дифференциальным приближением

Диссипацию и дисперсию можно увидеть и без характеристического уравнения — по первому дифференциальному приближению §4. Запишем П-форму п.д.п. схемы для уравнения переноса, удерживая члены со второй и третьей производными:

\[ \frac{\partial u}{\partial t} + c\,\frac{\partial u}{\partial x} = \nu\,\frac{\partial^2 u}{\partial x^2} + \beta\,\frac{\partial^3 u}{\partial x^3} + \dots \tag{6.11} \]

Для схемы «уголок» коэффициент \(\nu\) был получен в §4 (формула (4.4)); продолжение той же выкладки до третьего порядка (упражнение 6) даёт

\[ \nu = \frac{ch}{2}(1 - r), \qquad \beta = -\frac{ch^2}{6}(1 - r)(1 - 2r). \tag{6.12} \]

Будем искать частное решение уравнения (6.11) в виде бегущей волны \(u = D\,e^{i(\omega t - kx)}\). Производные: \(u_t = i\omega u\), \(u_x = -ik\,u\), \(u_{xx} = -k^2 u\), \(u_{xxx} = ik^3 u\). Подставляя и сокращая \(u\), получаем дисперсионное соотношение п.д.п.:

\[ i\omega - ick = -\nu k^2 + i\beta k^3 \qquad\Longrightarrow\qquad \omega = ck + \beta k^3 + i\,\nu k^2, \tag{6.13} \]

и, следовательно, частное решение имеет вид

\[ u(x, t) = D\,e^{-\nu k^2 t}\,\exp\Bigl\{ik\bigl[(c + \beta k^2)\,t - x\bigr]\Bigr\}. \tag{6.14} \]

Формула (6.14) разделяет роли двух членов п.д.п. Член с чётной производной \(u_{xx}\) вошёл только в амплитуду: она затухает как \(e^{-\nu k^2 t}\), если \(\nu > 0\) (схемная вязкость положительна), и растёт, если \(\nu < 0\); затухание тем быстрее, чем больше \(k\). Член с нечётной производной \(u_{xxx}\) вошёл только в фазу: фазовая скорость равна \(c + \beta k^2\), то есть

\[ \gamma \approx 1 + \frac{\beta}{c}\,k^2 = 1 - \frac{(kh)^2}{6}(1 - r)(1 - 2r) \quad\text{для «уголка»}. \tag{6.15} \]
Согласование с точными формулами Разложим точные выражения (6.6) и (6.9) при \(kh \to 0\): \(|q|^2 = 1 - 4r(1-r)\sin^2(kh/2) \approx 1 - r(1-r)(kh)^2\), а из (6.14) за один шаг \(\tau\) амплитуда умножается на \(e^{-\nu k^2\tau}\), \(e^{-2\nu k^2\tau} \approx 1 - 2\nu k^2\tau = 1 - ch(1-r)k^2\tau = 1 - r(1-r)(kh)^2\) — совпало. Разложение \(\arg q = \arctan\dfrac{r\sin kh}{1 - r + r\cos kh}\) до третьего порядка даёт \(\gamma = 1 - \dfrac{(kh)^2}{6}(1-r)(1-2r) + O((kh)^4)\) — совпало с (6.15). Так метод дифференциального приближения и спектральный анализ описывают одно и то же явление; первый проще для длинных волн, второй точен для всех.

§6.7. Общие свойства поверхностей. Канал высокой точности

Стремление к нулю дисперсии и диссипации длинноволновых гармоник является общим свойством всех дискретных операторов, аппроксимирующих исходный дифференциальный оператор: при \(kh \to 0\) волна разрешается всё большим числом узлов, и разностные отношения всё точнее воспроизводят производные. Характер касания дисперсионных и диссипативных поверхностей единичной плоскости определяется порядком аппроксимации: у схемы первого порядка \(|q|^2 = 1 - O((kh)^2)\), у схемы второго порядка (Лакс–Вендрофф, §6.10) \(|q|^2 = 1 - O((kh)^4)\) — поверхность «плотнее прилегает» к единичной плоскости.

Тот факт, что при \(r = 1\) все гармоники не диссипируют и не диспергируют, говорит о том, что разностный оператор при данном числе Куранта переносит начальный профиль без каких-либо искажений. Из непрерывности обеих поверхностей следует, что в некоторой окрестности этого числа точность численного решения также будет аномально высокой; эту область называют каналом высокой точности дискретного оператора [1]. Практический вывод: если устойчивость позволяет, считать с числом Куранта, близким к единице.

Итого для схемы «уголок» Область устойчивости \(r \in [0, 1]\). Диссипация: есть при \(0 < r < 1\), максимальна при \(r = 1/2\), отсутствует при \(r = 1\). Дисперсия: нормальная при \(r < 1/2\), отсутствует при \(r = 1/2\) и \(r = 1\), аномальная при \(1/2 < r < 1\). Канал высокой точности — у \(r = 1\). Диссипативная и дисперсионная поверхности дают полное представление о свойствах разностной схемы и позволяют предсказывать поведение дискретного решения на разных начальных условиях — проверим это расчётом.

§6.8. Модельная задача и разложение начальных данных по гармоникам

Рассмотрим модельную задачу с периодическими условиями на отрезке \(x \in [0, 2\pi]\):

\[ \frac{\partial u}{\partial t} + c\,\frac{\partial u}{\partial x} = 0, \quad c = 1, \quad t \in [0, \infty); \qquad u(x, 0) = f(x), \quad u(0, t) = u(2\pi, t), \tag{6.16} \]

и два вида начальных условий — достаточно гладкое и разрывное. В качестве гладкого возьмём «двойной гауссиан»

\[ f(x) = \exp\Bigl[-\frac{(x - x_1)^2}{\Delta^2}\Bigr] + \exp\Bigl[-\frac{(x - x_2)^2}{\Delta^2}\Bigr], \qquad x_1 = 0.5\pi,\ x_2 = 0.7\pi,\ \Delta = 0.1\pi, \tag{6.17} \]

а в качестве разрывного — «ступеньку»

\[ f(x) = \begin{cases} 1, & 0.2\pi \le x \le 0.4\pi, \\ 0, & \text{иначе}. \end{cases} \tag{6.18} \]

Разобьём отрезок на \(N = 100\) равных интервалов, \(h = 2\pi/N = 0.02\pi\), и спроектируем начальные данные на сетку: \(f_j = f(x_j)\), \(x_j = jh\). Сеточную функцию на \(N\) узлах периода можно разложить в конечный ряд Фурье по бегущим волнам (6.2):

\[ f_j = \sum_{k=0}^{N-1} a_k\,e^{-i(kh)\,j}, \qquad a_k = \frac{1}{N}\sum_{j=0}^{N-1} f_j\,e^{i(kh)\,j}. \tag{6.19} \]

Здесь номер гармоники \(k\) и приведённое волновое число связаны как \(kh = 2\pi k/N\); гармоники с \(k > N/2\) неотличимы от гармоник с отрицательным волновым числом \(kh - 2\pi\). На рис. 3 показаны начальные профили и модули их коэффициентов Фурье.

Рис. 3. Начальные данные (6.17), (6.18) на сетке \(N = 100\) и модули коэффициентов их разложения (6.19). Спектр гладкого профиля сосредоточен в первых десяти гармониках; спектр ступеньки убывает медленно и содержит все короткие волны.

Схема линейна, а бегущие волны — её частные решения, поэтому решение разностной задачи с начальными данными (6.19) есть сумма

\[ u_j^n = \sum_{k=0}^{N-1} a_k\,\bigl[q(r, kh)\bigr]^n\,e^{-i(kh)\,j}. \tag{6.20} \]

В начальный момент времени все гармоники разложения подогнаны друг к другу так, что в сумме составляют начальные данные. В последующие моменты каждая гармоника будет уменьшаться в амплитуде в соответствии с её местом на диссипативной поверхности и распространяться со своей фазовой скоростью, определяемой дисперсионной поверхностью, так что «пакет» гармоник начнёт разъезжаться. Полная картина зависит от числа Куранта \(r\), и предсказать её можно, глядя на рис. 1–2 и рис. 3: у гауссиана значимы только длинные волны, для которых \(|q| \approx 1\), \(\gamma \approx 1\); у ступеньки значимы и короткие волны, которые уголок гасит и замедляет.

§6.10. Схема Лакса–Вендроффа: второй паспорт

Чтобы увидеть, как выглядят поверхности схемы второго порядка, построим схему Лакса–Вендроффа тем же способом, каким в §5 был объяснён «уголок», — интерполяционно-характеристическим методом [1, п. 2.4]. Решение уравнения (6.1) постоянно вдоль характеристик \(x - ct = \mathrm{const}\). Проведём через узел \((x_j, t_{n+1})\) характеристику назад до слоя \(t_n\): она придёт в точку \(x_A = x_j - c\tau = x_j - rh\), и \(u_j^{n+1} = u(x_A, t_n)\). Остаётся интерполировать \(u(x_A, t_n)\) по известным значениям в узлах слоя \(t_n\). Линейная интерполяция по двум узлам \(x_{j-1}, x_j\) даёт \(u_j^{n+1} = r\,u_{j-1}^n + (1-r)\,u_j^n\) — это «уголок». Квадратичная интерполяция по трём узлам \(x_{j-1}, x_j, x_{j+1}\) многочленом Лагранжа

\[ u_j^{n+1} = u_{j-1}^n P_{j-1}(x_A) + u_j^n P_j(x_A) + u_{j+1}^n P_{j+1}(x_A), \qquad P_{j-1}(x_A) = \tfrac{r(1 + r)}{2},\ \ P_j(x_A) = 1 - r^2,\ \ P_{j+1}(x_A) = -\tfrac{r(1 - r)}{2}, \tag{6.21} \]

(значения многочленов Лагранжа в точке \(x_A = x_j - rh\) вычислены прямой подстановкой) приводит к схеме

\[ \frac{u_j^{n+1} - u_j^n}{\tau} + c\,\frac{u_{j+1}^n - u_{j-1}^n}{2h} = \frac{c^2\tau}{2}\,\frac{u_{j+1}^n - 2u_j^n + u_{j-1}^n}{h^2}, \tag{6.22} \]

которая называется схемой Лакса–Вендроффа. Это схема 3 из задания §4: явная, трёхточечная, второго порядка аппроксимации на решении по \(\tau\) и \(h\); её п.д.п. не содержит \(u_{xx}\) (табл. 1) — схемной вязкости первого порядка у неё нет.

Характеристическое уравнение. Разрешим (6.22) относительно верхнего слоя и подставим бегущую волну по правилу (6.3): узлам \(j \pm 1\) отвечают множители \(e^{\mp ikh}\):

\[ q = 1 - \frac{r}{2}\bigl(e^{-ikh} - e^{ikh}\bigr) + \frac{r^2}{2}\bigl(e^{-ikh} - 2 + e^{ikh}\bigr) = 1 - r^2(1 - \cos kh) + i\,r\sin kh, \tag{6.23} \]

где использовано \(e^{-ikh} - e^{ikh} = -2i\sin kh\) и \(e^{-ikh} + e^{ikh} = 2\cos kh\). Модуль:

\[ |q|^2 = \bigl(1 - r^2(1 - \cos kh)\bigr)^2 + r^2\sin^2 kh = 1 - 4r^2(1 - r^2)\sin^4\frac{kh}{2}. \tag{6.24} \]

(Проверка: положим \(s = \sin^2(kh/2)\); тогда \(1 - \cos kh = 2s\), \(\sin^2 kh = 4s(1 - s)\), и \(|q|^2 = (1 - 2r^2 s)^2 + 4r^2 s(1-s) = 1 - 4r^2 s + 4r^4 s^2 + 4r^2 s - 4r^2 s^2 = 1 - 4r^2 s^2(1 - r^2)\).) Область устойчивости: \(|q| \le 1\) при всех \(kh\) тогда и только тогда, когда \(r^2(1 - r^2) \ge 0\), то есть снова \(r \in [0, 1]\). Но поправка к единице теперь пропорциональна \(\sin^4(kh/2) \sim (kh)^4\): диссипативная поверхность касается единичной плоскости с четвёртым порядком, а не со вторым, как у уголка, — это и есть «плотное прилегание» схемы второго порядка (§6.7).

а) диссипация \(|q(r, kh)|\)

Сравнение двух паспортов на тестах
  • Гауссиан схема Лакса–Вендроффа переносит почти без потерь: диссипация второго порядка мала, оба пика сохранили высоту. Заметно лишь небольшое отставание (нормальная дисперсия).
  • Ступенька переносится с крутым фронтом, но позади фронта возникают осцилляции: короткие волны ступеньки затухают слабо, а бегут медленнее длинных (\(\gamma < 1\)) — они «отстают» и образуют хвост. Это дисперсия во всей красе; у уголка она была скрыта диссипацией.
  • Чем меньше \(r\), тем сильнее осцилляции: при \(r = 0.25\) поверхность \(\gamma\) дальше от единицы, чем при \(r = 0.75\).
  • Появление пилообразных структур возле разрывов — общее свойство всех линейных схем второго и более высокого порядка; это утверждение известно как теорема Годунова (§9). Если дисперсия нормальная, пила появляется сзади фронта, если аномальная — спереди.

§6.13. Упражнения

Упражнение 1 (неявный «уголок»). Для схемы \(\dfrac{u_j^{n+1} - u_j^n}{\tau} + c\,\dfrac{u_j^{n+1} - u_{j-1}^{n+1}}{h} = 0\) получите характеристическое уравнение \(q = \bigl[1 + r - r e^{ikh}\bigr]^{-1}\) и покажите, что \(|q|^2 = \bigl[1 + 2r(1 + r)(1 - \cos kh)\bigr]^{-1} \le 1\) при всех \(r > 0\): область устойчивости — вся полуось. Сравните с разбором 2 §5а (энергетический метод). Есть ли у этой схемы канал высокой точности?
Упражнение 2 (явная центральная схема). Для схемы \(\dfrac{u_j^{n+1} - u_j^n}{\tau} + c\,\dfrac{u_{j+1}^n - u_{j-1}^n}{2h} = 0\) получите \(q = 1 + ir\sin kh\) и \(|q|^2 = 1 + r^2\sin^2 kh\). Объясните, почему область устойчивости пуста, и как это согласуется со знаком \(\nu\) в таблице 1 и с разбором 3 §5а.
Упражнение 3 (схема Бима–Уорминга). Квадратичная интерполяция по узлам \(x_{j-2}, x_{j-1}, x_j\) даёт схему \[ \frac{u_j^{n+1} - u_j^n}{\tau} + c\,\frac{3u_j^n - 4u_{j-1}^n + u_{j-2}^n}{2h} = \frac{c^2\tau}{2}\,\frac{u_j^n - 2u_{j-1}^n + u_{j-2}^n}{h^2}. \] Получите характеристическое уравнение \(q = 1 - \frac{r}{2}\bigl(3 - 4e^{ikh} + e^{2ikh}\bigr) + \frac{r^2}{2}\bigl(1 - e^{ikh}\bigr)^2\) и, вычислив \(|q|\) при \(kh = \pi\), покажите, что область устойчивости не шире отрезка \(r \in [0, 2]\) (на самом деле она с ним совпадает). Убедитесь, что при \(r = 1\) и \(r = 2\) схема точна: у неё два канала высокой точности. Проверьте по интерактиву §6.12, при каких \(r\) дисперсия аномальная.
Упражнение 4 (схема «крест»). Для трёхслойной схемы \(\dfrac{u_j^{n+1} - u_j^{n-1}}{2\tau} + c\,\dfrac{u_{j+1}^n - u_{j-1}^n}{2h} = 0\) получите квадратное характеристическое уравнение \(q^2 - 2ir\sin(kh)\,q - 1 = 0\) и его корни \(q_{1,2} = ir\sin kh \pm \sqrt{1 - r^2\sin^2 kh}\). Покажите, что при \(r \le 1\) оба корня по модулю равны единице (схема бездиссипативна), и определите, какой из корней реальный, а какой паразитный. Почему при \(r > 1\) схема неустойчива?
Упражнение 5 (дисперсия «креста»). Для реального корня схемы «крест» найдите \(\gamma(r, kh)\) при \(kh = \pi/2\), \(r = 0.5\), и определите характер дисперсии. Объясните по рис. 16 атласа [1] (осцилляции позади фронта на всех тестах), почему у бездиссипативной схемы осцилляции не затухают.
Упражнение 6 (третий член п.д.п.). Продолжите выкладку §4 для схемы «уголок» до членов третьего порядка и получите коэффициент \(\beta\) в (6.12). Указание: производные \(u_{tt}\), \(u_{ttt}\) исключать не по исходному уравнению, а по самому п.д.п. \(u_t = -cu_x + \nu u_{xx} + \dots\), удерживая члены нужного порядка: \(u_{tt} = c^2u_{xx} - 2c\nu u_{xxx} + O(h^2)\).
Упражнение 7 (предсказание по поверхностям). Не проводя расчёта, предскажите по рис. 1–2, как схема «уголок» при \(r = 0.9\) перенесёт треугольный профиль за 100 шагов: что произойдёт с вершиной, с наклоном сторон, появятся ли осцилляции. Проверьте прогноз в интерактиве §6.12.
