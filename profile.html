Мои курсы

Отметьте курсы, которые слушаете. Преподаватель курса подтверждает запись — после этого появляется доступ к сдаче и оценкам.

Мои рабочие группы

Для каждого одобренного курса — выберите свою рабочую группу (2–3 человека сдают вместе). По одному курсу может быть только одна группа.

Посещаемость

Процент занятий, на которых вы фактически присутствовали, по каждому вашему курсу. Уважительные пропуски не учитываются ни в числителе, ни в знаменателе.

Домашние задания

По каждому вашему курсу — актуальные ДЗ, срок сдачи, файлы решения, оценки и комментарии преподавателя. Перед сдачей — ознакомьтесь с правилами курса (в частности с политикой по генеративным моделям).
