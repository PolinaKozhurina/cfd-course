§8.1 · Постановка

Закон сохранения, сетка и разности на границах ячеек

Рассматривается скалярный закон сохранения с плотностью \(u\) и потоком \(f(u)\):

\[ \frac{\partial u}{\partial t} + \frac{\partial f(u)}{\partial x} = 0, \qquad a(u) = f'(u) \ \text{— характеристическая скорость}. \tag{8.1} \]
Модельные задачи Перенос: \(f(u) = au\), \(a = \mathrm{const}\), знак \(a\) произволен: при \(a > 0\) решение переносится вправо, при \(a \lt 0\) — влево.
Уравнение Бюргерса: \(f(u) = u^2/2\), \(a(u) = u\).
Сетка и обозначения Узлы \(x_j = jh\), слои \(t_n = n\tau\); ячейка узла \(j\) — отрезок \([x_{j-1/2}, x_{j+1/2}]\). На слое \(n\) верхний индекс опускается: \(y_j = y_j^n\). \[ \Delta_{j+1/2} = y_{j+1} - y_j = h\,(y_r)_j = h\,(y_l)_{j+1}. \]

Отношение шагов \(\tau\) и \(h\) входит во все схемы через одну безразмерную величину — число Куранта.

§8.1 · Число Куранта

Число Куранта и его геометрический смысл

Для уравнения переноса число Куранта — знаковая безразмерная величина

\[ r = \frac{a\tau}{h}, \qquad |r| = \frac{|a|\tau}{h}, \qquad \operatorname{sign} r = \operatorname{sign} a. \]
Характеристика через \((x_j, t_{n+1})\) при \(0 \lt r \lt 1\): её основание смещено на \(rh\) против направления переноса.
АналогТочное решение: \(u(x_j, t_{n+1}) = u(x_j - rh,\, t_n)\). Число \(r\) — смещение основания характеристики, измеренное в шагах \(h\); явная схема приближает значение в точке \(x_j - rh\) по узлам слоя \(n\).
РольУсловие Куранта–Фридрихса–Леви \(|r| \le 1\): основание характеристики лежит в шаблоне \([x_{j-1}, x_{j+1}]\) — необходимое условие устойчивости явных трёхточечных схем. Знак \(r\) определяет направление «против потока».

Перейдём к форме записи схемы, наследующей интегральный закон сохранения.

§8.2 · Интегральная форма

Интегральная форма закона сохранения на ячейке

Интегрируя (8.1) по ячейке \([x_{j-1/2}, x_{j+1/2}]\) и по шагу \([t_n, t_{n+1}]\), получаем соотношение, верное и для разрывных решений:

\[ \int_{x_{j-1/2}}^{x_{j+1/2}}\! u(x, t_{n+1})\,dx = \int_{x_{j-1/2}}^{x_{j+1/2}}\! u(x, t_n)\,dx - \int_{t_n}^{t_{n+1}}\!\Bigl[f\bigl(u(x_{j+1/2}, t)\bigr) - f\bigl(u(x_{j-1/2}, t)\bigr)\Bigr]dt. \tag{8.1′} \]

Обозначим среднее по ячейке и средний по шагу поток через границу:

\[ \bar u_j^n = \frac1h\int_{x_{j-1/2}}^{x_{j+1/2}}\! u(x, t_n)\,dx, \qquad \bar f_{j+1/2} = \frac1\tau\int_{t_n}^{t_{n+1}}\! f\bigl(u(x_{j+1/2}, t)\bigr)\,dt; \qquad \bar u_j^{n+1} = \bar u_j^n - \frac\tau h\bigl(\bar f_{j+1/2} - \bar f_{j-1/2}\bigr). \]
Последнее равенство точное. Разностная схема возникает, когда средний поток \(\bar f_{j+1/2}\) приближается функцией сеточных значений — численным потоком; структура равенства при этом сохраняется.

Схемы, сохраняющие эту структуру, называются консервативными.

§8.2 · Определение 8.1

Консервативная схема относительно закона сохранения

Разностная схема называется консервативной относительно закона сохранения (8.1), если она записывается в виде \[ y_j^{n+1} = y_j - \frac{\tau}{h}\bigl(F_{j+1/2} - F_{j-1/2}\bigr), \qquad F_{j+1/2} = F\bigl(y_{j-p+1}, \dots, y_{j+q}\bigr), \tag{8.2} \] где численный поток \(F\) — функция \(p + q\) аргументов, одна и та же для всех \(j\), согласованная с потоком \(f\): \[ F(v, v, \dots, v) = f(v) \quad \text{для всех } v. \]
АналогИнтегральная форма (8.1′): \(y_j\) — приближение среднего \(\bar u_j\) по ячейке, \(F_{j+1/2}\) — приближение среднего по шагу потока \(\bar f_{j+1/2}\) через границу \(x_{j+1/2}\).
РольПоток \(F_{j+1/2}\) входит в уравнения ячеек \(j\) и \(j+1\) с противоположными знаками: «масса», покидающая ячейку \(j\) через границу \(x_{j+1/2}\), поступает в ячейку \(j+1\). Отсюда — дискретный закон сохранения и теорема Лакса–Вендроффа.

Свойство относится к паре «схема — закон сохранения»; поясним это на уравнении Бюргерса.

§8.2 · Замечание к определению 8.1

Одно уравнение — разные законы сохранения

Для гладких решений уравнение Бюргерса допускает несколько записей; для разрывных решений они не равносильны.

\[ \text{(а)}\ \ u_t + \Bigl(\frac{u^2}{2}\Bigr)_x = 0, \qquad \text{(б)}\ \ (u^2)_t + \Bigl(\frac{2u^3}{3}\Bigr)_x = 0, \qquad \text{(в)}\ \ u_t + u\,u_x = 0. \]
Разрывные решенияУсловие Ренкина–Гюгонио \(s = [f]/[u]\) даёт разные скорости разрыва: \[ s_{\text{а}} = \frac{u_l + u_r}{2}, \qquad s_{\text{б}} = \frac23\,\frac{u_l^2 + u_l u_r + u_r^2}{u_l + u_r}; \] при \(u_l = 1{,}2\), \(u_r = 0{,}4\): \(s_{\text{а}} = 0{,}8\), \(s_{\text{б}} \approx 0{,}867\).
Следствие для схемСхема, консервативная относительно (а), сохраняет \(\sum_j y_j h\), но не \(\sum_j y_j^2 h\); относительно (б) — наоборот. Запись (в) не является дивергентной: построенная по ней схема не имеет вида (8.2) ни с каким согласованным потоком. Какая величина должна сохраняться, определяет физическая постановка задачи.

Докажем, что консервативная схема сохраняет дискретный аналог интеграла от плотности.

§8.2 · Утверждение 8.1

Дискретный закон сохранения

Утверждение 8.1. Для схемы (8.2) на сетке \(j = 1, \dots, N\) \[ \sum_{j=1}^{N} y_j^{n+1}h = \sum_{j=1}^{N} y_j^n h - \tau\bigl(F_{N+1/2} - F_{1/2}\bigr); \] на периодической сетке \(\sum_j y_j^n h\) не зависит от \(n\).
Доказательство. Умножим (8.2) на \(h\) и просуммируем по \(j\). Сумма разностей потоков телескопическая: поток \(F_{j+1/2}\), \(1 \le j \le N-1\), входит в слагаемое с номером \(j\) со знаком «+» и в слагаемое с номером \(j+1\) со знаком «−»: \[ \sum_{j=1}^{N}\bigl(F_{j+1/2} - F_{j-1/2}\bigr) = F_{N+1/2} - F_{1/2}. \] При периодических условиях \(F_{N+1/2} = F_{1/2}\). ∎
Аналог и рольАналог — \(\tfrac{d}{dt}\int_0^l u\,dx = f\bigl(u(0,t)\bigr) - f\bigl(u(l,t)\bigr)\). «Масса» меняется только через границы; на периодической сетке сохраняется до ошибок округления, что служит проверкой программы.

Сохранение интеграла определяет скорость разрыва в пределе — теорема Лакса–Вендроффа.

§8.2 · Теорема Лакса–Вендроффа

Предел консервативной схемы — слабое решение

Теорема (Лакс, Вендрофф, 1960). Пусть схема (8.2) консервативна относительно (8.1), численный поток \(F\) непрерывен и согласован с \(f\), и при \(h \to 0\), \(\tau/h = \mathrm{const}\), её решения сходятся в \(L_1\) на каждом ограниченном множестве к функции \(u(x, t)\), причём \(\mathrm{TV}(y^n)\) ограничены равномерно. Тогда \(u\) — слабое решение (8.1): для всякой гладкой финитной функции \(\psi\) \[ \int_0^\infty\!\!\int_{-\infty}^{\infty}\bigl(u\,\psi_t + f(u)\,\psi_x\bigr)\,dx\,dt + \int_{-\infty}^{\infty} u(x, 0)\,\psi(x, 0)\,dx = 0, \] и на линиях разрыва выполнено условие Ренкина–Гюгонио \(s\,[u] = [f(u)]\).
Что предполагаетсяСходимость схемы — условие теоремы, а не её вывод. Теорема определяет, к какому объекту сходится консервативная схема, если сходится.
Где используется консервативностьСуммирование по частям в \(\sum_{j,n}\bigl(F_{j+1/2} - F_{j-1/2}\bigr)\psi_j^n\) переносит разность на пробную функцию; для неконсервативной схемы такой перенос невозможен.

Численный пример: консервативная и неконсервативная схемы для уравнения Бюргерса.

§8.3 · Утверждение 8.2

Консервативность линейных схем для уравнения переноса

Утверждение 8.2. Пусть линейная схема \(y_j^{n+1} = \sum_\mu \alpha_\mu\,y_{j+\mu}\) с постоянными коэффициентами удовлетворяет \(\sum_\mu\alpha_\mu = 1\). Тогда (а) она записывается в виде (8.2) с линейным потоком \(F_{j+1/2} = \sum_k b_k\,y_{j+k}\); (б) поток согласован с \(f = au\) тогда и только тогда, когда \(\sum_\mu \mu\,\alpha_\mu = -r\) — условие первого порядка (теорема 1 §7, \(k = 1\)).
Доказательство. Пусть \((Sy)_j = y_{j+1}\) — оператор сдвига, \(P(z) = \sum_\mu\alpha_\mu z^\mu\) — символ схемы: \(y^{n+1} = P(S)\,y\). Так как \(P(1) = 1\), многочлен Лорана \(P(z) - 1\) делится на \(1 - z^{-1}\): \[ P(z) - 1 = \bigl(1 - z^{-1}\bigr)\,Q(z). \] (а) Поток \(F = -\tfrac h\tau\,Q(S)\,y\) даёт \(F_{j+1/2} - F_{j-1/2} = \bigl((I - S^{-1})F\bigr)_j = -\tfrac h\tau\bigl(y^{n+1} - y\bigr)_j\), что и есть (8.2).
(б) \(F(v, \dots, v) = -\tfrac h\tau\,Q(1)\,v\); дифференцируя тождество при \(z = 1\), получаем \(Q(1) = P'(1) = \sum_\mu\mu\,\alpha_\mu\). Равенство \(F(v) = av\) равносильно \(\sum_\mu\mu\,\alpha_\mu = -a\tau/h = -r\). ∎

Доказательство конструктивно; на практике поток удобнее находить преобразованием разностей.

§8.3 · Алгоритм 8.1

Приведение линейной схемы к консервативной форме

Дана схема \(y_j^{n+1} = \sum_\mu\alpha_\mu\,y_{j+\mu}\), аппроксимирующая уравнение переноса. Требуется найти численный поток \(F_{j+1/2}\).

Алгоритм 8.1
  1. Представить приращение в виде \(y_j^{n+1} - y_j = -\dfrac\tau h\bigl[\ \cdots\ \bigr]\).
  2. Выразить все разности в скобке через разности на границах ячеек, используя тождества \[ y_{j+1} - y_{j-1} = \Delta_{j+1/2} + \Delta_{j-1/2}, \qquad y_{j+1} - 2y_j + y_{j-1} = \Delta_{j+1/2} - \Delta_{j-1/2}. \]
  3. Подобрать \(F_{j+1/2}\) так, чтобы \(F_{j+1/2} - F_{j-1/2}\) совпало со скобкой; \(F_{j-1/2}\) получается из \(F_{j+1/2}\) заменой \(j \to j-1\). При затруднении — \(F_{j+1/2} = \sum_k b_k\,y_{j+k}\) с неизвестными \(b_k\) (метод неопределённых коэффициентов, §7).
  4. Проверить согласованность \(F(v, \dots, v) = av\) и восстановить схему подстановкой потока в (8.2).

Применим алгоритм к схемам «уголок» и Лакса–Вендроффа при произвольном знаке \(a\).

§8.3 · Пример 8.2

Поток схемы «уголок»

Разность берётся против потока: левая при \(a > 0\), правая при \(a \lt 0\).

Скорость положительна \[ y_j^{n+1} = y_j - r\,(y_j - y_{j-1}) = y_j - \frac\tau h\bigl(\underbrace{a\,y_j}_{F_{j+1/2}} - \underbrace{a\,y_{j-1}}_{F_{j-1/2}}\bigr). \]
Скорость отрицательна \[ y_j^{n+1} = y_j - r\,(y_{j+1} - y_j) = y_j - \frac\tau h\bigl(\underbrace{a\,y_{j+1}}_{F_{j+1/2}} - \underbrace{a\,y_{j}}_{F_{j-1/2}}\bigr). \]
Единая записьОбозначим положительную и отрицательную части скорости \[ a^+ = \max(a, 0) = \frac{a + |a|}{2}, \qquad a^- = \min(a, 0) = \frac{a - |a|}{2}, \qquad a^+ + a^- = a,\quad a^+ - a^- = |a|. \] Тогда при любом знаке \(a\) \[ F^{\text{уг}}_{j+1/2} = a^+\,y_j + a^-\,y_{j+1}: \] через границу \(x_{j+1/2}\) переносится значение из ячейки, лежащей выше по потоку; \(F^{\text{уг}}(v, v) = av\).

Схема Лакса–Вендроффа записывается одной формулой при любом знаке \(r\); найдём её поток.

§8.3 · Пример 8.3 · шаги 1–2

Схема Лакса–Вендроффа: приращение через разности \(\Delta_{j\pm1/2}\)

Схема второго порядка, одна формула при любом знаке \(r\):

\[ y_j^{n+1} = y_j - \frac r2\,(y_{j+1} - y_{j-1}) + \frac{r^2}{2}\,(y_{j+1} - 2y_j + y_{j-1}). \]
Шаги 1 и 2 \[ \begin{aligned} y_j^{n+1} - y_j &= -\frac\tau h\Bigl[\frac a2\,(y_{j+1} - y_{j-1}) - \frac{ar}{2}\,(y_{j+1} - 2y_j + y_{j-1})\Bigr]\\ &= -\frac\tau h\Bigl[\frac{a(1 - r)}{2}\,\Delta_{j+1/2} + \frac{a(1 + r)}{2}\,\Delta_{j-1/2}\Bigr]. \end{aligned} \]
Скорость положительнаИз \(\tfrac{1+r}{2} = 1 - \tfrac{1-r}{2}\): \[ [\ \cdots\ ] = a\,\Delta_{j-1/2} + \frac{a(1 - r)}{2}\bigl(\Delta_{j+1/2} - \Delta_{j-1/2}\bigr). \]
Скорость отрицательнаИз \(\tfrac{1-r}{2} = 1 - \tfrac{1+r}{2}\): \[ [\ \cdots\ ] = a\,\Delta_{j+1/2} - \frac{a(1 + r)}{2}\bigl(\Delta_{j+1/2} - \Delta_{j-1/2}\bigr). \]

В каждом случае скобка — разность значений одного выражения на границах \(x_{j+1/2}\) и \(x_{j-1/2}\).

§8.3 · Пример 8.3 · шаги 3–4

Поток схемы Лакса–Вендроффа

При \(a > 0\): \(a = |a|\), \(1 - r = 1 - |r|\); при \(a \lt 0\): \(-a = |a|\), \(1 + r = 1 - |r|\). Оба случая дают одну формулу:

\[ F^{\text{ЛВ}}_{j+1/2} = \underbrace{a^+\,y_j + a^-\,y_{j+1}}_{F^{\text{уг}}_{j+1/2}} + \underbrace{\frac{|a|}{2}\,(1 - |r|)\,\Delta_{j+1/2}}_{\text{антидиффузионная поправка}}, \qquad F^{\text{ЛВ}}(v, v) = av. \]
Вклад поправки в схему \[ \begin{aligned} -\frac\tau h\,\frac{|a|(1 - |r|)}{2}\bigl(\Delta_{j+1/2} - \Delta_{j-1/2}\bigr)\\ &= -\frac{|r|(1 - |r|)}{2}\,\bigl(y_{j+1} - 2y_j + y_{j-1}\bigr) \end{aligned} \] — вторая разность с отрицательным коэффициентом: снимается схемная вязкость «уголка» \(\nu = \tfrac{|a|h}{2}(1 - |r|)\) (§5).
СледствиеПоправка повышает порядок аппроксимации до второго и порождает осцилляции у разрывов (паспорт схемы, §5). Естественно умножить её на коэффициент из \([0, 1]\), зависящий от решения: \(0\) — «уголок», \(1\) — схема Лакса–Вендроффа.

Прежде чем вводить такой коэффициент, уточним, какие свойства схемы запрещают осцилляции.

§8.3 · Программная реализация

Консервативная форма в программе

Элемент \(j\) массива потоков хранит \(F_{j+1/2}\); сдвиг массива на один элемент даёт \(F_{j-1/2}\); \(\tau/h = r/a\).

# F[j] = F_{j+1/2};  np.roll(F, 1)[j] = F_{j-1/2};  np.roll(u, -1)[j] = y_{j+1}
def step_flux(u, r, flux):
    F = flux(u, r)
    return u - (r / A) * (F - np.roll(F, 1))         # (8.2), tau/h = r/a

def flux_upwind(u, r):                               # a+ y_j + a- y_{j+1}
    return max(A, 0) * u + min(A, 0) * np.roll(u, -1)

def flux_lw(u, r):                                   # + |a|(1-|r|)/2 * Delta_{j+1/2}
    return flux_upwind(u, r) + 0.5 * abs(A) * (1 - abs(r)) * (np.roll(u, -1) - u)
Контроль 1. \(\max_j\bigl|\)шаг по формуле схемы − шаг через поток\(\bigr|\) порядка \(10^{-16}\) при \(a = 1\) и \(a = -1\).

2. \(\sum_j y_j^n h\) не меняется по шагам (утверждение 8.1).

Перейдём к свойствам, запрещающим появление осцилляций; первое из них — монотонность.

§8.4 · Определение 8.2

Монотонная схема

Явная двухслойная схема \(y_j^{n+1} = H\bigl(y_{j-p}, \dots, y_{j+q}\bigr)\) называется монотонной (по Годунову), если функция \(H\) не убывает по каждому аргументу: \[ \frac{\partial H}{\partial y_{j+\mu}} \ge 0, \qquad \mu = -p, \dots, q. \tag{8.4} \] Для линейной схемы \(y_j^{n+1} = \sum_\mu\alpha_\mu\,y_{j+\mu}\) условие (8.4) равносильно \(\alpha_\mu \ge 0\) для всех \(\mu\).
Равносильная формулировка (Фридрихс): из \(y_j \ge z_j\) при всех \(j\) следует \(y_j^{n+1} \ge z_j^{n+1}\) при всех \(j\); по теореме о среднем \(H(y) - H(z) = \sum_\mu \partial_\mu H(\xi)\,(y_{j+\mu} - z_{j+\mu}) \ge 0\).
АналогПринцип сравнения для (8.1): из \(u_0(x) \le v_0(x)\) следует \(u(x, t) \le v(x, t)\) при всех \(t > 0\). Для переноса оба профиля сдвигаются на одно и то же расстояние.
РольМонотонность влечёт принцип максимума и невозрастание полной вариации (теорема 8.1); для линейных схем она ограничивает порядок первым (теорема 9.1).

Проверим определение на схемах «уголок» и Лакса–Вендроффа.

§8.4 · Пример 8.4

Монотонность схем «уголок» и Лакса–Вендроффа

Монотонность линейной схемы проверяется по знакам коэффициентов.

«Уголок», \(a > 0\) \[ y_j^{n+1} = r\,y_{j-1} + (1 - r)\,y_j: \qquad \alpha_{-1} = r,\ \ \alpha_0 = 1 - r. \] Монотонна \(\iff 0 \le r \le 1\) — условие Куранта. При \(a \lt 0\) — то же с \(|r|\).
Лакс–Вендрофф \[ \alpha_{-1} = \frac{r(1 + r)}{2}, \qquad \alpha_0 = 1 - r^2, \qquad \alpha_1 = -\frac{r(1 - r)}{2}. \] При \(0 \lt r \lt 1\) отрицателен \(\alpha_1\), при \(-1 \lt r \lt 0\) — \(\alpha_{-1}\): схема не монотонна ни при каком нецелом \(r\).
Отрицательный коэффициент \(\alpha_\mu\) означает, что увеличение значения в узле \(j + \mu\) уменьшает \(y_j^{n+1}\); на разрыве это создаёт новый экстремум.

Отсутствие новых экстремумов формулируется как принцип максимума.

§8.4 · Определение 8.4

Дискретный принцип максимума

Схема удовлетворяет дискретному принципу максимума, если для всех \(j\) и \(n\) \[ \min_{-p \le \mu \le q} y_{j+\mu} \ \le\ y_j^{n+1}\ \le\ \max_{-p \le \mu \le q} y_{j+\mu}. \tag{8.5} \]
Утверждение 8.3. Линейная схема с \(\sum_\mu\alpha_\mu = 1\) удовлетворяет (8.5) тогда и только тогда, когда она монотонна.
Доказательство. Если \(\alpha_\mu \ge 0\) и \(\sum\alpha_\mu = 1\), то \(y_j^{n+1}\) — выпуклая комбинация значений на шаблоне и лежит между их минимумом и максимумом. Если \(\alpha_\nu \lt 0\), возьмём \(y_{j+\nu} = 1\), остальные значения на шаблоне равны нулю: тогда \(y_j^{n+1} = \alpha_\nu \lt 0 = \min_\mu y_{j+\mu}\). ∎
АналогРешение уравнения переноса постоянно вдоль характеристик, поэтому \(\min u_0 \le u(x, t) \le \max u_0\).
РольНовые локальные экстремумы не возникают; данные из \([0, 1]\) (концентрация, объёмная доля) остаются в \([0, 1]\).

Принцип максимума локален; глобальной мерой осцилляций служит полная вариация.

§8.4 · Определение 8.5

Полная вариация сеточной функции

Полной вариацией сеточной функции \(y\) называется величина \[ \mathrm{TV}(y) = \sum_j |\Delta_{j+1/2}| = \sum_j |y_{j+1} - y_j|. \tag{8.7} \]
АналогПолная вариация функции: \(\mathrm{TV}(u) = \displaystyle\int |u_x|\,dx\) для гладкой \(u\); в общем случае — верхняя грань \(\sum_k |u(x_{k+1}) - u(x_k)|\) по всем разбиениям. Сеточная величина (8.7) — значение этой суммы на разбиении, порождённом сеткой.
РольМера суммарной изрезанности профиля. Монотонная ступенька от \(0\) до \(1\): \(\mathrm{TV} = 1\) при любом числе узлов на переходе. Новый локальный экстремум амплитуды \(\delta\) увеличивает \(\mathrm{TV}\) на \(2\delta\).

Требование, чтобы полная вариация не возрастала, — свойство TVD.

§8.4 · Определение 8.6

Схемы с невозрастающей полной вариацией (TVD)

Схема называется TVD-схемой (total variation diminishing, Хартен, 1983), если для любой сеточной функции \(y^n\) с конечной полной вариацией \[ \mathrm{TV}(y^{n+1}) \le \mathrm{TV}(y^n). \tag{8.8} \]
АналогДля уравнения переноса \(\mathrm{TV}\bigl(u(\cdot, t)\bigr) = \mathrm{TV}(u_0)\): профиль сдвигается без изменения формы. Для нелинейного закона (8.1) полная вариация энтропийного решения не возрастает.
РольЗапрет роста осцилляций одним неравенством на весь слой. Проверяется и для нелинейных схем (лемма Хартена, §10); равномерная ограниченность \(\mathrm{TV}\) входит в условия теоремы Лакса–Вендроффа.

Установим связь между монотонностью и свойством TVD.

§8.4 · Теорема 8.1

Связь монотонности и свойства TVD для линейных схем

Пусть \(y_j^{n+1} = \sum_\mu\alpha_\mu\,y_{j+\mu}\), \(\sum_\mu\alpha_\mu = 1\). Тогда (а) если схема монотонна, она является TVD-схемой; (б) если схема является TVD-схемой, она монотонна.
Доказательство (а). Коэффициенты не зависят от \(j\), поэтому \[ \Delta^{n+1}_{j+1/2} = y^{n+1}_{j+1} - y^{n+1}_j = \sum_\mu\alpha_\mu\,\Delta_{j+\mu+1/2}. \] Так как \(\alpha_\mu \ge 0\) (здесь использована монотонность), \[ |\Delta^{n+1}_{j+1/2}| \le \sum_\mu\alpha_\mu\,|\Delta_{j+\mu+1/2}|. \] Суммируя по \(j\) и меняя порядок суммирования, получаем \[ \mathrm{TV}(y^{n+1}) \le \sum_\mu\alpha_\mu\sum_j|\Delta_{j+\mu+1/2}| = \sum_\mu\alpha_\mu\,\mathrm{TV}(y^n) = \mathrm{TV}(y^n). \]

Часть (б) доказывается выбором начальных данных — ступеньки.

§8.4 · Теорема 8.1 · доказательство (б)

Линейная TVD-схема монотонна

Доказательство (б). Возьмём ступеньку \(y_j^0 = 1\) при \(j \le 0\), \(y_j^0 = 0\) при \(j > 0\). Её единственная ненулевая разность \(\Delta^0_{1/2} = -1\), \(\mathrm{TV}(y^0) = 1\). По формуле из (а) \[ \Delta^1_{j+1/2} = \sum_\mu\alpha_\mu\,\Delta^0_{j+\mu+1/2} = -\alpha_{-j}, \qquad \mathrm{TV}(y^1) = \sum_\mu|\alpha_\mu| \ \ge\ \Bigl|\sum_\mu\alpha_\mu\Bigr| = 1, \] причём равенство достигается тогда и только тогда, когда все \(\alpha_\mu \ge 0\). Если схема TVD, то \(\mathrm{TV}(y^1) \le 1\), следовательно, \(\alpha_\mu \ge 0\) для всех \(\mu\). ∎
Следствие. Для линейных схем с \(\sum\alpha_\mu = 1\) монотонность, принцип максимума (8.5) и свойство TVD (8.8) равносильны. Для нелинейных схем эти свойства различны.

Выясним, какой порядок аппроксимации совместим с неотрицательностью коэффициентов.

§9.1 · Условия порядка (теорема 1 §7)

Условия аппроксимации как условия на моменты весов

Линейная схема \(y_j^{n+1} = \sum_\mu\alpha_\mu\,y_{j+\mu}\) аппроксимирует уравнение переноса с порядком \(p\) тогда и только тогда, когда \(\sum_\mu\alpha_\mu(-\mu)^k = r^k\), \(k = 0, 1, \dots, p\) (теорема 1 §7). При \(p = 2\):

\[ \sum_\mu\alpha_\mu = 1, \tag{9.3} \]
\[ \sum_\mu \mu\,\alpha_\mu = -r, \tag{9.5} \]
\[ \sum_\mu \mu^2\,\alpha_\mu = r^2. \tag{9.6} \]
АналогТочное решение берёт значение в одной точке \(x_j - rh\): «схема» с единичной массой в точке \(-r\). Её моменты: \(1\), \(-r\), \(r^2, \dots\)
РольУсловия порядка \(p\) — совпадение первых \(p + 1\) моментов весов \(\alpha_\mu\) с моментами точечной массы в \(-r\). При \(p = 1\) совпадает «центр масс», при \(p = 2\) — и второй момент.

Неотрицательные веса с теми же первыми тремя моментами, что у точечной массы, обязаны быть точечной массой.

§9.2 · Теорема 9.1

Теорема Годунова

(Годунов, 1959). Линейная монотонная схема \(y_j^{n+1} = \sum_\mu\alpha_\mu\,y_{j+\mu}\) с постоянными коэффициентами, аппроксимирующая уравнение переноса, при нецелом \(r\) имеет порядок аппроксимации не выше первого.
Условия теоремыШаблон — любой ширины. Нецелое \(r\) существенно: при целом \(r\) точный сдвиг \(y_j^{n+1} = y_{j-r}\) монотонен и имеет любой порядок.
Следствие теоремы 8.1Линейная TVD-схема монотонна (теорема 8.1(б)); следовательно, при нецелом \(r\) она также имеет порядок не выше первого.

Доказательство проводится от противного: предполагаем второй порядок и монотонность.

§9.2 · Доказательство теоремы 9.1 · этапы 1–2

Тождество для моментов весов

Этап 1 (предположение). Пусть схема монотонна, \(\alpha_\mu \ge 0\) для всех \(\mu\), и имеет порядок аппроксимации не ниже второго. Тогда выполнены условия (9.3), (9.5), (9.6).

Этап 2 (тождество). Вычислим взвешенную сумму квадратов расстояний от узлов \(\mu\) до точки \(-r\). Раскрывая квадрат и подставляя (9.6), (9.5), (9.3):

\[ \sum_\mu\alpha_\mu\,(\mu + r)^2 = \sum_\mu\mu^2\alpha_\mu + 2r\sum_\mu\mu\,\alpha_\mu + r^2\sum_\mu\alpha_\mu = r^2 - 2r\cdot r + r^2\cdot 1 = 0. \tag{9.7} \]

На этапе 2 неотрицательность коэффициентов не использована: равенство (9.7) верно для любой схемы второго порядка.

Используем теперь гипотезу \(\alpha_\mu \ge 0\).

§9.2 · Доказательство теоремы 9.1 · этапы 3–4

Неотрицательные веса с нулевым разбросом сосредоточены в одной точке

Этап 3 (здесь использована монотонность). В сумме (9.7) каждое слагаемое \(\alpha_\mu(\mu + r)^2\) неотрицательно, а сумма равна нулю; следовательно,

\[ \alpha_\mu\,(\mu + r)^2 = 0 \quad \text{для всех } \mu, \qquad \text{т. е. } \ \alpha_\mu \ne 0 \ \Rightarrow\ \mu = -r. \]

Этап 4 (противоречие). Узлы шаблона — целые числа. При нецелом \(r\) равенство \(\mu = -r\) невозможно, поэтому \(\alpha_\mu = 0\) для всех \(\mu\), что противоречит (9.3). ∎

Целое \(r\)Остаётся \(\alpha_{-r} = 1\): схема совпадает с точным сдвигом на \(r\) узлов.
Геометрия §7Для шаблона \(\{-2, -1, 0, 1\}\) при \(0 \lt r \lt 1\) прямая схем второго порядка не пересекает четырёхугольник неотрицательности коэффициентов.
Следствие 9.1. Схема второго порядка, не порождающая осцилляций, обязана быть нелинейной: её коэффициенты зависят от решения.

Для нелинейных схем теорема 8.1 неприменима; свойство TVD проверяется леммой Хартена.

§10.1 · Теорема 10.2 (лемма Хартена)

Достаточное условие TVD для нелинейных схем

(Хартен, 1983). Пусть схема записана в приращениях \[ y_j^{n+1} = y_j + C_{j+1/2}\,\Delta_{j+1/2} - D_{j-1/2}\,\Delta_{j-1/2}, \tag{10.4} \] где коэффициенты \(C_{j+1/2}\), \(D_{j+1/2}\) могут зависеть от \(y^n\), и для всех \(j\) \[ C_{j+1/2} \ge 0, \qquad D_{j+1/2} \ge 0, \qquad C_{j+1/2} + D_{j+1/2} \le 1. \] Тогда схема (10.4) является TVD-схемой.
Смысл условийНовое значение смещается к значениям в соседних узлах (\(C, D \ge 0\)) не далее, чем на величину соответствующей разности (\(C + D \le 1\)).
Связь с теоремой 8.1Для линейной трёхточечной схемы \(C\), \(D\) постоянны, и условия леммы совпадают с \(\alpha_\mu \ge 0\), \(\sum\alpha_\mu = 1\).

Доказательство повторяет доказательство теоремы 8.1(а) с переменными коэффициентами.

§10.1 · Доказательство теоремы 10.2

Доказательство леммы Хартена

Этап 1. Вычитая (10.4) для узла \(j\) из (10.4) для узла \(j+1\), получаем

\[ \Delta^{n+1}_{j+1/2} = \bigl(1 - C_{j+1/2} - D_{j+1/2}\bigr)\Delta_{j+1/2} + C_{j+3/2}\,\Delta_{j+3/2} + D_{j-1/2}\,\Delta_{j-1/2}. \]

Этап 2 (здесь использованы условия теоремы). Все три множителя неотрицательны, поэтому

\[ |\Delta^{n+1}_{j+1/2}| \le \bigl(1 - C_{j+1/2} - D_{j+1/2}\bigr)|\Delta_{j+1/2}| + C_{j+3/2}\,|\Delta_{j+3/2}| + D_{j-1/2}\,|\Delta_{j-1/2}|. \]

Этап 3. Суммируя по \(j\) и сдвигая индекс во второй и третьей суммах, получаем при каждом \(|\Delta_{j+1/2}|\) коэффициент \((1 - C - D) + C + D = 1\):

\[ \mathrm{TV}(y^{n+1}) \le \sum_j|\Delta_{j+1/2}| = \mathrm{TV}(y^n). \ ∎ \]

Применим лемму к известным схемам первого порядка.

§10.1 · Пример 10.1

Лемма Хартена для схемы «уголок» и схемы Лакса–Вендроффа

Коэффициенты \(C\), \(D\) находятся представлением схемы через разности \(\Delta_{j\pm1/2}\).

Схема «уголок» \[ \begin{aligned} a > 0:&\quad y_j^{n+1} = y_j - r\,\Delta_{j-1/2}, && C = 0,\ \ D = r;\\ a \lt 0:&\quad y_j^{n+1} = y_j + |r|\,\Delta_{j+1/2}, && C = |r|,\ \ D = 0. \end{aligned} \] В обоих случаях условия теоремы 10.2 равносильны условию Куранта \(|r| \le 1\).
Для схемы Лакса–Вендроффа при \(0 \lt r \lt 1\) коэффициент при \(\Delta_{j+1/2}\) равен \(-\tfrac{r(1-r)}{2} \lt 0\): лемма неприменима, и по теореме 8.1(б) схема не является TVD.

Построим нелинейную схему, коэффициенты \(C\), \(D\) которой удовлетворяют лемме при сохранении второго порядка.

§10.2 · Определение 10.3

Схема с ограничителем потока

Схемой с ограничителем потока для уравнения переноса называется консервативная схема (8.2) с потоком \[ F_{j+1/2} = a^+\,y_j + a^-\,y_{j+1} + \frac{|a|}{2}\,(1 - |r|)\,\varphi\bigl(\theta_{j+1/2}\bigr)\,\Delta_{j+1/2}, \qquad \theta_{j+1/2} = \frac{\Delta_{j+1/2-\sigma}}{\Delta_{j+1/2}}, \quad \sigma = \operatorname{sign} a, \tag{10.5} \] где \(\varphi\colon \mathbb R \to \mathbb R\) — заданная функция, ограничитель. В числителе \(\theta_{j+1/2}\) — разность на соседней границе, лежащей выше по потоку: \[ a > 0:\ \ \theta_{j+1/2} = \frac{\Delta_{j-1/2}}{\Delta_{j+1/2}}, \qquad a \lt 0:\ \ \theta_{j+1/2} = \frac{\Delta_{j+3/2}}{\Delta_{j+1/2}}. \]
Частные случаи\(\varphi \equiv 0\) — «уголок», \(\varphi \equiv 1\) — схема Лакса–Вендроффа. При \(\Delta_{j+1/2} = 0\) поправка равна нулю при любом \(\theta_{j+1/2}\).
НелинейностьПри постоянном \(\varphi\) схема линейна и подчиняется теореме 9.1. Зависимость от решения вводится только через \(\theta_{j+1/2}\). Для нелинейного закона \(a\) заменяется скоростью \(a_{j+1/2}\) на границе.

Выясним смысл аргумента \(\theta_{j+1/2}\) и значения \(\varphi\).

§10.2 · Смысл \(\theta\)

Отношение соседних разностей как индикатор гладкости

Пусть \(a > 0\) и \(y_j = u(x_j)\) для гладкой \(u\) с \(u_x(x_j) \ne 0\). Разложение Тейлора в точке \(x_j\) даёт

\[ \theta_{j+1/2} = \frac{h\,u_x - \tfrac{h^2}{2}u_{xx} + O(h^3)}{h\,u_x + \tfrac{h^2}{2}u_{xx} + O(h^3)} = 1 - h\,\frac{u_{xx}}{u_x} + O(h^2). \]
Значения \(\theta_{j+1/2}\) \(\theta = 1 + O(h)\) — гладкий монотонный участок;
\(\theta \lt 0\) — соседние разности разных знаков: экстремум;
\(\theta\) близко к нулю или велико — разрыв на одной из двух границ.
Почему выше по потокуЗначение в ячейке на слое \(n+1\) определяется данными, приходящими по характеристикам сверху по потоку. Разность выше по потоку характеризует профиль, который пересечёт границу на следующем шаге; при выборе разности ниже по потоку схема не является TVD.

Значение \(\varphi(\theta_{j+1/2})\) допускает три равносильных истолкования.

§10.2 · Смысл \(\varphi\)

Три истолкования значения ограничителя

1. Доля потока схемы Лакса–Вендроффа \[ F_{j+1/2} = \bigl(1 - \varphi\bigr)\,F^{\text{уг}}_{j+1/2} + \varphi\,F^{\text{ЛВ}}_{j+1/2}, \qquad \varphi = \varphi(\theta_{j+1/2}); \] значения \(\varphi > 1\) означают поправку с коэффициентом, бо́льшим, чем у схемы Лакса–Вендроффа.
2. Схемная вязкостьПри \(\varphi \approx \mathrm{const}\) на участке первое дифференциальное приближение содержит вязкость \[ \nu_\varphi = \frac{|a|h}{2}\,(1 - |r|)\,(1 - \varphi): \] \(\varphi = 0\) — вязкость «уголка», \(\varphi = 1\) — нулевая (второй порядок), \(\varphi > 1\) — отрицательная (обострение профиля).
3. Ограниченная разностьВ поправку входит \(\varphi(\theta_{j+1/2})\,\Delta_{j+1/2}\) вместо \(\Delta_{j+1/2}\). Для ограничителя minmod (\(a > 0\)): \[ \varphi(\theta_{j+1/2})\,\Delta_{j+1/2} = \mathrm{minmod}\bigl(\Delta_{j-1/2}, \Delta_{j+1/2}\bigr) = \begin{cases} 0, & \Delta_{j-1/2}\Delta_{j+1/2} \le 0,\\ \text{меньшая по модулю}, & \text{иначе}. \end{cases} \]

Какие функции \(\varphi\) обеспечивают свойство TVD — теорема Свеби.

§10.3 · Теорема 10.3

Условие Свеби

(Свеби, 1984). Схема с ограничителем потока (10.5) при \(|r| \le 1\) является TVD-схемой, если \[ \varphi(\theta) = 0 \ \ \text{при } \theta \le 0, \qquad 0 \le \varphi(\theta) \le \min(2\theta,\, 2) \ \ \text{при } \theta > 0. \tag{10.6} \]
Знак скоростиУсловие (10.6) от знака \(a\) не зависит; от знака зависит только выбор разности в числителе \(\theta_{j+1/2}\).
ЭкстремумПри \(\theta \le 0\) поправка выключается: в окрестности экстремума схема совпадает с «уголком».

Доказательство — приведение схемы к виду (10.4) и проверка условий леммы Хартена.

§10.3 · Доказательство теоремы 10.3

Доказательство условия Свеби

Этап 1 (\(a > 0\), приведение к виду (10.4)). Так как \(\Delta_{j+1/2} = \Delta_{j-1/2}/\theta_{j+1/2}\), схема принимает вид (10.4) с \(C_{j+1/2} = 0\) и

\[ D_{j-1/2} = r\Bigl[1 + \frac{1 - r}{2}\,X\Bigr], \qquad X = \frac{\varphi(\theta_{j+1/2})}{\theta_{j+1/2}} - \varphi(\theta_{j-1/2}). \]

Этап 2 (здесь использовано (10.6)). Из (10.6) \(0 \le \varphi(\theta)/\theta \le 2\) и \(0 \le \varphi(\theta) \le 2\); следовательно, \(-2 \le X \le 2\).

Этап 3. При \(0 \le r \le 1\)

\[ r^2 = r\bigl[1 - (1 - r)\bigr] \le D_{j-1/2} \le r\bigl[1 + (1 - r)\bigr] = 1 - (1 - r)^2 \le 1, \]

и по теореме 10.2 схема является TVD. Случай \(a \lt 0\) сводится к рассмотренному заменой \(x \to -x\). ∎

Условие (10.6) не гарантирует второго порядка; его обеспечивает дополнительное условие в точке \(\theta = 1\).

§10.4 · Второй порядок · Определение 10.4

Условие второго порядка и классические ограничители

Утверждение 10.1 (Свеби, без доказательства). Если \(\varphi(1) = 1\) и при \(0 \le \theta \le 2\) значение \(\varphi(\theta)\) лежит между \(1\) и \(\theta\), то поток (10.5) — выпуклая комбинация потоков двух схем второго порядка (\(\varphi = 1\) и \(\varphi = \theta\)), и на гладких монотонных участках схема имеет второй порядок.
Классические ограничители: \[ \begin{aligned} &\text{minmod:} && \varphi(\theta) = \max\bigl(0, \min(1, \theta)\bigr), &\qquad &\text{van Leer:} && \varphi(\theta) = \frac{\theta + |\theta|}{1 + |\theta|},\\ &\text{superbee:} && \varphi(\theta) = \max\bigl(0, \min(2\theta, 1), \min(\theta, 2)\bigr), & &\text{MC:} && \varphi(\theta) = \max\bigl(0, \min\bigl(2\theta, \tfrac{1+\theta}{2}, 2\bigr)\bigr). \end{aligned} \] Все четыре удовлетворяют (10.6), \(\varphi(\theta) = 0\) при \(\theta \le 0\) и \(\varphi(1) = 1\).

Условия (10.6) и утверждения 10.1 наглядно представляются на плоскости \((\theta, \varphi)\).

§10.4 · Диаграмма Свеби

Область TVD и графики ограничителей на плоскости \((\theta, \varphi)\)

ОбластиСветлая — множество (10.6): отрезок оси при \(\theta \le 0\), сверху — прямая \(\varphi = 2\theta\) при \(0 \le \theta \le 1\) и уровень \(\varphi = 2\) при \(\theta \ge 1\). Тёмная — условие утверждения 10.1: между прямыми \(\varphi = 1\) и \(\varphi = \theta\).
ГрафикиВсе проходят через точку \((1, 1)\). minmod — нижняя граница тёмной области, superbee — верхняя граница светлой, van Leer и MC — между ними.
Диаграмма Свеби: светлое — область (10.6), тёмное — область утверждения 10.1.

Поясним, как по диаграмме судить о свойствах схемы.

§10.4 · Диаграмма Свеби

Чтение диаграммы: сечения, границы, порядок графиков

Вертикальное сечениеПри фиксированном \(\theta\) пересечение вертикали со светлой областью — множество допустимых значений \(\varphi\): при \(\theta \le 0\) только \(\varphi = 0\); при \(\theta = \tfrac12\) — отрезок \([0, 1]\); при \(\theta \ge 1\) — отрезок \([0, 2]\).
Смысл границ (\(a > 0\), разности одного знака) \[ \varphi(\theta_{j+1/2}) \le 2\theta_{j+1/2} \iff \bigl|\varphi(\theta_{j+1/2})\,\Delta_{j+1/2}\bigr| \le 2\,|\Delta_{j-1/2}|: \] ограниченная разность на границе не превосходит удвоенной разности выше по потоку; при нарушении значение в ячейке \(j\) выходит за значения соседей. Граница \(\varphi \le 2\) — то же условие для соседней границы; \(\varphi = 0\) — схема «уголок».
Порядок графиковПри фиксированном \(\theta\) больший \(\varphi\) — меньшая схемная вязкость: при \(\theta = \tfrac12\) minmod, van Leer, superbee дают \(\tfrac12\), \(\tfrac23\), \(1\); при \(\theta = 2\) — \(1\), \(\tfrac43\), \(2\). Схема Лакса–Вендроффа (\(\varphi \equiv 1\)) при \(\theta \lt \tfrac12\) лежит вне области (10.6).

Проверим эти выводы вычислением одного шага.

§10.5 · Утверждение 10.2

Порядок TVD-схем в окрестности экстремума

Утверждение 10.2 (Ошер, 1984). TVD-схема в окрестности нелинейного гладкого экстремума решения имеет порядок аппроксимации не выше первого.
ПричинаУ экстремума \(\theta_{j+1/2} \lt 0\), и по (10.6) \(\varphi = 0\): схема совпадает с «уголком». Максимум точного решения обычно лежит между узлами; после переноса узловой максимум должен возрасти, что запрещено свойством TVD.
