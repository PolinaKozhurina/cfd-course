§12 · Семестр 1

Уравнения газовой динамики в переменных Лагранжа

В одномерных задачах с ударными волнами и контактными границами удобно следить за частицами газа, а не за точками пространства: тогда вещество не переносится через сетку.

Эйлер и Лагранж · Массовая координата · Три закона сохранения · Система · Внутренняя энергия · Акустика

Неизвестные: скорость \(u\), удельный объём \(V = 1/\rho\), удельная внутренняя энергия \(\varepsilon\), давление \(p\).

§12.1 · Два описания

Эйлерово и лагранжево описания

В эйлеровом описании величины — функции точки пространства и времени: \(\rho(x,t)\), \(u(x,t)\), \(p(x,t)\); сетка неподвижна, вещество протекает сквозь ячейки.

В лагранжевом описании каждая частица получает постоянную метку \(\xi\), величины — функции метки и времени, а положение частицы \(x(\xi,t)\) удовлетворяет уравнению \(\partial x/\partial t|_\xi = u\). Линии лагранжевой сетки — траектории частиц.

§12.2 · Определение 1

Массовая координата

Массовая координата. Пусть \(x_0(t)\) — траектория выделенной частицы. Массовой координатой точки \(x\) в момент \(t\) называется масса газа между выделенной частицей и точкой \(x\): \[ s(x,t) = \int_{x_0(t)}^{x}\rho\,dx . \tag{12.2} \]

Нижний предел движется вместе с веществом, поэтому масса между выделенной частицей и любой другой частицей не меняется: у каждой частицы \(s = \mathrm{const}\), и \(s\) служит её меткой. Из (12.2) \(\partial s/\partial x = \rho\), откуда

\[ \frac{\partial x}{\partial s} = V = \frac1\rho . \tag{12.3} \]

В переменных \((s,t)\) частная производная по \(t\) берётся вдоль траектории частицы и совпадает с материальной производной \(\partial_t + u\,\partial_x\) эйлерова описания.

§12.3 · Вывод

Законы сохранения для отрезка газа

Отрезок газа между частицами \(s_1 < s_2\) имеет постоянную массу \(s_2 - s_1\): через торцы вещество не течёт, на торцы действуют давления соседнего газа.

Масса (12.4)Длина отрезка \(\int V\,ds\) меняется со скоростью торцов: \[ \frac{d}{dt}\int_{s_1}^{s_2} V\,ds = u(s_2) - u(s_1). \]
Импульс (12.5)Второй закон Ньютона для отрезка: \[ \frac{d}{dt}\int_{s_1}^{s_2} u\,ds = p(s_1) - p(s_2). \]
Энергия (12.6)Полная энергия меняется на мощность сил давления: \[ \frac{d}{dt}\int_{s_1}^{s_2}\Bigl(\varepsilon + \frac{u^2}{2}\Bigr)ds = (pu)(s_1) - (pu)(s_2). \]

Соотношения (12.4)–(12.6) не содержат производных по \(s\) и верны, когда внутри отрезка есть разрыв.

§12.4 · Теорема 1

Система уравнений в переменных Лагранжа

Теорема. Для гладких течений идеального газа из (12.4)–(12.6) следует система \[ V_t - u_s = 0, \qquad u_t + p_s = 0, \qquad \Bigl(\varepsilon + \frac{u^2}{2}\Bigr)_t + (pu)_s = 0, \tag{12.7} \] \[ x_t = u, \qquad p = p(V, \varepsilon), \quad\text{для политропного газа}\quad p = \frac{(\gamma - 1)\,\varepsilon}{V}. \tag{12.8} \]

Все три уравнения (12.7) — законы сохранения вида \(\partial_t(\text{плотность}) + \partial_s(\text{поток}) = 0\) с плотностями \(V\), \(u\), \(\varepsilon + u^2/2\) и потоками \(-u\), \(p\), \(pu\); на них строятся консервативные схемы. Конвективных членов вида \(u\,u_x\) нет: перенос вещества убран выбором переменных.

Замена \(\partial_t|_s = \partial_t|_x + u\,\partial_x\), \(\partial_s = V\partial_x\) переводит (12.7) в эйлеровы уравнения для \(\rho\), \(\rho u\), \(\rho(\varepsilon + u^2/2)\).

§12.4 · Внутренняя энергия

Уравнение для внутренней энергии

Умножим второе уравнение (12.7) на \(u\): \((u^2/2)_t + u\,p_s = 0\). Вычтем результат из третьего уравнения: \(\varepsilon_t + (pu)_s - u\,p_s = \varepsilon_t + p\,u_s = 0\). По первому уравнению \(u_s = V_t\), поэтому

\[ \varepsilon_t + p\,V_t = 0 \qquad (d\varepsilon = -p\,dV). \tag{12.9} \]

Это первое начало термодинамики для частицы: внутренняя энергия расходуется на работу расширения.

На гладких решениях (12.9) равносильно закону сохранения полной энергии. На ударной волне — нет: (12.9) не является законом сохранения, и скачок энергии на волне определяет только интегральное соотношение (12.6). Уравнение (12.9) называют недивергентной формой уравнения энергии, третье уравнение (12.7) — дивергентной.

Схема «крест» (§13) аппроксимирует недивергентную форму; к сравнению двух форм вернёмся в §13.7.

§12.5 · Акустика

Акустическое приближение

Линеаризуем (12.7) около покоя \(V_0\), \(u_0 = 0\), \(p_0\). На гладком течении энтропия частицы постоянна, поэтому малое изменение давления связано с изменением объёма адиабатической производной:

\[ p' = \Bigl(\frac{\partial p}{\partial V}\Bigr)_S V' = -a^2 V', \qquad a^2 = -\Bigl(\frac{\partial p}{\partial V}\Bigr)_S = \rho_0^2 c^2 . \tag{12.10} \]

Здесь \(c\) — скорость звука, \(a = \rho_0 c\) — массовая скорость звука: масса газа, которую звуковая волна проходит за единицу времени. Знак минус — при сжатии давление растёт. Первые два уравнения (12.7) дают

\[ V'_t - u'_s = 0, \qquad u'_t - a^2 V'_s = 0, \qquad V'_{tt} = a^2 V'_{ss} . \tag{12.11} \]

Волны бегут по массе со скоростями \(ds/dt = \pm a\); система (12.11) — модельная задача для исследования устойчивости схемы «крест» в §14.

§12.6 · Итоги

Достоинства, ограничения, итоги

Достоинства лагранжевых переменных. Переноса вещества через сетку нет, поэтому контактные разрывы и границы раздела веществ не размазываются и всё время остаются на одних и тех же узлах. Масса каждой ячейки сохраняется по построению. Свободные границы и поршни задаются в фиксированных узлах \(s = 0\) и \(s = M\).

Ограничения. Ячейки сжимаются и растягиваются вместе с газом: в сильно сжатом газе ячейки мелкие, и по условию устойчивости (§14) уменьшается шаг по времени. При больших деформациях соседние узлы могут поменяться местами — ячейка «выворачивается» (\(x_{i+1} < x_i\)), и расчёт останавливается. В многомерных вихревых течениях сетка запутывается; применяют ALE-методы с перестроением сетки.

Итог. Массовая координата (12.2) — метка частицы; (12.7) — законы сохранения объёма, импульса и полной энергии; (12.9) равносильно уравнению энергии только на гладких решениях; акустика (12.11) — волны \(ds/dt = \pm a\).

Далее — разностная схема «крест» на лагранжевой сетке.
