Узлы Чебышёва и сплайны

▶ Слайды ▶ Лаба

В § 3 мы увидели: интерполяционный многочлен на равномерной сетке может катастрофически расходиться (феномен Рунге). Погрешность (3.6) распадается на два независимых сомножителя: производную функции \(f^{(n+1)}/(n+1)!\), которую мы не контролируем, и узловой множитель \(\omega_{n+1}(x)\), зависящий только от расположения узлов. Управляемая величина одна — сетка. Первая часть занятия — как её выбирать оптимально; вторая — совсем другой путь, когда полиномы высокой степени заменяют на кусочные многочлены низкой.

Задача выбора узлов

Задача: на отрезке \([-1, 1]\) выбрать \(n+1\) узлов \(x_0, \ldots, x_n\) так, чтобы минимизировать

\[ \|\omega_{n+1}\|_\infty \;=\; \max_{x\in[-1,1]}\Bigl|\prod_{i=0}^{n}(x - x_i)\Bigr| \tag{4.1} \]

по всем возможным наборам узлов. Величина \(\omega_{n+1}(x)\) — приведённый (monic) многочлен степени \(n+1\): его старший коэффициент равен \(1\). Задача сводится к поиску приведённого многочлена степени \(n+1\) с наименьшей равномерной нормой на \([-1, 1]\). Ответ дают знаменитые полиномы Чебышёва.

Полиномы Чебышёва первого рода

полином Чебышёва первого рода. \[ T_n(x) \;=\; \cos\!\bigl(n\arccos x\bigr),\qquad x\in[-1, 1]. \tag{4.2} \] Несмотря на тригонометрическую запись, \(T_n\) — алгебраический многочлен степени \(n\) с целыми коэффициентами.

Что это многочлен, видно из рекуррентного соотношения, вытекающего из \(\cos((n+1)\theta) + \cos((n-1)\theta) = 2\cos\theta\cos(n\theta)\) при \(\theta = \arccos x\):

\[ T_0(x) = 1,\quad T_1(x) = x,\qquad T_{n+1}(x) = 2x\,T_n(x) - T_{n-1}(x). \tag{4.3} \]

Отсюда \(T_2 = 2x^2 - 1\), \(T_3 = 4x^3 - 3x\), \(T_4 = 8x^4 - 8x^2 + 1\). Старший коэффициент \(T_n\) при \(n\ge 1\) равен \(2^{n-1}\).

свойство равноколебательности. На отрезке \([-1, 1]\) выполнено \(|T_n(x)|\le 1\), то есть \(\|T_n\|_\infty = 1\). Причём \(T_n\) ровно \(n+1\) раз достигает экстремальных значений \(\pm 1\) в точках \[ x_k^{*} = \cos\bigl(k\pi/n\bigr),\quad k = 0, 1, \ldots, n, \tag{4.4} \] меняя знак при каждом переходе.
Рис. 1. Полиномы Чебышёва равномерно колеблются между \(-1\) и \(+1\), \(T_n\) касается границ \(n+1\) раз.

Минимаксное свойство

Поделив \(T_n\) на его старший коэффициент \(2^{n-1}\), получим приведённый многочлен \(\widetilde T_n = 2^{1-n}\,T_n\) с нормой \(\|\widetilde T_n\|_\infty = 2^{1-n}\). Оказывается, среди всех приведённых многочленов заданной степени именно \(\widetilde T_n\) обладает наименьшей равномерной нормой.

минимаксное свойство Чебышёва. Среди всех приведённых многочленов степени \(n \ge 1\) наименьшую равномерную норму на \([-1, 1]\) даёт \(\widetilde T_n = 2^{1-n}\,T_n\): \[ \min_{\substack{q\ \text{приведён}\\ \deg q = n}}\ \max_{x\in[-1,1]}|q(x)| \;=\; \frac{1}{2^{n-1}}, \tag{4.5} \] и минимум достигается единственным образом на \(\widetilde T_n\).

Доказательство (эскиз). Пусть \(q\) — приведённый степени \(n\) с \(\|q\|_\infty < 2^{1-n}\). Рассмотрим \(r = \widetilde T_n - q\). В \(n+1\) точках экстремума (4.4) многочлен \(\widetilde T_n\) принимает значения \(\pm 2^{1-n}\) с чередованием знаков; поскольку \(|q| < 2^{1-n}\), знак \(r(x_k^{*})\) совпадает со знаком \(\widetilde T_n(x_k^{*})\) и тоже чередуется. Значит, \(r\) меняет знак не менее \(n\) раз и имеет \(\ge n\) корней. Но \(\widetilde T_n\) и \(q\) — оба приведены степени \(n\), их разность \(r\) имеет степень \(\le n-1\), а ненулевой многочлен степени \(\le n-1\) не может иметь \(n\) корней. Противоречие. \(\square\)

Чебышёвские узлы интерполяции

Чтобы минимизировать (4.1), берём \(\omega_{n+1} = \widetilde T_{n+1}\); тогда узлы — корни \(T_{n+1}\). Из \(T_{n+1}(x) = \cos((n+1)\arccos x) = 0\) получаем \((n+1)\arccos x = \pi/2 + k\pi\), то есть

чебышёвские узлы интерполяции на \([-1, 1]\). \[ x_k \;=\; \cos\!\left(\frac{2k+1}{2(n+1)}\,\pi\right),\qquad k = 0, 1, \ldots, n. \tag{4.6} \] На произвольный отрезок \([a, b]\) переводятся аффинным преобразованием \(x_k^{[a,b]} = \tfrac{a+b}{2} + \tfrac{b-a}{2}\,x_k\).

Ключевое свойство чебышёвских узлов — сгущение у концов отрезка. Именно это компенсирует рост узлового множителя \(\omega_{n+1}\) у краёв и подавляет феномен Рунге.

оценка ошибки на чебышёвской сетке. Пусть \(f\in C^{n+1}[-1, 1]\), \(P_n\) — интерполяционный многочлен на чебышёвских узлах (4.6). Тогда \[ \|f - P_n\|_\infty \;\le\; \frac{\|f^{(n+1)}\|_\infty}{2^{n}\,(n+1)!}. \tag{4.7} \]

Знаменатель растёт как \(2^n \cdot (n+1)!\) — очень быстро. Для аналитической \(f\) сходимость экспоненциальная. Функция Рунге \(f = 1/(1+25x^2)\) на чебышёвской сетке при \(n=20\) даёт максимум ошибки \(\sim 10^{-4}\) вместо \(\sim 60\) на равномерной.

Рис. 2. Сравнение равномерной и чебышёвской сеток на \([-1, 1]\), \(n = 10\). Чебышёвские узлы сгущаются у концов.

Кусочная линейная интерполяция

Второй путь борьбы с Рунге — не строить многочлен высокой степени, а склеить много многочленов низкой степени, каждый — на своём подотрезке.

кусочная линейная интерполяция. Пусть на \([a, b]\) заданы \(n+1\) узлов \(a = x_0 < x_1 < \ldots < x_n = b\) и значения \(y_i = f(x_i)\). Кусочная линейная интерполяция \(L(x)\) — это функция, совпадающая с \(f\) в узлах и линейная на каждом подотрезке \([x_i, x_{i+1}]\): \[ L(x) \;=\; y_i + \frac{y_{i+1} - y_i}{x_{i+1} - x_i}\,(x - x_i),\qquad x\in[x_i, x_{i+1}]. \tag{4.8} \]

Ошибка кусочной линейной интерполяции контролируется только шагом \(h = \max(x_{i+1} - x_i)\), не гладкостью \(f\) выше второй производной:

\[ \|f - L\|_\infty \;\le\; \frac{h^2}{8}\,\|f''\|_\infty. \tag{4.9} \]

Никакого Рунге нет: уменьшая шаг вдвое, ошибку уменьшаем в четыре раза. Плата — \(L(x)\) не гладкая: в узлах производная терпит разрыв.

Кубический сплайн

Гладкий вариант — кубический сплайн: на каждом подотрезке — многочлен степени 3, а между кусками стыковка обеспечивает совпадение значений и первых двух производных.

кубический сплайн. Функция \(S(x)\), удовлетворяющая:
  1. на каждом подотрезке \([x_i, x_{i+1}]\) \(S\) — многочлен степени не выше 3;
  2. \(S(x_i) = y_i\) для \(i = 0, \ldots, n\) (интерполяция);
  3. \(S \in C^2[a, b]\) — гладкая до второй производной включительно.

Условия дают \(4n\) неизвестных (по 4 коэффициента на каждый из \(n\) кусков) и \(4n - 2\) уравнений: интерполяция даёт \(2n\), непрерывность первой и второй производных на \(n-1\) внутренних узлах — ещё \(2(n-1)\). Не хватает двух уравнений; их задают краевыми условиями.

типичные краевые условия сплайна.
  • Natural («естественный»): \(S''(a) = S''(b) = 0\). Удобно, если \(f''\) на концах неизвестна.
  • Clamped («жёсткий»): \(S'(a) = f'(a)\), \(S'(b) = f'(b)\). Требует значений производной; даёт наименьшую погрешность.
  • Not-a-knot: \(S'''\) непрерывна в \(x_1\) и \(x_{n-1}\). Стандарт MATLAB.

Трёхдиагональная система на моменты

Практически сплайн строят через моменты \(M_i = S''(x_i)\). На каждом подотрезке кубика однозначно восстанавливается по значениям \(y_{i}, y_{i+1}\) и моментам \(M_{i}, M_{i+1}\). Условие непрерывности первой производной в узле \(x_i\) даёт линейное уравнение относительно \(M_{i-1}, M_i, M_{i+1}\):

\[ h_{i-1}\,M_{i-1} + 2(h_{i-1} + h_i)\,M_i + h_i\,M_{i+1} \;=\; 6\left(\frac{y_{i+1} - y_i}{h_i} - \frac{y_i - y_{i-1}}{h_{i-1}}\right), \tag{4.10} \]

где \(h_i = x_{i+1} - x_i\). Уравнения (4.10) для \(i = 1, \ldots, n-1\) вместе с краевыми условиями образуют трёхдиагональную систему на моменты \(M_0, M_1, \ldots, M_n\), которая эффективно решается методом прогонки за \(O(n)\) операций.

Связь с § 10. Метод прогонки для трёхдиагональных систем разберём как самостоятельный алгоритм в § 10 — там же будет и подробное обсуждение устойчивости и условия диагонального преобладания. Для нашей матрицы сплайна диагональное преобладание выполняется автоматически: коэффициент \(2(h_{i-1} + h_i)\) на диагонали больше суммы \(h_{i-1} + h_i\) по модулю на побочных.

Итоги занятия

Что нужно унести с занятия 4.
  1. Полиномы Чебышёва (4.2) — минимаксные среди приведённых многочленов на \([-1, 1]\).
  2. Чебышёвские узлы (4.6) сгущаются у концов; интерполяция на них подавляет феномен Рунге. Оценка ошибки (4.7) — экспоненциальная сходимость для гладких \(f\).
  3. Кусочная линейная интерполяция (4.8) даёт \(O(h^2)\) без всякого Рунге, ценой негладкости.
  4. Кубический сплайн — гладкая ($C^2$) кусочная интерполяция степени 3 с одним из стандартных краевых условий.
  5. Система на моменты (4.10) — трёхдиагональная; решается прогонкой за \(O(n)\).
