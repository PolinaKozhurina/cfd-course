§5 · Напоминание

Что именно нужно проверить

В §2 устойчивость определена, в §3 теорема Лакса сделала её решающим свойством: аппроксимация и устойчивость вместе дают сходимость. Осталось научиться устойчивость проверять.

Семейство схем \(L_h u_h = f_h\) устойчиво (корректно), если решение существует, единственно и \[ \|u_h\| \le C\,\|f_h\|, \qquad C \ne C(h). \]
Трудность Неравенство должно выполняться при всех правых частях и всех сетках, с одной постоянной \(C\). Проверять его непосредственно — значит решать задачу для всех данных сразу.
Идея Найти для оператора перехода \(u^{n} \mapsto u^{n+1}\) собственные функции и проследить за каждой из них отдельно.

Для линейных схем с постоянными коэффициентами такие собственные функции известны заранее — это гармоники.

§5.1 · Спектральный признак устойчивости

Идея: следить не за решением, а за собственными функциями оператора перехода

Оператор перехода — оператор, обеспечивающий переход решения с предыдущего временного слоя на следующий: \(u^{n+1} = S\,u^{n}\).

Если коэффициенты схемы одинаковы во всех узлах, а границ нет, то \(S\) перестановочен со сдвигом по сетке \(u_m \mapsto u_{m+1}\). Собственные функции сдвига — экспоненты \(e^{i\alpha m}\); значит, они же — собственные функции \(S\):

\[ S\,e^{i\alpha m} = \lambda(\alpha)\,e^{i\alpha m}. \]
Что даёт Действие \(S\) на гармонику — умножение на число \(\lambda(\alpha)\). Поведение решения за \(n\) шагов сводится к степеням \(\lambda^n\): вопрос об устойчивости становится вопросом о модуле \(|\lambda|\).
Область применения Явные и неявные схемы, системы уравнений (\(\lambda\) — матрица), несколько пространственных переменных (\(\alpha\) — вектор). Самый распространённый метод в силу простоты.

Но простота куплена ценой жёстких предположений — назовём их явно, прежде чем идти дальше.

§5.1 · Границы применимости

Предположения метода гармоник

Метод гармоник допускает использование только для однородных уравнений с постоянными коэффициентами без учёта краевых условий. За каждым словом — своя причина.

линейность
Принцип суперпозиции
Решение разлагается на гармоники, и за каждой следят отдельно — только для линейных однородных схем.
коэффициенты
Постоянные по \(x\) и \(t\)
Иначе оператор перехода не перестановочен со сдвигом, и \(e^{i\alpha m}\) — не его собственная функция.
границы
Бесконечная или периодическая сетка
Гармоника не удовлетворяет условию \(u = 0\) на границе; краевые условия метод не видит.
результат
Условие необходимое
Оно получено для одного специального класса данных; о достаточности — отдельный разговор.

Задачи с переменными коэффициентами и краевыми условиями потребуют другого инструмента — энергетического метода §5а. А пока введём гармоники на сетке.

§5.2 · Гармоники

Гармоника на сетке

Для непрерывных аргументов гармоника — \(u = e^{i\omega t + ikx}\), \(k\) вещественно. На сетке \(x_m = mh\), \(t_n = n\tau\):

\[ u_m^n = e^{i\omega\tau\,n}\,e^{ikh\,m} = \lambda^n\,e^{i\alpha m}, \qquad \lambda = e^{i\omega\tau},\quad \alpha = kh. \tag{5.1} \]

\(\alpha\) — приведённое волновое число: от \(0\) (постоянная по \(x\) функция) до \(2\pi\); значение \(\alpha = \pi\) — самая короткая волна, различимая на сетке.

Вещественные части гармоник \(\cos(\alpha m)\) в узлах сетки.

Подставим (5.1) в схему: множитель \(e^{i\alpha m}\) сократится, и останется уравнение на \(\lambda\).

§5.3 · Множитель перехода

Множитель перехода и характеристическое уравнение

Подстановка \(u_m^n = \lambda^n e^{i\alpha m}\) в разностную схему даёт соотношение между \(\lambda\) и \(\alpha\) — характеристическое (дисперсионное) уравнение \(\lambda = \lambda(\alpha)\). Величина \(\lambda\), вообще говоря комплексная, называется множителем (коэффициентом) перехода.

Смысл названия ясен из равенств

\[ u_m^{n} = \lambda^{n}e^{i\alpha m}, \qquad u_m^{n+1} = \lambda^{n+1}e^{i\alpha m} \quad\Rightarrow\quad u_m^{n+1} = \lambda\,u_m^{n}. \]

Функция \(u_m^0 = e^{i\alpha m}\) — начальное условие; из (5.1) \(u_m^n = \lambda^n u_m^0\), откуда

\[ \max_m |u_m^n| = |\lambda|^n \max_m |u_m^0|. \tag{5.2} \]

Равенство (5.2) — это готовая оценка решения через начальные данные. Сопоставим её с определением устойчивости.

§5.4 · Необходимое условие устойчивости

Вывод условия Неймана

Воспользуемся вторым определением устойчивости и введём нормы через максимум:

\[ \|u^{(h)}\|_{U_h} \le C\,\|f^{(h)}\|_{F_h}, \qquad \|u^{(h)}\|_{U_h} = \max_{m,n}|u_m^n|, \qquad \|f^{(h)}\|_{F_h} = \max_m |u_m^0|. \tag{5.3, 5.4} \]

Из (5.2)–(5.4): для устойчивости во всяком случае необходимо, чтобы при всех \(n = 0, 1, \dots, N\) и всех гармониках \(0 \le \alpha \le 2\pi\)

\[ |\lambda(\alpha)|^n \le C. \]

Число шагов \(N = T/\tau\), то есть \(n \sim 1/\tau\). Тогда \(|\lambda| \le C^{\tau/T} = e^{(\tau/T)\ln C}\), и

\[ |\lambda(\alpha)| \le 1 + C\tau. \tag{5.5} \]

Неравенство (5.5) — необходимое спектральное условие устойчивости (условие Неймана): гармоники ограничены по модулю при \(\tau \to 0\), \(n \to \infty\).

§5.4 · Геометрический смысл

Кривая \(\lambda(\alpha)\) должна лежать в единичном круге

При \(\alpha\), пробегающем \([0, 2\pi]\), точка \(\lambda(\alpha)\) описывает в комплексной плоскости замкнутую кривую. Условие (5.5) означает, что она не выходит из круга радиуса \(1 + C\tau\).

На практике Неравенство (5.5) заменяют условием \[ |\lambda(\alpha)| \le 1 \quad\text{при всех } \alpha. \] Запас \(C\tau\) нужен лишь тогда, когда само дифференциальное уравнение допускает растущие решения.
Схема «уголок», \(r = 0.7\): окружность радиуса \(r\) с центром \(1 - r\) внутри единичного круга.

Применим признак к схеме «уголок» и получим эту окружность явно.

§5.5 · Пример: схема «уголок»

Пример: схема «уголок» для \(u_t + a u_x = 0\), \(a > 0\)

Явная схема с несимметричной аппроксимацией \(u_x\) разностью назад:

\[ \frac{u_m^{n+1} - u_m^n}{\tau} + a\,\frac{u_m^n - u_{m-1}^n}{h} = 0 \qquad\Longleftrightarrow\qquad u_m^{n+1} = (1 - r)\,u_m^n + r\,u_{m-1}^n, \quad r = \frac{a\tau}{h}. \]

Подставляем гармонику; у каждого узла шаблона — свой множитель:

\[ u_m^{n+1} \to \lambda^{n+1}e^{i\alpha m}, \qquad u_{m-1}^{n} \to \lambda^{n}e^{i\alpha m}\,e^{-i\alpha}. \]

Сокращаем общий множитель \(\lambda^n e^{i\alpha m}\) и получаем характеристическое уравнение

\[ \lambda = 1 - r + r\,e^{-i\alpha}. \]

Это уравнение окружности радиуса \(r\) с центром в точке \(1 - r\): к точке \(1 - r\) прибавляется вектор длины \(r\), поворачивающийся вместе с \(\alpha\).

§5.5 · Условие Неймана для «уголка»

Окружность внутри единичного круга \(\iff\) \(0 \le r \le 1\)

Выделим вещественную и мнимую части и вычислим модуль:

\[ |\lambda|^2 = (1 - r + r\cos\alpha)^2 + r^2\sin^2\alpha = 1 - 2r(1 - r)(1 - \cos\alpha). \]

Так как \(1 - \cos\alpha \ge 0\), неравенство \(|\lambda| \le 1\) при всех \(\alpha\) равносильно \(r(1 - r) \ge 0\):

\[ 0 \le r = \frac{a\tau}{h} \le 1. \]

Условие Неймана выполняется при \(r \le 1\), что совпадает с критерием Куранта.

При \(r = 1.2\) точка \(\alpha = \pi\) выходит из круга: «пила» растёт как \(1.4^n\).

Число \(r\) уже встречалось в §4 как число Куранта; у условия \(r \le 1\) есть и наглядный геометрический смысл.

§5.5 · Критерий Куранта

Геометрический смысл: область зависимости

Точное значение \(u(x_m, t_{n+1})\) определяется значением на слое \(t_n\) в основании характеристики \(x = x_m - a\tau\). Разностное значение \(u_m^{n+1}\) — значениями в узлах шаблона \(x_{m-1}\), \(x_m\).

Условие Куранта–Фридрихса–Леви Основание характеристики должно попадать в шаблон: \(x_m - a\tau \ge x_{m-1}\), то есть \(a\tau \le h\), \(r \le 1\). Иначе схема не получает информацию, от которой зависит точное решение.

Условие Неймана получено алгебраически, условие Куранта — геометрически; для «уголка» они совпали. Проверьте признак на схеме, у которой шаблон «смотрит» в другую сторону.

§5.6 · Упражнение

Упражнение: схема с разностью вперёд

Найдите характеристическое уравнение и определите область устойчивости для схемы

\[ \frac{u_m^{n+1} - u_m^n}{\tau} + a\,\frac{u_{m+1}^n - u_m^n}{h} = 0, \qquad a > 0. \]
План
  1. Разрешить схему относительно \(u_m^{n+1}\), выразить через \(r = a\tau/h\).
  2. Подставить \(u_m^n = \lambda^n e^{i\alpha m}\); у узла \(m + 1\) множитель \(e^{+i\alpha}\).
  3. Описать кривую \(\lambda(\alpha)\) и найти, при каких \(r\) она лежит в единичном круге.
Проверьте себя Сопоставьте ответ с условием Куранта–Фридрихса–Леви: куда «смотрит» шаблон и откуда приходит характеристика при \(a > 0\)?

Итог упражнения покажет, что спектральный признак чувствителен не только к величине шага, но и к направлению шаблона.

§5.7 · Необходимое и достаточное

Когда условия Неймана достаточно, а когда — нет

Достаточно Скалярная двухслойная схема, постоянные коэффициенты, периодическая сетка, норма \(L_2\): по равенству Парсеваля \[ \|u^n\|^2 = \sum_\alpha |c_\alpha|^2\,|\lambda(\alpha)|^{2n} \le \max_\alpha|\lambda|^{2n}\,\|u^0\|^2, \] и из \(|\lambda| \le 1\) следует \(\|u^n\| \le \|u^0\|\).
Недостаточно
  • Системы: \(\lambda\) — матрица; при недиагонализуемой матрице \(\|\lambda^n\|\) растёт, хотя все собственные числа по модулю \(\le 1\).
  • Многослойные схемы: кратный корень на единичной окружности даёт рост \(n\lambda^n\).
  • Границы, переменные коэффициенты: гармоник-собственных функций нет вовсе.

Инструмент, дающий достаточные условия и работающий с границами и переменными коэффициентами, — энергетический метод (§5а).

§5 · Итоги

Итоги §5

  1. Спектральный признак: гармоники — собственные функции оператора перехода линейной схемы с постоянными коэффициентами без границ.
  2. Гармоника на сетке \(u_m^n = \lambda^n e^{i\alpha m}\), \(\alpha = kh \in [0, 2\pi]\).
  3. Множитель перехода \(\lambda(\alpha)\) из характеристического уравнения; \(\max|u^n| = |\lambda|^n\max|u^0|\).
  4. Условие Неймана \(|\lambda| \le 1 + C\tau\), на практике \(|\lambda| \le 1\): кривая \(\lambda(\alpha)\) в единичном круге. Необходимое условие.
  5. Уголок: \(\lambda = 1 - r + re^{-i\alpha}\), устойчивость при \(0 \le r \le 1\) — критерий Куранта.
Порядок исследования схемы
  1. Разрешить схему относительно верхнего слоя, ввести \(r = a\tau/h\).
  2. Подставить гармонику: узлу \((m + p,\ n + q)\) отвечает множитель \(\lambda^q e^{i\alpha p}\).
  3. Сократить общий множитель — характеристическое уравнение.
  4. Вычислить \(|\lambda|^2\) как функцию \(\alpha\); потребовать \(\le 1\) при всех \(\alpha\).
  5. Описать область устойчивости в терминах \(r\) (и других параметров).

Дальше: §5а — энергетический метод (достаточные условия, краевые условия, переменные коэффициенты); §6 — что говорят \(|\lambda|\) и \(\arg\lambda\) о качестве решения устойчивой схемы.
