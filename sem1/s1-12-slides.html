§12 · Семестр 1

Уравнения газовой динамики в переменных Лагранжа

В одномерных задачах с ударными волнами и контактными границами удобно следить за частицами газа, а не за точками пространства: тогда вещество не переносится через сетку.

Эйлер и Лагранж · Массовая координата · Три закона сохранения · Система · Внутренняя энергия · Акустика

Неизвестные: скорость \(u\), удельный объём \(V = 1/\rho\), удельная внутренняя энергия \(\varepsilon\), давление \(p\).

§12.1 · Два описания

Эйлерово и лагранжево описания

В эйлеровом описании величины — функции точки пространства и времени: \(\rho(x,t)\), \(u(x,t)\), \(p(x,t)\); сетка неподвижна, вещество протекает сквозь ячейки.

В лагранжевом описании каждая частица получает постоянную метку \(\xi\), величины — функции метки и времени, а положение частицы \(x(\xi,t)\) удовлетворяет уравнению \(\partial x/\partial t|_\xi = u\). Линии лагранжевой сетки — траектории частиц.

§12.2 · Определение 1

Массовая координата

Массовая координата. Пусть \(x_0(t)\) — траектория выделенной частицы. Массовой координатой точки \(x\) в момент \(t\) называется масса газа между выделенной частицей и точкой \(x\): \[ s(x,t) = \int_{x_0(t)}^{x}\rho\,dx . \tag{12.2} \]

Нижний предел движется вместе с веществом, поэтому масса между выделенной частицей и любой другой частицей не меняется: у каждой частицы \(s = \mathrm{const}\), и \(s\) служит её меткой. Из (12.2) \(\partial s/\partial x = \rho\), откуда

\[ \frac{\partial x}{\partial s} = V = \frac1\rho . \tag{12.3} \]

В переменных \((s,t)\) частная производная по \(t\) берётся вдоль траектории частицы и совпадает с материальной производной \(\partial_t + u\,\partial_x\) эйлерова описания.

§12.3 · Вывод

Законы сохранения для отрезка газа

Отрезок газа между частицами \(s_1 < s_2\) имеет постоянную массу \(s_2 - s_1\): через торцы вещество не течёт, на торцы действуют давления соседнего газа.

Масса (12.4)Длина отрезка \(\int V\,ds\) меняется со скоростью торцов: \[ \frac{d}{dt}\int_{s_1}^{s_2} V\,ds = u(s_2) - u(s_1). \]
Импульс (12.5)Второй закон Ньютона для отрезка: \[ \frac{d}{dt}\int_{s_1}^{s_2} u\,ds = p(s_1) - p(s_2). \]
Энергия (12.6)Полная энергия меняется на мощность сил давления: \[ \frac{d}{dt}\int_{s_1}^{s_2}\Bigl(\varepsilon + \frac{u^2}{2}\Bigr)ds = (pu)(s_1) - (pu)(s_2). \]

Соотношения (12.4)–(12.6) не содержат производных по \(s\) и верны, когда внутри отрезка есть разрыв.

§12.4 · Теорема 1

Система уравнений в переменных Лагранжа

Теорема. Для гладких течений идеального газа из (12.4)–(12.6) следует система \[ V_t - u_s = 0, \qquad u_t + p_s = 0, \qquad \Bigl(\varepsilon + \frac{u^2}{2}\Bigr)_t + (pu)_s = 0, \tag{12.7} \] \[ x_t = u, \qquad p = p(V, \varepsilon), \quad\text{для политропного газа}\quad p = \frac{(\gamma - 1)\,\varepsilon}{V}. \tag{12.8} \]

Все три уравнения (12.7) — законы сохранения вида \(\partial_t(\text{плотность}) + \partial_s(\text{поток}) = 0\) с плотностями \(V\), \(u\), \(\varepsilon + u^2/2\) и потоками \(-u\), \(p\), \(pu\); на них строятся консервативные схемы. Конвективных членов вида \(u\,u_x\) нет: перенос вещества убран выбором переменных.

Замена \(\partial_t|_s = \partial_t|_x + u\,\partial_x\), \(\partial_s = V\partial_x\) переводит (12.7) в эйлеровы уравнения для \(\rho\), \(\rho u\), \(\rho(\varepsilon + u^2/2)\).

§12.4 · Внутренняя энергия

Уравнение для внутренней энергии

Умножим второе уравнение (12.7) на \(u\): \((u^2/2)_t + u\,p_s = 0\). Вычтем результат из третьего уравнения: \(\varepsilon_t + (pu)_s - u\,p_s = \varepsilon_t + p\,u_s = 0\). По первому уравнению \(u_s = V_t\), поэтому

\[ \varepsilon_t + p\,V_t = 0 \qquad (d\varepsilon = -p\,dV). \tag{12.9} \]

Это первое начало термодинамики для частицы: внутренняя энергия расходуется на работу расширения.

На гладких решениях (12.9) равносильно закону сохранения полной энергии. На ударной волне — нет: (12.9) не является законом сохранения, и скачок энергии на волне определяет только интегральное соотношение (12.6). Уравнение (12.9) называют недивергентной формой уравнения энергии, третье уравнение (12.7) — дивергентной.

Схема «крест» (§13) аппроксимирует недивергентную форму; к сравнению двух форм вернёмся в §13.7.

§12.5 · Акустика

Акустическое приближение

Линеаризуем (12.7) около покоя \(V_0\), \(u_0 = 0\), \(p_0\). На гладком течении энтропия частицы постоянна, поэтому малое изменение давления связано с изменением объёма адиабатической производной:

\[ p' = \Bigl(\frac{\partial p}{\partial V}\Bigr)_S V' = -a^2 V', \qquad a^2 = -\Bigl(\frac{\partial p}{\partial V}\Bigr)_S = \rho_0^2 c^2 . \tag{12.10} \]

Здесь \(c\) — скорость звука, \(a = \rho_0 c\) — массовая скорость звука: масса газа, которую звуковая волна проходит за единицу времени. Знак минус — при сжатии давление растёт. Первые два уравнения (12.7) дают

\[ V'_t - u'_s = 0, \qquad u'_t - a^2 V'_s = 0, \qquad V'_{tt} = a^2 V'_{ss} . \tag{12.11} \]

Волны бегут по массе со скоростями \(ds/dt = \pm a\); система (12.11) — модельная задача для исследования устойчивости схемы «крест» в §14.

§12.6 · Граничные условия

Граничные условия в переменных Лагранжа

В массовой координате границы газа — фиксированные частицы \(s = 0\) и \(s = M\): область \([0, M]\) не меняется со временем. Из трёх характеристик \(ds/dt = -a,\ 0,\ +a\) (§12.5) в область через каждую границу входит одна, поэтому на каждой границе задают одно условие: скорость, давление или связь между ними.

Условия в реальных задачах

Неподвижная стенка: \(u(0, t) = 0\). Отражение ударной волны от стенки, ударная труба с закрытыми концами.

Поршень: \(u(0, t) = U(t)\), т. е. \(x(0, t) = X(t)\). Вдвигаемый поршень создаёт ударную волну, выдвигаемый — волну разрежения.

Заданное давление: \(p(M, t) = p_{\text{вн}}(t)\). Граница с вакуумом (\(p = 0\), разлёт газа), нагружение давлением (взрыв, лазерный импульс).

Особые случаи

Граница двух веществ внутри области: \([u] = 0\), \([p] = 0\). В переменных Лагранжа выполняется сама, если граница — узел, а у ячеек по разные стороны свои уравнения состояния.

Неотражающая граница (искусственная граница, волны должны уходить): входящая характеристика не несёт возмущения. В акустике на правой границе \(p - p_0 = a\,u\), на левой \(p - p_0 = -a\,u\), \(a = \rho c\).

Периодические: \(u(0, t) = u(M, t)\), \(p(0, t) = p(M, t)\) — для гладких тестов.

Втекание и истечение через границу в переменных Лагранжа невозможны: масса области фиксирована; нужна эйлерова или ALE-сетка.

§12.7 · Законы сохранения

Что сохраняет лагранжева схема, а что нет

Схема «крест» (§13): узлы \(x_i\) со скоростями \(u_i\), ячейки массы \(h\) с величинами \(V\), \(\varepsilon\), \(P = p + \omega\); масса узла \(m_i = h\) (на границе \(h/2\)).

Сохраняется точно

Масса ячейки \(h\) — по построению: узлы движутся с веществом, потока массы через грань нет.

Связь длины и объёма \(x^n_{i+1} - x^n_i = h\,V^n_{i+1/2}\) на каждом слое, если она верна при \(t = 0\): вычитая (13.3) для узлов \(i+1\) и \(i\), получаем (13.4).

Импульс: \(\sum_i m_i u_i^{n+1/2} - \sum_i m_i u_i^{n-1/2} = \tau\,(P_{\text{лев}} - P_{\text{прав}})\). Давление \(P_{i+1/2}\) входит в уравнения узлов \(i\) и \(i+1\) с разными знаками и при суммировании сокращается; остаются давления на границах области.

Положение контактной границы — граница двух веществ всё время совпадает с одним узлом.

Сохраняется приближённо

Полная энергия \(\sum_i h\,\varepsilon_{i+1/2} + \sum_i m_i u_i^2/2\). Схема аппроксимирует недивергентное уравнение (12.9), а не закон сохранения: дисбаланс за конечное время — \(O(\tau)\) на гладком решении (теорема 1 §13.8) и конечен на ударной волне. Соударение потоков: потеря 4,8 % энергии и \(\rho = 6{,}40\) вместо 6 при любом \(N\) (§13.7). Дивергентная форма сохраняет полную энергию точно, но \(\varepsilon = E - u^2/2\) при \(u \gg c\) может стать отрицательной.

Энтропия частицы. Из (13.5) с \(P = p + \omega\): \(T\,\Delta S = -\,\omega\,\Delta V\) плюс погрешность аппроксимации \(d\varepsilon = -p\,dV\) по формуле трапеций. Без вязкости на гладком решении энтропия сохраняется со вторым порядком; на ударной волне её производит только \(\omega\), и только в сжимающихся ячейках.

§12.7 · Достоинства и недостатки

Где лагранжева сетка хороша, где плоха и почему

Плюсы

1. Контакты и границы веществ не размазываются. Вещество не течёт через грани — нет численной диффузии переноса. Скачок плотности остаётся между двумя узлами.

2. Масса и импульс сохраняются точно. Масса — по построению сетки, импульс — потому что давления на гранях сокращаются попарно.

3. Сетка сама сгущается в сжатом газе. \(\Delta x = hV\): за ударной волной соударения \(\rho = 6\), ячейки в 6 раз короче, фронт разрешён лучше без адаптации сетки.

4. Границы задаются просто. Свободная граница, поршень, граница двух веществ — фиксированные узлы \(s\); их не нужно отслеживать, у каждой ячейки своё уравнение состояния.

Минусы

1. Ячейки выворачиваются. Если \(u_i > u_{i+1}\), узлы сближаются, \(\Delta x\) доходит до нуля и меняет знак: \(V < 0\). В газе без давления — при \(t^* = 1/\max(-u_0')\); в газе давление тормозит сжатие, но при большом \(\tau\) узел перескакивает соседа за один шаг.

2. Шаг по времени задают сжатые ячейки. \(\tau \le \min_i \Delta x_i/c_i\): при сжатии \(\Delta x\) падает, а \(c\) растёт. В соударении потоков ячейки сжимаются в 6 раз, \(c\) растёт с 0,012 до 0,53 — допустимый шаг уменьшается в 270 раз.

3. В разрежении сетка грубеет. Ячейки растягиваются вместе с газом: в разлёте (тест Торо 2, \(u = \pm 2\)) в центре \(\rho \approx 0{,}022\), ячейки в 46 раз длиннее начальных.

4. Сдвиг и вихри (в многомерных задачах). Соседние частицы расходятся, ячейки вытягиваются и перекручиваются даже без ударных волн. Выход — ALE: перестроение сетки и пересчёт величин; при пересчёте возвращается численная диффузия.

§12.7 · Расчёт

Пример: лагранжева сетка выигрывает и ломается в одной задаче

Слева — почему хорошоГаз без давления, \(u_0 = 0{,}3\sin 2\pi x\), скачки \(\rho_0\) в точках 0,15 и 0,45, \(N = 100\). Лагранжев расчёт совпадает с точным решением с точностью квадратуры масс: скачок остаётся между двумя узлами. Противопоточная эйлерова схема переносит массу через грани и размазывает скачок на 5 ячеек (уровни 10–90 %), её ошибка в 500 раз больше.
Справа — почему плохоОколо \(x = 0{,}5\) скорость убывает (\(u_0' < 0\)): левые узлы догоняют правые. Длина ячейки \(\Delta x(t) = \Delta x(0)\,(1 + u_0't)\); при \(t = 0{,}9t^*\) самая короткая ячейка в 10 раз короче начальной, при \(t = t^*\) траектории пересекаются: \(x_{i+1} < x_i\), \(\rho = h/\Delta x < 0\). При \(N = 100\) первая ячейка выворачивается при \(t = 0{,}5309\), \(t^* = 0{,}5305\).
§12.7 · Выворачивание

Что значит «ячейка вывернулась» и когда это происходит

Определение. Ячейка \(i + \tfrac12\) вывернута на слое \(n+1\), если \(x^{n+1}_{i+1} \le x^{n+1}_i\), т. е. по (13.1) \(V^{n+1}_{i+1/2} \le 0\): правая граница частицы обогнала левую. Отображение \(s \mapsto x\) перестаёт быть монотонным (\(x_s = V \le 0\)), одна точка пространства принадлежит двум частицам; \(\rho = 1/V < 0\), \(p = (\gamma - 1)\varepsilon/V < 0\), \(c^2 < 0\) — величины теряют смысл, расчёт останавливается.

Критерий за один шаг. По (13.3) \(x^{n+1}_{i+1} - x^{n+1}_i = \Delta x^n_{i+1/2} + \tau\bigl(u^{n+1/2}_{i+1} - u^{n+1/2}_i\bigr)\). Ячейка вывернется тогда и только тогда, когда узлы сближаются (\(u_i > u_{i+1}\)) и \[ \tau \ge \frac{\Delta x_{i+1/2}}{u_i - u_{i+1}} , \] т. е. \(\Delta V/V \le -1\): узлы встречаются раньше, чем закончился шаг.

Непрерывный критерий (газ без давления): \(\Delta x(t) = \Delta x(0)\,(1 + u_0't)\), траектории пересекаются при \(t^* = 1/\max(-u_0')\). В газе с давлением частицы не пересекаются (\(p \to \infty\) при \(V \to 0\)), и выворачивание — численный эффект слишком большого \(\tau\); в многомерных задачах — ещё и запутывание сетки при сдвиге.

§12.7 · Как бороться

Как не допустить выворачивания ячеек

Пример. Соударение потоков: \(\rho = 1\), \(u = \pm 1\), \(p = 10^{-4}\), \(N = 200\), \(\Delta x = 0{,}005\). Скорость звука \(c = 0{,}012\), и по Куранту \(\tau = 0{,}4\,\Delta x/c = 0{,}17\); узлы в центре сближаются со скоростью 2 и встречаются через \(\Delta x/2 = 0{,}0025\). Центральная ячейка выворачивается на первом же шаге: условие Куранта не защищает, когда \(|\Delta u| \gg c\).

Если выворачивание численное

1. Ограничить шаг по изменению объёма. \[ \tau = \min\Bigl(C\min_i\frac{\Delta x_i}{c_i},\ \ \eta\min_i\frac{\Delta x_i}{|\Delta u_i|}\Bigr), \quad \eta \approx 0{,}1\text{–}0{,}2 , \] т. е. за шаг объём ячейки меняется не больше чем на долю \(\eta\) — и при сжатии, и при расширении (при сильном расширении холодного газа (13.7) даёт \(\varepsilon < 0\)). С \(\eta = 0{,}2\) соударение считается до \(t = 0{,}6\) без выворачивания.

2. Проверить после шага. Если \(V^{n+1} \le 0\) или знаменатель (13.7) \(\le 0\) (сжатие за шаг больше \((\gamma+1)/(\gamma-1)\)), шаг отменяют и повторяют с \(\tau/2\) — алгоритм §13, шаг 3.

3. Искусственная вязкость. \(\omega = \nu_2\rho(\Delta u)^2\) растёт при сближении узлов и тормозит его; ударная волна размазывается на 3–4 ячейки вместо схлопывания одной.

Если деформация физическая

Газ без давления. Пересечение траекторий реально (частицы пыли проходят друг сквозь друга); однопотоковая модель после \(t^*\) неверна, нужна модель с несколькими скоростями или частицы.

Сдвиг и вихри (многомерные задачи). Уменьшение шага не помогает — сетка запутывается за конечное время. Применяют ALE: перестраивают сетку (выравнивают узлы) и консервативно пересчитывают на неё массу, импульс и энергию; при пересчёте появляется численная диффузия.

Сильно сжатые ячейки. Объединяют с соседними или в этой области переходят к эйлеровой сетке.

§12.7 · Параллельные вычисления

Лагранжева схема на многих процессорах

Область делят по массовой координате на куски, по одному на процессор. Процессор хранит свои ячейки и узлы и копию одной соседней ячейки с каждой стороны (теневой слой).

Плюсы

1. Обмен мал и постоянен. Схема «крест» явная, значение в узле зависит только от двух соседних ячеек: за шаг куски обмениваются одной ячейкой на границе, объём обмена не зависит от размера куска.

2. Связи сетки не меняются. Соседи узла всегда одни и те же: разбиение делается один раз, ячейки не переходят между процессорами. В методах частиц (SPH) соседей ищут заново на каждом шаге.

3. Нагрузка равномерна. Работа на ячейку одинакова и невелика, нет итераций решателя задачи Римана, как в методе Годунова. Равные по числу ячеек куски — равная нагрузка; схема хорошо векторизуется и переносится на GPU.

Минусы

1. Общий шаг — глобальная синхронизация. \(\tau = C\min_i \Delta x_i/c_i\) — минимум по всем процессорам (MPI_Allreduce) на каждом шаге; одна сжатая область задаёт шаг для всех.

2. Куски движутся в пространстве. Процессор со сжатым газом отвечает за малую область. Пространственные запросы — куда попал лазерный луч, какие тела соприкасаются — требуют поиска по всем процессорам.

3. Перестроение сетки (ALE) нелокально. Ячейки новой сетки пересекаются со старыми ячейками чужих кусков, работа распределена неравномерно — дисбаланс нагрузки.

4. Неявная схема (§13.8) последовательна. При \(\alpha \ge \tfrac12\) на каждом шаге решается трёхдиагональная система; прогонка последовательна, нужны параллельная прогонка или циклическая редукция и обмены на каждой итерации.

Далее — разностная схема «крест» на лагранжевой сетке.
