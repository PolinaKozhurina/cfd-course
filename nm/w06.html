Численное дифференцирование

▶ Слайды ▶ Лаба

Дифференцирование в аналитической форме — задача школы: правила Лейбница и цепное дают производную любой элементарной функции. В компьютерных вычислениях задача другая: функция задана значениями в узлах сетки, а производную требуется получить приближённо. Ответ дают конечные разности, выводимые из ряда Тейлора. Это же занятие приводит к первому в курсе примеру, где ошибки округления и ошибки метода конкурируют: с уменьшением шага сначала ошибка убывает, а затем — растёт. Существует оптимальный шаг, и найти его — прикладное умение.

Задача численного дифференцирования

Дана функция \(f\) и её значения в узлах равномерной сетки с шагом \(h\): \(f_i = f(x_0 + i\,h)\). Требуется приблизить производную \(f'(x_0)\) (либо \(f''(x_0)\)) через значения в соседних узлах.

разностный оператор. Линейная комбинация значений \(f_i\), возвращающая приближение производной: \[ D_h f(x_0) \;=\; \frac{1}{h^p}\sum_{k=-K}^{L} \alpha_k\,f(x_0 + k h) \;\approx\; f^{(p)}(x_0). \tag{6.1} \] Коэффициенты \(\alpha_k\) подбираются так, чтобы (6.1) совпадало с производной до максимально возможного порядка при \(h\to 0\).

Правая разность

Простейший вариант — сдвинуть аргумент на \(h\) вперёд:

\[ D_h^{+} f(x_0) \;=\; \frac{f(x_0 + h) - f(x_0)}{h}. \tag{6.2} \]

Насколько (6.2) близко к \(f'(x_0)\)? Разложим \(f(x_0 + h)\) в ряд Тейлора:

\[ f(x_0 + h) \;=\; f(x_0) + h\,f'(x_0) + \frac{h^2}{2}\,f''(x_0) + O(h^3). \tag{6.3} \]

Подставив в (6.2):

\[ D_h^{+} f(x_0) \;=\; f'(x_0) + \frac{h}{2}\,f''(x_0) + O(h^2). \tag{6.4} \]

Значит, ошибка усечения правой разности — первого порядка по \(h\):

\[ \bigl|D_h^{+}f - f'(x_0)\bigr| \;\le\; \frac{h}{2}\,M_2 + O(h^2),\qquad M_2 = \max|f''|. \tag{6.5} \]

Симметрично строится левая разность \(D_h^{-} = (f(x_0) - f(x_0 - h))/h\), тоже первого порядка.

Центральная разность

Складывая разложения (6.3) вперёд и симметричное назад:

\[ f(x_0 + h) - f(x_0 - h) \;=\; 2h\,f'(x_0) + \frac{h^3}{3}\,f'''(x_0) + O(h^5), \tag{6.6} \]

получаем

центральная разность. \[ D_h^{c} f(x_0) \;=\; \frac{f(x_0 + h) - f(x_0 - h)}{2h} \;=\; f'(x_0) + \frac{h^2}{6}\,f'''(x_0) + O(h^4). \tag{6.7} \] Ошибка усечения — второго порядка по \(h\).

При том же шаге центральная разность дает ошибку меньше правой в \(\sim h\) раз. Например, при \(h = 10^{-4}\): правая — \(\sim 10^{-4}\), центральная — \(\sim 10^{-8}\). Единственная плата — центральной нужны значения в двух соседях, а не в одном.

Порядок аппроксимации: как определить

порядок аппроксимации. Говорят, что разностный оператор \(D_h\) аппроксимирует производную \(f^{(p)}\) с порядком \(q\), если \[ D_h f(x_0) - f^{(p)}(x_0) \;=\; O(h^{q}),\qquad h \to 0. \tag{6.8} \]

Порядок аппроксимации — рабочая величина: удвоение шага увеличивает ошибку в \(2^q\) раз, а не просто «слабо ухудшает». В двойном логарифмическом графике \(\log|\text{err}|\) от \(\log h\) прямая с наклоном \(q\).

Рецепт вывода порядка. Подставить в разностный оператор ряд Тейлора и посмотреть, на какой степени \(h\) начинается несокращённый член. Пример: \((f(x_0 + 2h) - f(x_0 - 2h))/(4h) - f'(x_0) = \tfrac{4h^2}{3}f''' + \ldots\) — тоже второй порядок, но с константой в 8 раз больше центральной. Не только порядок важен, но и константа при \(h^q\).

Вторая производная

Складывая (не вычитая) разложения:

\[ f(x_0 + h) + f(x_0 - h) \;=\; 2f(x_0) + h^2 f''(x_0) + \frac{h^4}{12}\,f^{(4)}(x_0) + O(h^6), \tag{6.9} \]

получаем классическую центральную формулу для второй производной:

центральная разность второй производной. \[ D_h^{(2)} f(x_0) \;=\; \frac{f(x_0 + h) - 2f(x_0) + f(x_0 - h)}{h^2} \;=\; f''(x_0) + \frac{h^2}{12}\,f^{(4)}(x_0) + O(h^4). \tag{6.10} \] Порядок аппроксимации — второй.

Формула (6.10) — рабочий инструмент разностных схем для УрЧП: правая часть уравнения теплопроводности \(u_t = u_{xx}\) заменяется именно ей.

Ошибка округления в разностях

Формула (6.2) в машинной арифметике вычисляется не точно. Значения \(f(x_0 + h)\) и \(f(x_0)\) представимы с относительной ошибкой \(u\), значит абсолютная ошибка каждого — \(u \cdot |f|\). Их разность имеет абсолютную ошибку \(\le 2u |f|\), а деление на \(h\) даёт

\[ \bigl|D_h^{+}f - f'(x_0)\bigr|_{\text{round}} \;\lesssim\; \frac{2u\,|f|}{h}. \tag{6.11} \]

Итоговая ошибка правой разности — сумма ошибки усечения и ошибки округления:

\[ E(h) \;\approx\; \frac{h}{2}\,M_2 \;+\; \frac{2u\,|f|}{h}. \tag{6.12} \]

Первое слагаемое — растёт с \(h\); второе — убывает. Итог: с уменьшением шага сначала ошибка падает (доминирует усечение), потом растёт (доминирует округление).

Рис. 1. V-образная кривая полной ошибки правой разности в log-log-масштабе. Слева доминирует округление (~1/h), справа — усечение (~h). Минимум — оптимальный шаг \(h_{\text{opt}}\).

Оптимальный шаг

Дифференцируя (6.12) по \(h\) и приравнивая нулю:

\[ \frac{dE}{dh} \;=\; \frac{M_2}{2} \;-\; \frac{2u\,|f|}{h^2} \;=\; 0 \quad \Rightarrow \quad h_{\text{opt}} \;=\; 2\sqrt{\frac{u\,|f|}{M_2}}. \tag{6.13} \]

Для правой разности \(h_{\text{opt}} \sim \sqrt{u}\), при \(u\approx 10^{-16}\) получаем \(h_{\text{opt}} \approx 10^{-8}\). Аналогичный расчёт для центральной разности (усечение \(\sim h^2\), округление \(\sim u/h\)):

оптимальные шаги.
  • Правая разность: \(h_{\text{opt}} \sim \sqrt{u} \approx 10^{-8}\), минимальная ошибка \(\sim \sqrt{u} \approx 10^{-8}\).
  • Центральная разность: \(h_{\text{opt}} \sim u^{1/3} \approx 5\cdot 10^{-6}\), минимальная ошибка \(\sim u^{2/3} \approx 3\cdot 10^{-11}\).
  • Вторая производная: \(h_{\text{opt}} \sim u^{1/4} \approx 10^{-4}\), минимальная ошибка \(\sim \sqrt{u}\).
Наивное правило «маленькое h = точнее» неверно. Уменьшение \(h\) ниже \(h_{\text{opt}}\) ухудшает результат. Классическая ловушка: студент пишет \(h = 10^{-15}\), «чтобы точнее», и получает шум \(\sim 1\).

Экстраполяция Ричардсона

Есть способ увеличить порядок аппроксимации без уменьшения шага — экстраполяция Ричардсона. Идея: если разностная формула имеет разложение \(D_h = f' + c_1 h^{p_1} + c_2 h^{p_2} + \ldots\) с известными степенями \(p_1 < p_2\), линейная комбинация \(D_h\) и \(D_{h/2}\) с подходящими коэффициентами исключает первый член ошибки.

экстраполяция Ричардсона. Пусть \(D_h = f' + c_1 h^{p_1} + O(h^{p_2})\). Тогда \[ R_h \;=\; \frac{2^{p_1}\,D_{h/2} - D_h}{2^{p_1} - 1} \;=\; f' + O(h^{p_2}). \tag{6.14} \] Порядок аппроксимации повышается с \(p_1\) до \(p_2\).

Для центральной разности (\(p_1 = 2, p_2 = 4\)):

\[ R_h \;=\; \frac{4\,D_{h/2}^{c} - D_h^{c}}{3} \;=\; f'(x_0) + O(h^4). \tag{6.15} \]

Итерируя, можно получать всё более высокие порядки — но каждый уровень удваивает число вычислений \(f\) и не даёт нового «бесплатно», если исходная формула сама не обладает симметричным разложением.

Итоги занятия

Что нужно унести с занятия 6.
  1. Разностные производные (6.2), (6.7), (6.10) получаются подстановкой ряда Тейлора и подбором коэффициентов.
  2. Порядок аппроксимации — это степень \(h\), при которой начинается несокращённый член. Правая — \(O(h)\), центральная — \(O(h^2)\), вторая производная — \(O(h^2)\).
  3. Ошибка округления в разностях растёт как \(u/h\); с уменьшением шага доминирует и ухудшает результат.
  4. Оптимальный шаг — компромисс. Для правой \(\sim\sqrt{u}\); для центральной \(\sim u^{1/3}\); для второй \(\sim u^{1/4}\). Минимальная достижимая ошибка тем меньше, чем выше порядок.
  5. Экстраполяция Ричардсона (6.14) повышает порядок формально — за счёт вычислений в двух шагах и линейной комбинации.
