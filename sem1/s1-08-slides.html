§8–§10 · Практическое занятие · Семестр 1

Консервативные, монотонные и TVD-схемы. Схемы с ограничителем потока

Свойства схем, определяющие поведение решения на разрывах, и построение нелинейной схемы второго порядка без осцилляций.

§8 — консервативность, монотонность, полная вариация · §9 — теорема Годунова · §10 — лемма Хартена, ограничитель потока, условие Свеби

Практическая часть: схема варианта из практики §5–§6 в консервативной форме и с ограничителем потока.

§8.1 · Постановка и обозначения

Закон сохранения, сетка, число Куранта

\[ \frac{\partial u}{\partial t} + \frac{\partial f(u)}{\partial x} = 0, \qquad a(u) = f'(u); \qquad \text{перенос: } f = au, \quad \text{Бюргерс: } f = \frac{u^2}{2}. \tag{8.1} \]
СеткаУзлы \(x_j = jh\), слои \(t_n = n\tau\); ячейка узла \(j\) — отрезок \([x_{j-1/2}, x_{j+1/2}]\). На слое \(n\) верхний индекс опускается: \(y_j = y_j^n\). Разность на границе ячеек: \[ \Delta^n_{j+1/2} = y^n_{j+1} - y^n_j = h\,(y^n_r)_j, \qquad \Delta_{j+1/2} = \Delta^n_{j+1/2}. \]
Число Куранта \[ r = \frac{a\tau}{h}, \qquad r^\pm = \frac{a^\pm\tau}{h}, \qquad a^+ = \max(a, 0),\ \ a^- = \min(a, 0). \] За шаг \(\tau\) решение уравнения переноса сдвигается на \(r\) ячеек; \(|r| \le 1\) — условие Куранта.

Все построения опираются на две схемы, известные из §5.

§8.1 · Опорные схемы

Противопоточная схема и схема Лакса–Вендроффа

Противопоточная схема (upwind): \[ y_j^{n+1} = y_j - r^+\,(y_j - y_{j-1}) - r^-\,(y_{j+1} - y_j); \qquad a > 0:\ \ y_j^{n+1} = y_j - r\,(y_j - y_{j-1}). \] Первый порядок; схемная вязкость \(\nu = \tfrac{|a|h}{2}(1 - |r|)\) (§5); монотонна при \(|r| \le 1\).
Схема Лакса–Вендроффа: \[ y_j^{n+1} = y_j - \frac r2\,(y_{j+1} - y_{j-1}) + \frac{r^2}{2}\,(y_{j+1} - 2y_j + y_{j-1}). \] Второй порядок; главный член погрешности дисперсионный — осцилляции у разрывов (§5).
Далее \(a > 0\). Случай \(a \lt 0\) получается заменой \(j \to -j\) (левые и правые соседи меняются местами, \(r \to |r|\)); исключение — определение ограничителя потока (§10), данное в общем виде.

Первое свойство — консервативность.

§8.2 · Определение 8.1

Консервативная схема относительно закона сохранения

Схема называется консервативной относительно закона сохранения (8.1), если она записывается в виде \[ y_j^{n+1} = y_j - \frac{\tau}{h}\bigl(F_{j+1/2} - F_{j-1/2}\bigr), \qquad F_{j+1/2} = F\bigl(y_{j-m+1}, \dots, y_{j+m}\bigr), \tag{8.2} \] где численный поток \(F\) — одна и та же для всех \(j\) функция значений в \(2m\) узлах около границы \(x_{j+1/2}\) (\(m \ge 1\) фиксировано), согласованная с \(f\): \(F(v, \dots, v) = f(v)\).
АналогИнтегральная форма на ячейке, верная и для разрывных решений: \[ \bar u_j^{n+1} = \bar u_j^n - \frac\tau h\bigl(\bar f_{j+1/2} - \bar f_{j-1/2}\bigr), \] \(\bar u_j\) — среднее по ячейке, \(\bar f_{j+1/2}\) — среднее по шагу значение потока на границе.
РольПоток \(F_{j+1/2}\) входит в уравнения ячеек \(j\) и \(j+1\) с противоположными знаками: «масса», покидающая ячейку \(j\), поступает в ячейку \(j+1\). Отсюда дискретный закон сохранения и теорема Лакса–Вендроффа.

Свойство относится к паре «схема — закон сохранения».

§8.2 · Замечание к определению 8.1

Уравнение Бюргерса и его законы сохранения

Исходное уравнение — уравнение Бюргерса в недивергентной записи: \(\quad\text{(в)}\ \ u_t + u\,u_x = 0.\)

Законы сохранения — следствия (в) для гладких решенийУмножая (в) на \(\eta'(u)\), получаем закон сохранения плотности \(\eta(u)\): \[ \eta'(u)\,u_t + \eta'(u)\,u\,u_x = 0 \ \Longrightarrow\ \eta(u)_t + q(u)_x = 0, \qquad q'(u) = u\,\eta'(u). \] \[ \eta = u:\ \ \text{(а)}\ \ u_t + \Bigl(\frac{u^2}{2}\Bigr)_x = 0; \qquad\qquad \eta = u^2:\ \ \text{(б)}\ \ (u^2)_t + \Bigl(\frac{2u^3}{3}\Bigr)_x = 0. \]
Разрывные решенияДля гладких решений (а), (б), (в) равносильны; для разрывных — нет. Условие Ренкина–Гюгонио \(s = [q]/[\eta]\) при \(u_l = 1{,}2\), \(u_r = 0{,}4\): \[ s_{\text{а}} = \frac{u_l + u_r}{2} = 0{,}8, \qquad s_{\text{б}} = \frac23\,\frac{u_l^2 + u_l u_r + u_r^2}{u_l + u_r} \approx 0{,}867. \]
Следствие для схемСхема, консервативная относительно (а), сохраняет \(\sum_j y_j h\), но не \(\sum_j y_j^2 h\); относительно (б) — наоборот. Схемы, построенные по (в), не имеют вида (8.2).

Консервативная схема сохраняет дискретный аналог интеграла от плотности.

§8.2 · Утверждение 8.1

Дискретный закон сохранения

Утверждение 8.1. Для схемы (8.2) на сетке \(j = 1, \dots, N\) \[ \sum_{j=1}^{N} y_j^{n+1}h = \sum_{j=1}^{N} y_j h - \tau\bigl(F_{N+1/2} - F_{1/2}\bigr); \] на периодической сетке \(\sum_j y_j h\) не зависит от \(n\).
Доказательство. Умножим (8.2) на \(h\) и просуммируем по \(j\); поток \(F_{j+1/2}\), \(1 \le j \le N-1\), входит в слагаемые с номерами \(j\) и \(j+1\) с противоположными знаками, поэтому \(\sum_{j=1}^{N}\bigl(F_{j+1/2} - F_{j-1/2}\bigr) = F_{N+1/2} - F_{1/2}\). При периодических условиях \(F_{N+1/2} = F_{1/2}\). ∎
Аналог и роль\(\tfrac{d}{dt}\int_0^l u\,dx = f\bigl(u(0,t)\bigr) - f\bigl(u(l,t)\bigr)\). «Масса» меняется только через границы; на периодической сетке сохраняется до ошибок округления — проверка программы.

Сохранение интеграла определяет скорость разрыва в пределе.

§8.2 · Теорема Лакса–Вендроффа

Предел консервативной схемы — слабое решение

Теорема (Лакс, Вендрофф, 1960). Пусть схема (8.2) консервативна относительно (8.1), поток \(F\) непрерывен и согласован, и при \(h \to 0\), \(\tau/h = \mathrm{const}\), решения сходятся в \(L_1\) на ограниченных множествах к \(u(x, t)\), причём \(\mathrm{TV}(y^n)\) равномерно ограничены. Тогда \(u\) — слабое решение (8.1); на разрывах выполнено условие Ренкина–Гюгонио \(s\,[u] = [f(u)]\).
Условия теоремыСходимость схемы — предположение, а не вывод: теорема указывает, к какому объекту сходится консервативная схема, если она сходится.
Роль консервативностиБез консервативности скорость разрыва в пределе может не совпадать со скоростью Ренкина–Гюгонио, причём погрешность не убывает при измельчении сетки.

Когда линейная схема консервативна?

§8.3 · Утверждение 8.2 · Алгоритм 8.1

Консервативная форма линейной схемы

Утверждение 8.2. Линейная схема \(y_j^{n+1} = \sum_{\mu\in S}\alpha_\mu\,y_{j+\mu}\) на шаблоне \(S\) (обозначения §7) с постоянными коэффициентами и \(\sum_\mu\alpha_\mu = 1\) записывается в виде (8.2) с линейным потоком; поток согласован с \(f = au\) тогда и только тогда, когда \(\sum_\mu\mu\,\alpha_\mu = -r\) — условие первого порядка (теорема 1 §7).
Алгоритм 8.1 (нахождение потока)
  1. Записать приращение в виде \(y_j^{n+1} - y_j = -\tfrac\tau h\,[\ \cdots\ ]\).
  2. Выразить разности в скобке через \(\Delta_{j\pm1/2}\): \(\ y_{j+1} - y_{j-1} = \Delta_{j+1/2} + \Delta_{j-1/2}\), \(\ y_{j+1} - 2y_j + y_{j-1} = \Delta_{j+1/2} - \Delta_{j-1/2}\).
  3. Найти \(F_{j+1/2}\), для которого \(F_{j+1/2} - F_{j-1/2}\) совпадает со скобкой. Общий способ — метод неопределённых коэффициентов (§7): \(F_{j+1/2} = \sum_k b_k\,y_{j+k}\), коэффициенты при каждом \(y_{j+k}\) приравниваются.
  4. Проверить согласованность \(F(v, \dots, v) = av\) и восстановить схему подстановкой в (8.2).

Применим алгоритм к опорным схемам.

§8.3 · Пример 8.2

Потоки противопоточной схемы и схемы Лакса–Вендроффа

Противопоточная схема \[ y_j^{n+1} = y_j - \frac\tau h\bigl(a\,y_j - a\,y_{j-1}\bigr) \ \Rightarrow\ F^{\text{up}}_{j+1/2} = a\,y_j. \]
Схема Лакса–Вендроффа, шаги 1–2Приращение \(y_j^{n+1} - y_j = -\tfrac\tau h\,[\ \cdots\ ]\), где \[ \begin{aligned}{[\ \cdots\ ]} &= \frac{a(1-r)}{2}\Delta_{j+1/2} + \frac{a(1+r)}{2}\Delta_{j-1/2}\\ &= a\,\Delta_{j-1/2} + \frac{a(1-r)}{2}\bigl(\Delta_{j+1/2} - \Delta_{j-1/2}\bigr). \end{aligned} \]
\[ F^{\text{ЛВ}}_{j+1/2} = \underbrace{a\,y_j}_{F^{\text{up}}_{j+1/2}} + \underbrace{\frac{a(1 - r)}{2}\,\Delta_{j+1/2}}_{\text{антидиффузионная поправка}} \]

В общем виде: \(F^{\text{up}}_{j+1/2} = a^+y_j + a^-y_{j+1}\), поправка \(\tfrac{|a|}{2}(1 - |r|)\,\Delta_{j+1/2}\).

Вклад поправки в схему: \(-\tfrac{r(1-r)}{2}\,(y_{j+1} - 2y_j + y_{j-1})\) — отрицательная схемная вязкость, снимающая вязкость \(\nu = \tfrac{ah}{2}(1 - r)\) противопоточной схемы. Поправка повышает порядок до второго и порождает осцилляции у разрывов.

Те же потоки — в программе.

§8.3 · Программная реализация

Консервативная форма в программе

Элемент \(j\) массива потоков хранит \(F_{j+1/2}\); сдвиг на один элемент даёт \(F_{j-1/2}\); \(\tau/h = r/a\).

# F[j] = F_{j+1/2};  np.roll(F, 1)[j] = F_{j-1/2};  np.roll(u, -1)[j] = y_{j+1}
def step_flux(u, r, flux):
    F = flux(u, r)
    return u - (r / A) * (F - np.roll(F, 1))         # (8.2), tau/h = r/a

def flux_upwind(u, r):                               # a+ y_j + a- y_{j+1}
    return max(A, 0) * u + min(A, 0) * np.roll(u, -1)

def flux_lw(u, r):                                   # + |a|(1-|r|)/2 * Delta_{j+1/2}
    return flux_upwind(u, r) + 0.5 * abs(A) * (1 - abs(r)) * (np.roll(u, -1) - u)
Контроль 1. Шаг через поток совпадает с исходной формулой схемы до \(10^{-16}\).

2. \(\sum_j y_j^n h\) не меняется по шагам (утверждение 8.1).

Перейдём к свойствам, запрещающим осцилляции.

§8.4 · Общий вид схемы

Явная двухслойная схема как функция значений на шаблоне

Свойства, запрещающие осцилляции, формулируются для схемы общего вида; обозначения шаблона — как в §7.

Шаблон — конечное множество смещений \(S = \{\mu_1, \dots, \mu_N\} \subset \mathbb Z\). Явная двухслойная схема на шаблоне \(S\): \[ y_j^{n+1} = H\bigl(y^n_{j+\mu_1}, \dots, y^n_{j+\mu_N}\bigr), \] где \(H(v_{\mu_1}, \dots, v_{\mu_N})\) — функция \(N\) переменных, одна и та же для всех \(j\) и \(n\). Схема линейна, если \(H = \sum_{\mu\in S}\alpha_\mu v_\mu\) с постоянными \(\alpha_\mu\).
Примеры при положительной скорости \[ \begin{aligned} &\text{противопоточная:} && S = \{-1, 0\}, && H = r\,v_{-1} + (1 - r)\,v_0;\\ &\text{Лакса–Вендроффа:} && S = \{-1, 0, 1\}, && H = \tfrac{r(1+r)}{2}\,v_{-1} + (1 - r^2)\,v_0 - \tfrac{r(1-r)}{2}\,v_1;\\ &\text{с ограничителем (10.5):} && S = \{-2, -1, 0, 1\}, && H \text{ нелинейна: зависит от } v_\mu \text{ также через } \theta. \end{aligned} \]

Для схемы такого вида дадим три определения монотонности.

§8.4 · Определение 8.2

Три определения монотонности разностной схемы

Схема \(y_j^{n+1} = H\bigl(y^n_{j+\mu},\ \mu \in S\bigr)\); \(y^{n+1}\) и \(z^{n+1}\) — результаты одного шага схемы из \(y^n\) и \(z^n\).

Схема, сохраняющая монотонность (Годунов, 1959): \[ y^n_{j+1} \ge y^n_j \ \ \forall j \ \Longrightarrow\ \ y^{n+1}_{j+1} \ge y^{n+1}_j \ \ \forall j, \] и то же для невозрастающих сеточных функций.
Монотонная схема (Хартен, Хайман, Лакс, 1976): \(H\) не убывает по каждому аргументу, \[ \frac{\partial H}{\partial v_\mu} \ge 0 \quad \text{для всех } \mu \in S. \tag{8.4} \]
Схема, сохраняющая порядок (Фридрихс): \[ y^n_j \ge z^n_j \ \ \forall j \ \Longrightarrow\ \ y^{n+1}_j \ge z^{n+1}_j \ \ \forall j. \]

Как связаны три определения — лемма 8.1.

§8.4 · Лемма 8.1

Связь трёх определений монотонности

Лемма 8.1. (1) При дифференцируемой \(H\) определения 8.2б и 8.2в равносильны. (2) Для линейной схемы с \(\sum_{\mu\in S}\alpha_\mu = 1\) все три определения равносильны условию \(\alpha_\mu \ge 0\), \(\mu \in S\). (3) Для нелинейных схем из 8.2б следует 8.2а; обратное неверно.
Доказательство. (1) 8.2б ⇒ 8.2в: по формуле Лагранжа \(y^{n+1}_j - z^{n+1}_j = \sum_{\mu\in S} \dfrac{\partial H}{\partial v_\mu}(\xi)\,\bigl(y^n_{j+\mu} - z^n_{j+\mu}\bigr) \ge 0\), \(\xi\) — точка отрезка между наборами аргументов. 8.2в ⇒ 8.2б: пусть \(y^n\) отличается от \(z^n\) только в узле \(j + \mu\), на \(\varepsilon > 0\); тогда \(\bigl(y^{n+1}_j - z^{n+1}_j\bigr)/\varepsilon \ge 0\), и при \(\varepsilon \to 0\) получаем \(\partial H/\partial v_\mu \ge 0\).
(2) \(\partial H/\partial v_\mu = \alpha_\mu\), поэтому 8.2б \(\iff \alpha_\mu \ge 0\). При \(\alpha_\mu \ge 0\) разности \(\Delta^{n+1}_{j+1/2} = \sum_\mu\alpha_\mu\,\Delta^n_{j+\mu+1/2}\) сохраняют знак — выполнено 8.2а. Обратно, для невозрастающей ступеньки \(y^n_j = 1\) (\(j \le 0\)), \(0\) (\(j > 0\)) получаем \(\Delta^{n+1}_{j+1/2} = -\alpha_{-j}\); по 8.2а все они \(\le 0\), т. е. \(\alpha_\mu \ge 0\).
(3) 8.2б ⇒ TVD ⇒ 8.2а (Хартен, 1983). Схемы с ограничителем потока (§10) удовлетворяют 8.2а, но не 8.2б. ∎
Далее «монотонная схема» — в смысле 8.2б. По примерам предыдущего слайда противопоточная схема монотонна при \(0 \le r \le 1\); у схемы Лакса–Вендроффа \(\alpha_1 = -\tfrac{r(1-r)}{2} \lt 0\) при \(0 \lt r \lt 1\) — она не монотонна.

Отсутствие новых экстремумов — принцип максимума.

§8.4 · Определение 8.4 · Утверждение 8.3

Дискретный принцип максимума

Схема удовлетворяет дискретному принципу максимума, если для всех \(j\) и \(n\) \[ \min_{\mu\in S} y^n_{j+\mu} \ \le\ y_j^{n+1}\ \le\ \max_{\mu\in S} y^n_{j+\mu}. \tag{8.5} \]
Утверждение 8.3. Линейная схема с \(\sum_\mu\alpha_\mu = 1\) удовлетворяет (8.5) тогда и только тогда, когда она монотонна.
Доказательство. При \(\alpha_\mu \ge 0\), \(\sum\alpha_\mu = 1\) значение \(y_j^{n+1}\) — выпуклая комбинация значений на шаблоне. Если \(\alpha_\nu \lt 0\), то при \(y^n_{j+\nu} = 1\) и нулевых остальных значениях на шаблоне \(y_j^{n+1} = \alpha_\nu \lt 0 = \min_{\mu\in S} y^n_{j+\mu}\). ∎
Аналог и рольДля переноса \(\min u_0 \le u(x, t) \le \max u_0\). Новые экстремумы не возникают; данные из \([0, 1]\) (концентрация, объёмная доля) остаются в \([0, 1]\).

Глобальная мера осцилляций — полная вариация.

§8.4 · Определения 8.5, 8.6

Полная вариация и TVD-схемы

Полная вариация сеточной функции: \[ \mathrm{TV}(y) = \sum_j |\Delta_{j+1/2}| = \sum_j |y_{j+1} - y_j|. \tag{8.7} \]
Схема называется TVD-схемой (total variation diminishing, Хартен, 1983), если для любой \(y^n\) с конечной полной вариацией \[ \mathrm{TV}(y^{n+1}) \le \mathrm{TV}(y^n). \tag{8.8} \]
Аналог\(\mathrm{TV}(u) = \int|u_x|\,dx\). Для переноса \(\mathrm{TV}(u(\cdot, t)) = \mathrm{TV}(u_0)\); для нелинейного закона (8.1) полная вариация энтропийного решения не возрастает.
РольМонотонная ступенька: \(\mathrm{TV} = 1\); новый экстремум амплитуды \(\delta\) увеличивает \(\mathrm{TV}\) на \(2\delta\). Свойство TVD проверяется и для нелинейных схем (лемма Хартена).

Для линейных схем TVD равносильно монотонности.

§8.4 · Теорема 8.1

Монотонность и TVD для линейных схем

Пусть \(y_j^{n+1} = \sum_\mu\alpha_\mu\,y_{j+\mu}\), \(\sum_\mu\alpha_\mu = 1\). Схема является TVD-схемой тогда и только тогда, когда она монотонна.
Доказательство. (а) Монотонность ⇒ TVD. Так как \(\Delta^{n+1}_{j+1/2} = \sum_\mu\alpha_\mu\,\Delta_{j+\mu+1/2}\) и \(\alpha_\mu \ge 0\) (здесь использована монотонность), \[ \mathrm{TV}(y^{n+1}) \le \sum_j\sum_\mu\alpha_\mu\,|\Delta_{j+\mu+1/2}| = \sum_\mu\alpha_\mu\,\mathrm{TV}(y^n) = \mathrm{TV}(y^n). \] (б) TVD ⇒ монотонность. Для ступеньки \(y_j = 1\) (\(j \le 0\)), \(0\) (\(j > 0\)): \(\mathrm{TV}(y) = 1\), \(\Delta^{1}_{j+1/2} = -\alpha_{-j}\), \[ \mathrm{TV}(y^1) = \sum_\mu|\alpha_\mu| \ \ge\ \Bigl|\sum_\mu\alpha_\mu\Bigr| = 1, \] равенство — только при \(\alpha_\mu \ge 0\) для всех \(\mu\). ∎
Следствие. Для линейных схем с \(\sum\alpha_\mu = 1\) определения 8.2а–8.2в, принцип максимума (8.5) и TVD (8.8) равносильны; для нелинейных схем они различны.

Какой порядок совместим с \(\alpha_\mu \ge 0\)?

§9 · Теорема 9.1

Теорема Годунова

Условия порядка \(p\) из метода неопределённых коэффициентов (теорема 1 §7): \(\sum_\mu\alpha_\mu(-\mu)^k = r^k\), \(k = 0, \dots, p\). При \(p = 2\):

\[ \sum_\mu\alpha_\mu = 1, \tag{9.3} \qquad \]
\[ \sum_\mu \mu\,\alpha_\mu = -r, \tag{9.5} \]
\[ \sum_\mu \mu^2\,\alpha_\mu = r^2. \tag{9.6} \]
(Годунов, 1959). Линейная монотонная схема \(y_j^{n+1} = \sum_\mu\alpha_\mu\,y_{j+\mu}\) с постоянными коэффициентами, аппроксимирующая уравнение переноса, при нецелом \(r\) имеет порядок аппроксимации не выше первого. По теореме 8.1 то же верно для линейных TVD-схем.

Условия (9.3)–(9.6) — первые три момента весов \(\alpha_\mu\); у точного решения это моменты единичной массы в точке \(-r\).

§9 · Доказательство теоремы 9.1

Доказательство теоремы Годунова

Этап 1 (предположение). Пусть \(\alpha_\mu \ge 0\) для всех \(\mu\) и порядок не ниже второго: выполнены (9.3), (9.5), (9.6).

Этап 2 (тождество). Раскрывая квадрат и подставляя (9.6), (9.5), (9.3):

\[ \sum_\mu\alpha_\mu\,(\mu + r)^2 = \sum_\mu\mu^2\alpha_\mu + 2r\sum_\mu\mu\,\alpha_\mu + r^2\sum_\mu\alpha_\mu = r^2 - 2r^2 + r^2 = 0. \tag{9.7} \]

Монотонность здесь не использована: (9.7) верно для любой схемы второго порядка.

Этап 3 (здесь использована монотонность). Все слагаемые в (9.7) неотрицательны, сумма равна нулю, поэтому \(\alpha_\mu(\mu + r)^2 = 0\) для всех \(\mu\): \(\alpha_\mu \ne 0\) только при \(\mu = -r\).

Этап 4 (противоречие). Узлы \(\mu\) — целые; при нецелом \(r\) все \(\alpha_\mu = 0\), что противоречит (9.3). ∎

Следствие 9.1. Схема второго порядка, не порождающая осцилляций, обязана быть нелинейной: её коэффициенты зависят от решения.

Для нелинейных схем свойство TVD проверяется леммой Хартена.

§10.1 · Теорема 10.2 (лемма Хартена)

Достаточное условие TVD для нелинейных схем

(Хартен, 1983). Пусть схема записана в приращениях \[ y_j^{n+1} = y_j + C_{j+1/2}\,\Delta_{j+1/2} - D_{j-1/2}\,\Delta_{j-1/2}, \tag{10.4} \] коэффициенты могут зависеть от \(y^n\), и для всех \(j\): \(C_{j+1/2} \ge 0\), \(D_{j+1/2} \ge 0\), \(C_{j+1/2} + D_{j+1/2} \le 1\). Тогда схема TVD.
Доказательство. Вычитая (10.4) для узлов \(j+1\) и \(j\): \[ \Delta^{n+1}_{j+1/2} = \bigl(1 - C_{j+1/2} - D_{j+1/2}\bigr)\Delta_{j+1/2} + C_{j+3/2}\,\Delta_{j+3/2} + D_{j-1/2}\,\Delta_{j-1/2}. \] Все множители неотрицательны (здесь использованы условия теоремы). Берём модуль, суммируем по \(j\), сдвигаем индексы: при каждом \(|\Delta_{j+1/2}|\) коэффициент \((1 - C - D) + C + D = 1\), откуда \(\mathrm{TV}(y^{n+1}) \le \mathrm{TV}(y^n)\). ∎

Применим лемму к схемам, потоки которых найдены в примере 8.2.

§10.1 · Пример 10.1

Коэффициенты \(C\), \(D\) по численному потоку

Подставим в (8.2) потоки примера 8.2 (\(a > 0\), \(\tau a/h = r\)) и приведём схему к виду (10.4).

Противопоточная схемаПоток \(F_{j+1/2} = a\,y_j\): \[ y_j^{n+1} = y_j - r\,\Delta_{j-1/2}, \qquad C_{j+1/2} = 0, \quad D_{j-1/2} = r; \] условия теоремы 10.2 выполнены при \(0 \le r \le 1\).
Схема Лакса–ВендроффаПоток \(F_{j+1/2} = a\,y_j + \tfrac{a(1-r)}{2}\,\Delta_{j+1/2}\): \[ y_j^{n+1} = y_j - r\,\Delta_{j-1/2} - \frac{r(1-r)}{2}\bigl(\Delta_{j+1/2} - \Delta_{j-1/2}\bigr), \qquad C_{j+1/2} = -\frac{r(1-r)}{2}, \quad D_{j-1/2} = \frac{r(1+r)}{2}; \] при \(0 \lt r \lt 1\) \(C_{j+1/2} \lt 0\) — условия нарушены; отрицательный коэффициент вносит антидиффузионная поправка.

Поправку нужно домножить на множитель, зависящий от решения, так, чтобы выполнялись условия теоремы 10.2, — ограничитель потока.

§10.2 · Определение 10.3

Схема с ограничителем потока

Схемой с ограничителем потока называется схема (8.2) с потоком \[ F_{j+1/2} = a^+y_j + a^-y_{j+1} + \frac{|a|}{2}\,(1 - |r|)\,\varphi(\theta_{j+1/2})\,\Delta_{j+1/2}, \qquad \theta_{j+1/2} = \frac{\Delta_{j+1/2-\sigma}}{\Delta_{j+1/2}}, \quad \sigma = \operatorname{sign} a, \tag{10.5} \] где \(\varphi\) — заданная функция, ограничитель. При \(a > 0\): \[ F_{j+1/2} = a\,y_j + \frac{a(1 - r)}{2}\,\varphi(\theta_{j+1/2})\,\Delta_{j+1/2}, \qquad \theta_{j+1/2} = \frac{\Delta_{j-1/2}}{\Delta_{j+1/2}}. \]
Частные случаи\(\varphi \equiv 0\) — противопоточная схема, \(\varphi \equiv 1\) — схема Лакса–Вендроффа. При постоянном \(\varphi\) схема линейна (теорема 9.1); нелинейность — через \(\theta_{j+1/2}\). При \(\Delta_{j+1/2} = 0\) поправка равна нулю.
Индикатор гладкостиДля гладкой \(u\) с \(u_x \ne 0\): \(\theta_{j+1/2} = 1 - h\,u_{xx}/u_x + O(h^2)\). Гладкий монотонный участок — \(\theta \approx 1\); экстремум — \(\theta \lt 0\); разрыв — \(\theta\) близко к нулю или велико.

Значение \(\varphi(\theta_{j+1/2})\) допускает три истолкования.

§10.2 · Смысл \(\varphi\)

Три истолкования значения ограничителя

1. Доля потока Лакса–Вендроффа \[ F_{j+1/2} = \bigl(1 - \varphi\bigr)\,F^{\text{up}}_{j+1/2} + \varphi\,F^{\text{ЛВ}}_{j+1/2}, \qquad \varphi = \varphi(\theta_{j+1/2}). \]
2. Схемная вязкостьПри \(\varphi \approx \mathrm{const}\) первое дифференциальное приближение содержит вязкость \[ \nu_\varphi = \frac{ah}{2}\,(1 - r)\,(1 - \varphi): \qquad \varphi = 0 \text{ — как у противопоточной схемы},\ \ \varphi = 1 \text{ — нулевая},\ \ \varphi > 1 \text{ — отрицательная}. \]
3. Ограниченная разностьВ поправку входит \(\varphi(\theta_{j+1/2})\,\Delta_{j+1/2}\); для ограничителя minmod \[ \varphi(\theta_{j+1/2})\,\Delta_{j+1/2} = \mathrm{minmod}\bigl(\Delta_{j-1/2}, \Delta_{j+1/2}\bigr) = \begin{cases} 0, & \Delta_{j-1/2}\Delta_{j+1/2} \le 0,\\ \text{меньшая по модулю}, & \text{иначе}. \end{cases} \]

Какие \(\varphi\) обеспечивают свойство TVD — теорема Свеби.

§10.3 · Теорема 10.3

Условие Свеби

(Свеби, 1984). Схема (10.5) при \(|r| \le 1\) является TVD-схемой, если \[ \varphi(\theta) = 0 \ \ (\theta \le 0), \qquad 0 \le \varphi(\theta) \le \min(2\theta,\, 2) \ \ (\theta > 0). \tag{10.6} \]
Доказательство (\(a > 0\)). Этап 1. Так как \(\Delta_{j+1/2} = \Delta_{j-1/2}/\theta_{j+1/2}\), схема имеет вид (10.4) с \(C = 0\) и \[ D_{j-1/2} = r\Bigl[1 + \frac{1 - r}{2}\,X\Bigr], \qquad X = \frac{\varphi(\theta_{j+1/2})}{\theta_{j+1/2}} - \varphi(\theta_{j-1/2}). \] Этап 2 (здесь использовано (10.6)). \(0 \le \varphi(\theta)/\theta \le 2\) и \(0 \le \varphi(\theta) \le 2\), поэтому \(-2 \le X \le 2\).
Этап 3. \(r^2 \le D_{j-1/2} \le r(2 - r) = 1 - (1 - r)^2 \le 1\); по теореме 10.2 схема TVD. При \(a \lt 0\) — замена \(j \to -j\). ∎

При \(\theta \le 0\) поправка выключена: в экстремуме схема совпадает с противопоточной. Второй порядок требует условия в точке \(\theta = 1\).

§10.4 · Утверждение 10.1 · Определение 10.4

Второй порядок и классические ограничители

Утверждение 10.1 (Свеби, без доказательства). Если \(\varphi(1) = 1\) и при \(0 \le \theta \le 2\) значение \(\varphi(\theta)\) лежит между \(1\) и \(\theta\), то на гладких монотонных участках схема (10.5) имеет второй порядок.
Ограничители: \[ \begin{aligned} &\text{minmod:} && \max\bigl(0, \min(1, \theta)\bigr)\\ &\text{superbee:} && \max\bigl(0, \min(2\theta, 1), \min(\theta, 2)\bigr)\\ &\text{van Leer:} && \frac{\theta + |\theta|}{1 + |\theta|}\\ &\text{MC:} && \max\bigl(0, \min\bigl(2\theta, \tfrac{1+\theta}{2}, 2\bigr)\bigr) \end{aligned} \] Все удовлетворяют (10.6) и \(\varphi(1) = 1\).
Диаграмма Свеби: светлое — область (10.6), тёмное — область утверждения 10.1.
