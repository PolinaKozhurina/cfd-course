Организация обучения

Регистрация и доступ к курсу

  • Регистрация на сайте (кнопка Войти в шапке) — по email c подтверждением.
  • После входа — кнопка «Записаться на курс» на карточке выбранного курса.
  • Заявку одобряет преподаватель; после одобрения материалы курса становятся доступны в личном кабинете.
  • Один аккаунт — несколько курсов одновременно; общий профиль, отдельные группы и оценки по каждому.

Материалы и занятия

  • Лекции в веб-формате: формулы через MathJax, схемы и графики — интерактивные SVG.
  • Слайды к отдельным лекциям — для проекции в аудитории.
  • По части курсов — JS-солверы прямо в браузере (запускаются без установки).
  • Список литературы курса — в разделе Литература: учебники, монографии, статьи, рабочие материалы.

Домашние задания, оценки, посещаемость

  • Условия ДЗ публикуются в личном кабинете (Мои ДЗ) как PDF-вложение с дедлайном по МСК.
  • Сдача — файл (скан рукописи или PDF из LaTeX) или ссылка на облачный документ.
  • Оценки: зачёт (до 50 баллов, работа за семестр) и экзамен (до 50 баллов, индивидуальное задание). Итого 100.
  • Посещаемость — на профиле: процент фактически посещённых занятий по каждому курсу.

Академические правила и связь

  • Работы — самостоятельные. Использование генеративных языковых моделей для подготовки текста сдачи не допускается; подробнее — Правила курса.
  • Разрешено: обсуждение задач с однокурсниками, чтение учебной литературы, консультации с преподавателем.
  • Пересдача ДЗ возможна до конца семестра по согласованию с преподавателем.
  • Технические и организационные вопросы — в личные сообщения преподавателю через профиль.
