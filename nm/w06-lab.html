Задача — увидеть V-образную зависимость ошибки численной производной от шага \(h\) в log-log-масштабе. В § 6 показано, что \(E(h) \approx h^p \cdot M_{p+1}/p! + u\cdot|f|/h\): слева шум округления, справа усечение. Найдём эмпирически \(h_{\text{opt}}\) для правой и центральной разностей на \(f = \sin x\) в точке \(x = 1\); ответ сверим с формулой (6.13). Затем — как экстраполяция Ричардсона повышает порядок с 2 до 4.

§1. Оптимальный шаг эмпирически

Задача 1.1. V-образная кривая: центральная разность. Прогоните diff_ctr для \(h = 10^{-1}, 10^{-2}, \ldots, 10^{-15}\), запишите ошибку. Найдите \(h_{\text{opt}}\) — тот шаг, при котором ошибка минимальна. Введите десятичный логарифм \(h_{\text{opt}}\) (например, если \(h_{\text{opt}} = 10^{-5}\), введите -5).
task1_1.cpp
Формула (6.13) для центральной даёт \(h_{\text{opt}} \sim u^{1/3} \approx 4{,}8 \cdot 10^{-6}\), т. е. \(\log_{10} h_{\text{opt}} \approx -5{,}3\). На нашей грубой сетке \(k = 5\) или \(k = 6\) выигрывают в зависимости от округления констант.
Задача 1.2. Наклоны в log-log. На вашем графике ошибки:
Наклоны левой и правой ветвей V-кривой
В log-log-координатах \(\log|E| = \log(h^2/6) = 2\log h + \text{const}\) — прямая с наклоном +2 (при увеличении \(\log h\)); \(\log|E| = \log(u/h) = -\log h + \text{const}\) — прямая с наклоном -1. Или: слева (маленькое h) кривая идёт вниз-влево с наклоном 2 (это округление), справа — наверх с наклоном 2.
Задача 1.3. Правая разность — какой \(h_{\text{opt}}\)? Теоретически \(\sim \sqrt{u} \approx 10^{-8}\). Прогоните diff_fwd для \(h = 10^{-1}, \ldots, 10^{-15}\), найдите \(\log_{10} h_{\text{opt}}\).

§2. Экстраполяция Ричардсона

Для центральной разности \(D_h = f' + c_1 h^2 + c_2 h^4 + \ldots\). Комбинация \(R_h = (4 D_{h/2} - D_h)/3\) даёт \(R_h = f' + O(h^4)\).
Задача 2.1. Ричардсон повышает порядок. Возьмите \(h = 10^{-2}\), \(h/2 = 5\cdot 10^{-3}\). Посчитайте \(R_h\) для \(\sin\) в \(x = 1\). Ошибка должна быть \(\sim 10^{-13}\) вместо \(\sim 10^{-5}\).
