Нормы, пространства, корректность

Решение 1.Аксиомы нормы

1) Чебышёвская норма \(\|x\|_\infty = \max_{1\le i\le n} |x_i|\).

  • N1 (положительность). \(\max_i |x_i| \ge 0\); равенство нулю возможно только когда все \(|x_i| = 0\), т.е. \(x = 0\).
  • N2 (однородность). \(\|\alpha x\|_\infty = \max_i |\alpha x_i| = |\alpha|\,\max_i |x_i| = |\alpha|\,\|x\|_\infty\).
  • N3 (неравенство треугольника). Для каждого \(i\) верно \(|x_i + y_i| \le |x_i| + |y_i| \le \|x\|_\infty + \|y\|_\infty\), значит и максимум по \(i\) не превосходит правой части: \[\|x + y\|_\infty \;=\; \max_i |x_i + y_i| \;\le\; \|x\|_\infty + \|y\|_\infty.\] Ключевое место — неравенство \(|x_i + y_i| \le |x_i| + |y_i|\); это в точности неравенство треугольника для обычного модуля \(|\cdot|\) на \(\mathbb{R}\).

2) Манхэттенская норма \(\|x\|_1 = \sum_{i=1}^n |x_i|\).

  • N1. Сумма неотрицательных слагаемых неотрицательна и равна нулю тогда и только тогда, когда каждое из них нуль ⇒ \(x = 0\).
  • N2. \(\|\alpha x\|_1 = \sum_i |\alpha x_i| = |\alpha| \sum_i |x_i| = |\alpha|\,\|x\|_1\).
  • N3. Складывая покомпонентное неравенство \(|x_i + y_i| \le |x_i| + |y_i|\), получаем \[\|x + y\|_1 \;=\; \sum_i |x_i + y_i| \;\le\; \sum_i |x_i| + \sum_i |y_i| \;=\; \|x\|_1 + \|y\|_1.\]
Итогобе функции удовлетворяют аксиомам N1–N3 из Опр. 2 и, следовательно, задают норму на \(\mathbb{R}^n\); обе опираются на неравенство треугольника для модуля на \(\mathbb{R}\).
Решение 2.Задача Коши в операторной форме

Задачу (1.3)–(1.4) записываем в виде операторного уравнения (1.0):

\[ A\,u \;=\; F. \]

Оператор и правая часть. Естественный вариант — включить начальное условие в область определения:

  • \(B_1 = \{\,u(x, t)\in C^{1}(\mathbb{R}\times[0, T]) : u(x, 0) = u_0(x)\,\}\) — точное указание того, куда «упаковано» начальное условие;
  • \(A u \;:=\; u_t + a\,u_x\), \(A\colon B_1 \to B_2\);
  • \(F \equiv 0\) — правая часть тождественно нулевая (уравнение переноса однородное).
Возможна и эквивалентная запись, где \(B_1\) не заужен, а начальное условие «уводят» в правую часть отдельным уравнением; здесь принят первый, наиболее компактный вариант.

Две пары пространств \((B_1, B_2)\).

  • Равномерная норма (для гладких данных): \(\|u\|_1 = \|u\|_C = \sup_{x, t} |u(x, t)|\); \(B_2 = C(\mathbb{R}\times[0, T])\), \(\|\cdot\|_2 = \|\cdot\|_C\).
  • Интегральная норма (для оценок в среднеквадратичном): \(\|u\|_1 = \|u\|_{L_2}\); \(B_2 = L_2(\mathbb{R}\times[0, T])\), \(\|\cdot\|_2 = \|\cdot\|_{L_2}\).
Итогуравнение переноса — частный случай линейной операторной задачи \(Au = F\) с \(F \equiv 0\); выбор пар \((B_1, B_2)\) — вопрос того, в какой норме мы намерены оценивать сходимость.

Решение 4.Прямоугольная сетка в круге

Координаты узлов равномерной сетки \(x_i, y_j \in \{-1,\ -\tfrac12,\ 0,\ \tfrac12,\ 1\}\) (5×5 = 25 узлов пересечений).

Внутренние узлы \(\omega_h\) — те, для которых \(x_i^2 + y_j^2 < 1\) (строго):

\[ \omega_h = \bigl\{\,(0,0),\ (\pm\tfrac12,\,0),\ (0,\,\pm\tfrac12),\ (\pm\tfrac12,\,\pm\tfrac12)\,\bigr\}, \qquad |\omega_h| = 9. \]
Крайние узлы \((\pm 1, 0)\) и \((0, \pm 1)\) лежат на окружности, поэтому в открытую область \(\Omega\) не входят и относятся к \(\partial_h\).

Граничные узлы \(\partial_h\) — пересечения прямых сетки с окружностью \(x^2 + y^2 = 1\):

  • по вертикалям \(x = 0\), \(x = \pm\tfrac12\), \(x = \pm 1\) — точки \((0, \pm 1)\), \((\pm\tfrac12, \pm\tfrac{\sqrt3}{2})\), \((\pm 1, 0)\) — итого 8;
  • по горизонталям \(y = \pm\tfrac12\) — дополнительно \((\pm\tfrac{\sqrt3}{2}, \pm\tfrac12)\), итого ещё 4 (пересечения с \(y = 0, \pm 1\) дают точки, уже учтённые выше).
\[ |\partial_h| = 8 + 4 = 12. \]
Итог\(|\omega_h| = 9\), \(|\partial_h| = 12\), полная сетка \(|\bar\omega_h| = 21\) узел.
Зелёные точки — \(\omega_h\), коричневые — \(\partial_h\).

Решение 5.Сеточные аналоги норм \(C\) и \(L_2\)

Проектор (1.17): \(y_k = \sin(\pi k h)\). Пригодятся два наблюдения, справедливые при любом целом \(N\):

  • функция \(\sin(\pi x)\) на \([0, 1]\) симметрична относительно \(x = \tfrac12\); при чётном \(N\) в узле \(k = N/2\) значение равно \(1\);
  • тождество \(\sum_{k=1}^{N-1} \sin^2\!\bigl(\tfrac{\pi k}{N}\bigr) = \tfrac{N}{2}\) (следствие \(\sin^2\alpha = \tfrac{1 - \cos 2\alpha}{2}\) и суммирования геометрической прогрессии по \(\cos\)).

Учитывая, что \(y_0 = y_N = \sin 0 = \sin\pi = 0\), получаем при обоих способах суммирования из (1.14):

\[ \sum_{k=1}^{N} y_k^2 \;=\; \sum_{k=0}^{N-1} y_k^2 \;=\; \sum_{k=1}^{N-1} \sin^2\!\Bigl(\tfrac{\pi k}{N}\Bigr) \;=\; \frac{N}{2}. \]

Тогда обе версии сеточного \(L_2\) равны \(\sqrt{\tfrac{N}{2} \cdot h} = \sqrt{\tfrac{N}{2} \cdot \tfrac{1}{N}} = \tfrac{1}{\sqrt 2}\) — не зависят от \(N\) (и совпадают между собой).

Решение 6.Два проектора \(P_\tau\) для \(u(x) = x^2\)

Сетка \(h = \tfrac14\), \(x_k = \tfrac{k}{4}\), \(k = 0, 1, 2, 3, 4\).

Проектор (1.17) — значение в узле: \((P_\tau u)_k = x_k^2\).

Проектор (1.18). Для внутренних узлов \(k = 1, 2, 3\) пределы интегрирования — \([x_k - \tfrac{h}{2},\ x_k + \tfrac{h}{2}]\), длина ячейки \(\bar h_k = h\). Пользуемся тождеством \((a+b)^3 - (a-b)^3 = 2b\,(3a^2 + b^2)\):

\[ (P_\tau u)_k \;=\; \frac{1}{h}\!\int_{x_k - h/2}^{x_k + h/2}\! x^2\,dx \;=\; \frac{1}{3h}\cdot 2\cdot\frac{h}{2}\!\left(3 x_k^2 + \Bigl(\tfrac{h}{2}\Bigr)^{\!2}\right) \;=\; x_k^2 + \frac{h^2}{12}. \]

Для крайних узлов интеграл берётся по «половине» ячейки: \(k = 0 \Rightarrow [0,\ h/2]\), \(k = 4 \Rightarrow [1 - h/2,\ 1]\), делитель \(h/2\):

\[ (P_\tau u)_0 \;=\; \frac{2}{h}\!\int_0^{h/2}\! x^2\,dx \;=\; \frac{h^2}{12},\qquad (P_\tau u)_4 \;=\; \frac{2}{h}\!\int_{1-h/2}^1\! x^2\,dx \;=\; 1 - \frac{h}{2} + \frac{h^2}{12}. \]

Разностные схемы и шаблоны

Решение 7.Анализ шаблонов на верхнем слое

Явный трёхточечный. Узлы шаблона: \((i, n+1)\); \((i-1, n)\), \((i, n)\), \((i+1, n)\). Известные — со слоя \(n\); неизвестное — \((i, n+1)\), на верхнем слое всего 1 узел. Каждое \(y_i^{n+1}\) выражается через известные значения слоя \(n\) явной формулой; никакой системы решать не нужно.

Неявный трёхточечный. Узлы: \((i-1, n+1)\), \((i, n+1)\), \((i+1, n+1)\); \((i, n)\). Известное — \((i, n)\) (и всё, что вычислено на слоях \(\le n\)); неизвестных на слое \(n+1\) — 3 узла: \(y_{i-1}^{n+1}, y_i^{n+1}, y_{i+1}^{n+1}\). Пробегая \(i\), получаем систему линейных уравнений (при подходящих граничных условиях — трёхдиагональную), которую надо решить сразу для всего слоя.

«Крест». Узлы: \((i, n+1)\); \((i-1, n)\), \((i, n)\), \((i+1, n)\); \((i, n-1)\). Известные — со слоёв \(n\) и \(n-1\); неизвестное — \((i, n+1)\), на верхнем слое 1 узел. Явный расчёт, но для старта нужны два начальных временных слоя (задаются либо начальным условием + одношаговым разгоном по другой схеме).

Явный vs неявныйПризнак явности — ровно один неизвестный узел на верхнем слое: тогда каждое разностное уравнение — прямая формула для этого узла. Если верхний слой связан двумя и более узлами, схема неявная и требует решения линейной системы.

Погрешность, сходимость, точная схема

Решение 8.Сеточная функция погрешности

(1) Погрешность (Опр. 7). С проектором (1.17) \((P_{\tau\omega} u)_k = \sin(\pi x_k)\), поэтому

\[ z_k \;=\; y_k - \sin(\pi x_k) \;=\; (-1)^k\cdot 10^{-2}, \qquad k = 0, 1, \ldots, 10. \]

Значения \(z_k\) чередуются: \(+10^{-2}, -10^{-2}, +10^{-2}, \ldots\).

(2) Норма \(C\) по (1.13):

\[ \|z\|_C \;=\; \max_{0 \le k \le 10} |z_k| \;=\; 10^{-2}. \]

(3) Сеточная норма \(L_2\) по (1.14), сумма \(k = 0..N-1 = 0..9\); все \(|z_k| = 10^{-2}\), поэтому \(z_k^2 = 10^{-4}\), а сумма содержит 10 таких слагаемых:

\[ \|z\|_{L_2, h} \;=\; \Bigl(\sum_{k=0}^{9} z_k^2\,h\Bigr)^{1/2} \;=\; \bigl(10 \cdot 10^{-4} \cdot 10^{-1}\bigr)^{1/2} \;=\; \bigl(10^{-4}\bigr)^{1/2} \;=\; 10^{-2}. \]

(4) Что это говорит о сходимости (Опр. 8). Опр. 8 требует, чтобы норма погрешности могла быть сделана меньше любого наперёд заданного \(\varepsilon > 0\) за счёт выбора \(N\) (и расположения узлов). Мы имеем одну точку — при \(h = 1/10\) обе нормы равны \(10^{-2}\). Это ничего не говорит ни о сходимости, ни о её отсутствии: чтобы делать вывод, нужно провести серию измерений при \(h, h/2, h/4, \ldots\) и убедиться, что \(\|z\|_{1,H} \to 0\) при \(h \to 0\). Только тогда, если для любого \(\varepsilon\) удаётся подобрать \(N\), — по Опр. 8 схема сходится.

Решение 9.Точная схема (Опр. 9)

(1) Подстановка \(a\tau/h = 1\).

\[ y_i^{n+1} \;=\; y_i^n - 1\cdot\bigl(y_i^n - y_{i-1}^n\bigr) \;=\; y_{i-1}^n. \]

(2) Индукция по \(n\) для утверждения \(y_i^n = u_0(x_i - a\,t_n)\).

  • База, \(n = 0\). По условию \(y_i^0 = u_0(x_i)\), а \(t_0 = 0\), значит \(y_i^0 = u_0(x_i - a \cdot 0) = u_0(x_i - a t_0)\).
  • Переход. Пусть \(y_i^n = u_0(x_i - a t_n)\). Тогда \[ y_i^{n+1} \;\overset{(1)}{=}\; y_{i-1}^n \;=\; u_0(x_{i-1} - a t_n) \;=\; u_0(x_i - h - a t_n). \] Используем условие связи шагов: \(a\tau = h\). Значит \(h + a t_n = a\tau + a\cdot n\tau = a(n+1)\tau = a\,t_{n+1}\). Подставляя: \[ y_i^{n+1} \;=\; u_0(x_i - a\,t_{n+1}). \] Индукционный шаг доказан.

(3) Точная схема (Опр. 9). Точное решение задачи Коши \(u_t + a u_x = 0\), \(u(x, 0) = u_0(x)\) — это перенос начального условия вдоль характеристик: \[ u(x, t) = u_0(x - a t). \] В узлах сетки \(u(x_i, t_n) = u_0(x_i - a t_n) = y_i^n\) (по пункту 2), поэтому сеточная функция погрешности из Опр. 7

\[ z_i^n \;=\; y_i^n - (P_{\tau\omega}\,u)_i^n \;=\; 0 \quad \forall\,i,\ n. \]

По Опр. 9 (\(\|z\|_{1,H} = 0\)) — схема точна на сетке \(G_h\) при условии \(a\tau/h = 1\), причём для произвольного начального условия \(u_0(x)\).

Смыслусловие \(a\tau/h = 1\) (число Куранта, равное единице) синхронизирует шаг схемы с характеристикой уравнения переноса: за один шаг \(\tau\) значение сдвигается ровно на один узел \(h\) — то же, что делает точное решение. Ошибки просто некуда взяться.

Решение 10.Верификация и валидация

1) Верификация — «решаем уравнения правильно».

  1. Сравнение с аналитическим решением. Модельная задача: \(u_t + u_x = 0\) на периоде \([0, 1]\) с \(u_0(x) = \sin(2\pi x)\); точное решение — \(u(x, t) = \sin(2\pi(x - t))\). Считаем при \(t = 1\) (волна должна сделать один полный оборот), сравниваем \(y_i^N\) с \(u(x_i, 1) = \sin(2\pi x_i) = u_0(x_i)\). При \(a\tau/h = 1\) должно совпасть с машинной точностью (Задача 9); при иных значениях числа Куранта — ошибка должна убывать с уменьшением шагов.
  2. Исследование сходимости (grid refinement). Считаем на серии сеток \(h, h/2, h/4, h/8, h/16\), для каждой — \(\varepsilon_h = \|y - u\|_C\) (или \(L_2\)). На log-log графике \((\log h,\ \log\varepsilon)\) точки должны лечь на прямую с наклоном 1 — теоретический порядок схемы-«уголок» равен \(p = 1\). Наклон меньше единицы или излом графика — сигнал, что в реализации ошибка.

2) Валидация — «решаем правильные уравнения».

  1. Сравнение с экспериментом. Если моделируем реальный процесс — например, перенос красителя пассивным течением в лабораторной трубе, — сравниваем расчётное распределение концентрации с измеренным. В отличие от верификации, здесь под вопрос ставится не программа, а сама модель: «Правда ли, что \(u_t + a\,u_x = 0\) достаточно описывает наш процесс, или мы забыли диффузию, сжимаемость, что-то ещё?»
  2. Границы применимости модели. Уравнение \(u_t + u_x = 0\) — линейное, беcдиссипативное, скалярное. Валидация ставит вопрос: при каких режимах \((Re, Pe, \text{Mach})\) допущение об отсутствии диссипации остаётся адекватным, а где начинает влиять пренебрегаемая физика (диффузия, вязкость, нелинейность).

3) Верификация ≠ валидация — на примерах.

  • Верификация пройдена, валидация провалена. Программа корректно решает уравнение переноса — на всех модельных задачах наблюдается теоретический порядок сходимости. Но применяют её к переносу тепла в металлическом стержне, где на самом деле доминирует диффузия (\(u_t = \kappa\,u_{xx}\)). Результат расчёта не будет иметь ничего общего с реальным профилем температуры — не из-за ошибки в программе, а из-за неадекватности модели.
  • Валидация пройдена, верификация провалена. Программа решает уравнения Навье – Стокса — модель, физически адекватную для течения жидкости. Но в схеме допущена ошибка в разностном операторе: на грубой сетке результат случайно попадает в диапазон измерений (валидация даже «слабо» проходит). Grid refinement, однако, порядок сходимости не показывает, а при измельчении сетки решение начинает уходить от эксперимента — верификация ловит эту ошибку.
Почему одна не заменяет другуюверификация отвечает на вопрос «правильно ли алгоритм решает заданную математическую задачу»; валидация — «правильно ли заданная математическая задача описывает реальность». Между ними нет причинно-следственной связи: адекватную модель можно испортить реализацией; корректно реализованную программу можно применить к неверной модели.
