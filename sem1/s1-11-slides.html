§11 · Семестр 1

Линейные схемы с положительными коэффициентами

Для линейных схем с постоянными коэффициентами консервативность определяется суммой коэффициентов, а монотонность, принцип максимума, устойчивость в равномерной норме и TVD-свойство — одним и тем же условием: все коэффициенты неотрицательны.

Определение · Консервативность · Монотонность · Устойчивость в \(C\) · TVD · Итог

Схема \(y_i^{n+1} = \sum_k a_k\, y_{i+k}^n\) с постоянными коэффициентами; свойства — из §8–§10.

§11.1 · Определение 1

Схема с положительными коэффициентами

Рассмотрим явную линейную схему с постоянными коэффициентами; \(S\) — шаблон, то есть конечное множество целых сдвигов \(k\):

\[ y_i^{n+1} = \sum_{k\in S} a_k\, y_{i+k}^n . \tag{11.1} \]
Определение. Схема (11.1) называется схемой с положительными (точнее, неотрицательными) коэффициентами, если \(a_k \ge 0\) для всех \(k \in S\).

Новое значение в такой схеме — взвешенная сумма значений старого слоя на шаблоне с неотрицательными весами.

Противопоточная схема \(y_i^{n+1} = (1 - r)\,y_i^n + r\,y_{i-1}^n\) при \(0 \le r \le 1\) и схема Лакса–Фридрихса при \(|r| \le 1\) — схемы с положительными коэффициентами. У схемы Лакса–Вендроффа при \(0 < r < 1\) коэффициент \(a_{+1} = r(r-1)/2\) отрицателен.

Далее выясним, какие свойства схемы определяются знаком коэффициентов, а какие — их суммой.

§11.2 · Теорема 1

Консервативность определяется суммой коэффициентов

Теорема 1. Схема (11.1) записывается в консервативной форме (8.2) с линейным численным потоком тогда и только тогда, когда \[ \sum_{k\in S} a_k = 1 . \tag{11.2} \]
Необходимость. В консервативной схеме на периодической сетке потоки сокращаются, и \(\sum_i y_i^{n+1} = \sum_i y_i^n\). С другой стороны, из (11.1) \(\sum_i y_i^{n+1} = \bigl(\sum_k a_k\bigr)\sum_i y_i^n\); взяв \(y^n\) с \(\sum_i y_i^n \ne 0\), получаем (11.2).
Достаточность. При (11.2) \(y_i^{n+1} - y_i^n = \sum_k a_k\,(y_{i+k}^n - y_i^n)\). Каждая разность \(y_{i+k} - y_i\) — сумма разностей соседних значений, поэтому правая часть равна \(G_{i+1/2} - G_{i-1/2}\) с линейным \(G\); это форма (8.2) с потоком \(F = -(h/\tau)\,G\). ∎

Знак коэффициентов для консервативности не важен: схема Лакса–Вендроффа консервативна, хотя у неё есть отрицательный коэффициент.

§11.3 · Теорема 2

Монотонность и принцип максимума

Теорема 2. Схема (11.1) монотонна (оператор перехода не убывает по каждому аргументу) тогда и только тогда, когда \(a_k \ge 0\) для всех \(k\). При выполнении (11.2) это равносильно дискретному принципу максимума \[ \min_j y_j^n \le y_i^{n+1} \le \max_j y_j^n . \]
Для (11.1) \(\partial y_i^{n+1}/\partial y_{i+k}^n = a_k\), откуда первое утверждение. Если \(a_k \ge 0\) и \(\sum_k a_k = 1\), то \(y_i^{n+1}\) — выпуклая комбинация значений \(y^n_{i+k}\) и лежит между их минимумом и максимумом. Обратно, если \(a_m < 0\), возьмём \(y^n_{i+m} = 1\) и нули в остальных узлах: тогда \(y_i^{n+1} = a_m < 0 = \min_j y_j^n\). ∎

Отрицательный коэффициент создаёт новый экстремум, которого не было на старом слое; у разрыва это проявляется как осцилляции.

§11.4 · Теорема 3

Устойчивость в равномерной норме

Теорема 3. Пусть выполнено (11.2). Неравенство \(\max_i |y_i^{n+1}| \le \max_i |y_i^n|\) выполняется для всех \(y^n\) тогда и только тогда, когда \(a_k \ge 0\) для всех \(k\).
Из (11.1) \(|y_i^{n+1}| \le \sum_k |a_k|\,\max_j |y_j^n|\), и равенство достигается при \(y^n_{i+k} = \operatorname{sign} a_k\); значит, наибольший множитель роста за шаг равен \(\sum_k |a_k|\). При (11.2) \(\sum_k |a_k| \ge \sum_k a_k = 1\), и равенство \(\sum_k |a_k| = 1\) выполняется только при всех \(a_k \ge 0\). ∎

Теорема доказывается одним неравенством, без гармоник, и переносится на схемы с переменными коэффициентами \(a_{ik} \ge 0\), \(\sum_k a_{ik} = 1\). Вместе с аппроксимацией она даёт по теореме Лакса (§3) сходимость в норме \(C\).

§11.5 · Теорема 4

TVD-свойство

Теорема 4. Пусть выполнено (11.2). Схема (11.1) является TVD тогда и только тогда, когда \(a_k \ge 0\) для всех \(k\).
Достаточность (§8). Разности нового слоя — та же комбинация разностей старого: \(\Delta^{n+1}_{i+1/2} = \sum_k a_k\,\Delta^n_{i+k+1/2}\). По неравенству треугольника и после суммирования по \(i\): \(\mathrm{TV}(y^{n+1}) \le \sum_k a_k\,\mathrm{TV}(y^n) = \mathrm{TV}(y^n)\).
Необходимость (§10). Один шаг по единичной ступеньке даёт \(\mathrm{TV}(y^1) = \sum_k |a_k|\); это не больше \(\mathrm{TV}(y^0) = 1\) только при \(a_k \ge 0\). ∎

Условие то же, что в теоремах 2 и 3.

§11.6 · Итог

Для линейных схем все пять свойств равносильны

Для линейной схемы (11.1) с \(\sum_k a_k = 1\) неотрицательность коэффициентов, монотонность, принцип максимума, устойчивость в равномерной норме и TVD-свойство равносильны. Для нелинейных схем (§10) остаются только стрелки слева направо: TVD-схема может не быть монотонной.

По теореме Годунова (§9) схема с положительными коэффициентами имеет первый порядок аппроксимации. Поэтому схема второго порядка без осцилляций обязана быть нелинейной (ограничители потока, §10) или содержать искусственную вязкость (§13).
