§8 · Определение 1

Консервативная форма и численный поток

Закон сохранения \(u_t + f(u)_x = 0\); для переноса \(f(u) = au\).

Схема консервативна, если записывается в виде \[ y_j^{n+1} = y_j - \frac{\tau}{h}\bigl(F_{j+1/2} - F_{j-1/2}\bigr), \tag{8.2} \] где численный поток \(F_{j+1/2} = F(y_{j-p+1}, \dots, y_{j+q})\) — одна и та же функция для всех \(j\): поток \(F_{j+1/2}\) входит в уравнения ячеек \(j\) и \(j+1\) с противоположными знаками. Согласованность: \(F(y, \dots, y) = f(y)\).
АналогИнтегральный закон сохранения на ячейке \([x_{j-1/2}, x_{j+1/2}]\) за шаг \(\tau\): изменение массы в ячейке = поток через левую границу − поток через правую. Сумма по \(j\): \[ \sum_j y_j^{n+1}h = \sum_j y_j^n h - \tau\bigl(F_{\text{прав}} - F_{\text{лев}}\bigr). \]
РольВнутренние потоки сокращаются — масса меняется только через границы; на периодической сетке \(\sum_j y_j h\) сохраняется точно.
Для переноса удобно \(G_{j+1/2} = F_{j+1/2}/a\): \[ y_j^{n+1} = y_j - r\bigl(G_{j+1/2} - G_{j-1/2}\bigr), \quad G(y,\dots,y) = y. \]

Зачем это нужно на разрывах — теорема Лакса–Вендроффа.

§8 · Теорема Лакса–Вендроффа

Только консервативная схема ловит правильную скорость разрыва

Аппроксимация на гладком решении у консервативной и неконсервативной схем одинаковая; различие — на разрыве.

Теорема (Лакс, Вендрофф, 1960). Пусть схема (8.2) консервативна, поток непрерывен и согласован, и при \(h, \tau \to 0\), \(r = \mathrm{const}\), решения сходятся в \(L^1_{\mathrm{loc}}\) к функции \(u\) с ограниченной полной вариацией. Тогда \(u\) — слабое решение \(u_t + f(u)_x = 0\); на разрыве выполнено условие Ренкина–Гюгонио \(s = [f]/[u]\).
Опыт: уравнение Бюргерса \(f = u^2/2\), \(u_l = 1{,}2\), \(u_r = 0{,}4\), скачок из \(x = 0{,}25\); \(s = (u_l + u_r)/2 = 0{,}8\). Схемы против потока, \(N = 400\), \(t = 0{,}5\): \[ \text{конс.: } y_j - \tfrac{\tau}{h}\Bigl(\tfrac{y_j^2}{2} - \tfrac{y_{j-1}^2}{2}\Bigr), \qquad \text{неконс.: } y_j - \tfrac{\tau}{h}\,y_j\,(y_j - y_{j-1}). \]

§8 · Приведение к потоку · пример 1

Как выделить поток: рецепт и «уголок»

1
Вычесть \(y_j\), вынести \(-r\)
\(y_j^{n+1} - y_j = -r\,[\ \dots\ ]\); скобка должна стать разностью «правая граница − левая».
2
Разности через \(\Delta\)
\(y_{j+1} - y_{j-1} = \Delta_{j+1/2} + \Delta_{j-1/2}\), \(\ y_{j+1} - 2y_j + y_{j-1} = \Delta_{j+1/2} - \Delta_{j-1/2}\).
3
Подобрать \(G_{j+1/2}\)
\(G_{j-1/2}\) — тот же \(G_{j+1/2}\) со сдвигом всех индексов на \(-1\). Не подбирается — \(G_{j+1/2} = \sum_k b_k y_{j+k}\) с неизвестными \(b_k\), как в §7.
4
Проверка
согласованность \(G(y, \dots, y) = y\); раскрыть \(G_{j+1/2} - G_{j-1/2}\) и сравнить со схемой.
Пример 1: «уголок» \[ y_j^{n+1} = y_j - r\,(y_j - y_{j-1}) = y_j - r\bigl(\underbrace{y_j}_{G_{j+1/2}} - \underbrace{y_{j-1}}_{G_{j-1/2}}\bigr) \] \(G_{j+1/2} = y_j\): через границу \(j+\tfrac12\) переносится значение из ячейки против потока.
Когда поток существуетЛинейная схема \(y_j^{n+1} = \sum_\mu \alpha_\mu y_{j+\mu}\) с постоянными коэффициентами приводится к виду (8.2) тогда и только тогда, когда \(\sum_\mu\alpha_\mu = 1\) — константа переносится точно (шаг 3 даёт разрешимую систему для \(b_k\)).

Пример 2 — схема Лакса–Вендроффа: поток содержит «уголок» и поправку.

§8 · Приведение к потоку · пример 2, шаги 1–2

Лакс–Вендрофф: скобка через разности \(\Delta_{j\pm 1/2}\)

Трёхточечная схема второго порядка; поток окажется «уголком» плюс поправка.

\[ y_j^{n+1} = y_j - \frac r2\,(y_{j+1} - y_{j-1}) + \frac{r^2}{2}\,(y_{j+1} - 2y_j + y_{j-1}) \]
Шаг 1: вынести множитель \[ y_j^{n+1} - y_j = -r\Bigl[\tfrac12\,(y_{j+1} - y_{j-1}) - \tfrac r2\,(y_{j+1} - 2y_j + y_{j-1})\Bigr] \]
Шаг 2: через разности соседей \[ \begin{aligned}[\ \dots\ ] &= \tfrac12\bigl(\Delta_{j+1/2} + \Delta_{j-1/2}\bigr) - \tfrac r2\bigl(\Delta_{j+1/2} - \Delta_{j-1/2}\bigr)\\ &= \tfrac{1 - r}{2}\,\Delta_{j+1/2} + \tfrac{1 + r}{2}\,\Delta_{j-1/2}\end{aligned} \]
Коэффициенты при \(\Delta_{j+1/2}\) и \(\Delta_{j-1/2}\) разные — скобка ещё не разность сдвигов. Выделяем «уголок»: \(\tfrac{1+r}{2} = 1 - \tfrac{1-r}{2}\), откуда \[ [\ \dots\ ] = \underbrace{\Delta_{j-1/2}}_{y_j - y_{j-1}} + \tfrac{1-r}{2}\bigl(\Delta_{j+1/2} - \Delta_{j-1/2}\bigr). \]

Оба слагаемых — разности сдвигов одной функции.

§8 · Приведение к потоку · пример 2, шаги 3–4

Поток Лакса–Вендроффа = «уголок» + антидиффузионная поправка

Из последней формулы поток читается сразу; поправка снимает схемную вязкость «уголка».

\[ G^{\mathrm{ЛВ}}_{j+1/2} = \underbrace{y_j}_{\text{«уголок»}} + \underbrace{\frac{1 - r}{2}\,\Delta_{j+1/2}}_{\text{поправка}}, \qquad G(y, y) = y. \]
Шаг 4: проверка \(G_{j+1/2} - G_{j-1/2} = (y_j - y_{j-1}) + \tfrac{1-r}{2}\bigl(\Delta_{j+1/2} - \Delta_{j-1/2}\bigr)\) — скобка шага 2.
Вклад поправки в схему: \(-\tfrac{r(1-r)}{2}\,(y_{j+1} - 2y_j + y_{j-1})\) — вторая разность с отрицательным коэффициентом: снимает вязкость \(\nu = \tfrac{ah}{2}(1-r)\) «уголка» (§5).
# F[j] = F_{j+1/2},  np.roll(F, 1)[j] = F_{j-1/2}
def step_flux(u, r, flux):
    F = flux(u, r)
    return u - r * (F - np.roll(F, 1))

def flux_upwind(u, r):
    return u.copy()                     # y_j

def flux_lw(u, r):                      # y_j + (1-r)/2 Δ_{j+1/2}
    return u + 0.5*(1 - r)*(np.roll(u, -1) - u)
Проверка в коде: \(\max_j|\)step_lw(u) − step_flux(u, r, flux_lw)\(|\sim 10^{-16}\).

Поправку можно брать частично: множитель \(\varphi\) от 0 («уголок») до 1 (ЛВ). Почему его нельзя взять постоянным — теорема Годунова.

§8, §10 · Определения 2–6

Монотонность, принцип максимума, полная вариация

Три способа сказать «схема не рождает осцилляций»: поточечно, через экстремумы, через сумму скачков.

Монотонная схема (Годунов): \(y_j^{n+1} = H(y_{j-p}, \dots, y_{j+q})\), \(H\) не убывает по каждому аргументу. Для линейной \(y_j^{n+1} = \sum_\mu\alpha_\mu y_{j+\mu}\): \(\alpha_\mu \ge 0\) для всех \(\mu\) (8.4).
Принцип максимума: \(\min\limits_{\text{шаблон}} y \le y_j^{n+1} \le \max\limits_{\text{шаблон}} y\). Для линейной схемы \(\iff\) \(\alpha_\mu \ge 0\), \(\sum\alpha_\mu = 1\) (8.6).
Полная вариация \[ \mathrm{TV}(y) = \sum_j |\Delta_{j+1/2}| = \sum_j |y_{j+1} - y_j|. \tag{8.7} \]
TVD-схема (Хартен, 1983): \(\mathrm{TV}(y^{n+1}) \le \mathrm{TV}(y^n)\) при любых данных (8.8).
АналогТочное решение переноса — сдвиг профиля: экстремумы не появляются, \(\mathrm{TV}\) постоянна. Осцилляция с амплитудой \(\delta\) добавляет к \(\mathrm{TV}\) величину \(2\delta\).
РольМонотонность — локальное условие на коэффициенты; TVD — одно неравенство на весь слой, проверяемое и для нелинейной схемы (лемма Хартена).

Как связаны монотонность и TVD — две короткие теоремы.

§8, §10 · Теорема 1

Для линейных схем: монотонность \(\iff\) TVD

Прямое утверждение верно для любых схем; обратное — только для линейных, и доказывается одной ступенькой.

(а) Монотонная линейная схема с \(\sum\alpha_\mu = 1\) является TVD. (б) Линейная TVD-схема с \(\sum\alpha_\mu = 1\) монотонна: \(\alpha_\mu \ge 0\) для всех \(\mu\).
(а) \(\Delta^{n+1}_{j+1/2} = \sum_\mu \alpha_\mu\,\Delta_{j+\mu+1/2}\). Так как \(\alpha_\mu \ge 0\): \[ |\Delta^{n+1}_{j+1/2}| \le \sum_\mu \alpha_\mu\,|\Delta_{j+\mu+1/2}|. \] Суммируем по \(j\), меняем порядок: \[ \mathrm{TV}(y^{n+1}) \le \sum_\mu \alpha_\mu \sum_j |\Delta_{j+\mu+1/2}| = \mathrm{TV}(y^n). \]
(б) Ступенька: \(y_j^0 = 1\) при \(j \le 0\), \(0\) при \(j > 0\); единственный скачок \(\Delta^0_{1/2} = -1\), \(\mathrm{TV} = 1\). Через шаг \[ \Delta^1_{j+1/2} = -\alpha_{-j}, \qquad \mathrm{TV}(y^1) = \sum_\mu |\alpha_\mu| \ge \Bigl|\sum_\mu\alpha_\mu\Bigr| = 1, \] равенство — только при \(\alpha_\mu \ge 0\) для всех \(\mu\). ∎

Для линейных схем остаётся выяснить, какой порядок совместим с \(\alpha_\mu \ge 0\).

§9 · Теорема Годунова

Линейная монотонная схема — не выше первого порядка

Три строки в условиях порядка §7: «дисперсия» неотрицательных весов вокруг точки \(-r\) обязана быть нулём.

(Годунов, 1959). Линейная схема \(y_j^{n+1} = \sum_\mu\alpha_\mu y_{j+\mu}\) для \(u_t + au_x = 0\) с \(\alpha_\mu \ge 0\) при нецелом \(r\) имеет порядок аппроксимации не выше первого. По теореме 1 — то же для линейных TVD-схем.
Условия порядка 2 (теорема 1 §7, \(\sum\alpha_\mu(-\mu)^k = r^k\), \(k = 0, 1, 2\)): \[ \sum_\mu\alpha_\mu = 1, \qquad \sum_\mu\alpha_\mu\,\mu = -r, \qquad \sum_\mu\alpha_\mu\,\mu^2 = r^2. \] Отсюда \[ \sum_\mu \alpha_\mu\,(\mu + r)^2 = r^2 - 2r\cdot r + r^2\cdot 1 = 0. \] При \(\alpha_\mu \ge 0\) каждое слагаемое равно нулю: \(\alpha_\mu \ne 0\) только при \(\mu = -r\). Для нецелого \(r\) таких \(\mu\) нет — противоречие с \(\sum\alpha_\mu = 1\). ∎
Геометрия §7На плоскости \((\alpha_{-2}, \alpha_0)\) прямая схем второго порядка не заходит в четырёхугольник неотрицательности при \(0 \lt r \lt 1\).
Следствие. Второй порядок без осцилляций — только у нелинейной схемы: коэффициенты зависят от решения.

Для нелинейной схемы теорема 1 не работает — нужен другой инструмент проверки TVD.

§8, §10 · Лемма Хартена

Лемма Хартена: проверка TVD для нелинейной схемы

Коэффициенты могут зависеть от решения — важно лишь, чтобы при каждом \(\Delta\) они были неотрицательны.

Лемма (Хартен, 1983). Пусть схема записана в приращениях \[ y_j^{n+1} = y_j + C_{j+1/2}\,\Delta_{j+1/2} - D_{j-1/2}\,\Delta_{j-1/2}, \tag{8.9} \] где \(C, D\) могут зависеть от \(y^n\), и для всех \(j\): \(C_{j+1/2} \ge 0\), \(D_{j+1/2} \ge 0\), \(C_{j+1/2} + D_{j+1/2} \le 1\). Тогда схема TVD.
Вычитаем уравнения для \(j+1\) и \(j\): \[ \Delta^{n+1}_{j+1/2} = \bigl(1 - C_{j+1/2} - D_{j+1/2}\bigr)\Delta_{j+1/2} + C_{j+3/2}\,\Delta_{j+3/2} + D_{j-1/2}\,\Delta_{j-1/2}. \] Все три множителя \(\ge 0\). Модуль, сумма по \(j\), сдвиг индексов: при \(|\Delta_{j+1/2}|\) собирается \((1 - C - D) + C + D = 1\): \[ \mathrm{TV}(y^{n+1}) \le \mathrm{TV}(y^n). \ ∎ \]
Пример: «уголок»\(y_j - r\,\Delta_{j-1/2}\): \(C = 0\), \(D = r\); условия леммы \(\iff\) \(0 \le r \le 1\).

Лакс–Вендрофф с постоянными \(C, D \ge 0\) не записывается: на ступеньке рождает осцилляцию (упражнение ниже).

Применим лемму к потоку «уголок» + \(\varphi\,\cdot\) поправка и найдём, каким должен быть \(\varphi\).

§10 · Определение 7

Ограничитель потока \(\varphi(\theta)\)

Поправка Лакса–Вендроффа умножается на число, вычисленное по самому решению: на гладком участке \(\approx 1\), у разрыва и экстремума — меньше.

Схема с ограничителем потока (\(a > 0\)): \[ G_{j+1/2} = y_j + \frac{1 - r}{2}\,\varphi(\theta_j)\,\Delta_{j+1/2}, \qquad \theta_j = \frac{y_j - y_{j-1}}{y_{j+1} - y_j} = \frac{\Delta_{j-1/2}}{\Delta_{j+1/2}}, \tag{10.5} \] \(\varphi\) — заданная функция, ограничитель; схема — \(y_j^{n+1} = y_j - r\bigl(G_{j+1/2} - G_{j-1/2}\bigr)\).
Индикатор гладкости
  • гладкий монотонный участок: \(\theta_j = 1 + O(h)\);
  • экстремум: разности разного знака, \(\theta_j \lt 0\);
  • перед скачком \(\theta_j \to 0\), за скачком \(\theta_j \to \infty\).
Частные случаи\(\varphi \equiv 0\) — «уголок»; \(\varphi \equiv 1\) — Лакс–Вендрофф. Постоянное \(\varphi\) — линейная схема: по теореме 2 либо первый порядок, либо осцилляции. Нелинейность — только через \(\theta_j\).
При \(\Delta_{j+1/2} = 0\) поправка равна нулю при любом \(\theta_j\).

Что именно делает число φ на грани — три прочтения.

§10 · Что такое \(\varphi\)

Три прочтения \(\varphi\): вес, вязкость, ограниченная разность

Одна формула (10.5) — три способа понять, что делает число \(\varphi(\theta_j)\) на грани \(j+\tfrac12\).

1 · доля ЛВ в потоке \[ G_{j+1/2} = (1 - \varphi)\,G^{\text{уг}}_{j+1/2} + \varphi\,G^{\text{ЛВ}}_{j+1/2} \] \(\varphi = 0\) — «уголок», \(\varphi = 1\) — ЛВ, \(0 \lt \varphi \lt 1\) — смесь, \(\varphi > 1\) — поправка с запасом (superbee: до 2). Вес свой на каждой грани и на каждом шаге.
2 · схемная вязкость При \(\varphi \approx \mathrm{const}\) на участке первое дифференциальное приближение (§5) имеет вязкость \[ \nu_\varphi = \frac{ah}{2}\,(1 - r)\,(1 - \varphi). \] \(\varphi = 0\): как у «уголка»; \(\varphi = 1\): ноль; \(\varphi > 1\): \(\nu \lt 0\) — обострение; \(\varphi \lt 0\): вязче «уголка».
3 · ограниченная разность В потоке вместо \(\Delta_{j+1/2}\) стоит \(\varphi(\theta_j)\,\Delta_{j+1/2}\). Для minmod \[ \varphi(\theta_j)\,\Delta_{j+1/2} = \mathrm{minmod}\bigl(\Delta_{j-1/2}, \Delta_{j+1/2}\bigr): \] разные знаки — 0, иначе меньшая по модулю.
\(\varphi\) — решение, принимаемое на каждой грани: сколько второго порядка можно позволить здесь, глядя на отношение соседних разностей \(\theta_j\).

Отношение \(\theta_j\) берётся против потока — что меняется при \(a \lt 0\).

§10 · Направление потока

От знака \(a\) зависят «уголок», знак поправки и сторона \(\theta\)

\(\theta\) — всегда отношение разности выше по потоку к разности на самой грани; функция \(\varphi\) и диаграмма Свеби не меняются.

скорость положительна — информация слева \[ G_{j+1/2} = y_j + \frac{1 - r}{2}\,\varphi(\theta^+_j)\,\Delta_{j+1/2}, \qquad \theta^+_j = \frac{\Delta_{j-1/2}}{\Delta_{j+1/2}} \]
\(y_{j-1}\ \cdots\ y_j\ \longrightarrow\ \bigl|_{\,j+1/2}\ \ y_{j+1}\)
скорость отрицательна — информация справа \[ G_{j+1/2} = y_{j+1} - \frac{1 - |r|}{2}\,\varphi(\theta^-_{j+1})\,\Delta_{j+1/2}, \qquad \theta^-_{j+1} = \frac{\Delta_{j+3/2}}{\Delta_{j+1/2}} \]
\(y_j\ \ \bigl|_{\,j+1/2}\ \longleftarrow\ y_{j+1}\ \cdots\ y_{j+2}\)
Единая запись \[ F_{j+1/2} = a^+ y_j + a^- y_{j+1} + \frac{|a|}{2}\,(1 - |r|)\,\varphi(\theta_{\text{вверх}})\,\Delta_{j+1/2}, \qquad a^\pm = \tfrac{a \pm |a|}{2}. \] При \(\varphi \equiv 1\) — поток ЛВ \(\tfrac a2(y_j + y_{j+1}) - \tfrac{ar}{2}\Delta_{j+1/2}\) при любом знаке \(a\). Для нелинейного \(f(u)\) знак берётся на каждой грани по \(a_{j+1/2}\).

\(\theta\) с другой стороны делает ограничитель слепым к приходящему фронту — осцилляции перед ним. Дальше — какие \(\varphi\) допустимы.

§10 · Теорема 3 (Свеби)

Условие TVD для ограничителя: область Свеби

Схема (10.5) приводится к виду леммы Хартена с \(C = 0\) и коэффициентом \(D\), зависящим от решения.

Так как \(\Delta_{j+1/2} = \Delta_{j-1/2}/\theta_j\), при \(\varphi_j = \varphi(\theta_j)\): \[ y_j^{n+1} = y_j - D_{j-1/2}\,\Delta_{j-1/2}, \qquad D_{j-1/2} = r\Bigl[1 + \frac{1-r}{2}\Bigl(\frac{\varphi_j}{\theta_j} - \varphi_{j-1}\Bigr)\Bigr]. \] Если \(0 \le \varphi(\theta)/\theta \le 2\) и \(0 \le \varphi(\theta) \le 2\), скобка при \(\tfrac{1-r}{2}\) лежит в \([-2, 2]\): \[ r^2 \le D_{j-1/2} \le r(2 - r) = 1 - (1-r)^2 \le 1 \quad (0 \le r \le 1). \] Лемма Хартена с \(C = 0\) даёт TVD. ∎
Схема (10.5) при \(0 \le r \le 1\) является TVD, если \[ \varphi(\theta) = 0 \ \ (\theta \le 0), \qquad 0 \le \varphi(\theta) \le \min(2\theta,\, 2) \ \ (\theta > 0). \tag{10.6} \] В экстремуме (\(\theta \le 0\)) поправка выключена — схема локально становится «уголком».

Область (10.6) не требует второго порядка — его даёт условие \(\varphi(1) = 1\).

§10 · Диаграмма Свеби

Второй порядок и четыре ограничителя

Второй порядок на гладком монотонном участке (\(\theta \approx 1\)) — при \(\varphi(1) = 1\) и липшицевом \(\varphi\) рядом с единицей.

Ограничители \[ \begin{aligned} &\text{minmod:} && \max\bigl(0, \min(1, \theta)\bigr)\\ &\text{superbee:} && \max\bigl(0, \min(2\theta, 1), \min(\theta, 2)\bigr)\\ &\text{van Leer:} && \frac{\theta + |\theta|}{1 + |\theta|}\\ &\text{MC:} && \max\bigl(0, \min(2\theta, \tfrac{1+\theta}{2}, 2)\bigr) \end{aligned} \] Все четыре: \(\varphi(1) = 1\), \(\varphi = 0\) при \(\theta \le 0\), внутри (10.6).
Светлое — область TVD (10.6); тёмное — коридор второго порядка. minmod — нижний край коридора, superbee — верхний край области TVD.

§10 · Как читать диаграмму Свеби

Диаграмма Свеби: «увидел \(\theta\) — взял \(\varphi\)»

По горизонтали — что схема видит на грани, по вертикали — какую долю поправки ЛВ берёт.

Как читать
  1. Вертикаль при данном \(\theta\): светлый отрезок — допустимые \(\varphi\). При \(\theta \le 0\) — только \(\varphi = 0\); при \(\theta = \tfrac12\) — \([0, 1]\); при \(\theta \ge 1\) — \([0, 2]\).
  2. Границы: \(\varphi = 0\) — «уголок»; \(\varphi \le 2\theta \iff \varphi\,\Delta_{j+1/2} \le 2\Delta_{j-1/2}\) — не отдать больше, чем пришло сверху по потоку (иначе перелёт); \(\varphi \le 2\) — то же для соседней грани.
  3. Точка \((1, 1)\): на гладком участке схема — ЛВ; тёмный коридор между \(\varphi = 1\) и \(\varphi = \theta\) — второй порядок.
  4. Выше — круче, ниже — вязче: растёт доля ЛВ, падает \(\nu_\varphi\): minmod → van Leer, MC → superbee.

§10 · Цена TVD

Срезание экстремумов: в гладком максимуме — первый порядок

В экстремуме \(\theta_j \lt 0\), ограничитель обнуляет поправку — схема локально становится «уголком».

Почему так должно бытьМаксимум точного решения обычно лежит между узлами; после сдвига узловой максимум должен вырасти. TVD-схема этого не допускает — вершина срезается. В нелинейном экстремуме TVD-схема не лучше первого порядка (Ошер, 1984).
