I. МатрицыIIIIIIVV§9.0. Пример: неявная схема

Откуда берётся система: неявная схема

Уравнение \(u_t=u_{xx}\), неявная схема: вторая производная на новом слое. С \(\sigma=\tau/h^2\):

\[-\sigma\,y_{i-1}^{n+1}+(1+2\sigma)\,y_i^{n+1}-\sigma\,y_{i+1}^{n+1}=y_i^n,\qquad i=1,\ldots,n.\]

Каждое уравнение связывает три соседних неизвестных — ненулевые элементы стоят на трёх диагоналях. Матрица постоянна, а правая часть меняется на каждом шаге по времени.

Матрица наследует устройство задачи: связи между узлами сетки.

В 2D та же схема на сетке \(m\times m\): \(n=m^2\) неизвестных, в строке 5 ненулевых (узел и четыре соседа).

I. МатрицыIIIIIIVV§9.0. Положительная определённость

Симметричные положительно определённые матрицы

Определение. Матрица \(A\) симметричная положительно определённая, если \(A=A^{\mathsf T}\) и \(x^{\mathsf T}Ax>0\) для любого \(x\ne0\).

Смысл: положительность энергии. Для матрицы неявной схемы

\[x^{\mathsf T}Ax=\sum_ix_i^2+\sigma\sum_i(x_{i+1}-x_i)^2+\ldots>0\]

— сумма квадратов, дискретный аналог \(\int(u^2+\tau u_x^2)\,dx\).

  • Положительно определены: диффузия, упругость (МКР, МКЭ); нормальные уравнения МНК: \(x^{\mathsf T}A^{\mathsf T}Ax=\|Ax\|^2>0\) (§ 5).
  • Несимметричны: перенос (конвекция), якобиан метода Ньютона.
  • Симметричны, но знаконеопределённы: несжимаемость (задача Стокса).

Соберём классы матриц и задачи, из которых они берутся.

III. РешателиIIIIVV§9.1. Метод Гаусса

Метод 1. Исключение Гаусса

Идея: вычитая из уравнений кратные других уравнений, привести систему к треугольному виду. Шаг \(k\), ведущий элемент \(a_{kk}\):

\[m_{ik}=\frac{a_{ik}}{a_{kk}},\qquad a_{ij}\leftarrow a_{ij}-m_{ik}a_{kj},\qquad b_i\leftarrow b_i-m_{ik}b_k,\qquad i,j>k. \tag{9.2}\]

Обратный ход — снизу вверх: \(x_i=\bigl(b_i-\sum_{j>i}a_{ij}x_j\bigr)/a_{ii}\)  (9.3).

Проследим метод на числах.

III. РешателиIIIIVV§9.1. Пример B

Пример B: система третьего порядка

\[2x_1+x_2+x_3=4,\qquad 4x_1+3x_2+3x_3=10,\qquad 8x_1+7x_2+9x_3=24.\]
  1. Шаг 1. Ведущий \(2\); \(m_{21}=2\), \(m_{31}=4\). Получаем \(x_2+x_3=2\), \(\ 3x_2+5x_3=8\).
  2. Шаг 2. Ведущий \(1\); \(m_{32}=3\). Получаем \(2x_3=2\).
  3. Обратный ход. \(x_3=1\), \(x_2=2-x_3=1\), \(x_1=(4-x_2-x_3)/2=1\).

Стоимость. На шаге \(k\) пересчитывается \((n-k)^2\) элементов, по 2 операции:

\[2\sum_{k=1}^{n-1}(n-k)^2\approx\tfrac23n^3\ \text{(прямой ход)},\qquad n^2\ \text{(обратный ход)}.\]

Удвоение \(n\) — время в 8 раз больше.

В формуле (9.2) — деление на ведущий элемент. Что, если он мал?

III. РешателиIIIIVV§9.1. Малый ведущий элемент

Пример C: малый ведущий элемент

\(0{,}0001\,x_1+x_2=1,\ \ x_1+x_2=2\). Решение \(x_1=1{,}0001\ldots,\ x_2=0{,}9999\ldots\) Счёт с тремя значащими цифрами:

Без перестановки \(m_{21}=10^4\). Второе уравнение: \((1-10^4)x_2=2-10^4\) → \(-1{,}00\cdot10^4x_2=-1{,}00\cdot10^4\), \(x_2=1\).
\(x_1=(1-x_2)/0{,}0001=0\). Неверно.
С перестановкой уравнений Ведущий \(1\), \(m_{21}=0{,}0001\). \((1-0{,}0001)x_2=1-0{,}0002\) → \(x_2=1\).
\(x_1=2-x_2=1\). Верно.

Большой множитель \(10^4\) усиливает ошибку округления, и информация о первом уравнении пропадает. В double то же при ведущем \(10^{-20}\): \(x_1=0\).

Отсюда правило: ведущим брать наибольший по модулю элемент столбца.

III. РешателиIIIIVV§9.1. Выбор главного элемента

Частичный выбор главного элемента

На шаге \(k\) в столбце \(a_{kk},\ldots,a_{nk}\) найти наибольший по модулю и переставить его строку на место \(k\)-й.

  • Все множители \(|m_{ik}|\le1\) — ошибки округления не усиливаются.
  • Перестановка строк — перестановка уравнений; решение не меняется. Весь столбец нулевой — \(A\) вырождена.
  • Выбор не нужен, если \(A\) симметрична положительно определена или имеет диагональное преобладание \(|a_{ii}|>\sum_{j\ne i}|a_{ij}|\).

Соберём метод в блок-схему.

III. РешателиIIIIVV§9.2. LU-разложение

Метод 2. LU-разложение

Идея: множители \(m_{ik}\) зависят только от \(A\). Сохраним их — правую часть обработаем потом.

\[\begin{pmatrix}2&1&1\\4&3&3\\8&7&9\end{pmatrix}=\begin{pmatrix}1&0&0\\2&1&0\\4&3&1\end{pmatrix}\begin{pmatrix}2&1&1\\0&1&1\\0&0&2\end{pmatrix}\]
\[PA=LU;\qquad Ly=Pb\ \ (\text{сверху вниз}),\qquad Ux=y\ \ (\text{снизу вверх}). \tag{9.4}\]

Дорогое разложение — один раз, дешёвые подстановки — на каждую \(b\).

III. РешателиIIIIVV§9.3. Разложение Холецкого

Метод 3. Разложение Холецкого

Для симметричной положительно определённой \(A\): \(A=LL^{\mathsf T}\), \(l_{jj}>0\) (А.-Л. Холе́цкий, ≈1910, геодезия и МНК).

\[l_{jj}=\sqrt{a_{jj}-\sum_{k\lt j}l_{jk}^2},\qquad l_{ij}=\frac1{l_{jj}}\Bigl(a_{ij}-\sum_{k\lt j}l_{ik}l_{jk}\Bigr),\ \ i>j. \tag{9.6}\]

Пример D. \(b=(8,10,11)\): \(Ly=b\Rightarrow y=(4,3,2)\); \(L^{\mathsf T}x=y\Rightarrow x=(1,1,1)\).

Половина памяти, половина операций, выбор главного не нужен. А если матрица не положительно определена?

III. РешателиIIIIVV§9.3. Холецкий как проверка

Разложение как проверка положительной определённости

Если \(A\) не положительно определена, на некотором шаге \(d\le0\).

\(A=\begin{pmatrix}1&2\\2&1\end{pmatrix}\): \(l_{11}=1\), \(l_{21}=2\), \(l_{22}^2=1-4=-3\lt0\). Проверка: \(x=(1,-1)\), \(x^{\mathsf T}Ax=-2\).

Библиотека сообщает об этом кодом ошибки — его надо проверять. Седловые матрицы: \(LDL^{\mathsf T}\) или LU.

Паспорт: Холецкий
Хорошо\(\tfrac13n^3\), половина памяти, без выбора. Плохо: несимметричные и знаконеопределённые
БиблиотекиLAPACK potrf; Eigen LLT, LDLT; SciPy cho_factor

IIIIII. РазреженныеIVV§9.4. Три фазы

Три фазы разреженного решателя

  1. Анализ — только по шаблону ненулевых: переупорядочение, шаблон \(L\).
  2. Численное разложение — по значениям.
  3. Решение — подстановки для \(b\).

Меняются значения, шаблон тот же (нелинейная задача, переменный шаг) — повторяют фазы 2–3. Новая \(b\) — только фазу 3.

IIIIIIIV. Проверка и выборV§9.5. Невязка

Проверка решения: невязка

Точное решение \(x^*\) неизвестно — ошибку \(\tilde x-x^*\) не вычислить. Вычисляют невязку:

\[r=b-A\tilde x. \tag{9.7}\]
Факт (Дж. Уи́лкинсон, 1961). Решение, найденное LU с выбором или Холецким, практически всегда — точное решение близкой системы \((A+\delta A)\tilde x=b\), \(\delta A\) порядка ошибки округления.
  • У правильно вызванного решателя \(\|r\|\sim10^{-16}\|A\|\|\tilde x\|\). Большая невязка — ошибка в программе: матрица, формат хранения, пропущенный код ошибки.

Значит ли малая невязка, что ответ точен?

IIIIIIIV. Проверка и выборV§9.5. Невязка и ошибка

Пример E: малая невязка, большая ошибка

\(x_1+x_2=2,\ \ x_1+1{,}0001\,x_2=2{,}0001\); \(x^*=(1,1)\). Подставим \(\tilde x=(2,0)\):

\[r=(0;\ 0{,}0001)\ \text{— мала},\qquad \tilde x-x^*=(1;\,-1)\ \text{— как само решение}.\]

Прямые почти параллельны: точка пересечения определена плохо. Во сколько раз ошибка может превышать невязку, определяет число обусловленности \(\kappa(A)\); здесь \(\kappa\approx4\cdot10^4\) — свойство задачи, а не метода (§ 10).

Невязка проверяет программу, обусловленность ограничивает точность. Теперь — как выбрать решатель.

IIIIIIIVV. Пакеты§9.7. Как устроены библиотеки

Как устроены библиотеки

  1. BLAS (Basic Linear Algebra Subprograms): скалярное произведение, матрица × вектор, матрица × матрица. Реализации: OpenBLAS, Intel oneMKL, Apple Accelerate — векторные команды и все ядра.
  2. LAPACK: разложения и решатели для плотных и ленточных матриц на основе BLAS. Имена: dgesv — double, general, solve; dpotrf — positive definite, triangular factorization.
  3. Обёртки: Eigen (C++), NumPy/SciPy (Python).
  4. Большие задачи: PARDISO, MUMPS, PETSc.

Скорость решателя почти целиком определяется реализацией BLAS.

Теперь — как решать систему.

IIIIIIIVV. Пакеты§9.7. Eigen: плотные системы

Eigen: плотные системы

#include <Eigen/Dense>
using namespace Eigen;

Matrix3d A;
A << 2, 1, 1,
     4, 3, 3,
     8, 7, 9;
Vector3d b(4, 10, 24);

PartialPivLU<Matrix3d> lu(A); // PA = LU, один раз
Vector3d x  = lu.solve(b);     // x = (1, 1, 1)
double det  = lu.determinant();// 4
Vector3d x2 = lu.solve(Vector3d(1, 0, 0));
double r = (A * x - b).norm(); // невязка
Matrix3d S;
S << 4, 2, 2,
     2, 5, 3,
     2, 3, 6;
LLT<Matrix3d> chol(S);         // S = L L^T
if (chol.info() != Success) {
    // не положительно определена:
    // перейти к LDLT или PartialPivLU
}
Vector3d y = chol.solve(Vector3d(8, 10, 11));
// y = (1, 1, 1)

Для размера, известного при выполнении, — MatrixXd A(n, n), VectorXd b(n).

Плотные матрицы — для малых систем. Для сеточных — разреженные.

IIIIIIIVV. Пакеты§9.7. Eigen: разреженные системы

Eigen: разреженная система, \(n=10^6\)

#include <Eigen/Sparse>
std::vector<Triplet<double>> t;              // (строка, столбец, значение)
for (int i = 0; i < n; ++i) {
    t.emplace_back(i, i, 1 + 2 * s);
    if (i > 0)     t.emplace_back(i, i - 1, -s);
    if (i < n - 1) t.emplace_back(i, i + 1, -s);
}
SparseMatrix<double> A(n, n);
A.setFromTriplets(t.begin(), t.end());         // повторы складываются

SimplicialLLT<SparseMatrix<double>> solver;   // ДО цикла по времени
solver.compute(A);                             // анализ + разложение
for (int step = 0; step < nsteps; ++step)
    y = solver.solve(y);                       // только подстановки

Миллион неизвестных: 0,15 с, невязка \(4\cdot10^{-13}\). Значения меняются, шаблон нет — analyzePattern один раз, factorize на шаге. Несимметричная — SparseLU<SparseMatrix<double>, COLAMDOrdering<int>>.

IIIIIIIVV. Пакеты§9.7. NumPy и SciPy

NumPy и SciPy

pip install numpy scipy. Внутри — LAPACK с OpenBLAS или oneMKL: плотные системы так же быстры, как в C++.

import numpy as np
from scipy import linalg

x = np.linalg.solve(A, b)        # LU (gesv)

lu, piv = linalg.lu_factor(A)    # один раз
x = linalg.lu_solve((lu, piv), b)

c = linalg.cho_factor(S)         # Холецкий
y = linalg.cho_solve(c, b)
from scipy import sparse
from scipy.sparse.linalg import spsolve, splu

A = sparse.diags([-s, 1 + 2*s, -s], [-1, 0, 1],
                 shape=(n, n), format='csc')
x = spsolve(A, b)                # SuperLU

F = splu(A)                      # один раз
x = F.solve(b)

Ленточные: linalg.solve_banded, solveh_banded. Удобно для проверки: систему из программы на C++ сохранить в файл и решить в SciPy.

Для задач с миллионами неизвестных на многих ядрах — специализированные пакеты.

IIIIIIIVV. Пакеты§9.7. PETSc, MUMPS, PARDISO

Большие задачи: PARDISO, MUMPS, PETSc

  • PARDISO — разреженный прямой, многопоточный, один компьютер. В бесплатной Intel oneMKL; из Eigen — PardisoLU, PardisoLLT; из Python — pypardiso.
  • MUMPS — разреженный прямой для кластеров (MPI); несимметричные, симметричные, седловые. Обычно через PETSc.
  • PETSc — среда для больших систем на кластерах: распределённые матрицы, итерационные методы, внешние прямые решатели. На ней построены FEniCS, Firedrake.
./configure --download-mumps --download-scalapack --download-metis --download-parmetis
mpiexec -n 8 ./prog -ksp_type preonly -pc_type lu -pc_factor_mat_solver_type mumps
mpiexec -n 8 ./prog -ksp_type cg -pc_type gamg          # итерационный, §10

В PETSc решатель выбирают ключами запуска, а не в коде.
