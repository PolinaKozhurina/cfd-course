Нормы, пространства, корректность

Решение 1.Аксиомы нормы

Обозначения и посылки. Пусть \(\mathbb{R}^n\) — линейное пространство над \(\mathbb{R}\) с покомпонентными операциями (Опр. 1); \(I_n := \{1, 2, \ldots, n\}\). Модуль на \(\mathbb{R}\) считаем известным, свойства модуля берём за исходные:

\[ \text{(M1)}\ |a| \ge 0;\ \ |a| = 0 \Leftrightarrow a = 0;\qquad \text{(M2)}\ |\alpha\, a| = |\alpha|\cdot |a|;\qquad \text{(M3)}\ |a + b| \le |a| + |b|. \]

Ниже пригодятся ещё два арифметических факта:

Лемма L1 (максимум неотрицательного набора) Пусть \(f\colon I_n \to \mathbb{R}_{\ge 0}\). Тогда (a) \(\max_{i\in I_n} f(i) \ge 0\); (b) \(\max_{i\in I_n} f(i) = 0 \Leftrightarrow \forall i\in I_n\ \ f(i) = 0\); (c) для любого \(\lambda \ge 0\) справедливо \(\max_{i\in I_n} \bigl(\lambda\, f(i)\bigr) = \lambda\,\max_{i\in I_n} f(i)\). ▢

Так как \(I_n\) конечно, максимум достигается на некотором \(k^*\in I_n\): \(\max_i f(i) = f(k^*)\). (a) \(f(k^*) \ge 0\) в силу \(f \ge 0\). (b) Если \(\max_i f = 0\) и \(j \in I_n\) произвольно, то \(0 \le f(j) \le f(k^*) = 0\), откуда \(f(j) = 0\); обратно, из \(f \equiv 0\) очевидно \(\max f = 0\). (c) \(\max_i \lambda f(i) \le \lambda\,\max_i f(i)\) — так как \(\lambda f(i) \le \lambda f(k^*)\) для каждого \(i\) (\(\lambda \ge 0\), функция \(t \mapsto \lambda t\) монотонна на \([0, \infty)\)); обратно, \(\lambda f(k^*) \le \max_i \lambda f(i)\), так как \(k^* \in I_n\).

Лемма L2 (max суммы неотрицательных) Для \(f, g\colon I_n \to \mathbb{R}_{\ge 0}\) \(\ \max_{i\in I_n} \bigl(f(i) + g(i)\bigr) \le \max_{i\in I_n} f(i) + \max_{i\in I_n} g(i)\). ▢

Пусть \(k^*\) — индекс максимума суммы: \(\max_i (f + g) = f(k^*) + g(k^*)\). Тогда \(f(k^*) \le \max_i f\) и \(g(k^*) \le \max_i g\) (по определению максимума); сложив, получаем требуемое.

1) Чебышёвская норма \(\|x\|_\infty := \max_{i\in I_n} |x_i|\).

Проверка (N1): невырожденность. Применим лемму L1 к \(f(i) := |x_i|\) (значения неотрицательны по (M1)).

  • Неотрицательность. По L1(a): \(\|x\|_\infty = \max_i |x_i| \ge 0\).
  • Импликация \(x = 0 \Rightarrow \|x\|_\infty = 0\). Пусть \(x = 0\), т. е. \(x_i = 0\) для всех \(i\). По (M1) \(|x_i| = 0\) для всех \(i\), значит по L1(b) \(\max_i |x_i| = 0\).
  • Импликация \(\|x\|_\infty = 0 \Rightarrow x = 0\). Пусть \(\max_i |x_i| = 0\). По L1(b) \(|x_j| = 0\) для каждого \(j \in I_n\); по (M1) \(x_j = 0\) для каждого \(j\). Итого \(x = 0\).

Проверка (N2): однородность. Пусть \(\alpha \in \mathbb{R}\). Применим (M2) поточечно и лемму L1(c) с \(\lambda := |\alpha| \ge 0\):

\[ \|\alpha x\|_\infty \;=\; \max_{i\in I_n} |\alpha\, x_i| \;\overset{\text{(M2)}}{=}\; \max_{i\in I_n} \bigl(|\alpha|\cdot |x_i|\bigr) \;\overset{\text{L1(c)}}{=}\; |\alpha|\cdot \max_{i\in I_n} |x_i| \;=\; |\alpha|\cdot \|x\|_\infty. \]

Проверка (N3): неравенство треугольника. Обозначим \(k^*\in I_n\) — индекс, реализующий максимум суммы: \(\|x + y\|_\infty = |x_{k^*} + y_{k^*}|\) (существует, так как \(I_n\) конечно). Тогда

\[ \|x + y\|_\infty \;=\; |x_{k^*} + y_{k^*}| \;\overset{\text{(M3)}}{\le}\; |x_{k^*}| + |y_{k^*}| \;\overset{(\dagger)}{\le}\; \max_{i\in I_n} |x_i| + \max_{i\in I_n} |y_i| \;=\; \|x\|_\infty + \|y\|_\infty, \]

где \((\dagger)\) — из \(|x_{k^*}| \le \max_i |x_i|\) и \(|y_{k^*}| \le \max_i |y_i|\) по определению максимума. Единственное «внешнее» неравенство — (M3), т. е. треугольник для модуля на \(\mathbb{R}\).

2) Манхэттенская норма \(\|x\|_1 := \sum_{i=1}^n |x_i|\). Ниже используем свойство суммы неотрицательных чисел: \(\sum_i c_i \ge 0\) при \(c_i \ge 0\), причём равенство нулю \(\Leftrightarrow c_i = 0\) для всех \(i\).

Проверка (N1).

  • По (M1) \(|x_i| \ge 0\), значит \(\|x\|_1 = \sum_i |x_i| \ge 0\).
  • \(x = 0 \Rightarrow \|x\|_1 = 0\): \(x_i = 0 \Rightarrow_{\text{(M1)}} |x_i| = 0\), сумма нулей — нуль.
  • \(\|x\|_1 = 0 \Rightarrow x = 0\): сумма неотрицательных членов равна нулю тогда и только тогда, когда каждое слагаемое равно нулю; значит \(|x_j| = 0\) для каждого \(j\), откуда по (M1) \(x_j = 0\) для каждого \(j\); \(x = 0\).

Проверка (N2). По (M2) поточечно и линейности суммы:

\[ \|\alpha x\|_1 \;=\; \sum_{i=1}^n |\alpha\, x_i| \;\overset{\text{(M2)}}{=}\; \sum_{i=1}^n |\alpha|\cdot |x_i| \;=\; |\alpha|\cdot \sum_{i=1}^n |x_i| \;=\; |\alpha|\cdot \|x\|_1. \]

Проверка (N3). По (M3) поточечно и монотонности суммы неотрицательных членов:

\[ \|x + y\|_1 \;=\; \sum_{i=1}^n |x_i + y_i| \;\overset{\text{(M3)}}{\le}\; \sum_{i=1}^n \bigl(|x_i| + |y_i|\bigr) \;=\; \sum_{i=1}^n |x_i| + \sum_{i=1}^n |y_i| \;=\; \|x\|_1 + \|y\|_1. \]
Итогобе функции удовлетворяют аксиомам (N1)–(N3) Опр. 2 и, следовательно, задают норму на \(\mathbb{R}^n\). Ключевое внешнее место в обоих доказательствах — неравенство треугольника (M3) для модуля \(|\cdot|\) на \(\mathbb{R}\); остальное — арифметика максимума (леммы L1, L2) и суммы неотрицательных чисел.
Решение 2.Задача Коши в операторной форме

Задача. Записать (1.3)–(1.4) в виде операторного уравнения (1.0) \(A u = F\), явно указав четвёрку \((A, B_1, B_2, F)\) и куда «упаковано» начальное условие.

Обозначения. \(\Omega := \mathbb{R} \times [0, T]\); начальные данные фиксированы: \(u_0 \in C^{1}(\mathbb{R})\), \(\|u_0\|_{L^\infty(\mathbb{R})}, \|u_0'\|_{L^\infty(\mathbb{R})} < \infty\). Для классической постановки удобно пространство ограниченных \(C^{1}\)-функций:

\[ C^{1}_b(\Omega) \;:=\; \bigl\{\,v \in C^{1}(\Omega) \;:\; \|v\|_{L^\infty}, \|\partial_t v\|_{L^\infty}, \|\partial_x v\|_{L^\infty} < \infty\,\bigr\}. \]

Область определения оператора.

\[ B_1 \;:=\; \bigl\{\,u \in C^{1}_b(\Omega) \;:\; u(x, 0) = u_0(x)\ \ \forall\, x \in \mathbb{R}\,\bigr\}. \]

Множество \(B_1\) — аффинное подмножество линейного пространства \(C^{1}_b(\Omega)\), выделенное условием следа при \(t = 0\). Именно так «упаковано» начальное условие (1.4): оно не переносится в правую часть, а сужает область определения оператора \(A\).

Стандартный приём для работы с аффинным \(B_1\): выделить фиксированную «затравку» \(\tilde u \in B_1\) (например, \(\tilde u(x, t) := u_0(x)\)) и представить \(u = \tilde u + v\), где \(v\) пробегает линейное подпространство \(V := \{v \in C^{1}_b(\Omega) : v(\cdot, 0) \equiv 0\}\). На \(V\) оператор \(A\) действует как обычный линейный ограниченный оператор.

Оператор.

\[ A u \;:=\; \frac{\partial u}{\partial t} + a\,\frac{\partial u}{\partial x}, \qquad A\colon B_1 \to B_2. \]

Корректность области значений. Для \(u \in B_1 \subset C^{1}_b(\Omega)\) обе частные производные \(\partial_t u\) и \(\partial_x u\) существуют, непрерывны и ограничены. Тогда \(A u = \partial_t u + a\,\partial_x u\) непрерывна как линейная комбинация непрерывных, и ограничена:

\[ \|A u\|_{L^\infty(\Omega)} \;\le\; \|\partial_t u\|_{L^\infty} + |a|\cdot \|\partial_x u\|_{L^\infty} \;<\; \infty, \]

т. е. \(A u \in C_b(\Omega) =: B_2\); оператор действительно переводит \(B_1\) в \(B_2\).

Линейность. На линейном подпространстве \(V\) прямо из линейности частных производных: \(A(\alpha v_1 + \beta v_2) = \alpha (Av_1) + \beta (Av_2)\) для любых \(\alpha, \beta \in \mathbb{R}\), \(v_1, v_2 \in V\).

Правая часть. Уравнение (1.3) однородное, поэтому

\[ F \;\equiv\; 0 \;\in\; B_2. \]

Пара \((B_1, B_2)\) — вариант 1 (равномерная норма).

\[ \|u\|_1 \;:=\; \|u\|_{L^\infty(\Omega)} \;=\; \sup_{(x, t) \in \Omega} |u(x, t)|; \qquad B_2 \;=\; C_b(\Omega),\quad \|v\|_2 \;:=\; \|v\|_{L^\infty(\Omega)}. \]

Естественно, когда требуются равномерные оценки сходимости — согласовано с сеточной нормой \(\|\cdot\|_C\), формула (1.13).

Пара \((B_1, B_2)\) — вариант 2 (интегральная норма).

\[ \|u\|_1 \;:=\; \|u\|_{L_2(\Omega)} \;=\; \Bigl(\iint_\Omega u^2(x, t)\,dx\,dt\Bigr)^{\!1/2}; \qquad B_2 \;=\; L_2(\Omega),\quad \|v\|_2 \;:=\; \|v\|_{L_2(\Omega)}. \]

При таком выборе \(C^{1}_b\)-подход тесен: удобно расширить \(B_1\) до соболевского подпространства \(H^{1}(\Omega)\) со следом \(u_0 \in H^{1/2}(\mathbb{R})\) на \(\{t = 0\}\) (теорема о следе, \(\mathrm{tr}\colon H^{1}(\Omega) \to H^{1/2}(\partial\Omega)\)). Тогда \(\partial_t u, \partial_x u \in L_2\) в слабом смысле, \(A\) ограничен: \(\|A u\|_{L_2} \le (1 + |a|)\,\|u\|_{H^{1}}\).

Итог задача Коши (1.3)–(1.4) переписывается в форме (1.0) как \(A u = 0\) с \(A = \partial_t + a\,\partial_x\); начальное условие входит через сужение области определения \(B_1\), а не через правую часть \(F \equiv 0\). Естественные пары \((B_1, B_2)\) — \((C^{1}_b, C_b)\) под равномерную норму либо \((H^{1}, L_2)\) под интегральную.

Решение 3.Неравномерная сетка через \(\varphi(t) = t^2\)

Явный вид узлов. При \(a = 0\), \(b = 1\), \(N = 4\), \(h = 1/N = 1/4\), \(\varphi(t) = t^2\) имеем \(\varphi(0) = 0\), \(\varphi(1) - \varphi(0) = 1\), \(b - a = 1\). Подстановка в (1.8а):

\[ \Phi(t) \;=\; \frac{\varphi(t) - \varphi(0)}{\varphi(1) - \varphi(0)}\,(b - a) + a \;=\; t^2, \qquad x_k \;=\; \Phi(k h) \;=\; (k h)^2 \;=\; \frac{k^2}{16},\quad k = 0, 1, 2, 3, 4. \]

Шаги. По определению \(h_k := x_k - x_{k-1}\); прямое вычисление:

\[ h_k \;=\; \frac{k^2 - (k-1)^2}{16} \;=\; \frac{2 k - 1}{16}, \qquad k = 1, 2, 3, 4. \]
\(k\)01234
\(x_k\)\(0\)\(\tfrac{1}{16}\)\(\tfrac{4}{16}\)\(\tfrac{9}{16}\)\(\tfrac{16}{16}\)
\(h_k\)—\(\tfrac{1}{16}\)\(\tfrac{3}{16}\)\(\tfrac{5}{16}\)\(\tfrac{7}{16}\)

Характеристический шаг по (1.5):

\[ |h| \;=\; \max_{1 \le k \le N} h_k \;=\; \max_k \frac{2 k - 1}{16} \;=\; \frac{2 N - 1}{16} \;=\; \frac{7}{16}. \]

Реализующий индекс — \(k^* = N = 4\); максимум достигается на нём, поскольку последовательность \(h_k = (2k - 1)/16\) строго возрастает по \(k\) (арифметическая прогрессия с разностью \(2/16 > 0\)).

Усреднённые шаги по (1.6) во внутренних узлах \(k = 1, 2, 3\):

\[ \bar h_1 = \tfrac12(h_1 + h_2) = \tfrac12\!\bigl(\tfrac{1}{16} + \tfrac{3}{16}\bigr) = \tfrac{1}{8},\quad \bar h_2 = \tfrac12(h_2 + h_3) = \tfrac{1}{4},\quad \bar h_3 = \tfrac12(h_3 + h_4) = \tfrac{3}{8}. \]
Лемма (сгущение через теорему Лагранжа) Пусть \(\Phi \in C^{1}([0, 1])\) строго возрастает. Для каждого \(k = 1, \ldots, N\) существует \(\xi_k \in \bigl((k - 1) h,\ k h\bigr)\), для которого \[ h_k \;=\; \Phi(k h) - \Phi\bigl((k - 1) h\bigr) \;=\; h \cdot \Phi'(\xi_k). \] ▢

Прямое применение теоремы Лагранжа о среднем к \(\Phi\) на отрезке \([(k - 1) h,\ k h]\): непрерывность на замкнутом отрезке и дифференцируемость на открытом обеспечены посылкой \(\Phi \in C^{1}\).

Куда сгущается сетка и почему. Для \(\varphi(t) = t^2\) имеем \(\Phi'(t) = 2 t\), поэтому \(h_k = 2 h\,\xi_k\), где \(\xi_k \in ((k - 1) h,\ k h)\). Оценки для крайних индексов:

  • для \(k = 1\): \(\xi_1 \in (0,\ h)\), значит \(h_1 = 2 h\,\xi_1 \in (0,\ 2 h^2)\); в частности \(h_1 \le 2 h^2 = 2/16 = 1/8\);
  • для \(k = N = 4\): \(\xi_N \in ((N - 1) h,\ 1)\), значит \(h_N = 2 h\,\xi_N \in (2 (N - 1) h^2,\ 2 h)\); в частности \(h_N \ge 2 (N - 1) h^2 = 6/16 = 3/8\).

Отношение \(h_1 / h_4 = 1/7\) — семикратное сгущение к левому концу \(x = 0\).

Причина: \(\Phi'(0) = 0\) означает, что локальный масштаб растяжения преобразования \(\Phi\) в левом конце обращается в нуль. По формуле леммы \(h_k \approx h\,\Phi'(\xi_k)\), а значит равные шаги параметра \(t\) переходят в тем более мелкие шаги \(x\), чем меньше \(\Phi'\) на этом участке. У правого конца \(\Phi'(1) = 2\) — «умеренное» растяжение; у левого — «нулевое сжатие», поэтому сетка автоматически сгущается именно к \(x = 0\).

Решение 4.Прямоугольная сетка в круге

Сеточная решётка. Одномерные множества координат \(\Xi := \{-1,\ -\tfrac12,\ 0,\ \tfrac12,\ 1\}\), \(|\Xi| = 5\); множество узлов пересечений — \(\Xi \times \Xi\), \(|\Xi \times \Xi| = 25\).

Внутренние узлы \(\omega_h := \{\,(x, y) \in \Xi \times \Xi \;:\; x^2 + y^2 < 1\,\}\). Полный перебор через логическую дизъюнкцию:

  • если \(|x| = 1\) или \(|y| = 1\), то один из членов \(x^2\), \(y^2\) равен единице, а второй \(\ge 0\); значит \(x^2 + y^2 \ge 1\) — узел не внутренний. Число таких узлов: \(|\{(x, y): |x| = 1\} \cup \{|y| = 1\}| = 10 + 10 - 4 = 16\) (по формуле включения-исключения; \(|\{|x| = 1\}| = 2\cdot 5 = 10\); пересечение — 4 «угловых» узла \((\pm 1, \pm 1)\)).
  • если \(|x|, |y| \in \{0, \tfrac12\}\) (таких \(3 \cdot 3 = 9\) узлов), то \(x^2 + y^2 \in \{0, \tfrac14, \tfrac12\} \subset [0, 1)\) — все 9 узлов внутренние.

Итог (согласуется с 25 = 16 + 9):

\[ \omega_h \;=\; \bigl\{\,(0, 0),\ (\pm\tfrac12,\, 0),\ (0,\, \pm\tfrac12),\ (\pm\tfrac12,\, \pm\tfrac12)\,\bigr\}, \qquad |\omega_h| = 9. \]

Граничные узлы \(\partial_h\) — пересечения сеточных прямых с окружностью \(\{x^2 + y^2 = 1\}\). По (1.10)–(1.11) любая точка \(\partial_h\) лежит на одной из 5 вертикалей \(x = x_i\ (x_i \in \Xi)\) или 5 горизонталей \(y = y_j\ (y_j \in \Xi)\); всего 10 прямых, каждая пересекает окружность не более чем в двух точках. Переберём.

По вертикалям. Уравнение \(y^2 = 1 - x_i^2\) даёт:

  • \(x_i = \pm 1\ (2\text{ значения})\): \(y = 0\) (двойной корень, одна геометрическая точка на прямую). Итого 2 точки: \((\pm 1, 0)\).
  • \(x_i = \pm\tfrac12\ (2\text{ значения})\): \(y = \pm\tfrac{\sqrt 3}{2}\) (2 корня). Итого 4 точки: \((\pm\tfrac12,\, \pm\tfrac{\sqrt 3}{2})\).
  • \(x_i = 0\ (1\text{ значение})\): \(y = \pm 1\). Итого 2 точки: \((0, \pm 1)\).

Всего по вертикалям — 2 + 4 + 2 = 8 различных точек.

По горизонталям. Уравнение \(x^2 = 1 - y_j^2\); аналогично получаем набор:

  • \(y_j = \pm 1\): \(x = 0\); точки \((0, \pm 1)\) — уже посчитаны;
  • \(y_j = \pm\tfrac12\): \(x = \pm\tfrac{\sqrt 3}{2}\); точки \((\pm\tfrac{\sqrt 3}{2},\, \pm\tfrac12)\) — новые: \(x\)-координата \(\pm\tfrac{\sqrt 3}{2} \notin \Xi\), значит на вертикалях они не лежат. 4 новых точки.
  • \(y_j = 0\): \(x = \pm 1\); точки \((\pm 1, 0)\) — уже посчитаны.

Полнота перебора. Мы прошли все 5 вертикалей и все 5 горизонталей; других сеточных прямых нет, а окружность может пересекаться с каждой прямой не более чем в 2 точках — значит все точки \(\partial_h\) учтены.

\[ |\partial_h| \;=\; 8 + 4 \;=\; 12, \qquad |\bar\omega_h| \;=\; |\omega_h| + |\partial_h| \;=\; 9 + 12 \;=\; 21. \]
Зелёные точки — \(\omega_h\), коричневые — \(\partial_h\).

Решение 5.Сеточные аналоги норм \(C\) и \(L_2\)

Данные. \(u(x) = \sin(\pi x)\), \(x \in [0, 1]\); равномерная сетка \(\omega_h = \{x_k = k h,\ k = 0, \ldots, N\}\), \(h = 1/N\); проектор (1.17): \(y_k = \sin(\pi x_k) = \sin(\pi k / N)\).

(1) Сеточная норма \(C\) по (1.13):

\[ \|y\|_C \;=\; \max_{0 \le k \le N} |\sin(\pi k / N)|. \]

Так как \(|\sin\theta| \le 1\) для всех \(\theta \in \mathbb{R}\), верхняя оценка: \(\|y\|_C \le 1\). При чётном \(N\) индекс \(k^* := N/2\) даёт \(\sin(\pi k^*/N) = \sin(\pi/2) = 1\), т. е. верхняя граница достигается и \(\|y\|_C = 1\). Оба значения \(N = 10, 20\) чётные, поэтому \(\|y\|_C = 1\) в обоих случаях.

Лемма (сумма \(\sin^2\)) Для любого целого \(N \ge 1\) \[ S_N \;:=\; \sum_{k=1}^{N-1} \sin^2\!\Bigl(\frac{\pi k}{N}\Bigr) \;=\; \frac{N}{2}. \] ▢

По формуле понижения степени \(\sin^2\alpha = \tfrac{1 - \cos 2\alpha}{2}\):

\[ S_N \;=\; \sum_{k=1}^{N-1} \frac{1 - \cos(2\pi k / N)}{2} \;=\; \frac{N - 1}{2} \;-\; \frac{1}{2}\sum_{k=1}^{N-1} \cos\!\frac{2\pi k}{N}. \]

Пусть \(\zeta := e^{2\pi i / N}\) — примитивный корень степени \(N\) из \(1\). Числа \(\zeta^k\), \(k = 0, 1, \ldots, N - 1\), — все \(N\) различных корней уравнения \(z^N - 1 = 0\). По теореме Виета для многочлена \(z^N - 1 = 0\) (коэффициент при \(z^{N-1}\) равен нулю) их сумма равна нулю: \(\sum_{k=0}^{N-1} \zeta^k = 0\). Взяв вещественную часть:

\[ \sum_{k=0}^{N-1} \cos\!\frac{2\pi k}{N} \;=\; 0 \;\Longrightarrow\; 1 + \sum_{k=1}^{N-1} \cos\!\frac{2\pi k}{N} \;=\; 0 \;\Longrightarrow\; \sum_{k=1}^{N-1} \cos\!\frac{2\pi k}{N} \;=\; -1. \]

Подставляя, \(S_N = \tfrac{N - 1}{2} - \tfrac{-1}{2} = \tfrac{N}{2}\).

(2) Сеточная норма \(L_2\) по (1.14). Так как \(y_0 = \sin 0 = 0\) и \(y_N = \sin \pi = 0\), обе версии сумм в (1.14) совпадают:

\[ \sum_{k=1}^{N} y_k^2 \;=\; \sum_{k=0}^{N-1} y_k^2 \;=\; \sum_{k=1}^{N-1} y_k^2 \;=\; \sum_{k=1}^{N-1} \sin^2\!\frac{\pi k}{N} \;\overset{\text{лемма}}{=}\; \frac{N}{2}. \]

Тогда для любого \(N\)

\[ \|y\|_{L_2, h} \;=\; \Bigl(\frac{N}{2}\cdot h\Bigr)^{\!1/2} \;=\; \Bigl(\frac{N}{2}\cdot \frac{1}{N}\Bigr)^{\!1/2} \;=\; \frac{1}{\sqrt 2}. \]

Результат не зависит от \(N\), поэтому одинаков при \(N = 10\) и \(N = 20\).

Решение 6.Два проектора \(P_\tau\) для \(u(x) = x^2\)

Данные. Сетка \(h = 1/4\), узлы \(x_k = k h = k/4\), \(k = 0, 1, 2, 3, 4\); внутренние — \(k = 1, 2, 3\).

Проектор (1.17) — значение в узле: \((P_\tau u)_k = u(x_k) = x_k^2\).

Проектор (1.18) во внутренних узлах \(k = 1, 2, 3\). Ячейка \([x_k - h/2,\ x_k + h/2]\), знаменатель \(\bar h_k = h\). Замена \(x = x_k + t\), \(t \in [-h/2, h/2]\):

\[ (P_\tau u)_k \;=\; \frac{1}{h}\!\int_{-h/2}^{h/2}\! (x_k + t)^2\,dt \;=\; \frac{1}{h}\!\int_{-h/2}^{h/2}\! \bigl(x_k^2 + 2 x_k t + t^2\bigr)\,dt. \]

Три слагаемых интеграла:

  • \(\tfrac{1}{h}\!\int x_k^2\, dt = x_k^2 \cdot \tfrac{1}{h}\cdot h = x_k^2\);
  • \(\tfrac{1}{h}\!\int 2 x_k t\, dt = \tfrac{2 x_k}{h}\!\int_{-h/2}^{h/2}\! t\, dt = 0\) (интеграл нечётной функции по симметричному интервалу);
  • \(\tfrac{1}{h}\!\int t^2\, dt = \tfrac{1}{h}\cdot 2\cdot \tfrac{(h/2)^3}{3} = \tfrac{h^2}{12}\).

Складывая:

\[ (P_\tau u)_k \;=\; x_k^2 + \frac{h^2}{12}, \qquad k = 1, 2, 3. \]
Лемма (среднее по симметричной ячейке) Пусть \(u \in C^{3}([x_k - h/2,\ x_k + h/2])\). Тогда \[ \frac{1}{h}\!\int_{x_k - h/2}^{x_k + h/2}\! u(x)\,dx \;=\; u(x_k) + \frac{u''(x_k)\,h^2}{24} + O(h^3). \] При \(u \in C^{4}\) остаточный член — \(O(h^4)\). ▢

По формуле Тейлора с остаточным членом в форме Лагранжа \(u(x_k + t) = u(x_k) + u'(x_k)\, t + \tfrac12 u''(x_k)\, t^2 + r(t)\), где \(|r(t)| \le \tfrac{M_3}{6}|t|^3\) с \(M_3 := \sup |u'''|\). Интегрируя по симметричному интервалу и деля на \(h\); нечётный член \(u'(x_k) t\) даёт нуль:

\[ \frac{1}{h}\!\int_{-h/2}^{h/2}\! u(x_k + t)\, dt \;=\; u(x_k) + \frac{u''(x_k)}{2}\cdot \frac{h^2}{12} + \frac{1}{h}\!\int_{-h/2}^{h/2}\! r(t)\, dt. \]

Оценка остатка: \(\bigl|\tfrac1h \int r\bigr| \le \tfrac1h \cdot \tfrac{M_3}{6}\cdot 2\cdot \tfrac{(h/2)^4}{4} = \tfrac{M_3 h^3}{192} = O(h^3)\). Первый нетривиальный член — \(u''(x_k)\,h^2/24\).

Для \(u = x^2\) остаток тождественно нулевой (\(u''' \equiv 0\)), \(u'' \equiv 2\); поправка \(u''\, h^2/24 = h^2/12\) — точное значение (согласуется с прямым интегрированием выше).

Проектор (1.18) на крайних узлах.

Для \(k = 0\) ячейка — \([0,\ h/2]\), знаменатель — \(h/2\):

\[ (P_\tau u)_0 \;=\; \frac{1}{h/2}\!\int_0^{h/2}\! x^2\,dx \;=\; \frac{2}{h}\cdot \frac{(h/2)^3}{3} \;=\; \frac{h^2}{12}. \]

Для \(k = N = 4\) ячейка — \([1 - h/2,\ 1]\), знаменатель — \(h/2\):

\[ (P_\tau u)_4 \;=\; \frac{2}{h}\!\int_{1 - h/2}^1\! x^2\,dx \;=\; \frac{2}{h}\cdot \frac{1 - (1 - h/2)^3}{3}. \]

Раскрывая куб: \((1 - h/2)^3 = 1 - \tfrac{3 h}{2} + \tfrac{3 h^2}{4} - \tfrac{h^3}{8}\), значит \(1 - (1 - h/2)^3 = \tfrac{3 h}{2} - \tfrac{3 h^2}{4} + \tfrac{h^3}{8}\). Умножая на \(2/(3 h)\):

\[ (P_\tau u)_4 \;=\; 1 \;-\; \frac{h}{2} \;+\; \frac{h^2}{12}. \]

Общая закономерность: во внутренних узлах разность (1.18) − (1.17) — второго порядка по \(h\), обращается в нуль ровно на линейных \(u\); в крайних узлах разность содержит первый порядок и не обращается в нуль ни для какой \(u \not\equiv \mathrm{const}\).

Решение 7.Анализ шаблонов на верхнем слое

Определения. Шаблон \(\mathcal{S}\) элементарного шага (Опр. 6) — конечное множество узлов расчётной сетки, значения сеточной функции в которых входят в одно разностное уравнение. Обозначим \(\mathcal{S}^{n+1} := \{(i', n+1) \in \mathcal{S}\}\) — след шаблона на верхнем временном слое. Схема называется явной, если \(|\mathcal{S}^{n+1}| = 1\), и неявной, если \(|\mathcal{S}^{n+1}| \ge 2\).

Обоснование критерия. Если \(|\mathcal{S}^{n+1}| = 1\) и \(\mathcal{S}^{n+1} = \{(i, n+1)\}\), уравнение имеет вид \(F\bigl(y_i^{n+1};\ \{y_{i'}^{n'}\}_{(i', n') \in \mathcal{S}\setminus \mathcal{S}^{n+1}}\bigr) = 0\); при регулярности \(F\) по \(y_i^{n+1}\) уравнение однозначно разрешимо, давая явное выражение \(y_i^{n+1} = R(\ldots)\). Если \(|\mathcal{S}^{n+1}| \ge 2\), одно уравнение связывает несколько значений верхнего слоя между собой; повторяя уравнение для каждого \(i\), получаем систему уравнений относительно всего слоя одновременно.

Явный трёхточечный шаблон.

\[ \mathcal{S} \;=\; \bigl\{\,(i, n + 1);\ \ (i - 1, n),\ (i, n),\ (i + 1, n)\,\bigr\}, \qquad |\mathcal{S}^{n+1}| = 1. \]

Известные — три узла нижнего слоя \(n\) (значения на слоях \(\le n\) вычислены ранее). Неизвестное — единственный узел \((i, n + 1)\). Схема явная: \(y_i^{n+1} = R(y_{i-1}^n, y_i^n, y_{i+1}^n)\), вычисляется в цикле по \(i\) независимо, без решения системы.

Неявный трёхточечный шаблон.

\[ \mathcal{S} \;=\; \bigl\{\,(i - 1, n + 1),\ (i, n + 1),\ (i + 1, n + 1);\ \ (i, n)\,\bigr\}, \qquad |\mathcal{S}^{n+1}| = 3. \]

Известное — единственный узел нижнего слоя. Неизвестных на верхнем слое — три: \(y_{i-1}^{n+1}, y_i^{n+1}, y_{i+1}^{n+1}\). Схема неявная: пробегая \(i\), получаем систему уравнений вида \(\alpha_i\, y_{i-1}^{n+1} + \beta_i\, y_i^{n+1} + \gamma_i\, y_{i+1}^{n+1} = f_i^n\) с трёхдиагональной матрицей (при подходящих граничных условиях), которую решают одновременно для всего слоя — например, методом прогонки.

Шаблон «крест» (три временных слоя).

\[ \mathcal{S} \;=\; \bigl\{\,(i, n + 1);\ \ (i - 1, n),\ (i, n),\ (i + 1, n);\ \ (i, n - 1)\,\bigr\}, \qquad |\mathcal{S}^{n+1}| = 1. \]

Известные — пять узлов слоёв \(n\) и \(n - 1\); неизвестное — \((i, n + 1)\). Схема явная: \(y_i^{n+1} = R(y_{i-1}^n, y_i^n, y_{i+1}^n, y_i^{n-1})\). Особенность двухслойного старта: для запуска расчёта нужны данные на двух временных слоях, \(n = 0\) и \(n = 1\); слой \(n = 1\) задаётся либо доопределением начального условия для \(u_t\), либо одношаговым разгоном по вспомогательной явной схеме.

Критерий явная схема ⟺ \(|\mathcal{S}^{n+1}| = 1\); неявная ⟺ \(|\mathcal{S}^{n+1}| \ge 2\). Первое даёт прямое вычисление \(y_i^{n+1}\) в цикле по \(i\); второе — систему для всего слоя, решаемую одновременно.

Погрешность, сходимость, точная схема

Решение 8.Сеточная функция погрешности

Данные. \(u(x) = \sin(\pi x)\), \(x \in [0, 1]\); \(N = 10\), \(h = 1/10\), узлы \(x_k = k h\), \(k = 0, \ldots, 10\); численное решение \(y_k = \sin(\pi x_k) + (-1)^k\cdot 10^{-2}\); проектор (1.17): \((P_{\tau\omega} u)_k = u(x_k) = \sin(\pi x_k)\).

(1) Погрешность (Опр. 7).

\[ z_k \;=\; y_k - (P_{\tau\omega} u)_k \;=\; \bigl(\sin(\pi x_k) + (-1)^k\cdot 10^{-2}\bigr) - \sin(\pi x_k) \;=\; (-1)^k\cdot 10^{-2}, \qquad k = 0, 1, \ldots, 10. \]

Значения \(z_k\) чередуются: \(+10^{-2}, -10^{-2}, +10^{-2}, \ldots\).

(2) Норма \(C\) по (1.13). Все \(|z_k| = 10^{-2}\), поэтому

\[ \|z\|_C \;=\; \max_{0 \le k \le N} |z_k| \;=\; 10^{-2}. \]

(3) Сеточная норма \(L_2\) по (1.14) с суммой \(k = 0, \ldots, N - 1 = 0, \ldots, 9\). Каждое \(z_k^2 = 10^{-4}\), суммирование 10 таких слагаемых:

\[ \|z\|_{L_2, h} \;=\; \Bigl(\sum_{k=0}^{9} z_k^2\, h\Bigr)^{1/2} \;=\; \bigl(10 \cdot 10^{-4} \cdot 10^{-1}\bigr)^{1/2} \;=\; (10^{-4})^{1/2} \;=\; 10^{-2}. \]

(4) Что говорит одна точка о сходимости. По Опр. 8 схема сходится, если

\[ \forall\, \varepsilon > 0 \ \exists\, N_\varepsilon \in \mathbb{N}\colon \ \forall\, N \ge N_\varepsilon \ \|z_h\|_{1, H} < \varepsilon. \]

Логически это утверждение асимптотическое: оно говорит о поведении \(\|z_h\|_{1, H}\) при \(h \to 0\) (\(N \to \infty\)). Мы имеем одну точку — при \(h = 1/10\) обе нормы равны \(10^{-2}\). Из этого факта:

  • не следует «сходится» — конечное значение \(\|z\| = 10^{-2}\) не влечёт \(\forall \varepsilon \exists N\colon \|z\| < \varepsilon\);
  • не следует «не сходится» — при \(h \to 0\) \(\|z_h\|\) в принципе может убывать к нулю (например, если задача — численный эксперимент, где ошибка на самом деле \(\|z_h\| = C h^p\) с некоторым \(p > 0\), тогда при \(h = 1/10\) получим \(\|z\| = 10^{-2}\), а при \(h = 1/100\) — уже \(10^{-2 - p}\)).

Для утверждения о сходимости нужна серия \(h_j \to 0\) с наблюдением \(\|z_{h_j}\|_{1, H} \to 0\); только тогда по Опр. 8 схема сходится, и дополнительно из монотонного убывания оценивается порядок сходимости.

Решение 9.Точная схема (Опр. 9)

Данные. Уравнение переноса \(u_t + a\, u_x = 0\), \(a > 0\), задача Коши с \(u(x, 0) = u_0(x)\), \(u_0 \in C^{1}(\mathbb{R})\); расчётная сетка \(G_h\) с равномерными шагами \(h\) (по \(x\)) и \(\tau\) (по \(t\)); схема-«уголок» \(y_i^{n+1} = y_i^n - (a\tau/h)\,(y_i^n - y_{i-1}^n)\); начальные значения \(y_i^0 = u_0(x_i)\); условие \(a\tau/h = 1\) (\(\Leftrightarrow a\tau = h\)).

(1) Подстановка \(a\tau/h = 1\).

\[ y_i^{n+1} \;=\; y_i^n - 1\cdot(y_i^n - y_{i-1}^n) \;=\; y_i^n - y_i^n + y_{i-1}^n \;=\; y_{i-1}^n. \tag{$\ast$} \]

(2) Индукция по \(n\). Утверждение: для всех целых \(n \ge 0\) и всех \(i\)  \(y_i^n = u_0(x_i - a\,t_n)\).

  • База \(n = 0\). По условию \(y_i^0 = u_0(x_i)\); с другой стороны, \(t_0 = 0\), значит \(u_0(x_i - a\, t_0) = u_0(x_i)\). Равенство выполнено.
  • Индукционный переход \(n \to n + 1\). Пусть (ИП) \(y_j^n = u_0(x_j - a\, t_n)\) для всех \(j\). Применяя ИП к \(j = i - 1\) и подставляя в \((\ast)\): \[ y_i^{n+1} \;\overset{(\ast)}{=}\; y_{i-1}^n \;\overset{\text{ИП}}{=}\; u_0(x_{i-1} - a\,t_n) \;=\; u_0(x_i - h - a\,t_n). \] Из \(a\tau = h\) следует \(h + a\,t_n = a\tau + a\cdot n\tau = a\,(n + 1)\,\tau = a\,t_{n+1}\), поэтому \[ y_i^{n+1} \;=\; u_0(x_i - a\,t_{n+1}). \] Индукционный переход доказан. ▢

(3) Точность на сетке (Опр. 9). Классическое решение задачи Коши для линейного уравнения переноса с постоянной скоростью и \(u_0 \in C^{1}(\mathbb{R})\) существует, единственно и даётся методом характеристик: характеристические кривые — прямые \(\{x - a\, t = \mathrm{const}\}\); вдоль каждой из них \(u = \mathrm{const}\), поэтому

\[ u(x, t) \;=\; u_0(x - a\,t). \]

Единственность классического \(C^{1}\)-решения — стандартная теорема (доказывается сведением к ОДУ вдоль характеристик и теореме об однозначности его решения при \(C^{1}\)-данных).

Значит сеточный след точного решения по проектору (1.17): \((P_{\tau\omega}\, u)_i^n = u(x_i, t_n) = u_0(x_i - a\,t_n)\). По пункту (2) численное решение совпадает с этим следом узел в узел: \(y_i^n = u_0(x_i - a\,t_n) = (P_{\tau\omega}\, u)_i^n\). Тогда сеточная функция погрешности из Опр. 7:

\[ z_i^n \;=\; y_i^n - (P_{\tau\omega}\, u)_i^n \;=\; 0 \qquad \forall\, i,\ n, \]

и в любой сеточной норме \(\|\cdot\|_{1, H}\) на \(H\) имеем \(\|z\|_{1, H} = 0\). По Опр. 9 схема точна на сетке \(G_h\) при \(a\tau/h = 1\) — для произвольного \(u_0 \in C^{1}(\mathbb{R})\).

Смысл условие \(a\tau/h = 1\) (число Куранта \(\sigma = 1\)) синхронизирует дискретный шаг схемы с точной характеристикой: за один временной шаг \(\tau\) значение переносится ровно на один пространственный узел \(h = a\tau\) — то же, что делает точное решение по формуле \(u_0(x - a\, t)\). Разностный оператор и характеристический сдвиг здесь тождественно совпадают, а не приближённо, — отсюда \(z_i^n \equiv 0\).

Решение 10.Верификация и валидация

Определения (§1.0b).

  • Верификация — проверка того, что реализованный алгоритм корректно решает заданную дискретную задачу. Ключевой вопрос: «решаем ли мы уравнения правильно?». Референс — сама математическая модель и её теоретические свойства (аналитическое решение, порядок сходимости, законы сохранения).
  • Валидация — проверка того, что математическая модель адекватно описывает реальный физический процесс. Ключевой вопрос: «те ли уравнения мы решаем?». Референс — измерения, эксперимент, эталонные (benchmark) данные.

1) Верификация схемы-«уголок» для \(u_t + u_x = 0\) (\(a = 1\)).

  1. Сравнение с аналитическим решением (метод характеристик). Модельная задача: \(u_0(x) = \sin(2\pi x)\) на периоде \([0, 1]\); точное решение — \(u(x, t) = \sin\bigl(2\pi(x - t)\bigr)\). Считаем при \(t = 1\) (волна должна сделать один полный оборот) и сравниваем \(y_i^N\) с \(u(x_i, 1) = u_0(x_i)\). Что должно наблюдаться:
    • при \(\sigma := a\tau/h = 1\) — совпадение с машинной точностью (Задача 9);
    • при \(\sigma \in (0, 1)\) — ошибка \(\varepsilon = \|y - u\|_C\) отлична от нуля, но должна убывать при \(h \to 0\); численный порядок должен соответствовать теоретическому \(p = 1\) для «уголка».
  2. Исследование сходимости (grid refinement). Считаем ту же задачу на серии сеток \(h_j = h_0 / 2^j\), \(j = 0, 1, \ldots, J\) (\(J \sim 4{-}5\)); для каждой вычисляем \(\varepsilon_{h_j} = \|y_{h_j} - u\|_C\) (или \(\|\cdot\|_{L_2, h}\)). На log-log графике \((\log h,\ \log \varepsilon)\) точки должны лечь на прямую с наклоном \(p = 1\). Условие «прошло» — наблюдаемый наклон \(\hat p\) в пределах \(\pm 0{,}1\) от теоретического; условие «провалено» — \(\hat p < 0{,}9\), излом графика или отсутствие монотонности \(\varepsilon\) по \(h\) — сигнал ошибки реализации (неверные индексы, некорректные граничные условия, потерянные множители).

2) Валидация уравнения переноса как модели.

  1. Сравнение с экспериментом. Пример: пассивный перенос красителя ламинарным потоком в лабораторной трубе с известной средней скоростью \(U\); измеряется распределение концентрации \(c(x, t)\) на серии срезов трубы. Модель: \(c_t + U\, c_x = 0\). Сравниваем расчётный и измеренный профили \(c(x, t_{\text{изм}})\). Отличие от верификации принципиальное: здесь под вопрос ставится не программа, а сама модель — правда ли, что процесс достаточно описывается линейным уравнением переноса без учёта диффузии, пристеночных эффектов, флуктуаций скорости.
  2. Границы применимости модели. \(u_t + u_x = 0\) описывает чистую адвекцию: бездиссипативный, линейный, скалярный процесс с постоянной скоростью. Валидация ставит вопрос о безразмерных числах \((Re, Pe, Ma)\): при каких режимах отбрасывание пренебрегаемых физических эффектов не искажает результат сильнее заданной точности. Формальный критерий — оценка отношения адвективного члена \(a\, u_x\) к отброшенным (диффузионному \(\varepsilon\, u_{xx}\), нелинейному \(u\, u_x\), сжимаемому \(\rho_t + (\rho u)_x\)): пока это отношение мало, модель применима; когда становится порядка единицы — модель надо менять на более полную (конвекция-диффузия, уравнения Эйлера/Навье – Стокса и т. п.).

3) Независимость V и V — примеры.

  • Верификация пройдена, валидация провалена. Программа корректно реализует «уголок» для \(u_t + u_x = 0\): подтверждается порядок сходимости \(p = 1\), совпадение с точным решением при \(\sigma = 1\). Но её применяют к переносу тепла в металлическом стержне, где реальный процесс — диффузия, \(u_t = \kappa\, u_{xx}\). Модель качественно неверна (диффузия «размазывает» профиль, адвекция — переносит без изменения), расчёт не совпадёт с экспериментом. Виновата модель, не программа.
  • Валидация пройдена, верификация провалена. Программа решает уравнения Навье – Стокса — физически адекватную модель. Но в реализации разностного оператора допущена ошибка (например, потерян множитель \(1/2\) в конвективном члене). На грубой сетке результат случайно попадает в диапазон экспериментальных значений — валидация «формально» проходит. Grid refinement, однако, не даёт ожидаемого порядка сходимости, а на измельчённых сетках решение уходит от эксперимента — верификация выявляет ошибку. Виновата программа, не модель.
Почему одна не заменяет другую верификация отвечает на вопрос «правильно ли алгоритм решает заданную математическую задачу»; валидация — «правильно ли заданная математическая задача описывает реальность». Логически это независимые утверждения: адекватную модель можно испортить реализацией, а корректно реализованный алгоритм — применить к неверной модели. Поэтому обе процедуры необходимы: верификация страхует от ошибок программирования и дискретизации, валидация — от ошибок постановки.
