Начнём с двух определений устойчивости из §2.

Семинар № 3 · Определения 4, 5 · Теорема 2

Два определения устойчивости (в курсе — определения 3 и 4 §2)

Разностная задача \(L_h u_h = f_h\) называется устойчивой, если её решение существует и единственно и для решений двух возмущённых задач \[ L_h u_h = f_h + \eta_h, \qquad L_h \nu_h = f_h + \eta'_h \] выполнена оценка \[ \|u_h - \nu_h\| \le C_2\bigl(\|\eta_h\| + \|\eta'_h\|\bigr), \qquad C_2 \ne C_2(h). \tag{2.12} \]
Для линейной разностной задачи \(L_h u_h = f_h\) устойчивость есть оценка решения через правую часть: \[ \|u_h\| \le C\,\|f_h\|, \qquad C \ne C(h). \tag{2.14} \]
Для линейных разностных задач, решение которых существует и единственно при любой правой части, определения 4 и 5 эквивалентны.

Доказательство — в обе стороны, с указанием места, где используется линейность.

Семинар № 3 · Доказательство теоремы 2

Эквивалентность определений 4 и 5 для линейных задач

Определение 4 \(\Rightarrow\) определение 5. Пусть \(L_h u_h = f_h\). Положим \[ \eta_h = 0; \qquad \nu_h = 0, \quad \eta'_h = -f_h. \] используется линейность \(L_h 0 = 0 = f_h + \eta'_h\), т.е. \(\nu_h = 0\) — решение второй возмущённой задачи. По (2.12) \[ \|u_h - 0\| \le C_2\bigl(\|0\| + \|-f_h\|\bigr) = C_2\,\|f_h\|, \] это (2.14) с \(C = C_2\). ∎
Определение 5 \(\Rightarrow\) определение 4. Пусть \(L_h u_h = f_h + \eta_h\), \(L_h \nu_h = f_h + \eta'_h\). используется линейность \[ L_h(u_h - \nu_h) = L_hu_h - L_h\nu_h = \eta_h - \eta'_h. \] По (2.14) для задачи с правой частью \(\eta_h - \eta'_h\) \[ \|u_h - \nu_h\| \le C\,\|\eta_h - \eta'_h\| \le C\bigl(\|\eta_h\| + \|\eta'_h\|\bigr), \] это (2.12) с \(C_2 = C\). ∎

Промежуточная оценка через \(\|\eta_h - \eta'_h\|\) сильнее (2.12); для нелинейных задач это различие существенно.

Семинар № 3 · Замечание к определению 4

Оценка через сумму и оценка через разность возмущений

\[ \|u_h - \nu_h\| \le C\,\|\eta_h - \eta'_h\|. \tag{С.1} \]
Сравнение (С.1) и (2.12)Так как \(\|\eta_h - \eta'_h\| \le \|\eta_h\| + \|\eta'_h\|\), из (С.1) следует (2.12): оценка (С.1) сильнее. Для линейных задач они равносильны (теорема 2). Оценка (2.12) равносильна оценке \[ \|u_h(\eta) - u_h(0)\| \le C\,\|\eta\|, \] то есть непрерывности решения только около невозмущённой задачи.
Пример: нелинейная задача, (2.12) верно, (С.1) нетСкалярная задача \(L_h u = \eta\), решение \(u = F_h(\eta)\): \[ F_h(\eta) = \begin{cases} \eta, & \eta \le 1,\\ 1 + (\eta - 1)/h, & 1 \le \eta \le 1 + h,\\ \eta + 1, & \eta \ge 1 + h. \end{cases} \] \(F_h\) монотонна, \(|F_h(\eta)| \le 2|\eta|\) ⇒ (2.12) с \(C_2 = 2\). При \(\eta = 1\), \(\eta' = 1 + h\): \(|u - \nu| = 1\), \(|\eta - \eta'| = h\).

Для нелинейных схем устойчивость понимают в смысле (С.1). Далее — эволюционные задачи и устойчивость по начальным данным.

Семинар № 3 · Определение 7

Равномерная устойчивость по начальным данным

Двухслойная схема называется равномерно устойчивой по начальным данным, если существуют число \(\rho > 0\) и постоянная \(C\), не зависящая от \(h\) и \(\tau\), такие, что \[ \|y^{n+1}\| \le \rho\,\|y^{n}\|, \qquad \rho^{n} \le C \qquad\text{при всех } n = 0, 1, \dots, N = T/\tau. \] Тогда \(\ \|y^{n}\| \le \rho^{n}\|y^{0}\| \le C\,\|y^{0}\|\) — оценка (6.1) §6.
Строгая устойчивость\(\rho = 1\), \(C = 1\): \(\|y^{n+1}\| \le \|y^{n}\|\) — норма не возрастает. Так формулируются теоремы 1, 2 §6а.
Нестрогая устойчивость\(\rho = 1 + c_0\tau\) или \(\rho = e^{c_0\tau}\): так как \(n\tau \le T\), \[ \rho^{n} \le e^{c_0 n\tau} \le e^{c_0T} = C. \] Нужна для задач с растущими решениями.

Необходимое условие устойчивости по начальным данным — спектральный признак.

Семинар № 3 · Теорема 3

Спектральный признак устойчивости фон Неймана

Пусть линейная двухслойная схема \(y^{n+1} = Sy^{n}\) равномерно устойчива по начальным данным: \(\|S^{n}\| \le C\) при \(n \le N = T/\tau\). Тогда все собственные числа \(\lambda\) оператора перехода \(S\) удовлетворяют условию \[ |\lambda| \le 1 + c_0\tau, \qquad c_0 \ne c_0(h, \tau). \]
Доказательство. Пусть \(Sv = \lambda v\), \(v \ne 0\) (при комплексном \(\lambda\) — на комплексных функциях; в \(L_2\) \(\|a + ib\|^2 = \|a\|^2 + \|b\|^2\), поэтому \(\|S^n\| \le \sqrt2\,C = C'\)). При \(y^0 = v\) \[ y^{n} = S^{n}v = \lambda^{n}v \quad\Longrightarrow\quad |\lambda|^{n}\,\|v\| \le C'\|v\| \quad\Longrightarrow\quad |\lambda|^{n} \le C', \qquad n \le N. \] оценка верна лишь при \(n \le N\) Полагаем \(n = N = T/\tau\) и пользуемся \(e^{x} \le 1 + x\,e^{x}\), \(x \ge 0\): \[ |\lambda| \le C'^{\,\tau/T} = e^{\tau\ln C'/T} \le 1 + c_0\tau, \qquad c_0 = \frac{\ln C'}{T}\,C'^{\,\tau_0/T}, \quad \tau \le \tau_0. \ \ ∎ \]

Так же получено условие Неймана (6.5)–(6.6) §6; предельный переход \(n \to \infty\) при фиксированном \(\tau\) недопустим.

Семинар № 3 · Определение 8 · Теорема 4

Устойчивость по правой части двухслойной схемы

\[ B_1\,y^{n+1} = B_0\,y^{n} + \tau\,\varphi^{n+1}, \qquad S = B_1^{-1}B_0, \tag{С.2} \]

\(B_1\), \(B_0\) — линейные операторы (матрицы), \(B_1\) обратим; \(S\) — оператор перехода (§6.2).

Схема (С.2) устойчива по правой части, если при всех \(n \le N\) \[ \|y^{n}\| \le M\Bigl(\|y^0\| + \sum_{k=1}^{n}\tau\,\|\varphi^{k}\|\Bigr), \qquad M \ne M(h, \tau). \]
Пусть схема (С.2) устойчива по начальным данным, \(\|S^{m}\| \le C\) при \(m \le N\), и оператор \(B_1\) равномерно обратим, \(\|B_1^{-1}\| \le C_1\). Тогда \[ \max_{n \le N}\|y^{n}\| \le C\Bigl(\|y^{0}\| + C_1\sum_{k=1}^{N}\tau\,\|\varphi^{k}\|\Bigr). \]

Доказательство — явная формула решения через начальные данные и правые части.

Семинар № 3 · Доказательство теоремы 4

Формула решения через начальные данные и правые части

Этап 1. Формула решения. используется линейность Умножая (С.2) на \(B_1^{-1}\): \[ y^{n+1} = S\,y^{n} + \tau\,B_1^{-1}\varphi^{n+1}. \] Отсюда \(y^1 = Sy^0 + \tau B_1^{-1}\varphi^1\), \(\ y^2 = S^2y^0 + \tau SB_1^{-1}\varphi^1 + \tau B_1^{-1}\varphi^2\), и по индукции \[ y^{n} = S^{n}y^{0} + \tau\sum_{k=1}^{n} S^{\,n-k}B_1^{-1}\varphi^{k}. \] Дискретный аналог формулы Дюамеля.
Этап 2. Оценка. По неравенству треугольника и \(\|Ax\| \le \|A\|\,\|x\|\): \[ \|y^{n}\| \le \|S^{n}\|\,\|y^{0}\| + \tau\sum_{k=1}^{n}\|S^{\,n-k}\|\,\|B_1^{-1}\|\,\|\varphi^{k}\|. \] используются \(\|S^m\| \le C\), \(\|B_1^{-1}\| \le C_1\) \[ \|y^{n}\| \le C\Bigl(\|y^{0}\| + C_1\sum_{k=1}^{n}\tau\,\|\varphi^{k}\|\Bigr). \ \ ∎ \]

Для схем в канонической форме (6а.22) те же вопросы решаются энергетическим методом.

Семинар № 3 · Определения 9, 10

Каноническая форма; устойчивость по начальным данным и по правой части

\[ B\,\frac{y^{n+1} - y^{n}}{\tau} + A\,y^{n} = \varphi^{n}, \qquad y^0 \text{ задано}. \tag{6а.22} \]

\(A, B\colon H \to H\) — линейные операторы, \(B\) обратим; из (С.2): \(B = B_1\), \(A = (B_1 - B_0)/\tau\). При \(B = E\) схема явная, при \(\varphi^n = 0\) — однородная.

Однородная схема (6а.22) равномерно устойчива по начальным данным, если \(\ \|y^{n}\| \le M_1\|y^{0}\|\), \(n \le N\), \(M_1 \ne M_1(h, \tau)\) — оценка (6.1).
Схема (6а.22) устойчива по правой части, если при \(y^0 = 0\) выполнено \(\ \|y^{n}\| \le M_2\|\varphi\|_*\), \(n \le N\), \(M_2 \ne M_2(h, \tau)\), с указанной нормой \(\|\varphi\|_*\) правых частей \(\varphi^0, \dots, \varphi^{N-1}\).
Операторные неравенства (§6а.4)\(A > 0\): \((Ay, y) > 0\) при \(y \ne 0\); \(\ B \ge A\): \((By, y) \ge (Ay, y)\) при всех \(y \in H\); \(\ \|y\|_A = \sqrt{(Ay, y)}\) при \(A = A^* > 0\).

Энергетический признак Самарского — условие на \(B\) и \(A\), при котором \(\|y\|_A\) не возрастает.

Семинар № 3 · Теорема 5 (= теоремы 1, 2 §6а)

Энергетический признак устойчивости А. А. Самарского

Пусть в однородной схеме \(\ B\frac{y^{n+1} - y^{n}}{\tau} + Ay^{n} = 0\ \) операторы \(A, B\colon H \to H\) линейны, \(A = A^* > 0\), \(B\) обратим. Тогда условие \[ B \ge \frac{\tau}{2}\,A \tag{6а.34} \] необходимо и достаточно для того, чтобы при любых начальных данных \[ \|y^{n+1}\|_A \le \|y^{n}\|_A, \qquad n = 0, 1, \dots \tag{6а.35} \]
Самосопряжённость \(B\)Не требуется ни для достаточности, ни для необходимости; условие \(B = B^* > 0\) нужно только для оценки в норме \(H_B\) (теорема 2 §6а).
Характер необходимостиУсловие необходимо для оценки с постоянной \(1\) (строгая устойчивость). При \(\rho = 1 + c_0\tau\) оно не необходимо: \(B = E\), \(\tau\|A\| = 2 + c_0\tau\) дают \(\|E - \tau A\| = 1 + c_0\tau\), но \(E \ge \frac\tau2 A\) нарушено.

Обе части доказательства опираются на одно тождество.

Семинар № 3 · Доказательство теоремы 5 · Основное тождество

Энергетическое тождество схемы

Обозначим \(v^{n} = \dfrac{y^{n+1} - y^{n}}{\tau}\). Тогда \(y^{n+1} = y^{n} + \tau v^{n}\), а схема принимает вид \(Bv^{n} + Ay^{n} = 0\), т.е. \(Ay^{n} = -Bv^{n}\).

используются линейность \(A\) и \(A = A^*\) \[ \|y^{n+1}\|_A^2 = \bigl(A(y^{n} + \tau v^{n}),\ y^{n} + \tau v^{n}\bigr) = (Ay^{n}, y^{n}) + 2\tau\,(Ay^{n}, v^{n}) + \tau^2(Av^{n}, v^{n}), \] так как \((Av^n, y^n) = (v^n, Ay^n) = (Ay^n, v^n)\). Подставляя \(Ay^{n} = -Bv^{n}\): \[ \|y^{n+1}\|_A^2 = \|y^{n}\|_A^2 - 2\tau\,(Bv^{n}, v^{n}) + \tau^2(Av^{n}, v^{n}), \] \[ \boxed{\ \|y^{n+1}\|_A^2 = \|y^{n}\|_A^2 - 2\tau\Bigl(\bigl(B - \tfrac{\tau}{2}A\bigr)v^{n},\ v^{n}\Bigr)\ } \tag{С.3} \]
Связь с §6аПри \(w = y^{n+1} - y^{n} = \tau v^{n}\) тождество (С.3) совпадает с (6а.39): \(\ 2\tau\bigl((B - \frac\tau2A)v, v\bigr) = \frac2\tau\bigl((B - \frac\tau2A)w, w\bigr)\).

Из (С.3) следуют обе части теоремы 5.

Семинар № 3 · Доказательство теоремы 5 · Достаточность и необходимость

Достаточность и необходимость условия \(B \ge \frac{\tau}{2}A\)

Достаточность. используется (6а.34) При \(B \ge \frac\tau2A\) имеем \(\bigl((B - \frac\tau2A)v, v\bigr) \ge 0\) для всех \(v\); по (С.3) \[ \|y^{n+1}\|_A^2 \le \|y^{n}\|_A^2. \] используется \(A > 0\) \(\|\cdot\|_A\) — норма; извлекая корень, получаем (6а.35). ∎
Необходимость. Пусть (6а.35) верно при любых \(y^0\). По (С.3) при \(n = 0\) \[ 2\tau\Bigl(\bigl(B - \tfrac\tau2A\bigr)v^{0}, v^{0}\Bigr) = \|y^{0}\|_A^2 - \|y^{1}\|_A^2 \ge 0. \] используются \(A > 0\), обратимость \(B\) \(v^0 = -B^{-1}Ay^0\), и оператор \(B^{-1}A\) обратим (\(A > 0\) ⇒ \(Ay = 0\) лишь при \(y = 0\)). Для любого \(v \in H\) при \(y^0 = -A^{-1}Bv\) имеем \(v^0 = v\). Следовательно, \(\bigl((B - \frac\tau2A)v, v\bigr) \ge 0\) при всех \(v\), т.е. \(B \ge \frac\tau2A\). ∎
Необходимость получена из оценки с постоянной \(1\); из \(\|y^{1}\|_A \le \rho\,\|y^{0}\|_A\) при \(\rho > 1\) неотрицательность разности \(\|y^0\|_A^2 - \|y^1\|_A^2\) не следует.

Устойчивость по правой части выводится из устойчивости по начальным данным.

Семинар № 3 · Теорема 6

Устойчивость по правой части из устойчивости по начальным данным

Пусть линейная схема (6а.22) с обратимым \(B\) равномерно устойчива по начальным данным: \(\|S^{m}\| \le M_1\), \(m \le N\), где \(S = E - \tau B^{-1}A\). Тогда \[ \|y^{n}\| \le M_1\Bigl(\|y^{0}\| + \sum_{k=0}^{n-1}\tau\,\|B^{-1}\varphi^{k}\|\Bigr), \qquad n \le N. \]
Доказательство. используется линейность \(y^{n+1} = Sy^{n} + \tau B^{-1}\varphi^{n}\), откуда по индукции \[ y^{n} = S^{n}y^{0} + \tau\sum_{k=0}^{n-1}S^{\,n-1-k}B^{-1}\varphi^{k}, \qquad \|y^{n}\| \le \|S^{n}\|\,\|y^{0}\| + \tau\sum_{k=0}^{n-1}\|S^{\,n-1-k}\|\,\|B^{-1}\varphi^{k}\|, \] и \(\|S^m\| \le M_1\) даёт оценку. ∎
Гипотезы; сравнение с теоремой 3 §6а\(A = A^* > 0\) не используется: теорема верна для любой линейной схемы; вместе с теоремой 5 в норме \(H_A\) \(M_1 = 1\). Правая часть входит через \(\|B^{-1}\varphi^k\|\); оценка (6а.45) через \(\|\varphi^k\|\) требует \(B \ge \varepsilon E + \frac\tau2A\).

Все теоремы семинара — о линейных схемах. Требует ли линейности сам энергетический метод?

Семинар № 3 · Замечание о линейности

Линейность: теоремы и энергетический метод

Требуют линейностиОпределение 5 и теорема 2 (\(L_h0 = 0\), \(L_h(u - \nu) = L_hu - L_h\nu\)); теорема 3 (собственные числа \(S\)); теоремы 4, 6 (формула через \(S^n\)); теорема 5 (\(A = A^*\), \(B \ge \frac\tau2A\), \(\|\cdot\|_A\)).
Не требует линейностиЭнергетический метод: умножение на решение, разность квадратов, суммирование по частям; нужна лишь билинейность \((\cdot\,,\cdot)\), а не линейность схемы.
Пример: нелинейное уравнение теплопроводности \(\;u_t = (k(u)\,u_x)_x\), \(k \ge 0\), \(u(0,t) = u(l,t) = 0\); неявная схема \[ \frac{y^{n+1}_i - y^{n}_i}{\tau} = \bigl(a\,y^{n+1}_l\bigr)_{r,i}, \qquad a_i = k\Bigl(\tfrac{y^{n+1}_{i-1} + y^{n+1}_{i}}{2}\Bigr) \ge 0, \qquad y_0 = y_N = 0. \] Умножим скалярно на \(y^{n+1}\); \((p - q)\,p = \frac12(p^2 - q^2) + \frac12(p - q)^2\) и суммирование по частям (§6а.5) дают \[ \frac{\|y^{n+1}\|^2 - \|y^{n}\|^2}{2\tau} \le -\sum_{i=1}^{N} h\,a_i\,\bigl(y^{n+1}_{l,i}\bigr)^2 \le 0 \quad\Longrightarrow\quad \|y^{n+1}\| \le \|y^{n}\| \ \ \text{при любом } \tau. \]
Для нелинейной схемы это ограниченность решения, а не устойчивость в смысле (С.1): разность двух решений оценивается отдельно. Теорема о сходимости §3 — для линейных схем.

Итог: теорема Самарского — для линейных схем, энергетический метод — и для нелинейных.
