§3 · Место теоремы в курсе

Место теоремы в курсе

  • Аппроксимация (Опр. 2 §2): \(\|\xi_h\| \le C_1 h^p\), проверяется рядами Тейлора — умеем.
  • Устойчивость (Опр. 3 §2): \(\|u_h - \nu_h\| \le C_2(\|\eta_h\| + \|\eta'_h\|)\) — определили, проверять научимся в §5.
  • Сходимость (Опр. 1 §2): \(\|u_h - U_h\| \le C h^p\) — цель, по определению не проверяется: в нём стоит неизвестное \(U\).

Теорема Лакса заменяет непроверяемое свойство двумя проверяемыми.

§3.1 · Формулировка

Теорема Лакса

(Лакс). Пусть разностная схема \(L_h u_h = f_h\) аппроксимирует дифференциальную задачу \(Lu = f\) на решении \(u\) с порядком \(p\) и устойчива. Тогда решение \(u_h\) разностной задачи сходится к решению дифференциальной задачи \(Lu = f\), причём имеет место оценка \[ \|u_h - U_h\| \;\le\; C_1 C_2\, h^p \;=\; C\, h^p, \tag{3.1} \] где \(U_h\) — проекция точного решения на сетку.

Формулировка в терминах определений §2

  • аппроксимирует на решении с порядком \(p\) — Опр. 2: \(\|\xi_h\| \le C_1 h^p\);
  • устойчива — Опр. 3: \(\|u_h - \nu_h\| \le C_2(\|\eta_h\| + \|\eta'_h\|)\);
  • сходится — Опр. 1: \(\|u_h - U_h\| \to 0\); порядок сходимости тот же \(p\);
  • \(C = C_1 C_2\) — постоянная сходимости есть произведение постоянных аппроксимации и устойчивости.
§3.2 · Доказательство · Этап 1 из 4

Этап 1. Определение устойчивости

По Определению 3 (§2.4): для любых двух сеточных функций \(u_h\), \(\nu_h\), удовлетворяющих

\[ L_h u_h = f_h + \eta_h, \tag{3.2} \]
\[ L_h \nu_h = f_h + \eta'_h, \tag{3.3} \]

где \(\eta_h\), \(\eta'_h\) — малые возмущения правой части, выполняется

\[ \|u_h - \nu_h\| \;\le\; C_2\bigl(\|\eta_h\| + \|\eta'_h\|\bigr), \qquad C_2 \ne C_2(h). \tag{3.4} \]
Произвол в определении устойчивости Определение устойчивости допускает любые \(u_h\), \(\nu_h\), \(\eta_h\), \(\eta'_h\), удовлетворяющие (3.2)–(3.3). Доказательство состоит в выборе этих четырёх объектов.
Где используется гипотеза Здесь — устойчивость: даёт неравенство (3.4) с постоянной, не зависящей от \(h\). Аппроксимация пока не нужна.
§3.2 · Доказательство · Этап 2 из 4

Этап 2. Выбор функций \(u_h\) и \(\nu_h\)

Первая функция. Пусть \(u_h\) — точное решение разностной задачи \(L_h u_h = f_h\). Тогда в (3.2) возмущения нет:

\[ \eta_h = 0. \]

Вторая функция. Пусть \(\nu_h = U_h\) — проекция точного решения дифференциальной задачи на сетку. Подставим её в (3.3) и вспомним определение невязки (2.7):

\[ \eta'_h \;=\; L_h U_h - f_h \;=\; \xi_h. \tag{3.5} \]
Основной шаг доказательства Проекция точного решения удовлетворяет схеме с правой частью \(f_h + \xi_h\). Следовательно, невязка есть возмущение правой части в смысле Опр. 3.
§3.2 · Доказательство · Этап 3 из 4

Этап 3. Оценка через невязку

С выбранными \(u_h\), \(\nu_h = U_h\) система (3.2)–(3.3) принимает вид

\[ L_h u_h = f_h, \tag{3.6} \]
\[ L_h U_h = f_h + \xi_h. \tag{3.7} \]

Это в точности (3.2)–(3.3) с \(\eta_h = 0\), \(\eta'_h = \xi_h\). По определению устойчивости, то есть по (3.4):

\[ \|u_h - U_h\| \;\le\; C_2\bigl(\|0\| + \|\xi_h\|\bigr) \;=\; C_2\,\|\xi_h\|. \tag{3.8} \]
Результат этапа Слева — ровно та величина, которая стоит в определении сходимости: разность решения схемы и проекции точного решения. Справа — невязка с постоянной устойчивости. Погрешность решения оценена через погрешность аппроксимации.
Где использована гипотеза Снова устойчивость: неравенство (3.4) применено к конкретной паре. Аппроксимация ещё не использована — (3.8) верно для любой схемы, лишь бы она была устойчива.
§3.2 · Доказательство · Этап 4 из 4

Этап 4. Применение аппроксимации

По определению аппроксимации (Опр. 2, (2.8)) \(\|\xi_h\| \xrightarrow[h\to 0]{} 0\). Тогда из (3.8)

\[ \|u_h - U_h\| \;\le\; C_2\,\|\xi_h\| \xrightarrow[h \to 0]{} 0 \tag{3.9} \]

— это и есть сходимость по Опр. 1. Если, кроме того, аппроксимация имеет порядок \(p\), то есть \(\|\xi_h\| \le C_1 h^p\) по (2.9), то

\[ \|u_h - U_h\| \;\le\; C_2\,\|\xi_h\| \;\le\; C_2\,C_1\,h^p \;=\; C\,h^p. \qquad\blacksquare \tag{3.10} \]
Результат этапа Сходимость порядка \(p\) по Опр. 1 с постоянной \(C = C_1 C_2\), не зависящей от \(h\): \(C_1\) не зависит по Опр. 2, \(C_2\) — по Опр. 3.
Где использована гипотеза Здесь — аппроксимация, и только здесь: сначала как \(\|\xi_h\| \to 0\), затем как \(\|\xi_h\| \le C_1 h^p\).
§3.2 · Схема доказательства

Схема доказательства

Невязка из определения аппроксимации подставляется в оценку устойчивости как возмущение правой части при \(\nu_h = U_h\).
§3 · Следствия и замечания

Следствия теоремы

Следствие Для проверки сходимости схемы достаточно проверить два свойства по отдельности:
  • аппроксимацию — обычно просто: ряды Тейлора по алгоритму §2.8;
  • устойчивость — основная трудность; методам её исследования посвящён §5 и далее.
Порядок и постоянная Порядок сходимости равен порядку аппроксимации на решении; постоянная сходимости \(C = C_1 C_2\). Численно измеренный порядок \(\log_2(\|z_h\|/\|z_{h/2}\|)\) должен совпасть с порядком невязки — если нет, схема неустойчива или решение негладкое.

Замечание (обратная теорема). Для линейных корректно поставленных задач при наличии аппроксимации сходимость равносильна устойчивости — теорема эквивалентности Лакса — Рихтмайера. Мы её не доказываем; нам достаточно прямого утверждения.
§3 · Итоги

Итоги §3

  1. Теорема Лакса: аппроксимация на решении с порядком \(p\) + устойчивость \(\Rightarrow\) сходимость порядка \(p\), \(\|u_h - U_h\| \le C_1 C_2 h^p\).
  2. Идея доказательства: проекция точного решения — «почти решение» схемы с возмущением правой части, равным невязке; устойчивость переводит невязку в ошибку решения с множителем \(C_2\).
  3. Роли гипотез: устойчивость — этапы 1 и 3, невязка — этап 2, аппроксимация — этап 4.
  4. Программа курса: сходимость не проверяем — проверяем аппроксимацию (§2) и устойчивость (§5).
Следующие разделы
  • §4. Первое дифференциальное приближение: уравнение \(L_1 u = 0\) из алгоритма §2.8 как самостоятельный объект — что на самом деле решает схема.
  • Задание на пару в конце §4: по схеме на группу.
