Занятие 4 · Блок II. Интерполяция

Узлы Чебышёва и сплайны

Два пути победить Рунге
§4.1 · Развилка

Феномен Рунге лечится двумя разными путями

В § 3 погрешность интерполяции (3.6) распалась на два множителя:

\[ f(x) - P_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}\cdot\omega_{n+1}(x). \]
  • Первый путь: оптимизировать узловой множитель \(\omega_{n+1}\) — сгустить узлы у концов отрезка (чебышёвская сетка).
  • Второй путь: убить множитель \((f^{(n+1)}/(n+1)!)\) — не давать степени \(n\) расти, а склеить много кусочков низкой степени (сплайн).
§4.2 · Полиномы Чебышёва

Полиномы Чебышёва первого рода

\[ T_n(x) = \cos(n\arccos x),\qquad x\in[-1, 1]. \tag{4.2} \]
Через рекуррентное соотношение:
\[ T_0 = 1,\ T_1 = x,\ T_{n+1}(x) = 2x\,T_n(x) - T_{n-1}(x). \tag{4.3} \]
Старший коэффициент \(T_n\) при \(n\ge 1\) равен \(2^{n-1}\).
§4.2 · Равноколебательность

\(T_n\) «равномерно колеблется»

На \([-1, 1]\) выполнено \(|T_n(x)|\le 1\); \(T_n\) достигает \(\pm 1\) ровно \(n+1\) раз в точках \(x_k^{*} = \cos(k\pi/n)\), меняя знак.
Полином Чебышёва \(T_5\) — 6 экстремумов, все на границах \(\pm 1\).
§4.3 · Минимаксное свойство

\(\widetilde T_n = 2^{1-n} T_n\) — минимаксный приведённый

Среди всех приведённых (моника) многочленов степени \(n\) наименьшую равномерную норму на \([-1, 1]\) даёт \(\widetilde T_n\):
\[ \min_{\substack{q\ \text{приведён}\\ \deg q = n}}\max_{[-1,1]}|q(x)| = \frac{1}{2^{n-1}}. \tag{4.5} \]

Именно то, что нужно для узлового множителя \(\omega_{n+1}\).

§4.3 · Чебышёвские узлы

Узлы = корни \(T_{n+1}\)

\[ x_k = \cos\!\left(\frac{2k+1}{2(n+1)}\,\pi\right),\qquad k = 0, 1, \ldots, n. \tag{4.6} \]
Сгущаются у концов отрезка (шаг \(\sim 1/n^2\) у краёв vs \(\sim 1/n\) в середине).
оценка ошибки.
\[ \|f - P_n\|_\infty \le \frac{\|f^{(n+1)}\|_\infty}{2^n\,(n+1)!}. \tag{4.7} \]
Экспоненциальная сходимость для аналитических функций.
§4.3 · Практика

Рунге разгромлен

Равномерная сетка, n=20
Максимум ошибки на \(1/(1+25x^2)\) — \(\sim 60\).
Экспоненциальный рост с ростом \(n\).
Чебышёвская сетка, n=20
Максимум ошибки на \(1/(1+25x^2)\) — \(\sim 10^{-4}\).
Экспоненциальное убывание с ростом \(n\).

Различие — 6 порядков ценой одной строчки кода: x = cos((2k+1)*pi/(2(n+1))).

§4.4 · Второй путь

Кусочная линейная интерполяция

Функция, интерполирующая \(y_i\) в узлах \(x_0 < x_1 < \ldots < x_n\), линейная на каждом подотрезке:
\[ L(x) = y_i + \frac{y_{i+1}-y_i}{x_{i+1}-x_i}(x - x_i),\qquad x\in[x_i, x_{i+1}]. \]
Для \(f\in C^2\):
\[ \|f - L\|_\infty \le \frac{h^2}{8}\|f''\|_\infty. \tag{4.9} \]
Никакого Рунге. Шаг \(h\to 0\) — ошибка убывает как \(O(h^2)\).

Плата: \(L(x)\) — только \(C^0\); в узлах производная терпит разрыв.

§4.5 · Гладкий вариант

Кубический сплайн — \(C^2\), кусочный степени 3

\(S(x)\), удовлетворяющая:
  1. на каждом \([x_i, x_{i+1}]\) — многочлен степени \(\le 3\);
  2. \(S(x_i) = y_i\) (интерполяция);
  3. \(S \in C^2[a, b]\) — гладкая до второй производной.

Ограничений \(4n - 2\), неизвестных \(4n\). Нужны два краевых условия.

три стандартных типа.
  • Natural: \(S''(a) = S''(b) = 0\).
  • Clamped: \(S'(a) = f'(a),\ S'(b) = f'(b)\).
  • Not-a-knot: \(S'''\) непрерывна в \(x_1, x_{n-1}\) (стандарт MATLAB).
§4.6 · Метод построения

Моменты + трёхдиагональная система

Через моменты \(M_i = S''(x_i)\) кубик восстанавливается однозначно. Условие \(C^1\) в узле \(x_i\) даёт:

\[ h_{i-1} M_{i-1} + 2(h_{i-1}+h_i) M_i + h_i M_{i+1} = 6\!\left(\frac{y_{i+1}-y_i}{h_i} - \frac{y_i-y_{i-1}}{h_{i-1}}\right). \tag{4.10} \]

Матрица трёхдиагональная и диагонально преобладающая — метод прогонки за \(O(n)\).

Заглядываем в § 10: прогонка (Thomas) — стандартный алгоритм для трёхдиагональных систем; изучим отдельно.
§4.7 · Итоги

Что унести с занятия 4

  1. Полиномы Чебышёва \(T_n\) — минимаксные среди приведённых на \([-1, 1]\).
  2. Чебышёвские узлы (4.6) сгущаются у концов; интерполяция на них даёт экспоненциальную сходимость (4.7) для гладких функций.
  3. Кусочная линейная интерполяция даёт \(O(h^2)\) без всякого Рунге, но не гладкая.
  4. Кубический сплайн — гладкая \(C^2\) кусочная интерполяция степени 3.
  5. Строится через моменты и трёхдиагональную систему (4.10), решаемую прогонкой за \(O(n)\).
