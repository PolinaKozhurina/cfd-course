Энергетический метод доказывает априорную оценку — из одной лишь структуры схемы, до и без её решения:

\[ \|y^{n+1}\| \le \|y^{n}\| \quad\text{или}\quad \|y^{n}\|^2 \le \|y^{0}\|^2 + C\sum_{k=0}^{n-1}\tau\,\|\varphi^{k}\|^2. \tag{6а.1} \]
СледствиеЭто оценка (2.14) Определения 4 §2 с явной нормой и постоянной. Условия, при которых она доказана, — достаточные. Гармоники дают необходимые; совпали — ответ точен.

Само тождество — сеточная копия одной выкладки из теории уравнений в частных производных. Проведём её для уравнения.

§6а.2 · Дифференциальный прототип

Закон сохранения энергии: перенос и теплопроводность

\(u_t + a u_x = 0\), \(u(0,t) = u(l,t)\), \(a = \mathrm{const}\) — дифференциальный прототип уравнения, для которого построен «уголок». Умножим на \(u\) и проинтегрируем по \(x\) от \(0\) до \(l\):

первое слагаемое — точная производная энергии по \(t\)
\[ \int_0^l u\,u_t\,dx = \int_0^l \tfrac12\bigl(u^2\bigr)_t\,dx = \tfrac12\,\frac{d}{dt}\int_0^l u^2\,dx. \]

\(E(t) = \int_0^l u^2\,dx = \|u(\cdot,t)\|^2_{L_2}\) — энергия решения; левая колонка — это \(\tfrac12\,dE/dt\).

второе слагаемое — точная производная по \(x\); интеграл сводится к границам
\[ a\,u\,u_x = \tfrac{a}{2}\bigl(u^2\bigr)_x \ \Rightarrow\ \int_0^l a\,u\,u_x\,dx = \tfrac{a}{2}\Bigl[u^2(x,t)\Bigr]_{x=0}^{x=l} = \tfrac{a}{2}\bigl(\underbrace{u^2(l,t) - u^2(0,t)}_{=\,0\ \text{по периодичности}}\bigr) = 0. \]
\[ \frac{dE}{dt} = 0, \qquad \|u(\cdot,t)\|_{L_2} = \|u(\cdot,0)\|_{L_2}; \qquad\text{теплопроводность: }\ \tfrac12\frac{dE}{dt} = \nu\int_0^l u\,u_{xx}\,dx = -\nu\int_0^l u_x^2\,dx \le 0. \tag{6а.3–6а.4} \]
Где вошло краевое условиеВ квадратных скобках сократились \(u^2(l,t)\) и \(u^2(0,t)\) — по периодичности; в теплопроводности исчез внеинтегральный член \([uu_x]_0^l\). На сетке эту роль возьмут условие \(y_0 = y_N\) и сдвиг индекса.

Зачем эта выкладка стоит первой и почему всюду дальше будет именно квадрат нормы — на следующем слайде.

§6а.2 · Зачем прототип и откуда квадрат нормы

Зачем этот вывод стоит первым и почему всюду квадрат нормы

Выкладка — не иллюстрация, а образец: каждый шаг сеточного метода копирует её шаг; все понятия §6а.3–§6а.6 вводятся ради этой копии.

1. Откуда взялся квадратИз умножения уравнения на решение: \(u\,u_t = \tfrac12(u^2)_t\) — производная квадрата; уравнение говорит именно о \(\int u^2dx\). Для переноса сохраняется и любая \(\int\Phi(u)\,dx\), но для теплопроводности \(\frac{d}{dt}\int\Phi(u)dx = -\nu\int\Phi''(u)u_x^2dx\) имеет знак лишь при выпуклой \(\Phi\), и только \(\Phi = u^2\) порождена скалярным произведением.
2. Почему квадрат удобен на сеткеСхема линейна, а \(\|y\|^2 = (y, y)\) билинейна, поэтому разность энергий соседних слоёв раскладывается на множители:
\[ \|y^{n+1}\|^2 - \|y^{n}\|^2 = \bigl(y^{n+1} - y^{n},\ y^{n+1} + y^{n}\bigr) \]
— двойник \((u^2)_t = 2u\,u_t\): «приращение × сумма». Приращение схема выражает через \(A\); значит, умножаем схему на сумму (полусумму) слоёв — слева стоит разность энергий.
3. Почему это ничего не стоитКоши–Буняковский, \(\varepsilon\)-неравенство, знаки — всё работает с квадратами; из \(\|y^{n+1}\|^2 \le \|y^n\|^2\) корень даёт \(\|y^{n+1}\| \le \|y^n\|\) — устойчивость по Определению 4 §2 без потерь.

Оба результата (6а.3), (6а.4) имеют одну форму — «плотность и поток». Дадим ей имя и потренируемся на другом уравнении.

§6а.2 · Законы сохранения · упражнение

Законы сохранения: плотность и поток. Упражнение — уравнение Кортевега — де Вриза

\[ \frac{\partial T}{\partial t} + \frac{\partial X}{\partial x} = 0 \quad\Longrightarrow\quad \frac{d}{dt}\int_0^l T\,dx = -\Bigl[X\Bigr]_0^l = 0: \qquad T\ \text{— плотность},\ X\ \text{— поток},\ \int_0^l T\,dx\ \text{— интеграл движения}. \tag{6а.5} \]
Примеры (форма Н. А. Кудряшова [7])
  • Перенос (6а.3): \(T = u^2\), \(X = a\,u^2\) — закон сохранения.
  • Теплопроводность (6а.4): \((u^2)_t + (-2\nu u u_x)_x = -2\nu u_x^2\) — не закон, а баланс с неположительным источником: энергия диссипирует.
  • Устойчивость схемы, которую докажем, — сеточный закон сохранения (баланс) для плотности \(T = y_i^2\).
Упражнение — самостоятельно, вывод не показывается
\[ u_t + 6\,u\,u_x + u_{xxx} = 0, \qquad u(x + l, t) = u(x, t). \tag{6а.6} \]
  1. Дивергентная форма: \(T_1\), \(X_1\) и сохранение \(\int u\,dx\).
  2. Умножьте на \(u\): \(T_2 = u^2\), найдите \(X_2\). Что пришлось «свернуть» в производную и почему это сложнее, чем в (6а.3)?
  3. При каком \(\beta\) сохраняется \(\int(u^3 + \beta u_x^2)\,dx\)? Найдите \(X_3\).
  4. Что переживает линеаризацию \(u_t + u_{xxx} = 0\)? Сеточные аналоги \(\int u\,dx\), \(\int u^2dx\)?

У КдВ законов сохранения бесконечно много [7]; линейные схемы этого параграфа контролируют один — квадратичный. Его и переносим на сетку: нужны сетка, разности и скалярное произведение.

§6а.3 · Сетка, сеточные функции, пространства

Сетка, сеточная функция, пространства \(H\) и \(H_0\) — что это и аналог чего

Сетка — конечное множество точек \(\omega_h = \{x_i = ih,\ i = 0, \dots, N,\ h = l/N\}\); \(\omega_\tau = \{t_n = n\tau\}\), \(\omega_{h\tau} = \omega_h\times\omega_\tau\) (6а.7). Сеточная функция — отображение \(y\colon\omega_h\to\mathbb R\), набор чисел \((y_0, \dots, y_N)\); \(y^n\) — функция на слое \(t_n\). Соседние слои пишем явно: \(y^n\), \(y^{n+1}\). \(H\): \(y_0 = y_N\), \(y_{i+N} = y_i\) (размерность \(N\)); \(H_0\): \(y_0 = y_N = 0\) (размерность \(N - 1\)).

Слова «самосопряжённый», «положительный», «норма оператора» будут относиться к таким матрицам. Теперь — производные на сетке.

§6а.3 · Разностные производные

Разностные производные \(y_l\), \(y_r\), \(y_c\) и вывод второй разности \(y_{lr}\)

\[ y_{l,i} = \frac{y_i - y_{i-1}}{h}\ \text{(левая, назад)}, \qquad y_{r,i} = \frac{y_{i+1} - y_i}{h}\ \text{(правая, вперёд)}, \qquad y_{c,i} = \frac{y_{i+1} - y_{i-1}}{2h}\ \text{(центральная)}. \tag{6а.8} \] Все три — аналог \(\partial u/\partial x\); порядок \(O(h)\), \(O(h)\), \(O(h^2)\). Индексы \(l, r, c\) — left, right, centre.
вторая производная — разность от разности: правая от левой (или левая от правой — то же самое)
\[ (y_l)_{r,i} = \frac{y_{l,i+1} - y_{l,i}}{h} = \frac1h\Bigl(\frac{y_{i+1} - y_i}{h} - \frac{y_i - y_{i-1}}{h}\Bigr) = \frac{y_{i+1} - 2y_i + y_{i-1}}{h^2} = (y_r)_{l,i} \;=:\; y_{lr,i}. \tag{6а.9} \]
Три тождества (6а.10)\(y_c = \tfrac12(y_l + y_r)\), \(\ y_{lr} = (y_r - y_l)/h\), \(\ y_l = y_c - \tfrac h2\,y_{lr}\): односторонняя разность = центральная + половина шага × вторая разность. Почему не \((y_c)_c\): это вторая разность с шагом \(2h\) — чётные и нечётные узлы не связаны, «пила» неотличима от константы.
здесьу Самарского [1]
\(y_l,\ y_r,\ y_c,\ y_{lr}\)\(y_{\bar x},\ y_x,\ y_{\mathring x},\ y_{\bar xx}\)
\(y^n,\ y^{n+1},\ \frac{y^{n+1}-y^n}{\tau},\ \sigma y^{n+1} + (1-\sigma)y^n\)\(y,\ \hat y,\ y_t,\ y^{(\sigma)}\) — мы этих сокращений не вводим

Каждой разности отвечает оператор — матрица. Выпишем их: именно из них будет собран оператор \(A\).

§6а.3 · Разностные операторы

Разностные операторы \(D_l\), \(D_r\), \(D_c\), \(\Lambda = D_rD_l\) — это матрицы \(N\times N\)

\((D_l y)_i = y_{l,i}\), \((D_r y)_i = y_{r,i}\), \((D_c y)_i = y_{c,i}\), \(\Lambda y = y_{lr}\). На периодической сетке в базисе \((y_1, \dots, y_N)\):

\[ D_l = \frac{1}{h}\begin{pmatrix} 1 & & & & -1\\ -1 & 1 & & & \\ & -1 & 1 & & \\ & & \ddots & \ddots & \\ & & & -1 & 1\end{pmatrix}, \qquad \Lambda = \frac{1}{h^2}\begin{pmatrix} -2 & 1 & & & 1\\ 1 & -2 & 1 & & \\ & 1 & -2 & \ddots & \\ & & \ddots & \ddots & 1\\ 1 & & & 1 & -2\end{pmatrix} \]
Что видно по матрицамЕдиницы в углах — периодичность. \(\Lambda\) симметрична; \(D_l\) — нет: \(D_l^{\mathsf T} = -D_r\). Тождества (6а.10) в операторной записи: \(D_c = \tfrac12(D_l + D_r)\), \(\Lambda = \tfrac1h(D_r - D_l)\), \(D_l = D_c - \tfrac h2\Lambda\).
Аналог и роль\(D_l, D_r, D_c\) — оператор \(\partial/\partial x\); \(\Lambda\) — \(\partial^2/\partial x^2\). Оператор \(A\) канонической формы (§6а.6) собирается из них: \(A = aD_l\) («уголок»), \(A = aD_c\) (центральная схема), \(A = -\nu\Lambda\) (теплопроводность).

Осталось ввести на этом словаре скалярное произведение — сеточный аналог интеграла — и решить, какой нормой мерить.

§6а.3 · Скалярное произведение и норма

Скалярное произведение: одна норма — сеточная \(L_2\) — и почему она

\[ (y, v) = \sum_{i=1}^{N} h\,y_i v_i, \qquad \|y\| = \sqrt{(y, y)}. \tag{6а.11} \] Аналог \(\int_0^l uv\,dx\); \(\|y\|^2\) — энергия \(E\). Для разностей суммируем по всем \(N\) промежуткам: \(\|y_l\|^2 = \sum_{i=1}^N h\,y_{l,i}^2\) (для \(y\in H_0\) член \(i = N\) не нуль).
Инструменты разборов\(|(y, v)| \le \|y\|\,\|v\|\) (Коши–Буняковский); сдвиг индекса на периодической сетке: \(\sum h\,y_{i-1}^2 = \|y\|^2\).
Норм много (\(C\), \(L_1\), \(L_2\)) — мы берём одну. Почему \(L_2\)
  1. Только она порождена скалярным произведением: билинейность ⇒ разложение разности квадратов, сопряжённые операторы, Коши–Буняковский. В \(C\), \(L_1\) этого нет.
  2. Прямой аналог энергии прототипа \(E = \int u^2dx\); энергетические нормы \(\|y\|_A^2 = (Ay, y)\) — та же конструкция с \((Ay, v)\), копии других энергий (\(\int u_x^2\)).
  3. Согласована с гармониками: Парсеваль \(\|y\|^2 = \sum|c_k|^2\) ⇒ результаты двух методов сравнимы число к числу.
  4. Что теряем — норму \(C\): \(\sqrt h\|y\|_C \le \|y\| \le \sqrt l\|y\|_C\), оценка в \(L_2\) не равномерна по \(h\); принцип максимума — §11.

Норма выбрана; дальше — операторы на \(H\): что такое сопряжённый и что он значит конкретно.

§6а.4 · Операторы

Сопряжённый оператор — транспонированная матрица; три свойства

Сопряжённый оператор \(A^*\): \((Ay, v) = (y, A^*v)\) при всех \(y, v \in H\). Так как \((y, v) = h\,y^{\mathsf T}v\), то \((Ay, v) = h\,y^{\mathsf T}A^{\mathsf T}v\) и \[ A^* = A^{\mathsf T}. \tag{6а.12} \]
  • \(A\) самосопряжён, \(A^* = A\) — симметричная матрица; положителен, \(A > 0\): самосопряжён и \((Ay, y) > 0\) при \(y \ne 0\).
  • \(A\) кососимметричен, \(A^* = -A\); тогда \((Ay, y) = -(Ay, y) = 0\) — не меняет энергии.
  • \(A \ge B\) для самосопряжённых означает \(A - B \ge 0\) — операторное неравенство; в этой форме будут условия устойчивости.
АналогФормально сопряжённый по Лагранжу оператор \(L^*\): \(\int_0^l (Lu)v\,dx = \int_0^l u(L^*v)\,dx\) + внеинтегральные члены. \(L = \partial_x\): \(L^* = -\partial_x\) — кососимметричен; \(L = -\partial_{xx}\): \(L^* = L\), и \(\int(-u'')u\,dx = \int u'^2dx > 0\) при \(u(0) = u(l) = 0\) — положителен. По матрицам §6а.3: \(\Lambda^{\mathsf T} = \Lambda\), \(D_l^{\mathsf T} = -D_r\).

Три названных свойства решают, какой путь выбрать: теорема Самарского (§6а.10) или лемма 2 (§6а.6).

§6а.4 · Энергетическая норма

Какие операторы встретятся и что такое энергетическая норма

Какие операторы будут в разборах
  • \(-\Lambda\) на \(H_0\) — самосопряжён и положителен. Теплопроводность.
  • \(D_c\) на периодической сетке — кососимметричен. Неустойчивая явная схема и Кранк–Николсон.
  • \(aD_l\) в «уголке» — ни то ни другое: односторонность нарушает симметрию; но \(D_l = D_c - \frac h2\Lambda\) (следующий слайд).
Энергетическая норма. Только при \(A = A^* > 0\) форма \((Ay, v)\) — скалярное произведение; порождённая ею норма \[ \|y\|_A = \sqrt{(Ay, y)} \tag{6а.13} \] называется энергетической, пространство — \(H_A\). Для \(A = -\Lambda\): \(\|y\|_A^2 = \|y_l\|^2\) — сеточный интеграл Дирихле \(\int u_x^2\,dx\) из (6а.4).
Норма оператора\(\|A\| = \sup\|Ay\|/\|y\|\); для \(A = A^* \ge 0\): \((Ay, y) \le \|A\|\,\|y\|^2\), т.е. \(A \le \|A\|E\) (6а.15) — мост от операторных неравенств к условиям на \(\tau\), \(h\).

Несамосопряжённый оператор тоже можно измерить: выделить из него симметричную часть.

§6а.4 · Симметричная и кососимметричная части

\(A = A_s + A_k\): «диссипация» и «перенос». Схемная вязкость односторонней разности

Для любого линейного \(A\): \(A_s = \tfrac12(A + A^*)\), \(A_k = \tfrac12(A - A^*)\); \(A_s^* = A_s\), \(A_k^* = -A_k\), и для всех \(y\) \[ (Ay, y) = (A_s y, y), \qquad\text{так как } (A_k y, y) = 0. \tag{6а.14} \]
Аналог\(L = a\,\partial_x - \nu\,\partial_{xx}\): кососимметричная часть \(a\,\partial_x\) — перенос, симметричная \(-\nu\,\partial_{xx}\) — диффузия; в баланс \(\int u\,Lu\,dx = \nu\int u_x^2dx\) входит только диффузия.

§6а.5 · Суммирование по частям доп.

Лемма 1 и первая формула Грина

Для любых сеточных функций \(y\), \(v\) на \(\omega_h\): \[ \sum_{i=1}^{N} h\,y_i\,v_{l,i} = -\sum_{i=0}^{N-1} h\,y_{r,i}\,v_i + y_N v_N - y_0 v_0. \tag{6а.16} \]
Доказательство. \(\sum_{i=1}^N y_i(v_i - v_{i-1}) = \sum_{i=1}^N y_iv_i - \sum_{j=0}^{N-1} y_{j+1}v_j\); в первой сумме отделяем \(i = N\), добавляем и вычитаем \(j = 0\); разность даёт \(-\sum_{j=0}^{N-1}(y_{j+1} - y_j)v_j = -\sum h\,y_{r,j}v_j\). □ Аналог: \(\int_0^l yv'\,dx = -\int_0^l y'v\,dx + [yv]_0^l\); \(y_Nv_N - y_0v_0\) — внеинтегральные члены.

Следствие 1. Для \(y, v \in H_0\) применить к \(w = y_l\) (\(w_r = \Lambda y\); \(y_{l,0}\) доопределяем нулём — оно умножается на \(v_0 = 0\)); граничные члены исчезают:

\[ (\Lambda y, v) = -\sum_{i=1}^{N} h\,y_{l,i}v_{l,i}, \tag{6а.17} \]
\[ (-\Lambda y, y) = \sum_{i=1}^{N} h\,y_{l,i}^2 = \|y_l\|^2 \ge 0. \tag{6а.18} \]

Правая часть симметрична ⇒ \(\Lambda\) самосопряжён; нуль лишь при \(y = \mathrm{const}\), а с \(y_0 = 0\) — при \(y \equiv 0\). Итак, \(A = -\Lambda\) самосопряжён и положителен на \(H_0\). Краевые условия вошли именно здесь.

§6а.10 · Основная теорема

Теорема Самарского об устойчивости в \(H_A\)

Пусть двухслойная разностная схема без правой части записана в каноническом виде \[ B\,\frac{y^{n+1} - y^{n}}{\tau} + A\,y^{n} = 0 \] с линейными операторами \(A, B\colon H \to H\), причём:
  1. оператор \(A\) самосопряжён и положителен, \(A = A^* > 0\);
  2. оператор \(B\) обратим и удовлетворяет операторному неравенству \[ B \ge \tfrac{\tau}{2}\,A, \qquad\text{то есть}\qquad (By, y) \ge \tfrac{\tau}{2}\,(Ay, y) \ \ \text{при всех } y \in H. \tag{6а.34} \]
Тогда в энергетической норме \(\|y\|_A = \sqrt{(Ay, y)}\) справедливы оценки \[ \|y^{n+1}\|_A \le \|y^{n}\|_A \ \ (n = 0, 1, \dots) \qquad\text{и, следовательно,}\qquad \|y^{n}\|_A \le \|y^{0}\|_A. \tag{6а.35} \]

Устойчивость в \(H_A\) с постоянной \(C = 1\), не зависящей от \(\tau\), \(h\), \(n\). От \(B\) — только обратимость и операторное неравенство: ни самосопряжённости, ни вида \(E + \theta\tau A\). Ветвь I алгоритма.

Доказательство — четыре этапа, копирующие §6а.2 и (6а.25) в норме \(H_A\); после каждого — использованная гипотеза.

§6а.10 · Доказательство, этапы 1–2 доп.

Этап 1: полусумма и приращение. Этап 2: умножение на приращение

Этап 1 · тождественное преобразование, гипотезы не используются

Умножим схему на \(\tau\): \(B(y^{n+1} - y^n) + \tau Ay^n = 0\), и подставим \(y^n = \tfrac12(y^{n+1} + y^n) - \tfrac12(y^{n+1} - y^n)\). Собрав члены с приращением:

\[ \Bigl(B - \frac{\tau}{2}A\Bigr)\bigl(y^{n+1} - y^{n}\bigr) + \frac{\tau}{2}\,A\,\bigl(y^{n+1} + y^{n}\bigr) = 0. \tag{6а.36} \]

Зачем: теперь \(A\) действует на сумму слоёв — её произведение с приращением даст разность энергий, как в (6а.25).

Этап 2 · сеточное «умножение на решение и интегрирование»

Умножим (6а.36) скалярно на \(\frac{2}{\tau}(y^{n+1} - y^{n})\); множитель подобран так, чтобы второе слагаемое стало разностью энергий:

\[ \frac{2}{\tau}\Bigl(\bigl(B - \tfrac{\tau}{2}A\bigr)(y^{n+1} - y^{n}),\ y^{n+1} - y^{n}\Bigr) + \Bigl(A\,(y^{n+1} + y^{n}),\ y^{n+1} - y^{n}\Bigr) = 0. \tag{6а.37} \]

Осталось увидеть, что второе слагаемое — это \(\|y^{n+1}\|_A^2 - \|y^n\|_A^2\).

§6а.10 · Доказательство, этапы 3–4 доп.

Этап 3: разность энергий. Этап 4: энергетическое тождество

Этап 3 · используется A = A*
\[ \bigl(A(y^{n+1} + y^{n}),\ y^{n+1} - y^{n}\bigr) = (Ay^{n+1}, y^{n+1}) - \underbrace{(Ay^{n+1}, y^{n}) + (Ay^{n}, y^{n+1})}_{=\,0\ \text{по самосопряжённости}} - (Ay^{n}, y^{n}) = \|y^{n+1}\|_A^2 - \|y^{n}\|_A^2. \tag{6а.38} \]
Этап 4 · используется B ≥ (τ/2)A, затем A > 0
\[ \|y^{n+1}\|_A^2 = \|y^{n}\|_A^2 - \frac{2}{\tau}\Bigl(\bigl(B - \tfrac{\tau}{2}A\bigr)(y^{n+1} - y^{n}),\ y^{n+1} - y^{n}\Bigr). \tag{6а.39} \]

Точное энергетическое тождество — (6а.25) в норме \(H_A\). По (6а.34) вычитаемое неотрицательно ⇒ \(\|y^{n+1}\|_A^2 \le \|y^n\|_A^2\). Положительность \(A\) делает \(\|\cdot\|_A\) нормой; извлекаем корень — (6а.35). □ Без \(A = A^*\) средние члены в (6а.38) не сокращаются — вот где теорема нуждается в самосопряжённости.

Смысл тождестваЭнергия нового слоя = энергия старого − диссипация. Условие \(B \ge \frac{\tau}{2}A\): схема не производит энергии. Для \(B = E + \theta\tau A\) оно даёт \(E + (\theta - \frac12)\tau A \ge 0\) — тот же порог \(\theta = \frac12\), что в лемме 2.

Одна теорема объясняет условную устойчивость явных схем и безусловную — неявных. Есть и обратное утверждение.

§6а.10 · Теорема 2 доп.

Устойчивость в \(H_B\); необходимость условия (6а.34)

Пусть \(A = A^* > 0\) и \(B = B^* > 0\). Тогда условие (6а.34) необходимо и достаточно для оценки (6а.35); при его выполнении справедлива также оценка \(\|y^{n+1}\|_B \le \|y^{n}\|_B\). В частности, для явных схем (\(B = E\)) условие \(E \ge \frac{\tau}{2}A\) равносильно оценке \(\|y^{n+1}\| \le \|y^{n}\|\) в норме \(L_2\).

Принимаем без доказательства [Самарский, гл. VI, §2]. Для явной схемы проверяется по спектру: \(y^{n+1} = (E - \tau A)y^n\), и

\[ \|E - \tau A\| \le 1 \iff 1 - \tau\lambda_k \in [-1, 1]\ \forall k \]
\[ \iff \tau\lambda_k \le 2 \iff \frac{\tau}{2}A \le E; \]

то же даёт лемма 2 при \(\theta = 0\): \(2A \ge \tau A^2\).

Практический выводДля схем с самосопряжёнными \(A\) и \(B\) энергетический метод даёт критерий. Запас появляется лишь при грубой оценке \(\|A\|\) и при переходе к правой части. Применение к схеме с весами для теплопроводности — разбор 4 (§6а.11): \(\sigma \ge \frac12 - \frac{h^2}{4\tau}\), в точности ответ гармоник.

Правая часть — небольшое усиление условия и одно неравенство.

§6а.12 · Устойчивость по правой части доп.

ε-неравенство и теорема 3

\[ |(\varphi, v)| \le \|\varphi\|\,\|v\| \le \varepsilon\,\|v\|^2 + \frac{1}{4\varepsilon}\,\|\varphi\|^2, \qquad \varepsilon > 0. \tag{6а.43} \]

(получается раскрытием квадрата \((\sqrt{\varepsilon}\,a - b/(2\sqrt{\varepsilon}))^2 \ge 0\) и Коши–Буняковским; смысл — «разменять» произведение норм на сумму квадратов с малым коэффициентом при той норме, что уже стоит в левой части.)

Пусть \(A = A^* > 0\), \(B\) обратим и при некотором \(\varepsilon > 0\), не зависящем от \(\tau, h\), выполнено \(B \ge \varepsilon E + \tfrac{\tau}{2}A\) (6а.44). Тогда \[ \|y^{n+1}\|_A^2 \le \|y^{0}\|_A^2 + \frac{1}{2\varepsilon}\sum_{k=0}^{n}\tau\,\|\varphi^{k}\|^2. \tag{6а.45} \]
Доказательство. Этапы 1–3 с правой частью, \(w = y^{n+1} - y^n\): \(\frac{2}{\tau}((B - \tfrac{\tau}{2}A)w, w) + \|y^{n+1}\|_A^2 - \|y^n\|_A^2 = 2(\varphi^n, w)\). Слева \(\ge \frac{2\varepsilon}{\tau}\|w\|^2\); справа по (6а.43) с \(\varepsilon/\tau\): \(\le \frac{2\varepsilon}{\tau}\|w\|^2 + \tfrac{\tau}{2\varepsilon}\|\varphi^n\|^2\); члены с \(\|w\|^2\) сокращаются, остаётся \(\|y^{n+1}\|_A^2 \le \|y^n\|_A^2 + \tfrac{\tau}{2\varepsilon}\|\varphi^n\|^2\). Суммируем по слоям. □
ПлатаДля явной схемы условие (6а.44) даёт \(\tau \le (1 - \varepsilon)h^2/2\) вместо \(\tau \le h^2/2\): достаточные условия с запасом.

Дальше — тот разбор, ради которого всё делалось: перенос с переменной скоростью, где метод фон Неймана не работает. Это ветвь III.

§6а.13 · Разбор 5 · постановка

Задача, ради которой всё делалось: перенос с переменной скоростью

Возьмём уравнение переноса, у которого скорость зависит от координаты:

\[ \frac{\partial u}{\partial t} + a(x)\,\frac{\partial u}{\partial x} = 0, \qquad a(x) > 0, \qquad u(0,t) = u(l, t)\ (\text{периодичность}). \tag{6а.46} \]
Обозначения
  • \(a(x)\) — переменная скорость переноса (дальше — гладкая: \(|a'(x)| \le L\), где \(L\) — постоянная Липшица, не зависящая от \(x\)).
  • \(L\) отвечает за то, «насколько быстро» \(a(x)\) меняется на отрезке.
Разностная схема — «уголок» с локальным числом Куранта
\[ y_i^{n+1} = (1 - r_i)\,y_i^{n} + r_i\,y_{i-1}^{n}, \tag{6а.47} \]
\[ r_i = \frac{a(x_i)\,\tau}{h}, \qquad 0 \le r_i \le 1; \qquad (Ay)_i = a(x_i)\,y_{l,i},\ B = E. \]

\(r_i\) — локальное число Куранта: своё в каждом узле, потому что скорость \(a(x_i)\) своя.

Задача — доказать устойчивость без предположения о постоянстве \(a\). Первый вопрос: сработает ли здесь знакомый метод фон Неймана?

§6а.13 · Разбор 5 · почему фон Нейман здесь бессилен

Почему метод гармоник (§6) не даёт ответа

Метод фон Неймана держится на одном факте (лемма 1 §6):

Условие применимости леммы 1Оператор перехода \(S\) переводит слой в слой (\(u^{n+1} = S u^n\)) и перестановочен со сдвигом \(T\colon u_m \mapsto u_{m+1}\): \(ST = TS\). Только при этом гармоника \(e^{i\alpha m}\) — собственная функция \(S\), и всё сводится к одному числу \(\lambda(\alpha)\).

Проверка для (6а.47): запишем действие оператора \(S\) на \(y\):

\[ (Sy)_i = (1 - r_i)\,y_i + r_i\,y_{i-1}. \]

Коэффициенты \(1 - r_i\) и \(r_i\) зависят от номера узла. Значит, если сдвинуть сначала (\(v = Ty\), \(v_i = y_{i+1}\)) и потом применить \(S\), получим \((STy)_i = (1 - r_i)\,y_{i+1} + r_i\,y_i\); а если сначала применить \(S\) и потом сдвинуть — \((TSy)_i = (Sy)_{i+1} = (1 - r_{i+1})\,y_{i+1} + r_{i+1}\,y_i\). Числа \(r_i\) и \(r_{i+1}\) разные — \(ST \ne TS\).

Итак, \(ST \ne TS\): гармоника перестаёт быть собственной функцией. Что это значит для метода — на следующем слайде.

§6а.13 · Разбор 5 · вывод

Вывод: множитель перехода не определён; что тогда делать

ВыводГармоника \(e^{i\alpha m}\) не является собственной функцией \(S\); множитель перехода \(\lambda(\alpha)\) как одно число просто не определён. Метод фон Неймана здесь не формулируется.
Правдоподобная догадка «замороженных коэффициентов»Обычная в практике «отговорка»: зафиксировать \(a = a(x_i)\) в каждом узле и потребовать локальное условие Куранта \(r_i \le 1\) для всех \(i\). Звучит разумно, но не является доказательством: замороженная схема — другая, а связь между её устойчивостью и устойчивостью настоящей не установлена.

Что тогда делать? Работать не с гармониками, а с нормой решения целиком — как в дифференциальном прототипе (§6а.2). Это ветвь III: те же приёмы, что в ветви II, плюс оценка члена, порождённого переменностью коэффициента.

Ключ — то, что схема (6а.47) в каждом узле остаётся выпуклым средним: \(y_i^{n+1}\) — среднее \(y_i^n\) и \(y_{i-1}^n\) с весами \(1 - r_i, r_i \ge 0\), не превосходящими единицы. Значит поточечное неравенство выпуклости работает — как и в постоянном случае.

§6а.13 · Разбор 5 · энергетическая выкладка

Энергетический метод: три шага + оценка «сшивочного» члена

Инструменты (без операторной теории): норма \(\|y\|^2 = \sum h\,y_i^2\); неравенство выпуклости (см. ниже) и сдвиг индекса на периодической сетке \(\sum h\,y_{i-1}^2 = \|y\|^2\).

Шаг 1 · неравенство выпуклости в каждом узле

Для любых чисел \(a, b\) и веса \(\theta \in [0, 1]\) квадрат среднего не больше среднего квадратов:

\[ \bigl(\theta\,a + (1 - \theta)\,b\bigr)^2 \;\le\; \theta\,a^2 + (1 - \theta)\,b^2 \qquad \bigl(\text{разность равна } \theta(1 - \theta)(a - b)^2 \ge 0\bigr). \tag{6а.28} \]

Веса \(1 - r_i\) и \(r_i\) неотрицательны и в сумме дают единицу — при \(0 \le r_i \le 1\). Применяем (6а.28) в каждом узле \(i\) с \(\theta = 1 - r_i\), \(a = y_i^n\), \(b = y_{i-1}^n\):

\[ \bigl(y_i^{n+1}\bigr)^2 = \bigl((1 - r_i)\,y_i^n + r_i\,y_{i-1}^n\bigr)^2 \le (1 - r_i)\,\bigl(y_i^n\bigr)^2 + r_i\,\bigl(y_{i-1}^n\bigr)^2. \]

Неравенство получено в каждом узле; теперь — сложить по узлам.

§6а.13 · Разбор 5 · шаг 2

Шаг 2: суммирование и сдвиг индекса — откуда «сшивочный» член

Шаг 2 · суммирование и сдвиг индекса

Умножим на \(h\) и просуммируем по \(i = 1, \dots, N\). Слева — \(\|y^{n+1}\|^2\); справа — две суммы. Во второй сдвинем индекс на периодической сетке (заменим \(i \to i+1\) в \(y_{i-1}\)): \(\sum h\,r_i\,(y^n_{i-1})^2 = \sum h\,r_{i+1}\,(y^n_i)^2\). Собираем всё у одного и того же квадрата \((y_i^n)^2\):

\[ \|y^{n+1}\|^2 \le \sum_{i=1}^{N} h\bigl[(1 - r_i) + r_{i+1}\bigr]\,\bigl(y_i^{n}\bigr)^2 = \|y^{n}\|^2 + \underbrace{\sum_{i=1}^{N} h\,(r_{i+1} - r_i)\,\bigl(y_i^{n}\bigr)^2}_{\text{«сшивочный» член}}. \tag{6а.48} \]
ЗамечаниеВ случае постоянного \(a\) все \(r_i\) равны, разность \(r_{i+1} - r_i = 0\), сшивочный член исчезает — получаем стандартную оценку \(\|y^{n+1}\|^2 \le \|y^n\|^2\), как в разборе 1 (6а.29).
§6а.13 · Разбор 5 · шаг 3 и итог

Шаг 3: оценка сшивочного члена и итерация по слоям

Шаг 3 · сшивочный член через гладкость \(a(x)\)

В сшивочный член входит разность \(r_{i+1} - r_i\). По определению \(r_i = a(x_i)\,\tau/h\):

\[ r_{i+1} - r_i = \frac{\tau}{h}\,\bigl(a(x_{i+1}) - a(x_i)\bigr) \overset{\text{теорема Лагранжа}}{=} \frac{\tau}{h}\cdot h\cdot a'(\xi_i) = \tau\,a'(\xi_i), \qquad \xi_i \in (x_i, x_{i+1}). \]

По условию \(|a'(x)| \le L\), поэтому \(r_{i+1} - r_i \le \tau L\), и сшивочный член оценивается сверху:

\[ \sum_{i=1}^{N} h\,(r_{i+1} - r_i)\,\bigl(y_i^{n}\bigr)^2 \le \tau L\,\|y^n\|^2 \quad\Longrightarrow\quad \|y^{n+1}\|^2 \le (1 + \tau L)\,\|y^{n}\|^2 \ \text{ по (6а.48)}. \]
Итерация по слоям \(0, 1, \dots, n\) — за конечное время \(t_n \le T\)
\[ \|y^{n}\|^2 \le (1 + \tau L)^{n}\,\|y^{0}\|^2 \le e^{L\,t_n}\,\|y^{0}\|^2 \quad\Longrightarrow\quad \|y^{n}\| \le e^{LT/2}\,\|y^{0}\|. \tag{6а.49} \]
Результат. Устойчивость по начальным данным (Опр. 3 §2) с постоянной \(C = e^{LT/2}\), не зависящей от \(\tau\), \(h\), \(n\): догадка о «замороженных коэффициентах» стала теоремой. Через лемму 2 то же: \((Ay, y) = \frac12\sum(a_i - a_{i+1})y_i^2 + \frac h2\sum h\,a_iy_{l,i}^2 \ge -\frac L2\|y\|^2 + \dots\), то есть \(A_s \ge -\frac L2 E\) с точностью до диссипации — ветвь III есть ветвь II с поправкой \(L\).

§6а.14 · Алгоритм 1, шаг 4

Шаг 4: три ветви — что делать и о каком операторе речь

Ветвь I. \(A = A^* > 0\) — теорема Самарского
теплопроводность, диффузия. Проверить \(B \ge \frac{\tau}{2}A\) (6а.34).
I-а \(B = E\): \(\tau \le 2/\|A\|\); для \(-\Lambda\) — \(\tau \le h^2/2\).
I-б \(B = E + \sigma\tau A\): \(\sigma \ge \frac12\) — всегда; \(\sigma \lt \frac12\) — (6а.42).
Вывод: \(\|y^n\|_A \le \|y^0\|_A\); при \(B = B^* > 0\) — критерий (т. 2); правая часть — т. 3. Разбор 4.
Ветвь II. \(A \ne A^*\) — лемма 2
перенос; теоремы неприменимы. \(A = A_s + A_k\), подставить \(\theta\) в (6а.26).

II-б \(\theta = \frac12\): \(A_s \ge 0\) — безусловно, \(A_s = 0\) — сохранение (упр. 3).
II-в \(\theta = 1\): \(A_s \ge 0\) — безусловно (разбор 2, упр. 5).
