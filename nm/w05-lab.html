Что вы делаете

Задача — приблизить \(f(x) = e^x\) на \([-1, 1]\) многочленом 5-й степени двумя способами: (а) через нормальные уравнения в степенном базисе \(\{1, x, x^2, \ldots, x^5\}\); (б) через проекцию на ортогональный базис Лежандра. Второй способ даст те же коэффициенты, но принципиально устойчивее — увидим уже на скромной размерности 6.

§0. Разминка: скалярное произведение на \([-1, 1]\)

Задача 0.1. Интеграл через трапеции. Реализуйте double inner_prod(double (*f)(double), double (*g)(double), int N) — приблизительное значение \((f, g) = \int_{-1}^{1} f(x)g(x)\,dx\) через составную формулу трапеций на \(N+1\) равномерных узлах. Тест: \(f = g \equiv 1\), результат должен быть 2.

§2. МНК через ортогональный базис Лежандра

Для непрерывной МНК-задачи оптимальный полином \(Q_n(x) = \sum_{k=0}^n c_k P_k(x)\), где \(c_k = \frac{2k+1}{2}\int_{-1}^{1} f(x) P_k(x)\,dx\). Каждый коэффициент считается независимо — прямая проекция.
Задача 2.1. Коэффициенты Лежандра для \(e^x\). Посчитайте \(c_0, c_1, \ldots, c_5\) — коэффициенты разложения \(e^x\) на \([-1, 1]\) по Лежандру. Тест: \(c_0 = \sinh(1) \approx 1{,}17520\), \(c_1 = 3/e \approx 1{,}10364\). Введите \(c_0\).
task2_1.cpp
Задача 2.2. Максимум ошибки. Собрав \(Q_5(x) = \sum_{k=0}^5 c_k P_k(x)\), замерьте \(\max_{[-1,1]}|e^x - Q_5(x)|\) на 1001 точке. Должно быть \(\sim 10^{-5}\).

§3. Нормальные уравнения — эффект \(\kappa^2\)

Тот же полином, но через степенной базис \(\{1, x, x^2, \ldots, x^5\}\). Матрица Грама \(G_{jk} = (x^j, x^k) = \int_{-1}^1 x^{j+k}\,dx\) — она плотная и хуже обусловлена: \(\kappa(G) \sim 10^5\)-\(10^6\) уже при \(n = 5\).
Задача 3.1. Собрать матрицу Грама степенного базиса. Реализуйте \(G_{jk} = \int_{-1}^{1} x^{j+k}\,dx = \frac{1 - (-1)^{j+k+1}}{j+k+1}\) (2 если \(j+k\) чётное, 0 если нечётное — но проще прямо посчитать через степень). Проверьте \(G_{00} = 2\), \(G_{01} = 0\), \(G_{02} = 2/3\).
task3_1.cpp
Задача 3.2. Решить нормальные уравнения методом Гаусса. Постройте \(G\) размера \(6\times 6\) и правую часть \(r_j = \int_{-1}^{1} e^x x^j\,dx\) (посчитайте её тем же inner_prod). Решите \(G c = r\) методом Гаусса без выбора главного элемента. Выведите \(c_0\).
task3_2.cpp
Полином \(Q_5\) через степенной базис получится тот же самый математически, но коэффициенты \(c_k\) — совершенно другие числа. Ожидается, что \(c_0 \approx \sinh(1)\) в первом приближении, но с ошибкой ~10⁻³ из-за κ² матрицы Грама. При Лежандре ошибка была ~10⁻¹⁴.
