§6а.1 · Зачем второй метод

Где гармоники не работают и что даёт энергия

коэффициенты
\(u_t + a(x)u_x = 0\)
оператор перехода не перестановочен со сдвигом
границы
\(u(0,t) = u(l,t) = 0\)
гармоника не обращается в нуль на концах
и главное
Условие Неймана — только необходимое
для систем и многослойных схем его может не хватать

Энергетический метод доказывает априорную оценку — из одной лишь структуры схемы, до и без её решения:

\[ \|y^{n+1}\| \le \|y^{n}\| \quad\text{или}\quad \|y^{n}\|^2 \le \|y^{0}\|^2 + C\sum_{k=0}^{n-1}\tau\,\|\varphi^{k}\|^2. \tag{6а.1} \]
СледствиеЭто оценка (2.14) Определения 4 §2 с явной нормой и постоянной. Условия, при которых она доказана, — достаточные. Гармоники дают необходимые; совпали — ответ точен.

Само тождество — сеточная копия одной выкладки из теории уравнений в частных производных. Проведём её для уравнения.

§6а.2 · Дифференциальный прототип

Закон сохранения энергии: перенос и теплопроводность

\(u_t + a u_x = 0\), \(u(0,t) = u(l,t)\), \(a = \mathrm{const}\) — дифференциальный прототип уравнения, для которого построен «уголок». Умножим на \(u\) и проинтегрируем по \(x\) от \(0\) до \(l\):

первое слагаемое — точная производная энергии по \(t\)
\[ \int_0^l u\,u_t\,dx = \int_0^l \tfrac12\bigl(u^2\bigr)_t\,dx = \tfrac12\,\frac{d}{dt}\int_0^l u^2\,dx. \]
Обозначение\(E(t) = \int_0^l u^2\,dx = \|u(\cdot,t)\|^2_{L_2}\) — энергия решения. Тогда левая колонка — это \(\tfrac12\,dE/dt\).
второе слагаемое — точная производная по \(x\); интеграл сводится к границам
\[ a\,u\,u_x = \tfrac{a}{2}\bigl(u^2\bigr)_x \ \Rightarrow\ \int_0^l a\,u\,u_x\,dx = \tfrac{a}{2}\Bigl[u^2(x,t)\Bigr]_{x=0}^{x=l} = \tfrac{a}{2}\bigl(\underbrace{u^2(l,t) - u^2(0,t)}_{=\,0\ \text{по периодичности}}\bigr) = 0. \]
\[ \tfrac12\,\frac{dE}{dt} + 0 = 0 \quad\Longrightarrow\quad \frac{dE}{dt} = 0, \qquad \|u(\cdot,t)\|_{L_2} = \|u(\cdot,0)\|_{L_2}. \tag{6а.3} \]
Что сократилось из краевого условияПо периодичности \(u(0,t) = u(l,t)\), значит и \(u^2(0,t) = u^2(l,t)\) — именно эти два значения на концах сократились в квадратных скобках. Без периодичности выкладка не проходит. На сетке роль периодичности возьмут условие \(y_0 = y_N\) и сдвиг индекса при суммировании.

Три действия — умножить на решение, проинтегрировать, обнулить границу — на сетке превратятся в скалярное произведение (§6а.3), суммирование по частям (§6а.5) и обращение граничных членов за счёт значений в узлах \(y_0, y_N\).

§6а.3 · Обозначения. Словарь сеточных величин

Словарь: сетка, сеточная функция, разностные производные

Сетка и функция
  • \(h\) — шаг сетки по \(x\); \(\tau\) — шаг по времени.
  • \(\omega_h = \{x_i = ih,\ i = \overline{0, N}\}\) — узлы сетки на отрезке \([0, l]\).
  • \(y = \{y_i\}\) — сеточная функция на текущем слое \(t_n\); значение в узле \(i\) — число \(y_i\).
  • \(\hat y = y^{n+1}\) — та же функция на следующем слое.
Пространства сеточных функций
  • \(H\) — пространство функций с периодическим условием: \(y_0 = y_N\).
  • \(H_0\) — пространство функций с нулевыми краевыми значениями: \(y_0 = y_N = 0\) (для краевой задачи первого рода — Дирихле).
Разностные производные — сеточные аналоги \(\partial/\partial x\), \(\partial^2/\partial x^2\)
\[ y_{x,i} = \frac{y_{i+1} - y_i}{h}\ \text{(вперёд)}, \quad y_{\bar x,i} = \frac{y_i - y_{i-1}}{h}\ \text{(назад)}, \quad y_{\mathring{x},i} = \frac{y_{i+1} - y_{i-1}}{2h}\ \text{(центральная)}, \quad y_{\bar x x,i} = \frac{y_{i+1} - 2y_i + y_{i-1}}{h^2}\ \text{(вторая)}. \]

Оператор \(\Lambda\) — сокращённое обозначение оператора второй разности: \(\Lambda y \equiv y_{\bar x x}\), т.е. \((\Lambda y)_i = (y_{i+1} - 2y_i + y_{i-1})/h^2\) — сеточный аналог \(\partial^2/\partial x^2\). Используется в схемах для уравнения теплопроводности. По времени: \(y_t = (\hat y - y)/\tau\), \(y^{(1/2)} = \tfrac12(\hat y + y)\).

Скалярное произведение двух сеточных функций и порождённая им норма: \[ (y, v) = \sum_{i=1}^{N} h\,y_i v_i, \qquad \|y\| = \sqrt{(y, y)} = \Bigl(\sum h\,y_i^2\Bigr)^{1/2}. \tag{6а.7} \] Множитель \(h\) — чтобы сумма была интегральной для \(\int y v\,dx\). Это сеточный аналог \(L_2\)-нормы.
Что понадобится в разборах
  • Коши–Буняковский: \(|(y, v)| \le \|y\|\,\|v\|\).
  • Сдвиг индекса на периодической сетке: \(\sum h\,y_{i-1}^2 = \sum h\,y_i^2 = \|y\|^2\) — периодичность позволяет перенумеровать узлы.
§6а.4 · Операторы и энергетическая норма

Три свойства оператора: самосопряжённость, положительность, кососимметричность

Оператор \(A\colon H \to H\) — линейное правило, ставящее сеточной функции \(y\) сеточную функцию \(Ay\). Тождественный оператор \(E\colon Ey = y\).

Сопряжённый оператор \(A^*\). Оператор \(A^*\) называется сопряжённым к \(A\), если \((Ay, v) = (y, A^*v)\) при всех \(y, v \in H\) — то есть \(A\) можно «перекинуть» с одного множителя скалярного произведения на другой.
  • \(A\) самосопряжён, если \(A^* = A\) (симметричная матрица): \((Ay, v) = (y, Av)\).
  • \(A\) положителен, \(A > 0\): самосопряжён и \((Ay, y) > 0\) при \(y \ne 0\).
  • \(A\) кососимметричен, если \(A^* = -A\); тогда автоматически \((Ay, y) = 0\) при любом \(y\) — не меняет норму.
Запись \(A \ge B\) для самосопряжённых означает \(A - B \ge 0\), т.е. \((Ay, y) \ge (By, y)\) при всех \(y\).
Какие операторы будут в разборах
  • \(-\Lambda\) (вторая разность) на \(H_0\) — самосопряжён и положителен. В теплопроводности.
  • Центральная разность \(y \mapsto y_{\mathring x}\) на периодической сетке — кососимметрична. В неустойчивой явной схеме и в Кранке–Николсон.
  • Разность назад \(y \mapsto a\,y_{\bar x}\) в «уголке» — не самосопряжённая: односторонность нарушает симметрию.
Энергетическая норма. Только при \(A = A^* > 0\) форма \((Ay, v)\) сама является скалярным произведением; порождённая ею норма \[ \|y\|_A = \sqrt{(Ay, y)} \tag{6а.8} \] называется энергетической. Для \(A = -\Lambda\): \(\|y\|_A^2 = \sum h\,y_{\bar x,i}^2\) — сеточный аналог \(\int u_x^2\,dx\).

Свойства оператора определяют, применима ли для схемы общая теорема §6а.10 или нужен «ручной» приём.

§6а.5 · Суммирование по частям доп.

Лемма 1 и первая формула Грина

Для любых сеточных функций \(y\), \(v\) на \(\omega_h\): \[ \sum_{i=1}^{N} h\,y_i\,v_{\bar x,i} = -\sum_{i=0}^{N-1} h\,y_{x,i}\,v_i + y_N v_N - y_0 v_0. \tag{6а.10} \]
Доказательство. \(\sum_{i=1}^N y_i(v_i - v_{i-1}) = \sum_{i=1}^N y_iv_i - \sum_{j=0}^{N-1} y_{j+1}v_j\); в первой сумме отделяем \(i = N\), добавляем и вычитаем \(j = 0\); разность даёт \(-\sum_{j=0}^{N-1}(y_{j+1} - y_j)v_j = -\sum h\,y_{x,j}v_j\). □ Сравните: \(\int_0^l yv'\,dx = -\int_0^l y'v\,dx + [yv]_0^l\).

Следствие 1. Для \(y, v \in H_0\) граничные члены исчезают:

\[ (\Lambda y, v) = -\sum_{i=1}^{N} h\,y_{\bar x,i}v_{\bar x,i}, \tag{6а.11} \]
\[ (-\Lambda y, y) = \sum_{i=1}^{N} h\,y_{\bar x,i}^2 \ge 0. \tag{6а.12} \]

Правая часть симметрична ⇒ \(\Lambda\) самосопряжён; равенство нулю лишь при \(y = \mathrm{const}\), а с \(y_0 = 0\) — при \(y \equiv 0\). Итак, \(A = -\Lambda\) самосопряжён и положителен на \(H_0\). Краевые условия вошли именно здесь.

§6а.5 · Следствия 2 и 3 доп.

Периодическая сетка; оценка \(\|\Lambda\|\)

Следствие 2. На периодической сетке граничные члены (6а.10) взаимно уничтожаются; \(-\Lambda \ge 0\) (постоянная функция даёт нуль). Для центральной разности

\[ (y_{\mathring x}, y) = \frac12\Bigl(\sum_{i=1}^{N} y_iy_{i+1} - \sum_{i=1}^{N} y_iy_{i-1}\Bigr) = 0, \tag{6а.13} \]

и \((y_{\mathring x}, v) = -(y, v_{\mathring x})\): центральная разность кососимметрична — двойник \(\int u\,u_x\,dx = 0\).

Следствие 3. Из (6а.12) и \((a - b)^2 \le 2a^2 + 2b^2\):

\[ (-\Lambda y, y) \le \frac{2}{h^2}\sum_{i=1}^{N} h\,(y_i^2 + y_{i-1}^2) \le \frac{4}{h^2}\|y\|^2, \]
\[ -\Lambda \le \frac{4}{h^2}E. \tag{6а.14} \]
ТочноСобственные числа \(-\Lambda\) на \(H_0\): \(\frac{4}{h^2}\sin^2\frac{k\pi h}{2l}\); наибольшее \(\frac{4}{h^2}\cos^2\frac{\pi h}{2l} < \frac{4}{h^2}\). Оценка точна по порядку.

Инструменты собраны. Первый парный разбор — схема, которую мы знаем лучше всех.

§6а.9 · Каноническая форма доп.

Каноническая форма двухслойной схемы

Двухслойная схема записана в канонической форме, если она имеет вид \[ B\,\frac{y^{n+1} - y^{n}}{\tau} + A\,y^{n} = \varphi^{n}, \qquad\text{то есть}\qquad B y_t + A y = \varphi, \tag{6а.21} \] где \(A, B\colon H \to H\) — линейные операторы и \(B\) обратим (разрешимость: \(y^{n+1} = y^n - \tau B^{-1}(Ay^n - \varphi^n)\)).
СхемаЗапись\(A\)\(B\)Свойства \(A\)
Явная, теплопроводность\(y_t = \Lambda y + \varphi\) на \(H_0\)\(-\Lambda\)\(E\)\(A = A^* > 0\)
С весами \(\sigma\)\(y_t = \Lambda y^{(\sigma)} + \varphi\), \(y^{(\sigma)} = y + \sigma\tau y_t\)\(-\Lambda\)\(E + \sigma\tau A\)\(A = A^* > 0\)
«Уголок», перенос\(y_t + a\,y_{\bar x} = 0\)\(a\,\partial_{\bar x}\)\(E\)не самосопряжён

Для схем с \(A = A^* > 0\) есть общая теорема; разборы 1–3 велись напрямую именно потому, что их \(A\) не самосопряжён.

§6а.10 · Основная теорема

Теорема Самарского об устойчивости в \(H_A\)

Пусть двухслойная разностная схема без правой части записана в каноническом виде \[ B\,\frac{y^{n+1} - y^{n}}{\tau} + A\,y^{n} = 0 \] с линейными операторами \(A, B\colon H \to H\), причём:
  1. оператор \(A\) самосопряжён и положителен, \(A = A^* > 0\);
  2. оператор \(B\) обратим и удовлетворяет операторному неравенству \[ B \ge \tfrac{\tau}{2}\,A, \qquad\text{то есть}\qquad (By, y) \ge \tfrac{\tau}{2}\,(Ay, y) \ \ \text{при всех } y \in H. \]
Тогда в энергетической норме \(\|y\|_A = \sqrt{(Ay, y)}\) справедливы оценки \[ \|y^{n+1}\|_A \le \|y^{n}\|_A \ \ (n = 0, 1, \dots) \qquad\text{и, следовательно,}\qquad \|y^{n}\|_A \le \|y^{0}\|_A. \tag{6а.23} \]
Что утверждаетсяУстойчивость по начальным данным в энергетической норме с постоянной \(C = 1\), не зависящей от \(\tau\), \(h\) и числа шагов.
Обратите вниманиеОт \(B\) не требуется ни самосопряжённости, ни положительности — только обратимость и операторное неравенство \(B \ge \tfrac{\tau}{2}A\).

Доказательство — четыре этапа; после каждого отмечаем, какая гипотеза использована.

§6а.10 · Доказательство, этапы 1–2 доп.

Этап 1: полусумма слоёв. Этап 2: умножение на \(2\tau y_t\)

Этап 1 · тождественное преобразование, гипотезы не используются

Выразим \(y\) через полусумму \(y^{(1/2)} = \frac12(\hat y + y)\) и разностную производную \(y_t = \frac1\tau(\hat y - y)\):

\[ y = y^{(1/2)} - \frac{\tau}{2}\,y_t \qquad\Bigl(\text{проверка: } \tfrac12(\hat y + y) - \tfrac12(\hat y - y) = y\Bigr). \]

Подставим в \(By_t + Ay = 0\) и сгруппируем:

\[ \Bigl(B - \frac{\tau}{2}A\Bigr)y_t + A\,y^{(1/2)} = 0. \tag{6а.24} \]
Этап 2 · сеточное «умножение на решение и интегрирование»

Умножим (6а.24) скалярно на \(2\tau y_t\); множитель \(2\tau\) подобран так, чтобы второе слагаемое стало разностью энергий:

\[ 2\tau\Bigl(\bigl(B - \tfrac{\tau}{2}A\bigr)y_t,\ y_t\Bigr) + 2\tau\bigl(A y^{(1/2)},\ y_t\bigr) = 0. \tag{6а.25} \]

Осталось увидеть, что второе слагаемое — это \(\|\hat y\|_A^2 - \|y\|_A^2\).

§6а.10 · Доказательство, этапы 3–4 доп.

Этап 3: разность энергий. Этап 4: энергетическое тождество

Этап 3 · используется A = A*
\[ 2\tau\bigl(A y^{(1/2)}, y_t\bigr) = \bigl(A(\hat y + y),\ \hat y - y\bigr) = (A\hat y, \hat y) - \underbrace{(A\hat y, y) + (Ay, \hat y)}_{=\,0\ \text{по самосопряжённости}} - (Ay, y) = \|\hat y\|_A^2 - \|y\|_A^2. \tag{6а.26} \]
Этап 4 · используется B ≥ (τ/2)A, затем A > 0
\[ \|\hat y\|_A^2 = \|y\|_A^2 - 2\tau\Bigl(\bigl(B - \tfrac{\tau}{2}A\bigr)y_t,\ y_t\Bigr). \tag{6а.27} \]

Точное энергетическое тождество. По (6а.22) вычитаемое неотрицательно ⇒ \(\|\hat y\|_A^2 \le \|y\|_A^2\). Положительность \(A\) делает \(\|\cdot\|_A\) нормой; извлекаем корень — (6а.23). □

Смысл тождестваЭнергия нового слоя = энергия старого − диссипация. Условие \(B \ge \frac{\tau}{2}A\): схема не производит энергии. Для \(B = E\) это ограничение на \(\tau\); слагаемое \(\sigma\tau A\) в \(B\) неявных схем «оплачивает» его при любом \(\tau\).

Одна теорема объясняет условную устойчивость явных схем и безусловную — неявных. Есть и обратное утверждение.

§6а.10 · Теорема 2 доп.

Устойчивость в \(H_B\); необходимость условия (6а.22)

Пусть \(A = A^* > 0\) и \(B = B^* > 0\). Тогда условие (6а.22) необходимо и достаточно для оценки (6а.23); при его выполнении справедлива также оценка \(\|y^{n+1}\|_B \le \|y^{n}\|_B\). В частности, для явных схем (\(B = E\)) условие \(E \ge \frac{\tau}{2}A\) равносильно оценке \(\|y^{n+1}\| \le \|y^{n}\|\) в норме \(L_2\).

Принимаем без доказательства [Самарский, гл. VI, §2]. Для явной схемы проверяется по спектру: \(\hat y = (E - \tau A)y\), и

\[ \|E - \tau A\| \le 1 \iff 1 - \tau\lambda_k \in [-1, 1]\ \forall k \]
\[ \iff \tau\lambda_k \le 2 \iff \frac{\tau}{2}A \le E. \]
Практический выводДля схем с самосопряжёнными \(A\) и \(B\) энергетический метод даёт критерий. Запас появляется лишь при грубой оценке \(\|A\|\) и при переходе к правой части.

Теорема 1 применяется, например, к схеме с весами для теплопроводности; выкладка вынесена в упражнения §6а.15. Здесь и сейчас — единственный разбор занятия: перенос с переменной скоростью, где гармоники не работают.

§6а.12 · Устойчивость по правой части доп.

ε-неравенство и теорема 3

\[ |(\varphi, v)| \le \|\varphi\|\,\|v\| \le \varepsilon\,\|v\|^2 + \frac{1}{4\varepsilon}\,\|\varphi\|^2 \qquad\bigl((\sqrt{\varepsilon}a - b/2\sqrt{\varepsilon})^2 \ge 0\bigr). \tag{6а.31} \]
Пусть \(A = A^* > 0\), \(B\) обратим и при некотором \(\varepsilon > 0\), не зависящем от \(\tau, h\): \(\ B \ge \varepsilon E + \frac{\tau}{2}A\ \) (6а.32). Тогда \[ \|y^{n+1}\|_A^2 \le \|y^{0}\|_A^2 + \frac{1}{2\varepsilon}\sum_{k=0}^{n}\tau\,\|\varphi^{k}\|^2. \tag{6а.33} \]
Доказательство. Этапы 1–3 с правой частью: \(2\tau((B - \frac{\tau}{2}A)y_t, y_t) + \|\hat y\|_A^2 - \|y\|_A^2 = 2\tau(\varphi, y_t)\). Слева \(\ge 2\tau\varepsilon\|y_t\|^2\), справа по (6а.31) \(\le 2\tau\varepsilon\|y_t\|^2 + \frac{\tau}{2\varepsilon}\|\varphi\|^2\); члены с \(\|y_t\|^2\) сокращаются, остаётся \(\|\hat y\|_A^2 \le \|y\|_A^2 + \frac{\tau}{2\varepsilon}\|\varphi\|^2\). Суммируем по слоям. □
ПлатаДля явной схемы (6а.32) даёт \(\tau \le (1 - \varepsilon)h^2/2\) вместо \(\tau \le h^2/2\): достаточные условия с запасом.

Последний разбор — задача, где гармоник нет вовсе.

§6а.13 · Разбор · постановка

Задача, ради которой всё делалось: перенос с переменной скоростью

Возьмём уравнение переноса, у которого скорость зависит от координаты:

\[ \frac{\partial u}{\partial t} + a(x)\,\frac{\partial u}{\partial x} = 0, \qquad a(x) > 0, \qquad u(0,t) = u(l, t)\ (\text{периодичность}). \tag{6а.34} \]
Обозначения
  • \(a(x)\) — переменная скорость переноса (дальше — гладкая: \(|a'(x)| \le L\), где \(L\) — постоянная Липшица, не зависящая от \(x\)).
  • \(L\) отвечает за то, «насколько быстро» \(a(x)\) меняется на отрезке.
Разностная схема — «уголок» с локальным числом Куранта \[ \hat y_i = (1 - r_i)\,y_i + r_i\,y_{i-1}, \qquad r_i = \frac{a(x_i)\,\tau}{h}, \qquad 0 \le r_i \le 1 \ \text{при всех } i. \tag{6а.35} \]

\(r_i\) — локальное число Куранта: своё в каждом узле, потому что скорость \(a(x_i)\) своя.

Задача — доказать устойчивость без предположения о постоянстве \(a\). Первый вопрос: сработает ли здесь знакомый метод фон Неймана?

§6а.13 · Разбор · почему фон Нейман здесь бессилен

Почему метод гармоник (§6) не даёт ответа

Метод фон Неймана держится на одном факте (лемма 1 §6):

Условие применимости леммы 1Оператор перехода \(S\) переводит слой в слой (\(u^{n+1} = S u^n\)) и перестановочен со сдвигом \(T\colon u_m \mapsto u_{m+1}\): \(ST = TS\). Только при этом гармоника \(e^{i\alpha m}\) — собственная функция \(S\), и всё сводится к одному числу \(\lambda(\alpha)\).

Проверка для (6а.35): запишем действие оператора \(S\) на \(y\):

\[ (Sy)_i = (1 - r_i)\,y_i + r_i\,y_{i-1}. \]

Коэффициенты \(1 - r_i\) и \(r_i\) зависят от номера узла. Значит, если сдвинуть сначала (\(v = Ty\), \(v_i = y_{i+1}\)) и потом применить \(S\), получим \((STy)_i = (1 - r_i)\,y_{i+1} + r_i\,y_i\); а если сначала применить \(S\) и потом сдвинуть — \((TSy)_i = (Sy)_{i+1} = (1 - r_{i+1})\,y_{i+1} + r_{i+1}\,y_i\). Числа \(r_i\) и \(r_{i+1}\) разные — \(ST \ne TS\).

ВыводГармоника \(e^{i\alpha m}\) не является собственной функцией \(S\); множитель перехода \(\lambda(\alpha)\) как одно число просто не определён. Метод фон Неймана здесь не формулируется.
Эвристика замороженных коэффициентовОбычная в практике «отговорка»: зафиксировать \(a = a(x_i)\) в каждом узле и потребовать локальное условие Куранта \(r_i \le 1\) для всех \(i\). Это правдоподобно, но не является доказательством: замороженная схема — другая, а связь между её устойчивостью и устойчивостью настоящей не установлена.

Что тогда делать? Работать не с гармониками, а с нормой решения целиком — как в дифференциальном прототипе (слайд §6а.2). Это и есть энергетический метод.

Ключ — то, что схема (6а.35) в каждом узле остаётся выпуклым средним: \(\hat y_i\) — среднее \(y_i\) и \(y_{i-1}\) с весами \(1 - r_i, r_i \ge 0\), не превосходящими единицы. Значит поточечное неравенство выпуклости работает — как и в постоянном случае.

§6а.13 · Разбор · энергетическая выкладка

Энергетический метод: три шага + оценка «сшивочного» члена

Инструменты (без операторной теории): норма \(\|y\|^2 = \sum h\,y_i^2\); неравенство выпуклости \((\theta a + (1 - \theta)b)^2 \le \theta a^2 + (1 - \theta)b^2\) при \(\theta \in [0,1]\); сдвиг индекса на периодической сетке \(\sum h\,y_{i-1}^2 = \|y\|^2\).

Шаг 1 · неравенство выпуклости в каждом узле

Веса \(1 - r_i\) и \(r_i\) неотрицательны и в сумме дают единицу — при \(0 \le r_i \le 1\). Значит для каждого узла \(i\) по (6а.16) с \(\theta = 1 - r_i\), \(a = y_i\), \(b = y_{i-1}\):

\[ \hat y_i^{\,2} = \bigl((1 - r_i)y_i + r_iy_{i-1}\bigr)^2 \le (1 - r_i)\,y_i^{\,2} + r_i\,y_{i-1}^{\,2}. \]
Шаг 2 · суммирование и сдвиг индекса

Умножим на \(h\) и просуммируем по \(i = 1, \dots, N\). Слева — \(\|\hat y\|^2\); справа — две суммы. Во второй сдвинем индекс на периодической сетке (заменим \(i \to i+1\) в \(y_{i-1}\)): \(\sum h\,r_i\,y_{i-1}^2 = \sum h\,r_{i+1}\,y_i^2\). Собираем всё у одного и того же квадрата \(y_i^2\):

\[ \|\hat y\|^2 \le \sum_{i=1}^{N} h\bigl[(1 - r_i) + r_{i+1}\bigr]\,y_i^{\,2} = \|y\|^2 + \underbrace{\sum_{i=1}^{N} h\,(r_{i+1} - r_i)\,y_i^{\,2}}_{\text{«сшивочный» член}}. \tag{6а.36} \]
ЗамечаниеВ случае постоянного \(a\) все \(r_i\) равны, разность \(r_{i+1} - r_i = 0\), сшивочный член исчезает — получаем стандартную оценку \(\|\hat y\|^2 \le \|y\|^2\), как в разборе 1.
§6а.13 · Разбор · шаг 3 и итог

Шаг 3: оценка сшивочного члена и итерация по слоям

Шаг 3 · сшивочный член через гладкость \(a(x)\)

В сшивочный член входит разность \(r_{i+1} - r_i\). По определению \(r_i = a(x_i)\,\tau/h\):

\[ r_{i+1} - r_i = \frac{\tau}{h}\,\bigl(a(x_{i+1}) - a(x_i)\bigr) \overset{\text{теорема Лагранжа}}{=} \frac{\tau}{h}\cdot h\cdot a'(\xi_i) = \tau\,a'(\xi_i), \qquad \xi_i \in (x_i, x_{i+1}). \]

По условию \(|a'(x)| \le L\) (\(L\) — постоянная Липшица), поэтому \(r_{i+1} - r_i \le \tau L\). Значит сшивочный член оценивается сверху так:

\[ \sum_{i=1}^{N} h\,(r_{i+1} - r_i)\,y_i^{\,2} \le \tau L\,\sum_{i=1}^{N} h\,y_i^{\,2} = \tau L\,\|y\|^2. \]

Подставляем в (6а.36):

\[ \|\hat y\|^2 \le (1 + \tau L)\,\|y\|^2. \]
Итерация по слоям \(0, 1, \dots, n\) — за конечное время \(t_n \le T\)
\[ \|y^{n}\|^2 \le (1 + \tau L)^{n}\,\|y^{0}\|^2 \le e^{L\,t_n}\,\|y^{0}\|^2 \quad\Longrightarrow\quad \|y^{n}\| \le e^{LT/2}\,\|y^{0}\|. \tag{6а.37} \]
Результат. Устойчивость по начальным данным (Опр. 3 §2) с постоянной \(C = e^{LT/2}\), не зависящей от \(\tau\), \(h\) и \(n\). Эвристика замороженных коэффициентов стала теоремой, с явной постоянной. Отметьте: норма может расти на каждом шаге не более чем в \(1 + \tau L\) раз — это ровно та ситуация, ради которой в самом условии Неймана (§6.4) стояло \(1 + C_1\tau\), а не \(1\). Единственное место, где вошла переменность \(a(x)\), — разность \(r_{i+1} - r_i\); тот же приём проходит для неравномерных сеток и краевых задач.

§6а.14 · Порядок действий

Порядок исследования схемы энергетическим методом

1
Сначала — гармоники
Если применимы: быстро дают необходимое условие и подсказывают ответ.
2
Каноническая форма
\(A\), \(B\), пространство \(H\) или \(H_0\) с учётом краевых условий.
3
Свойства \(A\)
Самосопряжённость, положительность — суммированием по частям; граничные члены обязаны исчезнуть.
4
Если \(A = A^* > 0\)
Проверить \(B \ge \frac{\tau}{2}A\) (для явных — \(\tau \le 2/\|A\|\)); вывод по теоремам 1–3.
5
Если \(A\) не самосопряжён
Умножить на \(\hat y\) или \(y^{(1/2)}\), выделить \(\|\hat y\|^2 - \|y\|^2\), остальное — Грин, Коши–Буняковский, ε; цель \(\|\hat y\|^2 \le (1 + c\tau)\|y\|^2\).
6
Сопоставить с гармониками
Совпадение — критерий; расхождение — запас метода или неустойчивость в \(C\).
Типичные ошибкипотерянные граничные члены при условиях второго и третьего рода; грубая \(\|A\|\) → слишком жёсткое условие (гармоники его «опровергают» — это не противоречие); перенос \(L_2\)-оценки на норму \(C\); попытка применить теорему 1 для несамосопряжённого \(A\).
§6а · Итоги

Итоги §6а

Что мы сделали
  1. Повторили на сетке дифференциальный вывод \(\tfrac{dE}{dt} = 0\) — три действия: умножить на решение, «проинтегрировать по частям», обнулить границу.
  2. Ввели минимум аппарата — скалярное произведение, норму \(L_2\), свойства оператора.
  3. Сформулировали основную теорему Самарского об устойчивости в энергетической норме (общий инструмент; при наличии времени применяется к схеме с весами — упр. 6а.15).
  4. Разобрали ключевой пример — перенос с переменной скоростью, где метод фон Неймана бессилен, а энергетический даёт строгую оценку \(\|y^n\| \le e^{LT/2}\|y^0\|\).
Главное
  • Гармоники дают необходимые условия; энергия — достаточные.
  • Энергетический метод работает там, где гармоники не формулируются: краевые условия, переменные коэффициенты, неравномерные сетки, неявные схемы.
  • Ключ переноса на сетку: скалярное произведение и сдвиг индекса — сеточные аналоги «умножить на решение» и «интегрирование по частям».
