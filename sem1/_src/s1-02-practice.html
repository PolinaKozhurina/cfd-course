Варианты (для задания B)

Уравнение переноса \(u_t + a\,u_x = 0\), \(a = \mathrm{const} > 0\); сетка с шагами \(h\) по \(x\) и \(\tau\) по \(t\).

ВариантСхемаВторая базовая точка
В1\(\displaystyle \frac{u_i^{n+1}-u_i^{n-1}}{2\tau} + a\,\frac{u_{i+1}^{n}-u_{i-1}^{n}}{2h} = 0\)\((x_i,\ t_{n-1})\)
В2\(\displaystyle \frac{u_i^{n+1}-u_i^{n}}{\tau} + \frac{a}{2}\left(\frac{u_i^{n+1}-u_{i-1}^{n+1}}{h} + \frac{u_{i+1}^{n}-u_{i}^{n}}{h}\right) = 0\)\((x_i,\ t_{n+1})\)

Задания

A.Алгоритм §2.8 на явном «уголке» (2.17)≈ 15 мин, общее

Схему задаём как функцию базовой точки и шагов; \(u\) — произвольная гладкая функция, Maple разложит её по Тейлору сам:

scheme := (x, t, h, tau) -> (u(x, t + tau) - u(x, t))/tau + a*(u(x, t) - u(x - h, t))/h;
L1 := collect(convert(mtaylor(scheme(x, t, h, tau), [h, tau], 3), diff), [tau, h], simplify);
Lu := diff(u(x, t), t) + a*diff(u(x, t), x):
Ru := collect(simplify(Lu - L1), [tau, h]);
  1. Сопоставьте вывод Maple с шагами 1–4 алгоритма §2.8: где здесь \(L_1 u\) из (2.22), где \(Ru = Lu - L_1 u\). Назовите порядок по \(\tau\) и по \(h\) на произвольной гладкой функции.
  2. Перейдите к аппроксимации на решении: подставьте общее решение \(u = F(x - at)\) — тогда все дифференциальные следствия уравнения (\(u_{tt} = a^2 u_{xx}\) и т. д.) выполняются автоматически: 
    onSol := expr -> collect(simplify(eval(expr, u = ((x, t) -> F(x - a*t)))), [tau, h], factor):
RuSol := onSol(Ru);
    Сравните с оценкой (2.21) лекции: какие производные и с какими множителями стоят в главном члене.
  3. Прочитайте множитель при \(F''\): при каком соотношении \(\tau\) и \(h\) член первого порядка обращается в нуль? Свяжите с задачей 9 ДЗ №1 (точная схема при \(a\tau/h = 1\)).
Вывод в листПорядок на произвольной функции; порядок на решении; главный член невязки и условие его обнуления.
B.Схема варианта≈ 30 мин, по вариантам
  1. Запишите схему варианта как функцию schemeV по образцу задания A (в заготовке для примера записана В3). Для трёхслойной В1 в функцию входит \(u(x, t-\tau)\).
  2. Получите \(L_1 u\) и \(Ru\) с точностью до членов третьего порядка (mtaylor(..., [h, tau], 4)). Назовите порядок по \(\tau\) и по \(h\) на произвольной функции.
  3. Примените onSol и назовите порядок на решении. Если он выше, чем в п. 2, — выпишите руками, какой член разложения обнулился и каким следствием уравнения (например, \(u_{tt} = a^2 u_{xx}\) или \(u_{xt} = -a\,u_{xx}\)). Это и есть замечание §2.9 о том, что аппроксимацию достаточно проверять на решении.
  4. Повторите расчёт во второй базовой точке из таблицы. Разложение Maple всегда идёт около \((x,t)\), поэтому сдвигаются аргументы схемы: для точки \((x_i, t_{n+1/2})\) вызываем schemeV(x, t - tau/2, h, tau), для \((x_{i-1/2}, t_{n+1})\) — schemeV(x + h/2, t - tau, h, tau). Убедитесь, что порядок на решении не изменился, а коэффициенты \(L_1\) — изменились.
  5. Для отдельного оператора \((u_i - u_{i-1})/h\) покажите тем же приёмом, что около \(x_i\) он приближает \(u_x\) с порядком \(O(h)\), а около \(x_{i-1/2}\) — с порядком \(O(h^2)\): 
    D1 := (x, h) -> (u(x) - u(x - h))/h:
mtaylor(D1(x, h), [h], 3);          # около x_i
mtaylor(D1(x + h/2, h), [h], 3);    # около x_{i-1/2}

C.Схема Лакса и закон предельного перехода≈ 15 мин, общее
\[ \frac{u_i^{n+1} - \tfrac12\bigl(u_{i-1}^{n} + u_{i+1}^{n}\bigr)}{\tau} + a\,\frac{u_{i+1}^{n} - u_{i-1}^{n}}{2h} = 0. \]
schemeL := (x, t, h, tau) -> (u(x, t + tau) - (u(x - h, t) + u(x + h, t))/2)/tau
    + a*(u(x + h, t) - u(x - h, t))/(2*h);
L1L    := collect(convert(mtaylor(schemeL(x, t, h, tau), [h, tau], 4), diff), [tau, h], simplify);
L1Lpar := collect(convert(mtaylor(subs(tau = h^2/mu,    schemeL(x, t, h, tau)), [h], 3), diff), h, simplify);
L1Lhyp := collect(convert(mtaylor(subs(tau = kappa*h,   schemeL(x, t, h, tau)), [h], 3), diff), h, simplify);
  1. В L1L найдите член \(-\dfrac{h^2}{2\tau}u_{xx}\). Почему его нельзя отнести ни к \(O(\tau)\), ни к \(O(h)\), пока не задано, как \(\tau\) и \(h\) связаны?
  2. При законе \(\tau = h^2/\mu\) выпишите предел \(L_1 u\) при \(h \to 0\). Аппроксимирует ли схема уравнение переноса по Опр. 2? Какое уравнение она аппроксимирует на самом деле?
  3. При законе \(\tau = \varkappa h\) назовите порядок аппроксимации.
Вывод в листОт чего, кроме самой схемы, зависит наличие аппроксимации; почему в Опр. 2 один предел \(h \to 0\), а не два независимых.
D.Аппроксимация без сходимости≈ 20 мин, общее

Задача Коши \(x' = 2t\), \(x(0) = 0\), точное решение \(x = t^2\); сетка \(t_i = i\tau\); явный двухшаговый метод

\[ \frac{x_i - 3x_{i-1} + 2x_{i-2}}{\tau} = f(t_{i-1}, x_{i-1}) - 2f(t_{i-2}, x_{i-2}), \qquad f(t,x) = 2t. \]
f := (t, x) -> 2*t:
resid := simplify((t^2 - 3*(t - tau)^2 + 2*(t - 2*tau)^2)/tau - (f(t - tau, 0) - 2*f(t - 2*tau, 0)));
rec := X(i) - 3*X(i - 1) + 2*X(i - 2) = tau*(f((i - 1)*tau, 0) - 2*f((i - 2)*tau, 0)):
solExact := factor(rsolve({rec, X(0) = 0, X(1) = tau^2}, X(i)));
solPert  := simplify(rsolve({rec, X(0) = 0, X(1) = tau^2 + eps}, X(i)));
errPert  := simplify(solPert - (i*tau)^2);
evalf(subs(eps = 1e-16, tau = 1e-2, i = 100, errPert));
  1. resid — невязка (2.7) на проекции точного решения. Есть ли аппроксимация по Опр. 2 и какого порядка?
  2. solExact — точное решение разностной задачи при точных стартовых значениях. Какова погрешность \(x_i - t_i^2\) и стремится ли она к нулю при \(\tau \to 0\)?
  3. solPert — то же при стартовом значении с погрешностью \(\varepsilon\). Выпишите, как растёт возмущение при \(t_i = T\) фиксированном и \(\tau \to 0\). Выполняется ли Опр. 3 с постоянной \(C_2 \ne C_2(\tau)\)?
  4. Оцените число: погрешность округления \(10^{-16}\) в \(x_1\) при \(\tau = 10^{-2}\) на \(t = 1\). Сходится ли метод по Опр. 1 на практике? Какого из свойств Опр. 1–4 ему не хватает?
Вывод в листАппроксимация есть / устойчивости нет / сходимости нет — с числами; одна фраза о том, что доказывает этот пример про связь трёх понятий (к §3).
E.Порядок сходимости численноесли осталось время

Процедура runCorner(N, sigma, T) из заготовки считает «уголком» задачу \(u_t + u_x = 0\), \(u_0 = \sin 2\pi x\) на периоде при \(\sigma = \tau/h\) и возвращает \(\|z\|_C\) в момент \(T\).

errs   := [seq(runCorner(N, 0.5, 1.0), N in [20, 40, 80, 160])];
orders := [seq(evalf(log[2](errs[k]/errs[k + 1])), k = 1 .. 3)];
runCorner(40, 1.0, 1.0);
  1. Выведите формулу \(p \approx \log_2(\|z_h\|/\|z_{h/2}\|)\) из (2.6) и сравните orders с порядком аппроксимации из задания A.
  2. Объясните результат при \(\sigma = 1\).
  3. Почему шаги измельчаются при фиксированном \(\sigma\), а не по отдельности? (Ответ — в задании C.)
