Занятие 5 · Блок II. Аппроксимация

Метод наименьших квадратов и ортогональные базисы

Нормальные уравнения · Лежандр · Чебышёв · DFT · κ²
§5.1 · Постановка

Данных больше, чем неизвестных

В § 3-4 через \(n+1\) точку проходил единственный полином степени \(\le n\). Сегодня — переопределённая задача: измерений \(m\), базисных функций \(n+1\), при \(m \gg n\).

Найти \(c^{*}\in\mathbb{R}^{n+1}\):
\[ c^{*} = \arg\min_c\|Ac - y\|_2^2. \tag{5.2} \]
В непрерывном случае — минимизация \(\|f - Q_n\|_{L_2}\).
§5.2 · Нормальные уравнения

Нормальные уравнения — прямой путь

Условие \(\nabla_c \|Ac - y\|^2 = 0\) даёт квадратную систему:

\[ A^\top A\,c^{*} = A^\top y. \tag{5.4} \]
Матрица \(A^\top A\) симметрична; при линейно независимых столбцах \(A\) — положительно определена.

Явно в непрерывном случае:

\[ \sum_{k=0}^{n}(\varphi_j,\varphi_k)\,c_k^{*} = (\varphi_j, f). \tag{5.5} \]

Матрица Грама \((\varphi_j, \varphi_k)\) — плотная. Хочется её сделать диагональной.

§5.3 · Ортогональные базисы

Ортогональный базис = диагональная матрица Грама

Система \(\{\varphi_k\}\) ортогональна на \([a,b]\) с весом \(w > 0\):
\[ (\varphi_j, \varphi_k)_w = \int_a^b w(x)\,\varphi_j\varphi_k\,dx = 0\ \ (j\ne k). \tag{5.6} \]
формула проекции.
\[ c_k^{*} = \frac{(f, \varphi_k)_w}{(\varphi_k, \varphi_k)_w}. \tag{5.7} \]
Каждый коэффициент — независимо. Добавили \(\varphi_{n+1}\) — предыдущие \(c_k\) не меняются.
§5.4 · Полиномы Лежандра

Полиномы Лежандра

Ортогональны на \([-1, 1]\) с весом \(w \equiv 1\).
\[ P_0 = 1,\ P_1 = x,\quad (n+1)P_{n+1} = (2n+1)xP_n - nP_{n-1}. \tag{5.8} \]
Норма:
\[ \int_{-1}^{1}P_j P_k\,dx = \frac{2}{2k+1}\delta_{jk}. \tag{5.9} \]

МНК-разложение по Лежандру:

\[ c_k = \frac{2k+1}{2}\int_{-1}^{1} f(x)P_k(x)\,dx. \tag{5.10} \]
§5.5 · Чебышёв как L²

Чебышёв — та же система, другой вес

В § 4 \(T_n\) появились как минимаксные. Оказывается, они одновременно ортогональны на \([-1, 1]\) с весом \(w = 1/\sqrt{1 - x^2}\):

\[ \int_{-1}^{1}\frac{T_j T_k}{\sqrt{1-x^2}}\,dx = \begin{cases}0, & j\ne k,\\ \pi, & j=k=0,\\ \pi/2, & j=k\ge 1.\end{cases} \tag{5.11} \]

Разложение — по (5.12). Для гладкой \(f\) — экспоненциальная сходимость.

Практика. Аппаратные библиотеки \(\sin, \cos, e^x\) хранят коэффициенты чебышёвского разложения. Для \(e^x\) на \([-1, 1]\) 12 коэффициентов дают полную точность double.
§5.6 · Фурье

Тригонометрическая аппроксимация

Для \(2\pi\)-периодической \(f\in L_2\):
\[ f \sim \frac{a_0}{2} + \sum_{k=1}^\infty(a_k\cos kx + b_k\sin kx), \tag{5.13} \]
\[ a_k = \frac{1}{\pi}\int_{-\pi}^{\pi} f\cos kx\,dx,\ \ b_k = \frac{1}{\pi}\int_{-\pi}^{\pi} f\sin kx\,dx. \]

Скорость сходимости связана с гладкостью: \(f\in C^p \Rightarrow a_k, b_k = O(k^{-p})\); для аналитических — экспоненциально.

§5.7 · DFT

Дискретное преобразование Фурье

Для дискретизации в \(N\) точках \(x_k = 2\pi k/N\):
\[ \hat f_j = \frac{1}{N}\sum_{k=0}^{N-1} f(x_k)\,e^{-2\pi i j k/N}. \tag{5.14} \]

Прямое вычисление — \(O(N^2)\). БПФ (FFT, Cooley-Tukey) — \(O(N\log N)\).

Роль DFT: свёртка за \(O(N\log N)\), сердце спектральных методов для УрЧП, стандартный инструмент цифровой обработки сигналов.
§5.8 · Проблема κ²

Нормальные уравнения возводят обусловленность в квадрат

\[ \kappa_2(A^\top A) = \bigl(\kappa_2(A)\bigr)^2. \tag{5.16} \]

Если \(\kappa_2(A) \sim 10^8\), то \(\kappa_2(A^\top A) \sim 10^{16}\) — на пределе double.

Пример: степенной базис \(\{1, x, \ldots, x^n\}\) на \([0, 1]\) даёт матрицу Гильберта, \(\kappa\) которой растёт экспоненциально.
Плохо: нормальные уравнения в степенном базисе → \(\kappa^2\).
Хорошо: ортогональный базис — \(\kappa = 1\); QR-разложение или SVD (§ 13).
§5.9 · Итоги

Что унести с занятия 5

  1. Задача МНК (5.2): переопределённая система решается в смысле минимума суммы квадратов.
  2. Нормальные уравнения (5.4) — прямой путь, работает пока задача не близка к вырождению.
  3. Ортогональный базис делает матрицу Грама диагональной; коэффициенты — по формуле проекции (5.7).
  4. Полиномы Лежандра — на \([-1,1]\) с весом 1; Чебышёва — с весом \(1/\sqrt{1-x^2}\).
  5. Тригонометрический базис + DFT — стандарт для периодических данных.
  6. Опасность: \(\kappa_2(A^\top A) = \kappa_2(A)^2\). Для больших размерностей — ортогональные базисы или обратно устойчивые алгоритмы (§ 13).
