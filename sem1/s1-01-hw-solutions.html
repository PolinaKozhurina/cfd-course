Нормы, пространства, корректность

Решение 1.Аксиомы нормы

Обозначения и посылки. Пусть \(\mathbb{R}^n\) — линейное пространство над \(\mathbb{R}\) с покомпонентными операциями (Опр. 1); \(I_n := \{1, 2, \ldots, n\}\). Модуль на \(\mathbb{R}\) считаем известным, свойства модуля берём за исходные:

\[ \text{(M1)}\ |a| \ge 0;\ \ |a| = 0 \Leftrightarrow a = 0;\qquad \text{(M2)}\ |\alpha\, a| = |\alpha|\cdot |a|;\qquad \text{(M3)}\ |a + b| \le |a| + |b|. \]

Ниже пригодятся ещё два арифметических факта:

Лемма L1 (максимум неотрицательного набора) Пусть \(f\colon I_n \to \mathbb{R}_{\ge 0}\). Тогда (a) \(\max_{i\in I_n} f(i) \ge 0\); (b) \(\max_{i\in I_n} f(i) = 0 \Leftrightarrow \forall i\in I_n\ \ f(i) = 0\); (c) для любого \(\lambda \ge 0\) справедливо \(\max_{i\in I_n} \bigl(\lambda\, f(i)\bigr) = \lambda\,\max_{i\in I_n} f(i)\). ▢

Так как \(I_n\) конечно, максимум достигается на некотором \(k^*\in I_n\): \(\max_i f(i) = f(k^*)\). (a) \(f(k^*) \ge 0\) в силу \(f \ge 0\). (b) Если \(\max_i f = 0\) и \(j \in I_n\) произвольно, то \(0 \le f(j) \le f(k^*) = 0\), откуда \(f(j) = 0\); обратно, из \(f \equiv 0\) очевидно \(\max f = 0\). (c) \(\max_i \lambda f(i) \le \lambda\,\max_i f(i)\) — так как \(\lambda f(i) \le \lambda f(k^*)\) для каждого \(i\) (\(\lambda \ge 0\), функция \(t \mapsto \lambda t\) монотонна на \([0, \infty)\)); обратно, \(\lambda f(k^*) \le \max_i \lambda f(i)\), так как \(k^* \in I_n\).

Лемма L2 (max суммы неотрицательных) Для \(f, g\colon I_n \to \mathbb{R}_{\ge 0}\) \(\ \max_{i\in I_n} \bigl(f(i) + g(i)\bigr) \le \max_{i\in I_n} f(i) + \max_{i\in I_n} g(i)\). ▢

Пусть \(k^*\) — индекс максимума суммы: \(\max_i (f + g) = f(k^*) + g(k^*)\). Тогда \(f(k^*) \le \max_i f\) и \(g(k^*) \le \max_i g\) (по определению максимума); сложив, получаем требуемое.

1) Чебышёвская норма \(\|x\|_\infty := \max_{i\in I_n} |x_i|\).

Проверка (N1): невырожденность. Применим лемму L1 к \(f(i) := |x_i|\) (значения неотрицательны по (M1)).

  • Неотрицательность. По L1(a): \(\|x\|_\infty = \max_i |x_i| \ge 0\).
  • Импликация \(x = 0 \Rightarrow \|x\|_\infty = 0\). Пусть \(x = 0\), т. е. \(x_i = 0\) для всех \(i\). По (M1) \(|x_i| = 0\) для всех \(i\), значит по L1(b) \(\max_i |x_i| = 0\).
  • Импликация \(\|x\|_\infty = 0 \Rightarrow x = 0\). Пусть \(\max_i |x_i| = 0\). По L1(b) \(|x_j| = 0\) для каждого \(j \in I_n\); по (M1) \(x_j = 0\) для каждого \(j\). Итого \(x = 0\).

Проверка (N2): однородность. Пусть \(\alpha \in \mathbb{R}\). Применим (M2) поточечно и лемму L1(c) с \(\lambda := |\alpha| \ge 0\):

\[ \|\alpha x\|_\infty \;=\; \max_{i\in I_n} |\alpha\, x_i| \;\overset{\text{(M2)}}{=}\; \max_{i\in I_n} \bigl(|\alpha|\cdot |x_i|\bigr) \;\overset{\text{L1(c)}}{=}\; |\alpha|\cdot \max_{i\in I_n} |x_i| \;=\; |\alpha|\cdot \|x\|_\infty. \]

Проверка (N3): неравенство треугольника. Обозначим \(k^*\in I_n\) — индекс, реализующий максимум суммы: \(\|x + y\|_\infty = |x_{k^*} + y_{k^*}|\) (существует, так как \(I_n\) конечно). Тогда

\[ \|x + y\|_\infty \;=\; |x_{k^*} + y_{k^*}| \;\overset{\text{(M3)}}{\le}\; |x_{k^*}| + |y_{k^*}| \;\overset{(\dagger)}{\le}\; \max_{i\in I_n} |x_i| + \max_{i\in I_n} |y_i| \;=\; \|x\|_\infty + \|y\|_\infty, \]

где \((\dagger)\) — из \(|x_{k^*}| \le \max_i |x_i|\) и \(|y_{k^*}| \le \max_i |y_i|\) по определению максимума. Единственное «внешнее» неравенство — (M3), т. е. треугольник для модуля на \(\mathbb{R}\).

2) Манхэттенская норма \(\|x\|_1 := \sum_{i=1}^n |x_i|\). Ниже используем свойство суммы неотрицательных чисел: \(\sum_i c_i \ge 0\) при \(c_i \ge 0\), причём равенство нулю \(\Leftrightarrow c_i = 0\) для всех \(i\).

Проверка (N1).

  • По (M1) \(|x_i| \ge 0\), значит \(\|x\|_1 = \sum_i |x_i| \ge 0\).
  • \(x = 0 \Rightarrow \|x\|_1 = 0\): \(x_i = 0 \Rightarrow_{\text{(M1)}} |x_i| = 0\), сумма нулей — нуль.
  • \(\|x\|_1 = 0 \Rightarrow x = 0\): сумма неотрицательных членов равна нулю тогда и только тогда, когда каждое слагаемое равно нулю; значит \(|x_j| = 0\) для каждого \(j\), откуда по (M1) \(x_j = 0\) для каждого \(j\); \(x = 0\).

Проверка (N2). По (M2) поточечно и линейности суммы:

\[ \|\alpha x\|_1 \;=\; \sum_{i=1}^n |\alpha\, x_i| \;\overset{\text{(M2)}}{=}\; \sum_{i=1}^n |\alpha|\cdot |x_i| \;=\; |\alpha|\cdot \sum_{i=1}^n |x_i| \;=\; |\alpha|\cdot \|x\|_1. \]

Проверка (N3). По (M3) поточечно и монотонности суммы неотрицательных членов:

\[ \|x + y\|_1 \;=\; \sum_{i=1}^n |x_i + y_i| \;\overset{\text{(M3)}}{\le}\; \sum_{i=1}^n \bigl(|x_i| + |y_i|\bigr) \;=\; \sum_{i=1}^n |x_i| + \sum_{i=1}^n |y_i| \;=\; \|x\|_1 + \|y\|_1. \]
Итогобе функции удовлетворяют аксиомам (N1)–(N3) Опр. 2 и, следовательно, задают норму на \(\mathbb{R}^n\). Ключевое внешнее место в обоих доказательствах — неравенство треугольника (M3) для модуля \(|\cdot|\) на \(\mathbb{R}\); остальное — арифметика максимума (леммы L1, L2) и суммы неотрицательных чисел.
Решение 2.Задача Коши в операторной форме

Записываем (1.3)–(1.4) в форме (1.0), явно выписывая четвёрку \((A, B_1, B_2, F)\).

Оператор и правая часть. Пусть область \(\Omega = \mathbb{R} \times [0, T]\). Класс функций, в котором ищется классическое решение:

\[ B_1 \;=\; \bigl\{\,u\in C^{1}(\Omega) \;:\; u(x, 0) = u_0(x)\ \ \forall\, x\in\mathbb{R}\,\bigr\}. \]

Иначе говоря, \(B_1\) — аффинное подпространство в \(C^{1}(\Omega)\), выделенное начальным условием как связью на след функции при \(t = 0\). Так в \(B_1\) «упаковано» условие (1.4): оно не появляется в правой части, а сужает область определения оператора.

Дифференциальный оператор:

\[ A\,u \;:=\; \frac{\partial u}{\partial t} + a\,\frac{\partial u}{\partial x}, \qquad A\colon B_1 \to B_2. \]

Так как \(u \in C^{1}(\Omega)\), обе производные существуют и непрерывны, поэтому \(A u\) корректно определено и принадлежит \(C(\Omega)\); в качестве \(B_2\) можно взять любое пространство, вкладывающее \(C(\Omega)\) — см. варианты ниже.

Правая часть уравнения (1.3) — тождественный нуль:

\[ F \;\equiv\; 0 \;\in\; B_2. \]
Возможна эквивалентная альтернативная запись, где \(B_1\) не заужен: тогда начальное условие «поднимают» в правую часть системой \(\{A u = 0,\ \mathrm{tr}_{t=0}\, u = u_0\}\) с составным оператором. Компактнее — принятый выше вариант.

Пара пространств \((B_1, B_2)\) — вариант с равномерной нормой.

\[ \|u\|_1 \;=\; \|u\|_{C(\Omega)} \;=\; \sup_{(x, t)\in\Omega} |u(x, t)|;\qquad B_2 = C_b(\Omega),\ \ \|v\|_2 = \sup_{(x, t)\in\Omega} |v(x, t)|. \]

Дополнительно требуется \(u_0 \in C^{1}(\mathbb{R})\), \(\|u_0\|_C < \infty\); тогда \(B_1 \subset C_b(\Omega)\) корректно и \(A\) переводит ограниченные \(C^{1}\)-функции в ограниченные непрерывные.

Пара с интегральной нормой.

\[ \|u\|_1 \;=\; \|u\|_{L_2(\Omega)} \;=\; \Bigl(\iint_\Omega u^2(x, t)\,dx\,dt\Bigr)^{\!1/2};\qquad B_2 = L_2(\Omega),\ \ \|v\|_2 = \|v\|_{L_2}. \]

Здесь удобно взять \(B_1\) в виде соболевского подпространства \(H^{1}(\Omega)\) со следом \(u_0\) на \(\{t = 0\}\); тогда все операции \(u_t, u_x\) осмыслены как элементы \(L_2\) (в слабом смысле) и \(A u \in L_2 = B_2\).

Итогзадача Коши для уравнения переноса — линейная задача \(A u = F\) с \(F \equiv 0\), \(A = \partial_t + a\,\partial_x\); начальное условие включено в область определения \(B_1\) как связь на след \(u|_{t=0}\); пара \((B_1, B_2)\) выбирается под тип оценок — \((C^{1}_b, C_b)\) для равномерной сходимости или \((H^{1}, L_2)\) для среднеквадратичной.

Решение 3.Неравномерная сетка через \(\varphi(t) = t^2\)

При \(a = 0\), \(b = 1\), \(\varphi(0) = 0\), \(\varphi(1) = 1\) формула (1.8а) сводится к \(\Phi(t) = t^2\), а равномерная сетка на \([0, 1]\) — к \(t_k = k h\), \(h = 1/N = 1/4\). Отсюда

Сгущение и его причина. \(h_1 : h_4 = 1 : 7\) — сетка семикратно чаще у левого конца. Формально: локальная плотность узлов равна \(1/h_k\), а \(h_k\) в свою очередь — приращение образа при равномерном шаге аргумента, т. е.

\[ h_k \;=\; \Phi(k h) - \Phi((k-1)\,h) \;=\; h \cdot \Phi'(\xi_k), \qquad \xi_k \in \bigl((k-1) h,\ k h\bigr), \]

по теореме Лагранжа. Для \(\varphi(t) = t^2\) имеем \(\Phi'(t) = 2 t\), значит \(h_k \approx 2 h\,\bar\xi_k\), и шаг тем меньше, чем меньше \(t\). У левого конца \(\Phi'(0) = 0\) — «локальное сжатие» преобразования сколь угодно велико; у правого \(\Phi'(1) = 2\) — умеренное растяжение. Отсюда монотонное сгущение к \(x = 0\).

Решение 4.Прямоугольная сетка в круге

Координаты узлов равномерной сетки \(x_i, y_j \in \Xi := \{-1,\ -\tfrac12,\ 0,\ \tfrac12,\ 1\}\); всего \(5 \times 5 = 25\) точек пересечения.

Внутренние узлы \(\omega_h = \{(x_i, y_j) \in \Omega\}\), \(\Omega = \{x^2 + y^2 < 1\}\). Перебор:

  • если \(|x| = 1\) или \(|y| = 1\), то \(x^2 + y^2 \ge 1\) — узел не внутренний;
  • если \(|x|, |y| \in \{0, \tfrac12\}\), то \(x^2 + y^2 \in \{0, \tfrac14, \tfrac12\}\), все \(< 1\).

Итого множество \(\omega_h\) — пересечение сеточных линий с открытым квадратом \([-\tfrac12, \tfrac12]^2\):

\[ \omega_h \;=\; \{(0, 0),\ (\pm\tfrac12, 0),\ (0, \pm\tfrac12),\ (\pm\tfrac12, \pm\tfrac12)\}, \qquad |\omega_h| = 9. \]

Граничные узлы \(\partial_h\) — пересечения сеточных прямых с окружностью \(x^2 + y^2 = 1\).

Для вертикали \(x = x_i \in \Xi\) уравнение \(y^2 = 1 - x_i^2\) даёт:

  • \(x_i = \pm 1\): \(y = 0\) — по одной точке касания (двойной корень), итого 2 точки: \((\pm 1, 0)\);
  • \(x_i = \pm\tfrac12\): \(y^2 = \tfrac34\), \(y = \pm\tfrac{\sqrt 3}{2}\) — по 2 точки, всего 4: \((\pm\tfrac12, \pm\tfrac{\sqrt 3}{2})\);
  • \(x_i = 0\): \(y = \pm 1\), 2 точки: \((0, \pm 1)\).

Итого по вертикалям \(8\) различных точек.

Для горизонтали \(y = y_j \in \Xi\) — аналогично; получаем ещё точки \((\pm\tfrac{\sqrt 3}{2}, \pm\tfrac12)\) (это новые точки: их \(x\)-координата \(\pm\tfrac{\sqrt 3}{2}\notin \Xi\), поэтому они не совпадают с найденными). Точки \((\pm 1, 0)\) и \((0, \pm 1)\) появляются повторно — уже посчитаны. Новых точек: \(4\).

\[ |\partial_h| = 8 + 4 = 12,\qquad |\bar\omega_h| = |\omega_h| + |\partial_h| = 9 + 12 = 21. \]
Полнота перебора: любая точка окружности лежит либо на сеточной вертикали, либо на сеточной горизонтали (по определению \(\partial_h\) в (1.10)–(1.11)); мы перебрали все 5 вертикалей и 5 горизонталей — других точек \(\partial_h\) быть не может.
Зелёные точки — \(\omega_h\), коричневые — \(\partial_h\).

Решение 5.Сеточные аналоги норм \(C\) и \(L_2\)

Проектор (1.17): \(y_k = \sin(\pi k h)\), \(k = 0, \ldots, N\), \(h = 1/N\).

(1) Норма \(C\) по (1.13). \(\|y\|_C = \max_{0\le k\le N} |\sin(\pi k h)|\). При чётном \(N\) узел \(k = N/2\) даёт \(\sin(\pi/2) = 1\), а \(|\sin(\cdot)| \le 1\) всюду, поэтому \(\|y\|_C = 1\). При \(N = 10\) и \(N = 20\) это условие выполнено.

Лемма (сумма \(\sin^2\)) Для любого целого \(N \ge 1\) \[ S_N \;:=\; \sum_{k=1}^{N-1} \sin^2\!\Bigl(\frac{\pi k}{N}\Bigr) \;=\; \frac{N}{2}. \qquad \] ▢

По формуле понижения степени \(\sin^2\alpha = \tfrac{1 - \cos 2\alpha}{2}\):

\[ S_N \;=\; \frac{N-1}{2} \;-\; \frac{1}{2}\sum_{k=1}^{N-1}\cos\!\frac{2\pi k}{N}. \]

Сумма \(N\) корней уравнения \(z^N = 1\) равна нулю: \(\sum_{k=0}^{N-1} e^{2\pi i k/N} = 0\); отделяя \(k = 0\) и переходя к вещественной части, получаем \(1 + \sum_{k=1}^{N-1}\cos\!\tfrac{2\pi k}{N} = 0\), т. е. \(\sum_{k=1}^{N-1}\cos\!\tfrac{2\pi k}{N} = -1\). Подставляя, \(S_N = \tfrac{N-1}{2} + \tfrac{1}{2} = \tfrac{N}{2}\).

(2) Норма \(L_2\) по (1.14). В узлах \(k = 0\) и \(k = N\) значения \(y_0 = \sin 0 = 0\), \(y_N = \sin \pi = 0\); поэтому обе версии суммы (1.14) совпадают с \(\sum_{k=1}^{N-1} y_k^2\), которая по лемме равна \(N/2\). Итого при любом \(N\)

\[ \|y\|_{L_2, h} \;=\; \sqrt{\,\tfrac{N}{2}\cdot h\,} \;=\; \sqrt{\,\tfrac{N}{2}\cdot \tfrac{1}{N}\,} \;=\; \tfrac{1}{\sqrt 2}. \]

Решение 6.Два проектора \(P_\tau\) для \(u(x) = x^2\)

Сетка \(h = \tfrac14\), \(x_k = \tfrac{k}{4}\), \(k = 0, 1, 2, 3, 4\), внутренние узлы — \(k = 1, 2, 3\).

Проектор (1.17) — значение в узле: \((P_\tau u)_k = x_k^2\).

Проектор (1.18) на внутреннем узле. Пределы интегрирования — \([x_k - \tfrac{h}{2},\ x_k + \tfrac{h}{2}]\), знаменатель \(\bar h_k = h\). Прямое вычисление через \((a + b)^3 - (a - b)^3 = 2 b\,(3 a^2 + b^2)\):

\[ (P_\tau u)_k \;=\; \frac{1}{h}\!\int_{x_k - h/2}^{x_k + h/2}\! x^2\,dx \;=\; \frac{1}{3 h}\cdot 2\cdot\frac{h}{2}\!\left(3 x_k^2 + \Bigl(\tfrac{h}{2}\Bigr)^{\!2}\right) \;=\; x_k^2 + \frac{h^2}{12}. \]
Замечание (общий случай) Для \(u \in C^{3}\) во внутреннем узле среднее по ячейке отклоняется от значения в узле ровно на \(u''(x_k)\,h^2/24 + O(h^4)\).

Разложим \(u(x_k + t) = u(x_k) + u'(x_k)\,t + \tfrac12 u''(x_k)\,t^2 + O(t^3)\). Интегрируя по \(t \in [-h/2, h/2]\) и деля на \(h\), нечётные члены исчезают:

\[ \frac{1}{h}\!\int_{-h/2}^{h/2}\! u(x_k + t)\,dt \;=\; u(x_k) + \frac{u''(x_k)}{2}\cdot \frac{1}{h}\!\int_{-h/2}^{h/2}\! t^2\,dt + O(h^4) \;=\; u(x_k) + \frac{u''(x_k)\,h^2}{24} + O(h^4). \]

Для \(u = x^2\) имеем \(u'' \equiv 2\), поэтому поправка равна \(2\cdot h^2/24 = h^2/12\) — совпадает с прямым расчётом.

Проектор (1.18) на крайних узлах. «Соответствующая половина ячейки»: \(k = 0 \Rightarrow [0,\ h/2]\), \(k = 4 \Rightarrow [1 - h/2,\ 1]\); знаменатель — \(h/2\).

\[ (P_\tau u)_0 \;=\; \frac{2}{h}\!\int_0^{h/2}\! x^2\,dx \;=\; \frac{2}{h}\cdot \frac{(h/2)^3}{3} \;=\; \frac{h^2}{12}, \qquad (P_\tau u)_4 \;=\; \frac{2}{h}\!\int_{1 - h/2}^1\! x^2\,dx \;=\; \frac{2}{h}\cdot \frac{1 - (1 - h/2)^3}{3}. \]

Разложение \(1 - (1 - h/2)^3 = \tfrac{3 h}{2} - \tfrac{3 h^2}{4} + \tfrac{h^3}{8}\), значит

\[ (P_\tau u)_4 \;=\; 1 - \frac{h}{2} + \frac{h^2}{12}. \]

Когда совпадают На внутренних узлах \(k = 1, 2, 3\) проекторы (1.17) и (1.18) отличаются на ровно \(u''(x_k)\,h^2/24 = h^2/12 = 1/192\); эта разность обращается в нуль тогда и только тогда, когда \(u'' \equiv 0\), т. е. когда \(u\) — линейная функция.
На крайних узлах картина иная: (1.18) даёт значение по односторонней «половине» ячейки, поэтому разность содержит уже член \(-h/2\) (вычислим: \((P_\tau u)_4 - u(x_4) = 1 - h/2 + h^2/12 - 1 = -h/2 + h^2/12\); для \(h = 1/4\) это \(-24/192 + 1/192 = -23/192\)). Совпадения в крайних узлах в общем случае не будет ни для какой функции \(u \not\equiv \mathrm{const}\).

Разностные схемы и шаблоны

Решение 7.Анализ шаблонов на верхнем слое

Далее «верхний слой» — слой \(n + 1\); шаблон опишем перечислением его узлов в форме \((i + p,\ n + q)\). Признак явности/неявности (по Опр. 5–6) — количество узлов шаблона, попадающих на слой \(n + 1\): если ровно один, то разностное уравнение однозначно разрешимо относительно этого узла и даёт явную формулу; если больше одного, значения на слое \(n + 1\) связаны алгебраически, и для их нахождения приходится решать систему.

Явный трёхточечный. Узлы шаблона:

\[ (i, n + 1);\qquad (i - 1, n),\ (i, n),\ (i + 1, n). \]

Известные — три узла нижнего слоя \(n\) (все на слоях \(\le n\) вычислены ранее); неизвестное — \((i, n + 1)\), один узел. Разностное уравнение имеет вид \(y_i^{n + 1} = R\bigl(y_{i - 1}^n, y_i^n, y_{i + 1}^n\bigr)\) и напрямую даёт \(y_i^{n + 1}\) для каждого \(i\) независимо (явный расчёт).

Неявный трёхточечный. Узлы шаблона:

\[ (i - 1, n + 1),\ (i, n + 1),\ (i + 1, n + 1);\qquad (i, n). \]

Известное — один узел нижнего слоя; неизвестных на верхнем слое — три. Пробегая \(i\), получаем систему разностных уравнений вида \(\alpha_i\, y_{i-1}^{n+1} + \beta_i\, y_i^{n+1} + \gamma_i\, y_{i+1}^{n+1} = f_i^n\) с трёхдиагональной матрицей (при подходящих граничных условиях), которую надо решать для всего слоя сразу (например, методом прогонки).

«Крест». Узлы шаблона (три временных слоя):

\[ (i, n + 1);\qquad (i - 1, n),\ (i, n),\ (i + 1, n);\qquad (i, n - 1). \]

Известные — узлы слоёв \(n\) и \(n - 1\) (пять узлов); неизвестное — \((i, n + 1)\), один. Расчёт явный: \(y_i^{n+1} = R\bigl(y_{i-1}^n, y_i^n, y_{i+1}^n, y_i^{n-1}\bigr)\). Особенность — двухслойный старт: для запуска нужны данные не только на \(n = 0\), но и на \(n = 1\); последний задаётся либо доопределением начального условия для \(u_t\), либо одношаговым разгоном по вспомогательной явной схеме.

Критерий явная схема = ровно один узел шаблона на слое \(n + 1\); неявная = два и более. Второе автоматически влечёт систему уравнений; первое — прямое вычисление в цикле по \(i\).

Погрешность, сходимость, точная схема

Решение 8.Сеточная функция погрешности

(1) Погрешность по Опр. 7. С проектором (1.17) имеем \((P_{\tau\omega} u)_k = \sin(\pi x_k)\), откуда

\[ z_k \;=\; y_k - (P_{\tau\omega} u)_k \;=\; (-1)^k\cdot 10^{-2},\qquad k = 0, 1, \ldots, 10. \]

(2) Норма \(C\) по (1.13):

\[ \|z\|_C \;=\; \max_{0 \le k \le 10} |z_k| \;=\; 10^{-2}. \]

(3) Сеточная норма \(L_2\) по (1.14) с суммой \(k = 0, \ldots, N - 1 = 0, \ldots, 9\). Все \(|z_k| = 10^{-2}\), поэтому \(z_k^2 = 10^{-4}\), а \(h = 1/10 = 10^{-1}\):

\[ \|z\|_{L_2, h} \;=\; \Bigl(\sum_{k=0}^{9} z_k^2\, h\Bigr)^{1/2} \;=\; \bigl(10\cdot 10^{-4}\cdot 10^{-1}\bigr)^{1/2} \;=\; \bigl(10^{-4}\bigr)^{1/2} \;=\; 10^{-2}. \]

(4) Что говорит одна точка о сходимости (Опр. 8). Опр. 8 требует, чтобы для любого наперёд заданного \(\varepsilon > 0\) можно было подобрать сетку (то есть достаточно большое \(N\)), при которой \(\|z\|_{1,H} < \varepsilon\). Это квантор «для всех \(\varepsilon\)», а значит утверждение о сходимости — асимптотическое: одна точка \((h, \|z\|)\) не подтверждает и не опровергает его — она сообщает лишь величину ошибки на конкретной сетке.

Иначе говоря, из данных задачи получен факт: при \(h = 1/10\) обе нормы погрешности равны \(10^{-2}\). Для утверждения о сходимости нужна серия \(h_j \to 0\) с наблюдением \(\|z_{h_j}\|_{1,H} \to 0\); только тогда по Опр. 8 схема сходится.

Решение 9.Точная схема (Опр. 9)

(1) Подстановка \(a\tau/h = 1\).

\[ y_i^{n + 1} \;=\; y_i^n \;-\; 1\cdot \bigl(y_i^n - y_{i-1}^n\bigr) \;=\; y_{i-1}^n. \tag{$\ast$} \]

(2) Индукция по \(n\). Докажем: для всех \(n \ge 0\) и всех \(i\)  \(y_i^n = u_0(x_i - a\,t_n)\).

  • База, \(n = 0\). По условию \(y_i^0 = u_0(x_i)\), а \(t_0 = 0\), значит правая часть — \(u_0(x_i - a\cdot 0) = u_0(x_i)\); равенство выполнено.
  • Индукционный переход \(n \to n + 1\). Предположим, что \(y_i^n = u_0(x_i - a\,t_n)\) для всех \(i\). Тогда по \((\ast)\) и предположению индукции \[ y_i^{n+1} \;=\; y_{i-1}^n \;=\; u_0\bigl(x_{i-1} - a\,t_n\bigr) \;=\; u_0\bigl(x_i - h - a\,t_n\bigr). \] Из условия \(a\tau = h\) имеем \(h + a\,t_n = a\tau + a\,n\tau = a\,(n+1)\,\tau = a\,t_{n+1}\), поэтому \[ y_i^{n+1} \;=\; u_0\bigl(x_i - a\,t_{n+1}\bigr), \] что и требовалось.

(3) Точность на сетке (Опр. 9). Классическое решение задачи Коши \(u_t + a\,u_x = 0\), \(u(x, 0) = u_0(x)\) при \(u_0 \in C^{1}(\mathbb{R})\) — единственно и даётся методом характеристик:

\[ u(x, t) \;=\; u_0(x - a\,t). \]

Тогда сеточный след \((P_{\tau\omega}\, u)_i^n = u(x_i, t_n) = u_0(x_i - a\,t_n)\). По пункту (2) численное решение \(y_i^n\) совпадает с этим следом узел в узел, поэтому сеточная функция погрешности из Опр. 7

\[ z_i^n \;=\; y_i^n - (P_{\tau\omega}\, u)_i^n \;=\; 0 \qquad \forall\, i,\ n, \]

и в любой сеточной норме \(\|\cdot\|_{1, H}\) имеем \(\|z\|_{1, H} = 0\). По Опр. 9 схема точна на сетке \(G_h\) при условии \(a\tau/h = 1\) — для произвольного начального условия \(u_0 \in C^{1}(\mathbb{R})\).

Смысл условие \(a\tau/h = 1\) (число Куранта \(\sigma = 1\)) синхронизирует шаг схемы с характеристикой уравнения переноса: за один шаг \(\tau\) сеточное значение сдвигается ровно на один пространственный узел \(h = a\tau\) — то же самое делает истинное решение \(u_0(x - at)\). Именно поэтому дискретная и непрерывная динамики совпадают тождественно, а не приближённо.

Вычислительный эксперимент: V и V

Решение 10.Верификация и валидация

1) Верификация — «решаем уравнения правильно».

  1. Сравнение с аналитическим решением. Модельная задача: \(u_t + u_x = 0\) на периодическом отрезке \([0, 1]\) с \(u_0(x) = \sin(2\pi x)\); точное решение — \(u(x, t) = \sin\bigl(2\pi(x - t)\bigr)\). Считаем при \(t = 1\) (волна должна сделать один полный оборот) и сравниваем \(y_i^N\) с \(u(x_i, 1) = u_0(x_i)\). При \(a\tau/h = 1\) — совпадение с машинной точностью (Задача 9); при других значениях числа Куранта \(\sigma \in (0, 1)\) ошибка должна убывать при уменьшении шагов.
  2. Grid refinement. Считаем ту же модельную задачу на серии сеток \(h,\ h/2,\ h/4,\ h/8,\ h/16\), для каждой вычисляем \(\varepsilon_h = \|y - u\|_C\) (или \(\|y - u\|_{L_2, h}\)). На log-log графике \((\log h,\ \log \varepsilon)\) точки должны лечь на прямую с наклоном \(p = 1\) — теоретический порядок схемы-«уголок». Наклон меньше единицы или излом графика — сигнал, что в реализации ошибка (неверная нумерация индексов, неправильная граничная условия, некорректный порядок операций).

2) Валидация — «решаем правильные уравнения».

  1. Сравнение с экспериментом. Пример: пассивный перенос красителя ламинарным потоком в лабораторной трубе. Расчётное распределение концентрации по длине трубы сравнивается с измеренным. В отличие от верификации, здесь под вопрос ставится сама модель: правда ли, что процесс достаточно описывается линейным уравнением переноса без диффузии; не забыты ли пристеночная вязкость, диффузия, флуктуации скорости.
  2. Границы применимости модели. Уравнение \(u_t + u_x = 0\) — линейное, бездиссипативное, скалярное, для постоянного \(a\). Валидация ставит вопрос: при каких режимах \((Re,\ Pe,\ Ma)\) отсутствие диссипации, нелинейности и трёхмерности не искажает картину сильнее заданной точности; на каких \(Re\) диффузионный член \(\varepsilon\,u_{xx}\) уже сопоставим с адвективным, — и уравнение переноса пора менять на конвекцию-диффузию.

3) Верификация ≠ валидация — примеры.

  • Верификация пройдена, валидация провалена. Программа корректно решает уравнение переноса: на всех модельных задачах наблюдается теоретический порядок сходимости \(O(h)\). Но пользователь применяет её к переносу тепла в металлическом стержне, где на самом деле доминирует диффузия, \(u_t = \kappa\,u_{xx}\). Профиль температуры расходится с экспериментом принципиально — из-за неадекватности модели, не программы.
  • Валидация пройдена, верификация провалена. Программа решает уравнения Навье – Стокса — физически адекватную модель. Однако в реализации разностного оператора допущена ошибка (например, потерян множитель \(1/2\) в конвективном члене). На грубой сетке результат случайно попадает в диапазон экспериментальных значений — «слабая» валидация проходит. Но grid refinement обнаруживает отсутствие ожидаемого порядка сходимости, а на измельчённых сетках решение начинает уходить от эксперимента — верификация ловит ошибку.
Почему одна не заменяет другую верификация отвечает на вопрос «правильно ли алгоритм решает заданную математическую задачу»; валидация — «правильно ли заданная математическая задача описывает реальность». Между этими вопросами нет логической связи: адекватную модель можно испортить реализацией, а корректно реализованный алгоритм — применить к неверной модели.
