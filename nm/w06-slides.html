Численное дифференцирование

Конечные разности · Оптимальный шаг · Ричардсон
§6.1 · Задача

Восстановить производную из значений в узлах

Функция задана в узлах сетки с шагом \(h\): \(f_i = f(x_0 + ih)\). Требуется приблизить \(f'(x_0)\) через значения в соседях.

разностный оператор.
\[ D_h f(x_0) = \frac{1}{h^p}\sum_k \alpha_k f(x_0 + kh) \approx f^{(p)}(x_0). \tag{6.1} \]
Коэффициенты подбираются так, чтобы совпадение с производной было до максимально возможного порядка.
§6.2 · Правая разность

Правая разность — первый порядок

\[ D_h^{+} f(x_0) = \frac{f(x_0+h) - f(x_0)}{h}. \tag{6.2} \]

Подставим ряд Тейлора \(f(x_0+h) = f + hf' + \tfrac{h^2}{2}f'' + O(h^3)\):

\[ D_h^{+}f = f'(x_0) + \frac{h}{2}f''(x_0) + O(h^2). \tag{6.4} \]
Ошибка усечения — \(O(h)\), т. е. первого порядка. Удвоение шага удваивает ошибку.
§6.3 · Центральная разность

Центральная разность — второй порядок

Вычтем ряд назад из ряда вперёд: чётные члены сокращаются.

\[ D_h^{c} f(x_0) = \frac{f(x_0+h) - f(x_0-h)}{2h} = f'(x_0) + \frac{h^2}{6}f'''(x_0) + O(h^4). \tag{6.7} \]
Ошибка \(O(h^2)\) — на порядок лучше правой при том же шаге.
При \(h = 10^{-4}\): правая \(\sim 10^{-4}\), центральная \(\sim 10^{-8}\). Практически бесплатное улучшение — цена лишь одна лишняя точка.
§6.4 · Вторая производная

Центральная формула для \(f''\)

Сложим ряды вперёд и назад — нечётные члены сокращаются:

\[ D_h^{(2)} f(x_0) = \frac{f(x_0+h) - 2f(x_0) + f(x_0-h)}{h^2} = f''(x_0) + \frac{h^2}{12}f^{(4)} + O(h^4). \tag{6.10} \]
Ошибка \(O(h^2)\). Это рабочая формула для правой части уравнения теплопроводности \(u_t = u_{xx}\).
§6.5 · Ошибка округления

Округление в разностях: \(\sim u/h\)

Значения \(f(x_0 \pm h)\) представимы с относительной ошибкой \(u\). Разность даёт абсолютную ошибку \(\sim 2u|f|\), делим на \(h\):

\[ E_{\text{round}} \sim \frac{2u|f|}{h}. \tag{6.11} \]

Полная ошибка правой разности:

\[ E(h) \;\approx\; \frac{h}{2}M_2 + \frac{2u|f|}{h}. \tag{6.12} \]

Первое слагаемое растёт с \(h\); второе — убывает. Есть оптимум.

§6.6 · V-образная кривая

Кривая ошибки в log-log

Слева доминирует округление, справа — усечение; минимум — \(h_{\text{opt}}\).
§6.7 · Оптимальные шаги

Явные формулы \(h_{\text{opt}}\)

Минимизируя \(E(h)\) по \(h\):

  • Правая разность: \(h_{\text{opt}} \sim \sqrt{u} \approx 10^{-8}\), \(E_{\min} \sim \sqrt{u} \approx 10^{-8}\).
  • Центральная разность: \(h_{\text{opt}} \sim u^{1/3} \approx 5\!\cdot\!10^{-6}\), \(E_{\min} \sim u^{2/3} \approx 3\!\cdot\!10^{-11}\).
  • Вторая производная: \(h_{\text{opt}} \sim u^{1/4} \approx 10^{-4}\), \(E_{\min} \sim \sqrt{u}\).
Не пишите \(h = 10^{-15}\) ради «точнее». Это классическая ловушка первокурсника — ошибка станет ~1, а не \(u\).
§6.8 · Ричардсон

Экстраполяция Ричардсона — «умножили порядок»

Пусть \(D_h = f' + c_1 h^{p_1} + c_2 h^{p_2} + \ldots\). Линейная комбинация \(D_h\) и \(D_{h/2}\) исключает главный член ошибки:

\[ R_h = \frac{2^{p_1} D_{h/2} - D_h}{2^{p_1} - 1} = f' + O(h^{p_2}). \tag{6.14} \]
Для центральной разности \((p_1=2, p_2=4)\):
\[ R_h = \frac{4\,D_{h/2}^{c} - D_h^{c}}{3} = f'(x_0) + O(h^4). \tag{6.15} \]
§6.9 · Итоги

Что унести с занятия 6

  1. Разностные производные — рецепт: подставляем Тейлор, смотрим первый несокращённый член.
  2. Порядок аппроксимации: правая \(O(h)\), центральная \(O(h^2)\), вторая производная \(O(h^2)\).
  3. Ошибка округления в разностях \(\sim u/h\) — растёт с уменьшением шага.
  4. Оптимальный шаг — компромисс. Не пишите \(h < h_{\text{opt}}\).
  5. Экстраполяция Ричардсона повышает порядок за счёт линейной комбинации двух шагов.
